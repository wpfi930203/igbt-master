## D2 · 问题描述（5W2H，量化）

| 维度 | 内容 |
|---|---|
| What | 什么失效（现象 + 电参数变化） |
| Where | 哪个工序/位置发现；模组内失效位置（哪个芯片/哪个端子） |
| When | 什么时候开始；失效发生在使用多久后 |
| Who | 哪条线/哪个班组/哪个批次 |
| Which | 具体型号、批次、日期码 |
| How | 失效模式（开路/短路/参数漂移/分层/炸裂） |
| How many | 失效数 / 总数 = 失效率；分布（是否集中） |

**附**：失效样品照片、SAM 图、X-ray、波形（如有）。

> 反例：「部分产品性能不稳定」——不是问题描述。
