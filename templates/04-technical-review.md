# 模板 04 · 技术评审（设计/选型/方案评审）

> **适用**：模块选型评审、驱动与保护方案评审、寿命与热设计评审、供应商技术对标评审。
> **不适用**：单个失效的机理分析（用 `03-FA-report.md`）、跨部门问题闭环（用 `02-8D-report.md`）。
>
> **纪律**：技术评审的产出不是"通过了"，而是**"在什么条件下通过、什么条件下不通过"**。任何不带条件的通过，都是把风险推给下一道工序。

---

| 若"不通过"：需要改什么 | |

| 评审人与日期 | |

> **"有条件通过"的许可条件必须是"改一个数就能验"的形式**，例如「低温 −50 ℃ 下 di/dt ≤ 13.9 A/ns」，不能写「注意低温」。

## 2. 输入数据台账（决定结论可信度的一节）

每个输入按下面的表登记。**凡等级为 L4 / L5 的，必须写"该值未经验证"，并且不能作为唯一判决依据。**

| # | 参数 | 值 | 条件（温度/电压/电流/几何） | 来源 | 等级 | 已验证？ |
|---|---|---|---|---|---|---|
| 1 | | | | | L1 / L2 / L3 / L4 / L5 | 是 / 否 |
| 2 | | | | | | |

**等级定义**（与 `references/synthesis.md` §0 一致）：

| 等级 | 含义 | 能否进判决 |
|---|---|---|
| **L1** | 一手标准 / 原厂 datasheet 明示值 | 能 |
| **L2** | 一手论文实测（带条件） | 能，须带条件 |
| **L3** | 书源 pXXX（书中表格/正文/图） | **能引用，不能当"实测"** |
| **L4** | 行业实践 / 经验值 | 只能当量级 |
| **L5** | 由公式推导 | 必须标"推断" |

> **本节的用处**：评审最常见的失败不是算错，而是**把一个 L4 当 L1 用了，然后整篇结论都在这个数上面**。

## 4. 敏感度与不确定度（决定结论是"结论"还是"猜测"）

| 不确定源 | 量级 | 对结论的影响 | 是否已评估最坏端 |
|---|---|---|---|
| | | | |

**必做三问**：

1. **最坏端的数值落在哪一侧？** 若不确定度区间跨越判据，则结论是"不能判定"，不是"通过"。
2. **哪个假设一旦错了结论就翻？** 把它单列成"许可条件"。
3. **有没有一个可以直接测的量能把区间收窄？** 有就写进"后续验证"。

## 5. 边界声明（不许省略）

| 项 | 声明 |
|---|---|
| 本评审**覆盖**了什么 | |
| 本评审**没覆盖**什么 | （如：只算了热，未算端子过压；只算了稳态，未算瞬态） |
| 本评审的**结论有效期** | （如：仅对本次输入的 datasheet 版本 + 该剖面有效） |
| 书源方法的**能力边界** | 书是 2010 年代中期手册，绝缘限值/SiC/AMB/DPC 均需回标准或厂商 |

> **一行纪律**：把"没覆盖"写清楚，比把"覆盖了"写漂亮更有价值。

## 附 B · 反模式（看到就退）

| 反模式 | 为什么不行 |
|---|---|
| 「按行业经验取 20 K 裕量」 | 20 K 是 L4，不能替代敏感度分析 |
| 「供应商说 13 万次，够用」 | 没说脉冲/非脉冲、ΔTj、判据，跨家不可比 |
| 「加 R_G 让波形更平滑」 | 书实测：R_G 8.2→1.0 Ω，di/dt 只动 2 %，E_on 降 56 % —— 加 R_G 是亏本买卖 |
| 「换烧结银就解决了」 | 34000→62000 是 **1.8 倍**不是数量级，且失效部位迁移到芯片/DCB 界面 |
| 「25 ℃ 测过没问题」 | 阻断能力随温**升**而强，低温最弱，−50 ℃ 时 6.5 kV 器件只剩 ≈5.7 kV |
| 「低温更危险所以高温不用管」 | 高温有另一套失效（蠕变、焊层、宇宙射线下降但热失控上升），两个方向都要核 |
| 「R_th(j-c)=0.055 是手册数，直接用」 | 书 p143 明说只是参考值；且 R_th,ch 随 TIM 规格/厚度/压力变 |
| 「这个系数是书里给的」 | `34-formula-index §12` 的 11 项里，**8 项书里完全没有**（γ、c、Peck n、β1~β4、E_as、驱动功率式、熔断器 I²t、探头延时补偿）；**另 3 项"给了但不可直接用"**（缓冲 `C_s` 式 13.9 量纲不成立、HDF 式 13.21–13.24 排版存疑、分流器 `C_comp` 三种取值互相矛盾）。**后一类比前一类危险**——前者逼你查厂商，后者让你直接抄 |
