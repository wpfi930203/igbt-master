# Track 02 — 工具地图（Tools）

> 调研日期：2026-10-17
> 可信度：`[一手-原厂]` = 原厂官网确认；`[行业通用]` = 业内广泛使用的事实标准，本次未逐一点开官网核实型号；`[推断]` = 推荐性判断
> **本轨的性质说明**：IGBT 的工具链与软件行业不同——它不是"一套软件搞定"，而是**仿真 + 试制 + 试验 + 失效分析四段分立**，且**工艺设备与试验设备才是真正的门槛**。软件只是配角。

## 1. 必备工具（按「四段分立」组织）

### 1.1 第一段：电-热-机仿真（设计期）

| 工具 | 类型 | 场景 | 上手难度 | 替代 / 备注 |
|---|---|---|---|---|
| **ANSYS Mechanical** | 有限元（热-结构） | 焊层热机械应力、翘曲、CTE 失配、功率循环应力幅 | 高 | ABAQUS；两者都是重武器，需要材料本构（粘塑性 Anand / Darveaux）才可信 |
| **ANSYS Icepak / Fluent** | CFD | 模组-散热器-风冷/水冷系统级热分析、流量分配 | 高 | Siemens Flotherm；Icepak 在功率电子界更常见 `[行业通用]` |
| **COMSOL Multiphysics** | 多物理场 | 电-热-机耦合、绝缘电场（PD 前评估）、烧结层细观建模 | 高 | 适合研究型问题，产线工程不如 ANSYS 顺手 |
| **Synopsys Sentaurus TCAD** | 器件 TCAD | 元胞结构/终端设计、击穿电压、载流子分布、SOA 边界 | 极高 | Silvaco Atlas。**这是芯片厂的工具，封装厂一般不碰** |
| **PLECS** | 系统级电热联合仿真 | 变换器拓扑 + 器件损耗 + 热网络（Cauer/Foster）闭环，算 mission profile 下的 ΔTj | 中 | 功率电子界最主流的电热联仿工具 `[行业通用]`； MATLAB/Simulink + Simscape 亦可 |
| **LTspice / SIMetrix / PSIM** | 电路仿真 | 驱动回路、杂散参数、尖峰与振荡、短路瞬态 | 低-中 | LTspice 免费；做栅极回路与寄生振荡分析够用 |
| **Infineon IPOSIM** | 在线损耗/热仿真 | 用原厂器件模型快速算指定拓扑下的损耗与结温 | 低 | 免费在线；**限定 Infineon 器件**，做竞品对标时不可用 `[一手-原厂]` |

> 判断原则：**封装厂做结构可靠性用 ANSYS/ABAQUS；做应用方案用 PLECS；做芯片结构才用 TCAD。** 用 TCAD 去算焊层应力是典型工具错配。

### 1.2 第二段：电特性测试（样件期）

| 工具 | 场景 | 关键要求 | 备注 |
|---|---|---|---|
| **功率器件分析仪**（如 Keysight B1505A 类） | 静态参数：VCE(sat)、VGE(th)、ICES、IGES、击穿电压、电容 | 需要能到 kV / 百 A 级，且支持脉冲模式（避免自热） | `[行业通用]`。低端曲线图示波仪替代不了高压高流 |
| **DPT 测试台（自建为主）** | Eon/Eoff/Erec、tr/tf、dv/dt、di/dt | **夹具杂散电感必须与被评估应用可比**；否则数据只能内部对比，不能对外承诺 | 这行的 DPT 台多为**自建**，没有统一商品化标准机。这是与软件行业最大的不同 |
| **示波器 + 高压差分探头 + 罗氏线圈** | 波形采集 | 带宽 ≥ 100 MHz、共模抑制足够；去嵌（deskew）必须做 | `[行业通用]` |
| **功率循环试验台** | PCsec / PCmin | 需精确控制 ton/toff、ΔTj、Tj,mean；需在线监测 VCE(sat) 与 Rth | 商品化设备 + 大量自建。**这是模组可靠性的核心资产**，比软件贵得多 |
| **HTRB / HTGB / H3TRB / HV-H3TRB 试验箱** | 高温反偏 / 栅偏 / 湿热 | 高压下的爬电与电弧风险；HV-H3TRB 对箱体绝缘与湿度均匀性要求极高 | 你做过的 1000h/1500h/168h 矩阵即在此体系内 |
| **温度循环 / 热冲击箱** | TC / TST | 转换时间（< 1 min 为热冲击）决定应力强度 |  |
| **热阻测试仪（电学法）** | Zth、结构函数 | 按 JESD51-1 流程：K factor 标定 → 加热 → 冷却曲线 → 结构函数 | 商业方案如 Siemens/MicRed T3Ster 体系 `[行业通用]` |
| **局部放电测试系统** | PD | 1700V+ 模组、铁路/电网必做 | 需要屏蔽室与校准 |

### 1.3 第三段：无损检测与失效分析（问题期）

| 工具 | 能看什么 | 局限 |
|---|---|---|
| **SAM 扫描声学显微** | 分层、焊层空洞、灌封界面脱粘（**AQG 324 QM 类项目**） | 需要耦合介质；对深层小空洞分辨率有限；判读依赖经验 |
| **X-ray / 工业 CT** | 焊层空洞率、键合线弧度与位置、内部裂纹 | 2D X-ray 有重叠；CT 贵且慢 |
| **SEM + EDS** | 失效点形貌、元素成分、IMC 厚度 | 需开封，破坏性 |
| **FIB / 双束** | 截面制备、微区结构 | 慢、贵，用于 pinpoint 问题 |
| **锁相红外热像（Lock-in Thermography）** | 局部热点定位（短路点、空洞热点） | 需要调制激励；空间分辨率受限于红外波长 |
| **OBIRCH / EMMI** | 漏电点定位 | 对封装后样品需开封 |
| **金相切片** | 焊层/IMC/键合界面真实形貌 | 破坏性，制样质量决定结论可信度 |
| **推拉力测试机（bond pull / shear）** | 键合线拉力、芯片剪切力 | 破坏性；需按标准做统计，单点无意义 |

### 1.4 第四段：工艺设备（真正的门槛）

| 环节 | 设备类型 | 关键控制点 |
|---|---|---|
| 芯片贴装 | 焊料贴片机 / 烧结炉（银烧结需压力 + 气氛） | 空洞率、焊层厚度、氧化控制；烧结银对压力均匀性与表面粗糙度极敏感 |
| 键合 | 粗铝线键合机 / 铜线键合机 / 铝带键合机 | 超声功率、压力、时间、工具磨损；铜线需防 cratering |
| 基板 | DBC/AMB  supplier 工艺 | 陶瓷裂纹、铜层起泡、AMB 钎焊层空洞 |
| 灌封 | 真空灌胶机 + 固化炉 | 真空度、脱泡、固化曲线；硅凝胶不阻水这个问题必须正视 |
| 外壳/端子 | 注塑、超声焊、激光焊 | 端子焊接强度、气密性 |
| 底板 | 焊接/压接/烧结到基板 | 大面积焊层空洞率是热循环寿命的头号杀手 |

## 2. 场景化选型

### 场景 A：客户问「你这个模组能扛多少年？」
- 主路径：**PLECS 算 mission profile 的 ΔTj 序列 → 雨流计数 → 选寿命模型（PCsec 用 Bayerer/SKiM，PCmin 用 CM/NL）→ Miner 累积 → Weibull 给 B10**
- 关键：**必须说清用的是哪个模型、它的已知局限**（Bayerer 不含基板焊层；SKiM 只适用于烧结+优化铝线）
- 不给：单一数字（"能用 20 年"）。给区间 + 假设 + 敏感性

### 场景 B：单管替换选型（客户要降本或二供）
- 主路径：**先比 VCE(sat) 的温度系数曲线 + Eon/Eoff 在同一 Rg/VCC/Tvj 下 → 再比 Rth 与封装热路径 → 最后比 SOA 与 tSC**
- 不推荐：只比 datasheet 首页的 "VCE(sat) typ" 和 "IC nom"。**这两项在真实工况下最不具区分度**

### 场景 C：模组功率循环失效，要定位是键合线还是焊层
- 主路径：**VCE(sat) 漂移 vs Rth 漂移的分离判读**（前者指向键合线抬升/跟部裂纹，后者指向焊层/烧结层分层）→ SAM 确认 → 切片看 IMC/裂纹路径
- 不推荐：一上来就切片。**先用电参数分离机制，再做破坏性分析**

### 场景 D：H3TRB / HV-H3TRB 失效
- 主路径：**先看终端与钝化（电场集中）→ 再看灌封料/界面（吸湿与离子）→ 再看芯片表面电荷**
- 关键认知：硅凝胶**不阻水**，H3TRB 表现很大程度由灌封体系与界面决定，而不是芯片本身

## 3. 避坑清单

- **不要用 datasheet 的 Eon/Eoff 直接做系统损耗预算**：测试条件（Rg、VCC、Lσ、Tvj）与你的实际回路不同，误差可达 30%+。要么复测，要么用厂商提供的多条件曲线。
- **不要把 Rth(j-c) 当成可以任意串联的常数**：实际系统的 Rth 依赖 TIM、压力、流量。模组的 Rth(j-f) 与 datasheet 的 Rth(j-c) 不可直接相加。
- **不要用 TC 数据推键合线寿命**：TC 的热源在外部，损伤在焊层。PC 与 TC 是两套机理。
- **不要用一个寿命模型套所有失效**：Bayerer 不含基板焊层；LESIT 未分离机理；CM 忽略平均温度。
- **不要在没有 K factor 标定的情况下做电法测温**：TSEP 的线性区与标定电流必须自测，厂家给的系数未必适用于你的测试电流。
- **不要用"同型号同批次"作为并联均流的依据**：动态均流由驱动回路对称性与 gmk/Lσ 分布决定。
- **不要在 DPT 台上用不同 Lσ 的夹具比较两家器件**：你测到的是夹具差异。
- **不要忽略宇宙射线/大气中子**：>2.5kV 高压模组在高原/高海拔应用，这条失效通道与常规可靠性试验无关，但真实存在。
