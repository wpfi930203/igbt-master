## 0. 本次核实中最有价值的 5 个「反直觉」事实

这 5 条是反复被中文圈传错、且直接影响工程判断的点。写进技能时应作为「防幻觉锚点」。

| # | 常见误传 | 核实结论 | 依据 |
|---|---|---|---|
| 1 | AQG 325 是宽禁带器件的对应标准 | **AQG 325 不存在**。ECPE 的 AQG 系列在功率模块领域只有 AQG 324；SiC/GaN 是通过 AQG 324 的附录（Annex）覆盖，2025 版新增 SiC 专章 | 检索 ECPE 官网与多篇 2025 年第三方解读，均只提及 AQG 324；无任何 AQG 325 的实体存在证据 `[一手-官方 + 反向验证]` |
| 2 | CIPS 是中国国际功率半导体会议 | **CIPS = Conference on Integrated Power Electronics Systems**，德国 VDE ETG + ECPE 在纽伦堡办，**不是中国会议** | https://www.cips.eu/en `[一手-官方]` |
| 3 | 功率循环只有一套方法 | IEC 在 2025 年新出了 **IEC 60749-34-1:2025**，专用于**功率半导体模组**（IGBT/MOSFET/二极管/晶闸管）；它与 60749-34 是「基础方法 vs 模组专用」的关系，且明确允许客户按 AQG 324 偏离 | https://webstore.iec.ch/publication/67897 `[一手-官方]` |
| 4 | 单管和模组用同一套国标 | 中国 2025 年新出 **JB/T 8951 系列**，已按 **单管 / 臂模块 / 单相桥模块 / 三相桥模块** 分册，正好对应单管-模组双轨 | https://std.samr.gov.cn/gb/search/gbDetailed?id=lXasfYI77eM%3D&mode=p 的标准关联列表 `[一手-官方]` |
| 5 | AEC-Q101 管模组 | AEC-Q101 只管**分立器件**（含 IGBT 单管）；模组级车规是 **AQG 324**。两者互补不替代，混用会导致试验矩阵搭错 | AEC-Q101 Rev E 标题即 "…for Discrete Semiconductors…"；AQG 324 用于 power modules `[一手-官方]` |

## 2. 术语表（97 条，按 6 组）

### 2.1 器件参数与物理（21 条）

| 术语 | 中文 | 精确定义 / 工程含义 | 归属 |
|---|---|---|---|
| **VCE(sat)** | 集射饱和压降 | 规定 IC、VGE 下的通态压降。**温度系数是关键**：大电流区为正（利于并联均流），小电流区可能为负（存在热失控风险点，并联时要按最坏点校核） | 共享 |
| **VGE(th)** | 栅射阈值电压 | IC 达到规定小电流时的 VGE。负温度系数 → 高温更易误触发，是栅极串扰与并联均流的根源之一 | 共享 |
| **ICES** | 集射漏电流 | VGE=0 时的阻断漏电；HTRB 的核心监测参数 | 共享 |
| **IGES** | 栅射漏电流 | 栅氧完整性的直接指示；HTGB 的核心监测参数 | 共享 |
| **VF / IF** | 二极管正向压降 / 电流 | RC-IGBT 与反并联 FWD 的通态参数；VF 温敏同样可做 TSEP | 共享 |
| **Eon / Eoff** | 开通 / 关断损耗 | 单脉冲能量（mJ），双脉冲测试（DPT）测得。**条件强相关**：Rg、VCC、IC、Tvj、Lσ 任一变化即不可比 | 共享 |
| **Erec** | 反向恢复损耗 | 反并联二极管的反向恢复能量；与 di/dt、Tvj 强相关 | 共享 |
| **Qg / Qge / Qgc** | 栅总电荷 / 栅射电荷 / 栅集电荷 | 驱动功率与开关时间的核心；Qgc 决定米勒平台时长 | 共享 |
| **Cies / Coes / Cres** | 输入 / 输出 / 反向传输电容 | IEC 命名体系（对应旧称 Ciss/Coss/Crss）。Cres 即米勒电容，决定 dV/dt 与串扰 | 共享 |
| **td(on) / tr / td(off) / tf** | 开关时间 | 数据手册标准项；注意测试条件中的感性负载与 Rg | 共享 |
| **FBSOA** | 正向偏置安全工作区 | 开通/通态下的 IC–VCE 允许区域 | 共享 |
| **RBSOA** | 反向偏置安全工作区 | 关断轨迹允许区域；由动态雪崩与寄生晶闸管掣住决定 | 共享 |
| **SCSOA** | 短路安全工作区 | 短路条件下的允许区域；与 tSC 互为表里 | 共享 |
| **tSC（SCWT）** | 短路耐受时间 | 典型 Si IGBT 在标准试验条件下约 **5–10 μs** 量级（原厂 datasheet/AN 口径），是 DESAT 保护动作预算的硬约束。**不可与 SiC 混谈** | 共享 |
| **动态雪崩** | dynamic avalanche | 关断过程中电流被挤向边缘导致的局部雪崩；RBSOA 的真正限制机制之一 | 共享 |
| **拖尾电流** | tail current | 关断末段少子复合形成的长尾；决定 Eoff 与关断"软硬"；FS 结构可显著缩短 | 共享 |
| **米勒平台** | Miller plateau | VGE 在 Qgc 充电期间近似恒定；平台长度与高度决定 dV/dt 与开关损耗分配 | 共享 |
| **gfs（跨导）** | 转移电导 | 输出特性斜率；决定短路峰值电流与并联动态均流 | 共享 |
| **VCE(sat) 温度系数** | — | 见 VCE(sat) 条。**这是并联设计的核心判据，不是附带说明** | 共享 |
| **latch-up（寄生晶闸管掣住）** | 擎住 | IGBT 内部 PNPN 结构误触发导致栅极失控；RBSOA 与短路失效的经典机理 | 共享 |
| **Rth 的温度与流量依赖** | — | Rth 不是常数：随冷却液流量、温度、TIM 厚度、安装压力变化。报 Rth 必须带条件 | 共享 |

### 2.2 芯片结构与工艺（12 条）

| 术语 | 中文 | 精确定义 | 归属 |
|---|---|---|---|
| **PT** | 穿通型 | 厚 n+ 缓冲层 + 厚漂移区；VCE(sat) 与 Eoff 折中差，但鲁棒性好 | 共享 |

| **LPT** | 弱穿通（Light Punch Through） | ABB 路线的场截止实现，强调软关断 | 共享 |
| **平面栅** | planar gate | 工艺简单、栅氧场强低、关断软；高压段仍主流 | 共享 |
| **沟槽栅** | trench gate | 元胞密度高、无 JFET 区、VCE(sat) 低；栅氧底部场强是可靠性焦点 | 共享 |
| **屏蔽栅（SPT / Shielded Trench） | — | 沟槽底部加屏蔽电极，改善米勒电容与击穿；与沟槽栅常组合使用 | 共享 |
| **载流子存储层（CSTBT）** | Carrier Stored Trench Bipolar Transistor | p-base 下加 n 型存储层，抬高发射极侧载流子浓度以降 VCE(sat)。三菱路线（Takahashi, ISPSD 1996/2001） | 共享 |
| **IEGT** | Injection Enhanced Gate Transistor | 东芝的注入增强路线，高压（4.5kV 级）与压接模组常用（Ogura, ISPSD'98） | 模组 |

| **RB-IGBT** | 逆阻 IGBT | 具备反向阻断能力的 IGBT；**IEC 60747-9:2019 才正式纳入标准内容** | 共享 |
| **终端结构** | 场限环 / 场板 / JTE | 边缘电场管理；决定击穿电压与表面电荷稳定性（H3TRB 失效常源于终端） | 共享 |

| **DPC** | 直接镀铜 | 薄膜工艺，线路精度高，适合高密度与小功率；铜厚受限 | 模组 |
| **IMS** | 绝缘金属基板 | 铝基 + 绝缘层，成本导向（非高可靠场景） | 模组 |
| **Die attach（芯片贴装）** | 焊料 / 烧结银 / 铜烧结 | 焊料（高铅 SnSb、SAC）成熟可返修；**烧结银**耐温 >200℃、疲劳寿命数倍（Bai & Lu 等，IEEE 2006/2007）；**铜烧结**成本更低但需还原气氛、氧化控制难 | 共享 |
| **Al 粗线键合** | — | 成熟、成本低；失效模式为**跟部开裂（heel crack）与铝线重构** | 模组 |
| **Cu 线键合** | — | 载流与可靠性更高，但硬度大 → 芯片表面 cratering 风险、需更硬的金属化 | 模组 |
| **Al 带（ribbon）** | — | 低寄生、均流好、抗功率循环优于圆线 | 模组 |
| **Clip（铜夹）** | — | 用铜夹替代键合线，降低 Rce 与寄生电感；单管（TOLL/DFN）与大电流模组均在用 | 共享 |
| **灌封（potting）** | 硅凝胶 / 环氧 / 聚氨酯 | 硅凝胶柔性、释放应力、可返修，但**不阻水**；环氧硬保护、耐湿好但热应力大。**H3TRB 表现与灌封材料直接相关** | 模组 |
| **基板（baseplate）** | Cu / AlSiC / Cu-MoCu-Cu | 铜导热好但 CTE 失配大；AlSiC 低 CTE、轻，但导热差、成本高。**基板-陶瓷焊层是热循环失效主战场** | 模组 |
| **Press-Pack（压接）** | — | 无键合线、无焊层，双面压接；失效模式为**短路（fail-safe）**，适合串联堆叠与 HVDC | 模组 |
| **Pin-Fin 基板** | 针翅基板 | 直接水冷，去掉 TIM 层，降 Rth(j-f) | 模组 |
| **DSC（双面散热）** | Double-Sided Cooling | 双面烧结/夹持，Rth 大幅下降、功率密度提升；对平面度与压力均匀性要求陡增 | 模组 |

### 2.4 热与可靠性（24 条）

| 术语 | 中文 | 精确定义 / 工程要点 | 归属 |
|---|---|---|---|
| **Rth(j-c) / Rth(j-s) / Rth(j-a)** | 结-壳 / 结-散热器 / 结-环境热阻 | 必须带测试条件（功率、流量、TIM、压力）。**Rth(j-c) 不等于可以线性外推到实际系统** | 共享 |
| **Zth(t)** | 瞬态热阻抗 | 阶跃功率下的温升响应；功率循环峰值结温计算的基础 | 共享 |
| **结构函数** | structure function | 由 Zth 经热-电类比变换得到累积热容-热阻曲线，可定位各层（芯片/焊层/陶瓷/底板/TIM）的热阻贡献与分层 | 共享 |
| **Tvj / Tjmax** | 虚拟结温 / 最大结温 | Tvj 是电学法折算的代表性结温（非物理点温）；Tjmax 常见 150/175℃ | 共享 |
| **ΔTj / ΔTc / ΔTvj** | 结温摆幅 / 壳温摆幅 | 寿命模型的自变量。**报 ΔTj 必须同时报 Tj,mean、ton、I**，否则模型不可比 | 共享 |
| **功率循环 PC** | Power Cycling | 器件自身损耗加热芯片。**PCsec（秒级）** 考核芯片附近连接（键合线、芯片焊层）；**PCmin（分钟级）** 考核基板/底板焊层。AQG 324 明确区分 | 模组 |
| **热循环 TC** | Thermal Cycling | 整体环境/壳温循环，热源在外部。主要考核**陶瓷-基板/基板-底板焊层、陶瓷裂纹、端子焊点** | 共享 |
| **PC 与 TC 的本质区别** | — | **热源位置不同 → 损伤部位不同**。PC 的 ΔTj 集中在芯片与近芯片互连；TC 的 ΔTc 作用在大面积焊层。**用 TC 数据推断键合线寿命是典型错误** | 共享 |
| **Coffin-Manson** | — | Nf ∝ (ΔT)^(-n)。最基础，忽略平均温度与时间效应 | 共享 |
| **Norris-Landzberg** | — | 在 CM 上加频率与峰值温度项，源自焊点疲劳 | 共享 |
| **LESIT 模型** | — | Nf = A·ΔTj^α·exp(Q/(R·Tj,m))；Held 等 PEDS 1997，牵引应用快功率循环试验得出 | 模组 |
| **Bayerer / CIPS2008 模型** | — | Nf = K·ΔTj^β1·exp(β2/(Tj+273))·ton^β3·I^β4·V^β5·D^β6。**已知局限：不含基板焊层失效，不适用于牵引厚芯片** | 模组 |
| **SKiM 模型** | — | Scheuermann & Schmidt，针对烧结芯片 + 优化铝线；基于约 97 组、5 年 PC 试验，分离焊层失效与键合线失效两种机制，引入键合线高宽比 | 模组 |
| **雨流计数（Rainflow）** | — | 把真实使命剖面（mission profile）的复杂温度历程分解为等效循环，再代入寿命模型线性累积损伤（Miner） | 共享 |
| **Weibull 分布** | — | 寿命数据分布拟合；形状参数 β 区分早期失效/随机/磨损失效 | 共享 |
| **加速因子 AF** | — | 加速试验循环数 ↔ 现场循环数的换算；**必须由同一失效机理验证，不可跨机理套用** | 共享 |
| **HTRB** | 高温反偏 | 高温下加高压阻断，监测 ICES。终端与钝化层质量的试金石 | 共享 |
| **HTGB** | 高温栅偏 | 高温下加栅压，监测 IGES / VGE(th) 漂移。栅氧可靠性 | 共享 |
| **H3TRB** | 高温高湿反偏 | 85℃/85%RH + 反偏，典型 1000h。湿度 + 电场 + 离子迁移耦合 | 共享 |
| **HV-H3TRB** | 高压 H3TRB | 把反偏电压提到接近额定（而非额定的 80% 或更低），专攻高压模组（1200V+、光伏/风电）的湿度鲁棒性。**你执行的 1000h/1500h/168h 矩阵即属此类** | 模组 |
| **MSL** | 湿敏等级 | 回流焊前的吸湿等级；对 SMD 单管（TOLL/D2PAK）关键，对已密封模组通常不适用 | 单管 |
| **分层（delamination）** | — | 界面脱粘；SAM 可检。常见于灌封料/陶瓷/焊层界面 | 模组 |
| **空洞（void）** | — | 焊层或灌封内的空腔；率超标 → 局部热点 → 加速疲劳。AQG/客户规范通常有空洞率上限 | 模组 |
| **IMC（金属间化合物）** | Cu₆Sn₅ / Cu₃Sn / Ni₃Sn₄ | 焊点界面反应产物；过厚变脆，是焊点长期退化的主因 | 共享 |
| **柯肯达尔空洞（Kirkendall void）** | — | 界面元素互扩散速率不等导致的一侧空洞化；Cu/Cu₃Sn 界面典型 | 共享 |
| **铝线重构 / 铝层剥离** | Al reconstruction / Al reconstruction & lift-off | 功率循环下 Al 与芯片金属化界面热机械疲劳；表现为 VCE(sat) 上升 | 模组 |
| **电迁移（electromigration）** | — | 高电流密度下的金属原子输运；细线/小焊盘在高结温下风险高 | 共享 |
| **宇宙射线 / 大气中子失效** | terrestrial neutron / cosmic ray induced failure | 高压功率器件（尤其 >2.5kV）在海拔/中子通量下的单粒子烧毁；Semikron AN 17-003 专门讨论。**做高压模组可靠性必须考虑的、与常规试验无关的失效通道** | 模组 |

### 2.5 应用与驱动（12 条）

| 术语 | 中文 | 精确定义 / 工程要点 | 归属 |
|---|---|---|---|
| **Lσ（杂散电感）** | stray inductance | 换流回路寄生电感；关断尖峰 ΔV = Lσ·di/dt 的直接来源。模组布局/母排叠层决定 | 模组 |
| **Rg(on) / Rg(off)** | 开通 / 关断栅阻 | 分开取值以独立调 Eon 与 Eoff/dV/dt。**Rg 变小不一定更好：会加剧振荡与串扰** | 共享 |
| **米勒钳位（Miller clamp）** | — | 关断时把栅极低阻钳到射极，防止 dV/dt 经 Cres 误开通 | 共享 |
| **有源钳位（active clamping）** | — | 用 TVS/齐纳把关断过压反馈到栅极，动态放慢关断，抑制尖峰 | 共享 |
| **DESAT（退饱和检测）** | — | 监测 VCE 是否退出饱和来识别短路；响应时间需 < tSC，留有裕量 | 共享 |
| **软关断（soft turn-off）** | — | 短路时用大 Rg 缓慢关断，避免 di/dt 过大引发过压 | 共享 |
| **两级关断（two-level turn-off）** | — | 先降到中间电平再完全关断，兼顾过压与损耗 | 共享 |
| **并联均流** | 静态 / 动态 | 静态由 VCE(sat) 正温度系数与 Rg 对称性决定；动态由驱动回路对称性、gfs、Lσ 分布决定。**"同型号同批次"不等于能均流** | 共享 |
| **死区时间（dead time）** | — | 桥臂防直通；过短→直通，过长→二极管损耗与失真。受 tf、驱动延时、温度影响，需留裕量 | 共享 |
| **dv/dt / di/dt** | — | 与 EMI、串扰、电机绝缘、轴电流直接相关；是选 Rg 的真正约束 | 共享 |
| **开关频率上限** | — | 由 Eon+Eoff 与 Rth、Tjmax 联立决定，不是凭经验拍。估算需闭环（见 `scripts/igbt_loss.py`） | 共享 |
| **母线尖峰与吸收** | — | 关断尖峰 = VDC + Lσ·di/dt + 振荡；必要时加 RC/钳位，但吸收电路自身有损耗 | 共享 |

| 术语 | 中文 | 精确定义 / 工程要点 | 归属 |
|---|---|---|---|
| **静态测试** | — | VCE(sat)、VGE(th)、ICES、IGES、VF 等；注意脉宽与结温（必须注明 Tvj） | 共享 |
| **DPT（双脉冲测试）** | double pulse test | 测 Eon/Eoff/Erec、开关时间、dv/dt、di/dt 的标准手段。**夹具 Lσ 必须与被测应用可比，否则数据无意义** | 共享 |

| **绝缘耐压 / PD** | 局部放电 | 模组端子-底板、端子间绝缘；1700V+ 与铁路/电网必须做 PD | 模组 |

| **X-ray / CT** | — | 焊层空洞、键合线位置、内部结构 | 共享 |
| **EOL 判定 / DPA** | 寿命终点 / 破坏性物理分析 | AQG 324 常用双判据思路：**通态压降上升约 5%（指向键合线抬升/跟部裂纹）或热阻上升约 20%（指向焊层/烧结层分层）** `[二手-可交叉，须以标准正文核对]`。DPA 用于结构符合性验证 | 共享 |
