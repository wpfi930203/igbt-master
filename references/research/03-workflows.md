# Track 03 — 工作流 / SOP（Workflows）

> 调研日期：2026-10-17
> 综合来源：Track 01（机构路线）+ Track 02（工具）+ Track 04（正典）+ 用户自身的封装可靠性实践（20 年、宏微科技、六西格玛黑带）
> 可信度：`[标准锚定]` = 有标准条文/原厂手册对应；`[行业实践]` = 业内通行做法但无单一标准规定；`[你的实践]` = 来自用户既有工作方式

---

## 0. 这行的三条主流水线（很多人只做其中一条，所以看问题会偏）

| 流水线 | 输入 | 输出 | 主要风险 |
|---|---|---|---|
| **A. 产品开发流**（设计→试制→认证） | 客户规格 / 应用工况 | 可量产的产品 + 技术文档 | 规格理解偏差、热设计不足、认证试验才发现失效 |
| **B. 可靠性认证流**（试验→判定→报告） | 产品 + 认证矩阵 | 认证报告 + 失效清单 | 试验条件与实际工况不符、判据用错、样本量不足 |
| **C. 失效分析闭环流**（问题→根因→措施→验证） | 失效样品 | 8D / FA 报告 + 设计/工艺变更 | 根因误判（把现象当原因）、措施不闭环 |

**关键认知**：A 的输出质量决定 B 的通过率，B 的失效是 C 的输入。**三流不连通的公司，问题会反复出现在同一处。**

## 1. 流水线 A：产品开发 SOP

### 入门 SOP（最小完整任务：给一个已知工况做封装方案）

| # | 步骤 | 具体动作 | 依据 |
|---|---|---|---|
| 1 | **工况翻译** | 把客户描述转成 6 个量：VDC、IC(rms/peak)、fsw、Tamb/Tcoolant、目标寿命、绝缘等级 | `[行业实践]` |
| 2 | **拓扑与器件定位** | 确定用单管还是模组、几个芯片并联、是否需要 RC-IGBT、电压等级裕量（通常 VDC×1.5~2） | `[行业实践]` |
| 3 | **损耗-热闭环** | 用 PLECS/自建表算 Eon+Eoff+Econ → 得 Ploss → 用 Zth 算 Tvj,peak → 校核 Tjmax 裕量（车规常留 15–25K） | `[行业实践]`；见 `scripts/igbt_loss.py` |
| 4 | **结构选型** | DBC vs AMB、有无底板、单面 vs 双面散热、灌封体系、端子形式 | `[机构路线]`：高可靠/SiC→AMB；成本导向→DBC+Cu 底板 |
| 5 | **材料与互连选型** | die attach（焊料/烧结银）、键合（Al 线/Cu 线/Al 带/Clip）、TIM | `[正典]` 烧结银物理依据见 Bai & Lu；成本权衡见 synthesis 分歧 1 |
| 6 | **薄弱点预判（FMEA 前置）** | 按 AIAG-VDA 七步法先做**结构分析→功能分析→失效分析**，把已知失效机理映射到具体界面 | `[标准锚定]` AIAG-VDA 2019 |
| 7 | **样件与特性验证** | 静态 → DPT → Rth/结构函数 → 绝缘/PD | `[标准锚定]` IEC 60747-9 |
| 8 | **可靠性认证** | 按目标市场选矩阵：车规模组→AQG 324；车规单管→AEC-Q101；工业→客户规范 + IEC 60749 | `[标准锚定]` |
| 9 | **量产导入** | 控制计划、SPC 关键特性、来料与出货判据 | `[行业实践]` |

### 资深路径（跳过/优化哪些）

- **跳过"从零算损耗"**：建**自有器件损耗库**（同封装同电压等级的历史 DPT 数据），只对新型号复测。这是资深与入门最大的效率差。
- **把 FMEA 前移到第 3 步之前**：不是等设计定型再做 FMEA，而是用**历史失效案例库**反查设计。你的 400+ 行 PFMEA 正是这个资产。
- **用结构函数替代反复切片**：Zth 结构函数能在不破坏样品的前提下看出焊层退化，把 FA 从"切开看"变成"先算再切"。
- **认证矩阵按"变更影响"裁剪**：AQG 324 04.1/2025 的 **Delta Qualification Matrix** 正是为此设计——不要每次改版都全项重做。

### 近期变化（2025 起）

| 变化 | 影响哪一步 | 具体改法 |
|---|---|---|
| AQG 324 04.1/2025 强化 SiC（DGS / DRB / dyn. H3TRB） | 步骤 8 | SiC 模组矩阵要从 Si 矩阵扩 11 项；动态栅极应力与动态反偏成为必做 |
| IEC 60749-34-1:2025 发布 | 步骤 8 | 模组 PC 试验有了 IEC 方法可引；对非车规客户可用它替代 AQG 324，避免过度认证 |
| JB/T 8951.1~.5-2025 分册 | 步骤 2、8 | 国内项目可按单管/臂模块/单相桥/三相桥分别引用，产品规范表述更精确 |
| AIAG-VDA AP 替代 RPN（2019 起逐步落地） | 步骤 6 | 客户评审时**用 RPN 的旧表会被退回**；高风险项必须用 AP 判据说明 |

## 2. 流水线 B：可靠性认证流 SOP

### 矩阵搭建的三条铁律

1. **先定"管什么"再定"测什么"**：单管 → AEC-Q101；模组 → AQG 324。混用是最常见的形式错误。
2. **PC 必须分 PCsec / PCmin**：秒级考芯片附近连接（键合线、芯片焊层），分钟级考基板/底板焊层。**只做一种等于只验证了一半**。
3. **样本量与批次**：AEC-Q101 类项目常见 3 批 × 77 件量级；AQG 324 按项目分别规定。`[二手-可交叉，须以标准正文核对]`

### 典型车规模组矩阵骨架（AQG 324 四类）

| 类 | 代表项 | 验证什么 |
|---|---|---|
| **QM 模块检测** | 外观、SAM、初始电参数 | 出厂无初始缺陷（这是"零公里"防线） |
| **QC 特性测试** | 杂散电感、Rth、短路耐受、绝缘 | 设计参数符合规格 |
| **QE 环境测试** | 热冲击、振动、机械冲击、湿热 | 环境应力下的结构完整性 |
| **QL 寿命测试** | PCsec、PCmin、HTRB、HTGB、H3TRB/HV-H3TRB（+SiC：DGS、DRB、dyn.H3TRB） | 长期退化与寿命 |

### EOL 判据（必须写清用哪条）

- **通态压降上升约 5%** → 指向**键合线抬升 / 跟部裂纹**（铝线重构）
- **热阻上升约 20%** → 指向**焊层 / 烧结层分层**
- 两个判据要**同时记录**，因为它区分了失效机理，而不只是"记录了一次失效" `[二手-可交叉，须以标准正文核对]`

> 这条是你写报告时最该坚持的一点：**只报"失效了"没有工程价值，报"哪个界面失效、按什么判据判定"才有。**

## 3. 流水线 C：失效分析 / 8D 闭环流

### 入门 SOP（八步）

| # | 步骤 | 关键动作 | 常见错误 |
|---|---|---|---|
| 1 | **失效现象固化** | 收集应用工况、失效时波形、故障率、批次、位置分布 | 只拿到"坏了"的样品，没有工况数据 |
| 2 | **非破坏性分析（NDA）** | 外观 → X-ray → SAM → 电参数复测（VCE(sat)、Rth） | 一上来就开封 |
| 3 | **电参数分离机理** | VCE(sat) 漂移 vs Rth 漂移 vs 漏电 → 初判键合线/焊层/芯片/终端 | 不分离，直接猜 |
| 4 | **开封与定位** | 去除灌封 → 锁相红外/OBIRCH 定位 → 显微观察 | 开封过程本身引入新损伤 |
| 5 | **破坏性分析（DPA）** | 切片、SEM/EDS、IMC 厚度、裂纹路径 | 单点观察当统计结论 |
| 6 | **根因判定** | 用"物理机制 + 试验复现"双证据；必要时做加速复现 | 把"最像的原因"当根因 |
| 7 | **措施与验证** | 设计/工艺/筛选三层措施；明确验证方法与判据 | 只改不说清验证 |
| 8 | **横向展开（Read-across）** | 同平台/同工艺/同材料的所有型号排查 | 只修当前型号 |

### 资深路径

- **第 2 步就把 SAM + 结构函数做完**，很多时候可以在不开封的情况下判定是焊层问题，省掉 80% 的工作量。
- **第 6 步要求"可复现"**：能在加速试验里重现的根因才是根因。不能复现的，写成"高度可疑"而不是"根因"。
- **第 8 步是真正体现黑带水平的地方**：单点失效解决是工程师，横向展开防再发是黑带。

### 已知的失效机理 → 界面映射（速查）

| 现象 | 最可能的界面 | 首选确认手段 |
|---|---|---|
| VCE(sat) 缓慢上升、Rth 基本不变 | 键合线跟部裂纹 / 铝层重构 | SAM + 切片看键合跟部 |
| Rth 上升、VCE(sat) 小幅变化 | 芯片焊层/烧结层分层、空洞扩展 | 结构函数 + SAM |
| H3TRB 后漏电上升 | 终端钝化 / 灌封界面 / 芯片表面电荷 | 去除灌封看终端；对比不同灌封体系 |
| 短路后立即失效 | 芯片热失控 / latch-up / 金属化熔融 | 开封看熔融点位置 |
| TC 后端子或底板焊层开裂 | 基板-底板大面积焊层 | X-ray/CT + 切片 |
| 高压下无故击穿（无过压记录） | 宇宙射线/大气中子（>2.5kV） | 海拔与中子通量核算，非试验可复现 |

## 4. 单管 vs 模组：工作流的实质差异（双轨落地）

| 环节 | 单管（discrete） | 模组（module） |
|---|---|---|
| 热设计 | Rth(j-a) 与 PCB 铜箔/散热片强相关；**PCB 是热路径的一部分** | Rth(j-c) + TIM + 散热器；**封装内部热路径已固定，可优化空间在结构与材料** |
| 关键互连 | 焊点到 PCB、Clip/线键合到框架 | 芯片焊层、粗线键合、基板焊层、底板焊层 |
| 主导失效 | 焊点热疲劳（PCB CTE 失配）、MSL 吸湿爆米花、浪涌 | 键合线疲劳、焊层分层、陶瓷裂纹、灌封界面 |
| 认证标准 | AEC-Q101（车规）/ IEC 60747-9（产品规范） | AQG 324（车规模组）/ IEC 60749-34-1（PC 方法）/ JB/T 8951.2/.4/.5 |
| 测试重点 | 静态参数 + 雪崩（UIS）+ MSL/回流 | PCsec/PCmin + 绝缘/PD + SAM + 振动 |
| 并联问题 | **多管并联**：驱动回路对称、VGE(th) 匹配 | **多芯片并联**：芯片位置、Lσ 分布、温度梯度 |
| 常见误用 | 用模组的可靠性结论套单管 | 用 AEC-Q101 做模组认证 |

## 5. 诚实边界

- 本轨的 SOP 是**行业通行路径的整合**，不是某一份标准的原文流程。具体项目必须回到客户规范与 AQG 324 / AEC-Q101 正文。
- EOL 判据（5% / 20%）来自二手可交叉源，**写正式报告前必须以标准正文核对**。
- 样本量数字（3 批 × 77 件）为 AEC-Q101 类项目的常见量级，不同试验项与不同客户规范会有差异。
