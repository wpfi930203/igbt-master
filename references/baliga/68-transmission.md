## I · 骨架（本模块的 9 个逻辑块）

### I.0 三代阀门，一次判决

| 代 | 器件 | 电压 | 变流器 | 关键限制 |
|---|---|---|---|---|
| 1 | 汞弧阀 | 50–100 kV | 相控 | 维护、汞污染 |
| 2 | **光触发晶闸管** | **8 kV / 2 kA**（单管）→ 线路 400–600 kV | **LCC**（电网换相 CSC） | **必须电网有电压才能换相**；需大量无功 + 滤波器（占安装量近一半） |
| 3 | **IGBT** | 3.3 / 4.5 / 6.5 kV（单管）→ 阀 | **VSC**（自换相） | 转换器损耗比晶闸管大；单阀功率 ~100 MW |

三个商品名：**ABB HVDC Light / 西门子 HVDC PLUS / 阿尔斯通 HVDC MaxSine**。

**为什么 VSC 必然取代 LCC？** p354 给了三条，全部指向同一件事——**LCC 依赖电网，VSC 不依赖**：

1. **LCC 的电流是单向的**，由两端直流侧平衡电压决定 → 无法独立控无功，必须**分流滤波器产生无功**
2. **LCC 换相必须靠电网电压过零** → 弱电网/孤岛/无源网络直接失效（这正是海上风电起动、黑启动场景的刚需）
3. **VSC 的高开关频率把谐波压到很小** → 滤波器从「占安装量近一半」降到「可省」

→ **判据：选 LCC 还是 VSC，不看功率等级，看「受端有没有强电网」。** 有强电网 + 超大功率（>1 GW）→ LCC 更便宜；弱电网/孤岛/海上风电/城市地下 → 必须 VSC。

### I.1 ★★ 格拉茨桥 vs 全链节：本章唯一的拓扑分水岭

书里把「串联 IGBT」的两种做法摆在一起，代价写得很直白：

| | **格拉茨桥（两级串联）** | **全链节 / MMC** |
|---|---|---|
| 结构 | 每支路**串联大量两级 IGBT 变换器** | **几十到几百个独立串联单元**，每单元 **4 只 IGBT + DC 电容** |
| 均压 | **需要大型、重型无源缓冲电路** | 靠电容自然分压，**无缓冲** |
| 调制 | 每周期切换多次 → **PWM 损耗显著** | 电平数多 → **几乎完美正弦** |
| 滤波 | 需要（PWM 高 dV/dt → EMC 问题） | **完全不需要滤波器** |
| 故障 | 可承受直流侧短路 | 可承受直流侧短路 |

**这一页是全书的第四个「不用滤波器」的地方**（前三个：`67` 的 HERIC 去掉变压器、`67` 的 NPC 提效、`66` 的 PEBB 把滤波器减 40 %）。
**对照 `66 · I.2`**：「电力滤波器占船用设备大小的 **1/3** 和重量的 **3/4**」。→ **MMC 把这一项直接归零，这是它在 HVDC 中胜出的真正理由，不是效率。**

**MMC 的代价（书未展开，本层补）**：
- 每单元一只 DC 电容 → **几十~几百只电容**，电容是 `66 · 表 14.7` 里「与 IGBT 并列的两大限制可靠性部件」
- 子模块数量多 → **失效率上升**，但**单模块失效只损失 1/N 输出**（与 `66 · I.3` 的「并联双刃剑」同构）
- 需要**子模块电容电压均衡控制**（书完全未提）

> **可迁移判据**：分布式（MMC / 多单元）与集中式（两级串联）的选择，本质是「**用器件数换滤波器体积 + 换失效的渐进性**」。这个 trade 在**滤波器体积占比 >30 %** 的场景（船舶、城市变电站、海上平台）永远成立。

### I.2 ★★★ p364：全书唯一「器件六项数字全给」的一页

三菱 3.3 kV DMOS-IGBT（R 系列），为 VSC-HVDC 定制：

| 参数 | 数值 | 意义 |
|---|---|---|
| **通态压降** | **3.6 V → 2.8 V**（−22.2 %） | 靠 **N 型载流子存储层**（P 基区旁）给 MOSFET 段补载流子 |
| **通态压降温度系数** | **强正** | → **允许芯片并联**（负温度系数会热失控） |
| **芯片并联数** | **18 只 / 模块** | → 每芯片约 **83 A** |
| **模块额定电流** | **1500 A** | 18 × 83.3 = 1500 ✓ |
| **衬底** | **氮化铝（AlN）** | 热匹配硅 + 散热优于 Al₂O₃/AlN 混合 |
| **键合引线** | **数量 +200 %** | 解决**键合引线浮空**（lift-off）可靠性 |
| **宇宙射线限压** | **DC 母线 ≤ 2.5 kV**（3.3 kV 器件） | **只用满 75.8 % 额定** |
| **RBSOA** | 2.5 kV 母线下可关断 **6000 A** | = 4 × 额定电流 |
| **SCSOA** | 峰值 **8600 A** 时 **20 μs** | 短路耐受时间 |

**六条工程判据，逐条落点**：

1. **载流子存储层是「用掺杂换压降」的第三个手段**（前两个：`54` 透明集电极、`57` 沟槽栅/场截止）。代价书里点明了：「**必须在掺杂和厚度方面进行优化以避免击穿电压和安全工作区的削弱**」→ **压降与 SOA 是同一块面积的零和**。
2. **「强正温度系数 → 可并联」是并联可行的前置条件**，不是结果。`66 · 表 14.6` 说并联能延寿 22.5 倍，但**前提是 `dV_CE/dT > 0`**。若器件是负温度系数，并联会电流集中到最热的那只，加速失效。
3. **键合引线 +200 %** —— 这是本层唯一量化的**封装可靠性改进手段**。章首 `change` 到 p364 都在说「可靠」，而唯一的数字就是这条。**与 `main §9.6` 的键合线失效（`50–65 ℃` 温区）直接对应**。
4. **AlN 衬底**：`67` 的封装层视角（`58`）讲的是模块结构，这里讲的是**为高压 + 高热流选的衬底材料**。→ **判据：电压 3.3 kV 以上 + 高电流密度的模块，AlN 是默认，不是选配。**
5. **宇宙射线限 2.5 kV / 3.3 kV = 75.8 % 额定** —— **这是全书最激进的电压利用率**。见 I.3。
6. **SCSOA 20 μs @ 8600 A** —— 对照 `main` 层的「短路耐受 10 μs」惯例，**HVDC 器件给了 2 倍**。原因：HVDC 阀的短路检测走**阀控 + 直流保护**，动作比驱动器 DESAT 慢，所以器件必须扛更久。→ **SCSOA 不是器件固有属性，是「保护速度」的镜像。**

### I.3 ★★ 宇宙射线：两个口径差 13–24 个百分点

同一个物理约束（宇宙射线诱发单粒子烧毁），书里给了两个完全不同的数字：

| 场景 | 器件 | 母线 | 用满额定 | 出处 |
|---|---|---|---|---|
| **HVDC 阀** | 3.3 kV | **2.5 kV** | **75.8 %** | p364 |
| 风电 2 级 | 1200 V | 620 V | **51.7 %** | `67` 表 15.2 |
| 风电 2 级 | 1700 V | 1070 V | **62.9 %** | `67` 表 15.2 |
| 风电 2 级 | 4500 V | 2800 V | **62.2 %** | `67` 表 15.2 |
| 风电 3 级 | 3300 V | 1900 V（单管承压） | **57.6 %** | `67` 表 15.3 |

**为什么 HVDC 敢用到 75.8 %，而风电只敢用 52–63 %？** 不是宇宙射线变了，是**另外三条约束在风电侧同时存在**：

1. **关断过冲**：风电逆变器是硬开关，`di/dt` 高 → `V_ce` 尖峰叠加在母线上（`61` 的 2.0–2.2×）
2. **电网波动**：风电并网点电压允许 ±10 % 波动，HVDC 阀在**受控直流母线**下运行
3. **海拔/纬度**：宇宙射线通量随海拔和纬度升高（书未给修正，但这是已知物理）

→ **★ 判据：宇宙射线限是「电压的上限」，但实际母线电压由「过冲 + 电网波动 + 宇宙射线」三者中最严的一条决定。**
→ **HVDC 之所以能用满 75.8 %，是因为它把「过冲」这一条几乎消掉了**（阀由 MMC 子模块 + 钳位构成，`dV/dt` 极低）。**这是 MMC 拓扑的隐性红利，书里没有连线。**

### I.4 ★ 表 16.1 CSC vs VSC：谁耐受短路

| | **电压源（VSC）** | **电流源（CSC）** |
|---|---|---|
| **优点** | PQ 可控（自换向）；**电压可通过串联单元调节**；**明确的半导体端电压**；**耐受短路故障**；几近完美正弦**电压** | PQ 可控（自换向）；**电流可通过并联单元调节**；几近完美正弦**电流** |
| **挑战** | 电感器与 RB 器件高损耗；**大量能量储存在电容器**；**内部和外部 DC 短路故障防护**；开路故障保护与器件过压保护；**有限电压调节能力** | 电感器与 RB 器件高损耗；**大封装电感**；开路故障保护与器件过压保护；**有限电压调节能力** |

读这张表的三个要点：

1. **「明确的半导体端电压」是 VSC 的结构性优势** —— 因为并联大电容，器件两端电压被钳死。这直接解释了 I.3 里「HVDC 敢用到 75.8 %」：**电容把过冲吃掉了。**
2. **「耐受短路故障」与「DC 短路防护」同时出现在 VSC 的优点和挑战里** —— 不矛盾：**VSC 能扛住外部短路（电感限流），但内部 DC 母线短路会经二极管反灌，无法用 IGBT 关断。** 这是 VSC 的**致命短板**，也是 MMC 要加 DC 断路器（`66 · I.2.3` 的固态断路器）的原因。
3. **CSC 用「并联单元调电流」，VSC 用「串联单元调电压」** —— 一句话记：**电压源串起来调压，电流源并起来调流。** 这解释了为什么 `67` 的反向阻断 IGBT 是 **CSI 拓扑的钥匙**（CSC 需要双向阻断）。

→ **与 `67 · I.1` 的闭环**：`67` 说反向阻断 IGBT 让 CSI 省掉串联二极管，代价是开关损耗涨 2.75 倍。**本章表 16.1 说明 CSC 的真正优势不是效率，是「天然限流 + 完美正弦电流」**。两章合起来才是完整判断。

### I.5 ★★ 离岸的损耗账：3 ‰/1000 km + 1.5 % × 2

p362 给了全章最实用的一组数：

```
线路损耗：3 % / 1000 km（HVDC）
换流器损耗：1.5 % / 台（每端一台，故两端 3 %）
```

**总损耗 = 0.003 × L(km) + 3 %**

| 距离 | 线路 | 换流器 | 总损耗 | 效率 |
|---|---|---|---|---|
| 100 km | 0.3 % | 3 % | **3.3 %** | 96.7 % |
| 500 km | 1.5 % | 3 % | 4.5 % | 95.5 % |
| **1000 km** | 3 % | 3 % | **6.0 %** | 94.0 % |
| 2000 km | 6 % | 3 % | 9.0 % | 91.0 % |
| 2375 km（马德拉） | 7.1 % | 3 % | **10.1 %** | 89.9 % |

**这张表的三个用途**：

1. **算「交越点」**：HVDC 的固定成本是 **3 % 换流损耗**，且**与距离无关**。HVAC 的损耗与距离近似线性但斜率更低（无换流器），**但在长距离上有电缆充电电流（容性无功）**。→ `67 · I.3.3` 给的「典型交越点 **100 km**」就是这两条线的交点。
2. **验证「便宜三倍」**：p362「**100 km** 线路，HVDC 至少比 HVAC 便宜三倍」。**在 100 km 处 HVDC 的损耗只比 HVAC 高一点点（3.3 % vs 约 1–2 %），但电缆成本低得多**（XLPE 可承受更低电压等级 → 更便宜）。
3. **单端 1.5 % 是「每台换流器」还是「每端」**：书说「转换器中的损耗是传输功率的 **1.5 %**」，与 `67` 的「逆变器占 8.3 % 成本」对照 —— **1.5 % 的损耗对应 8.3 % 的成本占比，是极好的「器件价值密度」指标：每 1 % 损耗值 5.5 % 的系统成本。** 这是本层唯一可算的「损耗-成本汇率」。

→ **★ 可迁移判据：若某环节的「成本占比 / 损耗占比」> 3，该环节是「高价值密度」，值得为降损耗投钱。** 光伏逆变器 8.3/1.5 = 5.5 ✓；对比 `67` 的组件（成本 60 %+，无损耗项）→ 组件是「低价值密度」。

### I.6 ★ 串联的工程代价：32 只 / 32 kV

p360 奥斯汀霍利 STATCOM 是全章唯一的「串联」实例：

| 项 | 数值 |
|---|---|
| 交流总线 | **32 kV** |
| 串联只数 | **32 只** |
| 拓扑 | **三电平 NPC** |
| PWM 基频 | **1260 Hz** |
| 滤波组件 | **5–10 Mvar** |
| 占地面积 | **20 m × 30 m**（两层楼内） |
| 冗余 | **三个阀坏两个仍可运行**（N+1 冗余） |

**「32 kV / 32 只 = 1 kV per 器件」这个数字有问题**（见 B3）：若器件是 3.3 kV，余量 3.3×，过于保守；若器件是 1.7 kV，余量 1.7×，合理。**书未给器件电压，只能记「32 只」这个事实。**

**真正的知识点在「三电平 + 1260 Hz」这个组合**：
- 三电平把每管电压减半 → 串联数可以少一半
- 1260 Hz 是**基频的 21 倍**（60 Hz × 21）→ 属于「中频 PWM」，既不是基频开关（低损耗）也不是高频（小滤波器）
- **5–10 Mvar 滤波器在 1260 Hz 下才能做到 20×30 m 可接受**（若用 60 Hz 基频开关，滤波器会是几倍大）

→ **与 `66 · I.2` 的船舶变频器形成完整闭环**：滤波器占设备 1/3 体积 / 3/4 重量 → **提高开关频率是唯一能压缩它的手段**，而 1260 Hz 是「IGBT 损耗可接受」与「滤波器可接受」的折中点。

### I.7 中国 STATCOM：三峡 1 + 1.2 Gvar

p360：

| 项 | 数值 |
|---|---|
| 中国装机 | 1990 **17 GW** → 2000 **320 GW** → 2020 预计 **750 GW** |
| 三峡需求 | **1 Gvar STATCOM + 1.2 Gvar SVC**（合计 2.2 Gvar） |
| 技术路线 | **级联多电平（全链节）**，无需庞大变压器 |
| 器件 | 东芝 **IEGT 4500 V / 1500 A**（注入增强门） |

**IEGT 是本章唯一提到的「非纯 IGBT」器件**：注入增强门晶闸管 = IGBT 的栅结构 + 晶闸管式的电导调制。**它的存在本身就说明：3.3 kV 以上的高压 + 大电流，纯 IGBT 的通态压降不够低。** → 这与 `54`（透明集电极）、p364（载流子存储层）是**同一条技术路线的三站**：都在想办法「在不牺牲 SOA 的前提下多注载流子」。

**为什么三峡要 2.2 Gvar 无功？** 因为**远距离水电送端是弱电网**（`67` 的向家坝—上海 2000 km）。长距离线路的容性充电功率在轻载时过剩、重载时不足 → 需要**动态**无功（STATCOM 响应 ms 级，SVC 响应 10–20 ms）。**1 + 1.2 的配比说明：快的那台（STATCOM）承担暂态，慢的那台（SVC）承担稳态基荷。**

### I.8 城市与园区：VSC-M-HVDC 的「100 % 传输功率」

p363 是本层唯一讲**「优质电力园区」**的地方：

- 场景：银行/金融机构，**停机成本每小时几百万美元**（互联网经济 + 信用卡）
- 9 类电源质量问题：电压骤降/骤升/瞬变/谐波/闪烁/不平衡/频率方差/瞬时中断/停电
- 方案：**VSC-M-HVDC**（多端 VSC），**地下直流电缆环**，各 VSC 在 DC 端子并联
- **关键指标：设计具有 100 % 的传输功率** → 「不仅可以处理瞬态事件，而且在**断电期间也可以供电**」
- **IGBT 双重角色**：正常时是换流器件，故障时**串联 IGBT 用作断路器**隔离故障源，故障清除后**再次导通**

→ **「100 % 传输功率」是本章最重要的一个设计判据，也是最容易被忽略的**：常规 UPS 只带「关键负载」（20–40 %），而 VSC-M-HVDC 带 **100 %** —— 意味着**换流器额定 = 全部负载**，成本是 UPS 的 3–5 倍。
→ **判据：只有当「停机成本 > 换流器成本」时，100 % 冗余才成立。** 银行/数据中心成立，普通办公楼不成立。
→ **与 `69`（金融/UPS，下一模块）的分界线就在这里**：本章讲「园区级 100 %」，`69` 讲「设备级 UPS」。**两者的成本敏感度差一个量级。**

### I.9 交流输电：电压史 + 1 %/4 % + 电价三层

**电压等级史**（p358）：110 kV（1911 德国）→ 220（1929）→ 287（1932 美国博尔德坝）→ 380（1952 瑞典）→ **735（1965 加拿大）** → **1200（1985 苏联）**。**74 年涨 10.9 倍。**

**损耗的平方律验证**（p358）：「100 mile 的 1000 MW 线，**765 kV 时约 1 %，345 kV 时 4 %**」。

```
(765/345)² = 4.917
若 345 kV 为 4 % → 765 kV 应为 4/4.917 = 0.81 %（书说 1 %，偏高 0.19 百分点）
若 765 kV 为 1 % → 345 kV 应为 1×4.917 = 4.92 %（书说 4 %，偏低 0.92 百分点）
```

→ **两个数字的内部一致性在 ±25 % 内，符合 I²R 律，但不是精确的一对**（还有电晕、介质、集肤等项）。**这组数是全书最好用的「电压翻倍损耗降 4 倍」的实证。**

**电价三层结构**（p358）：

| 环节 | 美分/kW·h | 占终端电价 |
|---|---|---|
| 生产 | **1–2.5** | 10–25 % |
| 长距离传输 | **0.2–0.5** | **2–5 %** |
| 终端（美国均值） | **10** | 100 % |

→ **传输只占终端电价 2–5 %。** 这与 `67 · I.9` 的「逆变器占光伏系统成本 8.3 %」是同一类事实：**电力电子在整条价值链里的成本占比都只有个位数。**
→ **但两者的战略含义相反**：传输环节的 2–5 % 一旦失效就是**全网停电**（`66 · I.2` 的「停机成本每小时几百万美元」），而逆变器失效只是少发一点电。→ **判据：成本占比小 ≠ 重要性小；要看失效后果。**

## A1 · 案例

### A1.1 奥斯汀霍利电厂 STATCOM（本章最完整的单点设计）

- 背景：火电厂原计划 1995 年退役，因能源短缺继续运行；需回应居民对安全/美学的关注
- 决策：在 **SVC 与 STATCOM 之间比较**，选 **IGBT 电压源 STATCOM**（因 SVC 需要大电容器组 + 电抗器，占地与美学不可接受）
- 参数：32 kV 母线 / 32 只串联 / 三电平 NPC / 1260 Hz / 5–10 Mvar / 20×30 m / 两层楼
- **N+1 冗余**：三个阀坏两个仍可工作；损坏阀可在计划维护期修复，**不中断输电**
- **失效模式假设是「IGBT 短路失效」** → 这与 `67 表 15.4`「压接式失效=短路」呼应：**这里的冗余设计正是为「短路失效」准备的**

### A1.2 SVCLight 在瑞典 Uddeholm Tooling（1999）

- 负载：**37.8 MV·A 电弧炉 + 7.7 MV·A 钢包炉**（合计 45.5 MV·A）
- 母线：**10.5 kV**；2000 年升级接 **20 kV** 线；2002 年升级到 **33 kV**
- 目的：抑制**电压闪烁**（电弧炉是典型「闪变源」，会干扰邻近社区）
- 拓扑：**三电平 VSC**，电容器组作直流电压源，输出可接正/中性/负
- 卖点：**不需要庞大变压器** → 紧凑、稳定

**→ 「电弧炉 + 风电场」是两个最典型的闪变源**（p360：德州 McCamey 的 SVC 就是为稳定**风电场**的波动输出）。**这两者都需要 ms 级动态无功，只有 VSC 能给。**

### A1.3 Tres Amigas 超级站（新墨西哥 Clovis）

- 目的：连接美国**三大电网**（西部 WECC / 东部 Eastern / 德州 ERCOT）—— 三者**互不同步**
- 手段：**背靠背 HVDC**（同一建筑物内、短内部母线）
- 规模：**5 GW 需 6 个背靠背换流器** → 每个 **833 MW**
- 选址理由：**邻近新兴风电基地**
- 引用：「满量程（**11 MW**）IGBT 转换器的测试连续显示出优良的可靠性」

**→ 「背靠背」的唯一用途是「连接不同步电网」**。这是 HVDC 的第四种配置（`67` 之外）：① 背靠背 ② 电缆 ③ 架空远距离 ④ 多端。
**⚠ `11 MW` 与 `5 GW / 6 = 833 MW` 差 76 倍，见 B4。**

### A1.4 沙特海上 ESP：1742 套 / >500 MW

- 负载：**电潜泵（ESP）**，1742 套，总功率 **>500 MW**
- 距离：**10–100 km**
- 方案：**230 kV HVDC**（比 HVAC 更有效，因海底电缆的容性充电电流在 AC 下无法承受）
- 器件：IGBT 电压源换流器 + PWM，**有功/无功独立控制**
- 经济性：**100 km 内 HVDC 至少比 HVAC 便宜 3 倍**

**→ 这是「海上平台」这个特殊场景：负载是电机（不是电网），所以不需要频率/相位同步，只需要「送电」。→ HVDC 的唯一优势变成「电缆成本」，而不是「稳定性」。**

## A2 · 本地复算

### A2.1 交流线损耗的平方律（±25 % 内成立）

```
(765/345)² = 4.917
345 kV = 4 % → 765 kV 应为 0.814 %（书 1 %，高 0.19 百分点）
765 kV = 1 % → 345 kV 应为 4.917 %（书 4 %，低 0.92 百分点）
```

→ **方向、量级、系数全对；只是两个点不是同一条 I²R 曲线的精确解。** 可用作「电压升 2.2 倍，损耗降约 5 倍」的实证。

### A2.2 1970 年 400 kV 的串联数

```
400 kV / 3 kV（单管阻断） = 133 只/阀臂
```

→ 印证 p355「大量的晶闸管必须串联以承受这种高电压，因为每个器件的阻断电压能力约为 3 kV」。**133 只串联，均压是当年最大的工程难题**（与 I.6 的 32 只同类问题，规模大 4 倍）。

### A2.3 离岸损耗账（可直接查表）

```
L(km)          100   500   1000   2000   2375
线路损耗      0.3%  1.5%   3.0%   6.0%   7.1%
+ 换流器      3.0%  3.0%   3.0%   3.0%   3.0%
= 总损耗      3.3%  4.5%   6.0%   9.0%  10.1%
效率         96.7% 95.5%  94.0%  91.0%  89.9%
```

→ 与 `67 A2.x` 的「光伏 97 %」对照：**HVDC 在 1000 km 处的效率（94 %）已低于光伏逆变器（97 %），但仍远高于「送不出去」的 0 %。**

### A2.4 ★ 宇宙射线余量的两个口径（本章最重要的对比）

```
HVDC（p364）：3300 V 器件 / 2500 V 母线 = 用满 75.8 %
风电（`67` 表 15.2）：1200/620 = 51.7 %、1700/1070 = 62.9 %、4500/2800 = 62.2 %
风电（`67` 表 15.3）：3300/1900 = 57.6 %
```

→ **差 13.2–24.1 个百分点。** 不是测量误差，是**约束集不同**：HVDC 有电容钳位（无过冲），风电是硬开关（有过冲）+ 电网波动。
→ **实用结论：`V_rating / V_dc` 的取值区间应是 1.3–1.9，具体落在哪一端由「有没有电容钳位」决定。** 这条比任何单一数字都有用。

### A2.5 18 芯片并联的一致性

```
1500 A / 18 只 = 83.3 A/芯片
```

→ 这是「单芯片 83 A」的水平，对应 3.3 kV 芯片的典型电流密度（约 100–150 A/cm²，芯片面积约 0.6–0.8 cm²）。**书未给芯片面积，不能反推电流密度**（见 B6）。

### A2.6 32 kV / 32 只的电压对不上（见 B3）

```
32000 / 32 = 1000 V/只
若器件 3.3 kV → 余量 3.3×（过保守）
若器件 1.7 kV → 余量 1.7×（合理）
若三电平 → 每管承 16 kV，32 只/相 → 500 V/只（更不合理）
```

→ **只有「1.7 kV 器件 + 每臂 32 只」这一种读法自洽。** 书未给器件电压，故只记「32 只」这一事实。

### A2.7 通态压降改善的换算

```
3.6 → 2.8 V：Δ = 0.8 V，相对 −22.2 %
同电流下通态损耗同比 × 0.778（−22.2 %）
```

→ **注意：这是「同一电流」下的比较。若芯片面积不变，压降降 22 % 意味着载流子存储层的注入增强确实生效；若同时减薄了 N 漂移区（书说「较薄的 N 缓冲层」），则耐压也变了。书未给耐压-压降的联合曲线**（见 B7）。

### A2.8 5 GW / 6 与 11 MW 的矛盾

```
5000 MW / 6 = 833.3 MW per converter
书说「满量程（11 MW）IGBT 转换器」
833.3 / 11 = 75.8 倍
```

→ **量级差 76 倍，必有一处口径不同**（见 B4）。可能是「11 MW 是单个子模块/单阀测试容量」而非整台换流器。

### A2.9 三峡无功的配比

```
1 Gvar STATCOM + 1.2 Gvar SVC = 2.2 Gvar
STATCOM 占 45.5 %，SVC 占 54.5 %
```

→ 快的那台（STATCOM，ms 级）占不到一半，慢的那台（SVC，10–20 ms）占一半以上。**经济性判断：动态性能只买「够用」，其余用便宜的 SVC 补。** 这是一条可迁移的「无功配置」原则。

### A2.10 电价三层的占比

```
生产 1–2.5 + 传输 0.2–0.5 = 1.2–3.0 美分/kW·h
终端 10 美分/kW·h
→ 生产+传输 占 12–30 %，其余 70–88 % 是配电 + 税费 + 利润
```

→ **「传输占 2–5 %」这个数字必须限定为「只算长距离传输」，不含配电。** 若把配电算进去，占比会大幅上升。**书只给了传输，没给配电**（见 B8）。

### A2.11 IEGT 与 IGBT 的电压分工

```
IGBT 主流档：3.3 / 4.5 / 6.5 kV（p357 / `67` 表 15.4）
IEGT（东芝）：4.5 kV / 1.5 kA（中国 STATCOM）
```

→ **4.5 kV 及以上，IEGT 与 IGBT 正面竞争。** 判据：**通态压降要求苛刻 + 开关频率不高（<1 kHz）→ IEGT 有优势；开关频率高 → IGBT 胜。**

## S · 步骤（HVDC/VSC 系统设计 8 步）

```
① 定受端电网强度：
   强电网 + >1 GW → LCC（晶闸管）更便宜
   弱电网/孤岛/海上/城市地下 → VSC（IGBT）唯一选择

② 算线路损耗，定 AC/DC 分界：
   总损耗 = 0.003 × L(km) + 3 %（两端换流器）
   → 与 HVAC 的充电电流损耗对比，交点通常在 ~100 km（`67`）

③ 定拓扑：
   滤波器体积占比 >30 % → MMC（全链节），每单元 4 IGBT + DC 电容
   否则 → 两级/三电平串联（需大型无源缓冲 + 同步栅极）

④ 定母线电压 = min(过冲限, 宇宙射线限, 电网波动限)：
   有电容钳位（VSC/MMC）→ 可用到 75 % 额定
   硬开关（风电/光伏）→ 只能用 52–63 % 额定

⑤ 选器件：
   3.3 kV：载流子存储层 + 强正温度系数（可并联 18 只/1500 A）
   >4.5 kV 且 f_sw < 1 kHz：考虑 IEGT
   封装：压装（HVDC 标配，散热+大电流最优，但失效=短路）

⑥ 校核三个 SOA：
   RBSOA ≥ 4 × 额定电流（p364：6000 A @ 1500 A）
   SCSOA ≥ 保护动作时间（p364：20 μs @ 8600 A）
   宇宙射线：V_dc ≤ 0.76 × V_rating（HVDC 口径）

⑦ 冗余与失效隔离：
   阀级 N+1（霍利：3 阀坏 2 仍运行）
   系统级 MMC 子模块冗余
   DC 侧短路 → 必须加直流断路器（IGBT 关不断内部 DC 短路）

⑧ 滤波器/占地核算：
   1260 Hz PWM 时 5–10 Mvar 滤波器 ≈ 20×30 m
   提高 f_sw 是压缩滤波器体积的唯一手段（`66`：滤波器占 1/3 体积 / 3/4 重量）
```

## B · 边界（用这一章时不能越的 10 条线）

**B1｜本章与第 15 章有 30 % 内容重叠**
HVDC 基础、VSC 优势三条、300 MW/2002 案例在 `67`（p326–327）与 `68`（p353–354）**各写了一遍**，数字完全一致。→ **引用时用 `68` 的版本（更完整），不要两处都引以为「两个来源互相印证」——它们是同一段文字。**

**B2｜「VSC 将完全取代 LCC」是 2014 年的预测，未兑现**
p354 原话「预计即使在最高电压和功率的水平，VSC-HVDC 方法也将完全取代先前的 LCC HVDC 方法」。**至今（2026）中国 ±1100 kV / 12 GW 特高压仍用 LCC**（因 LCC 损耗更低、单位造价更低）。→ **该预测只能当「趋势方向」，不能当「已发生的事实」。**

**B3｜「32 kV 总线 / 32 只串联」的器件电压不自洽**
`32000/32 = 1000 V/只`。若器件 3.3 kV，余量 3.3×（过保守）；三电平下每管承 16 kV，若每臂 32 只则 500 V/只（更不合理）。→ **只有「1.7 kV 器件 + 每臂 32 只」自洽，但书未给器件电压。只能记「32 只」这一事实，不能反推器件。**

**B4｜「5 GW / 6 个换流器」与「11 MW 满量程测试」差 76 倍**
`5000/6 = 833 MW` vs 书说「满量程（**11 MW**）」。→ 必有一处口径不同（11 MW 可能是单子模块或单阀）。**两个数字不能放在同一句里引用。** 另：Tres Amigas 项目**实际从未建成**（2013 年后停滞），书中的规划不能当已实现业绩。

**B5｜表 16.1 是「定性对比」，不是评分表**
优点/挑战的条目没有权重，也不对应具体工况。→ **不能据此打分选型**；要用必须自己补「该工况下哪条优点值钱」。例如海上风电，「耐受短路故障」值钱、「电压调节能力有限」不要紧。

**B6｜「18 芯片 / 1500 A」不能反推电流密度**
`1500/18 = 83.3 A/芯片`，但书**未给芯片面积** → 无法算 `A/cm²`。→ 若需电流密度，回 `p364` 的「18 只」只能是并联数证据，不是密度证据。

**B7｜「3.6 V → 2.8 V」缺测试条件**
未给「额定电流下」还是「某参考电流下」，也未给对应的耐压（3.3 kV 是模块级还是芯片级）。且书同时说「较薄的 N 缓冲层 + 优化的 N 漂移区」→ **压降改善与耐压/SOA 是联动变量，不能单独引用压降数字**。

**B8｜「传输成本 0.2–0.5 美分/kW·h」只含长距离传输，不含配电**
→ 不能理解为「电网全部成本占终端电价 2–5 %」。配电（含变压器、低压网）成本未给。**引用时必须限定为「长距离传输段」。**

**B9｜图 16.3 / 16.8 是趋势图，不可读数**
HVDC 电压增长（16.3）与 HVAC 电压增长（16.8）均为示意曲线，**只有正文给出的点值可用**（1970/400 kV、1980/500 kV、1987/600 kV、1911/110 kV、1965/735 kV、1985/1200 kV）。

**B10｜数据年代 2014，器件能力已大幅前进**
书中最高电压器件 6.5 kV（`67` 表 15.4）、IGBT 逆变器功率上限 100 MW（p362）。**当前（2026）4.5 kV/3 kA 压接式、6.5 kV/1 kA 已是常规，MMC 单阀可达 GW 级。** → **本章只能作「判据与物理约束来源」，不能作「当前器件能力来源」。**
