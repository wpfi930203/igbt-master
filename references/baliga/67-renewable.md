## I · 骨架（本模块的 10 个逻辑块）

### I.0 六种能源，一个动作

书里从水电讲到地热，六种一次能源（水/光/风/浪/潮/地热）的物理机制完全不同，但**电力电子界面是同一个**：

```
不稳定的一次能源  →  [整流]  →  DC 母线  →  [PWM 逆变]  →  50/60 Hz 恒定
```

p325 把这句话说得很直接：「在**所有**可再生能源发电系统中，**必须使用逆变器**」。差别只在**整流侧是「被动」还是「主动」**：

| 能源 | 整流侧 | 为什么 | 器件 |
|---|---|---|---|
| 光伏 / 燃料电池 | **被动**（二极管） | 源本来就是 DC | 只要逆变级 6 只 IGBT |
| 风电（全变换） | **主动**（PWM 整流） | 频率随风速变，要 MPPT | 背靠背 12 只 |
| 风电（双馈） | 转子侧四象限 | 只处理 25 % 功率 | 部分功率变频器 |
| 水电（大型） | 同步机 + HVDC | 远距离送电 | VSC 三电平 |
| 波浪 / 潮汐 | 主动（变频） | 周期秒级波动 | VSI |
| 地热 | 被动 | 汽轮机恒速 | VSI（2 kHz 载波） |

→ **判据：看到「可再生能源」四个字，先问「源是 DC 还是变频 AC」。DC 源省掉整个整流桥，这是光伏逆变器能做得比风电变流器便宜一半的结构性原因**（书未直说，本层推论）。

### I.1 ★★ 表 15.1：省器件，但不省损耗（本章最硬的一张表）

BP275 光伏板、三相电流源逆变器（CSI），对比「非对称 IGBT + 串联二极管」与「反向阻断 IGBT」：

| 项目 | 加串联二极管的 IGBT | 反向阻断 IGBT | 变化 |
|---|---|---|---|
| **导通损耗 / W** | 386 | **232** | **−154（÷1.664）** |
| **开关损耗 / W** | 76 | **209** | **+133（×2.75）** |
| **总损耗 / W** | **462** | **441** | **−21（−4.5 %）** |
| 器件数 | IGBT + 外置二极管 | **仅 IGBT** | **少 1 种元件** |

**这张表的真正结论不是「反向阻断更好」，而是「收益几乎全被开关损耗吃回去了」**：

- 导通侧赚 **154 W**，开关侧赔 **133 W** → **86.4 % 被吃掉**
- 净剩 **21 W**（4.5 %），而正文的落点也不在损耗：「**总的功率损耗仅略微减小**，但这种方法**消除了串联二极管，减少了元件数**」
- 所以这一页的决策变量是 **BOM 与可靠性**，不是效率

→ **这是 `64 · I.0`「少一个开关 = 一代降本」在本层的第二次出现，但代价写得最清楚**：少一个二极管，代价是开关损耗涨 2.75 倍。**反向阻断 IGBT 用「更大的芯片面积 + 更厚的耐压结构」换掉了二极管的正向压降，但同一块面积在开关瞬间要扫出全部存储电荷。**

> **可迁移判据**：任何「用器件能力替代外置元件」的方案，先按 **`ΔP_cond` 与 `ΔP_sw` 分别列账**，再看净差。只报净差的方案书里都是营销，不是工程。

1. **表 15.3 的 `V_dc` 是单管承压，不是母线电压。** 证据：`2×V_dc/V_line` 七行全部落在 **1.623–1.652**（离散度 1.8 %）；若把 `V_dc` 当母线，则七行的 `V_dc/V_line` 会落在 0.81–0.83，与「整流后母线 ≈ 1.6×线电压」的物理不符。**书正文原话「每个 IGBT 必须承受一半的 DC 总线电压」与此一致。**
2. **表 15.2 内部有两套口径，不能当一组数据用。** 七行分成两族：**1.55 族**（400/620、690/1070，= `√2×1.1 = 1.556`）和 **1.20 族**（750/900、1500/1800、3000/3600、3300/4000）。同一张表混了两个标准来源。→ 用时**逐行查，不要插值**。
3. **器件余量 `V_rating/V_dc` 只有 1.57–1.94，中心 ~1.65**——**这比 `61` 的 2.1× 硬开关过冲惯例低 20 %**。原因是这张表的约束是**宇宙射线**（长期统计失效率，与峰值无关），不是**单次过冲**（瞬时击穿）。**P 层做器件选型必须先分清这两条约束，取大者。**

> **★ 本层第一次把「器件电压余量」拆成两个互不相干的物理机制**：
> - 过冲限：`V_rating ≥ 1.6–2.2 × V_dc`（`61` / `64` A2.3），**瞬时、可重复、与拓扑强相关**
> - 宇宙射线限：`V_dc ≤ V_rating / 1.65`（表 15.2/15.3），**长期、统计、只与电压和海拔相关**
> **在风电/光伏/牵引这类「年运行 8000 h、寿命 20 年」的场景，宇宙射线限常常先撞线。**

### I.3 ★ 双馈：只处理 25 % 功率，效率反而高 3 %

p337 是全章经济性最干净的一段：

| 方案 | 变频器额定 | 效率 |
|---|---|---|
| 全变换（图 15.25） | **100 % 发电机额定** | 基准 |
| **双馈 DFIG（图 15.26）** | **25 % 发电机额定** | **+3 %** |
| 直驱全变换（图 15.27 多单元） | 100 %，但拆成 N 个低额定模块 | 与大功率单机相当 |

**为什么「少处理 75 % 功率」能换来 3 % 效率？** 因为损耗发生在**被处理的功率**上，不是总功率上：

```
全变换损耗 ≈ 3 % × 100 % = 3.00 %
双馈损耗   ≈ 3 % × 25 %  = 0.75 %   → 效率 99.25 %
差值 = 2.25 %   （书说 3 %，同量级，差 0.75 个百分点）
```

→ **这是一条通用的「部分功率变换」经济学**：变频器成本 ∝ 额定功率，而**定子直接并网的那部分功率不经过任何开关器件**。
→ **代价**：双馈的转子侧必须四象限运行；且**故障穿越能力差**（定子直连电网，电网跌落时转子过流）。书中未展开故障穿越，**这是本章的结构性缺口**（见 B9）。

### I.4 ★ 表 15.4：压接式不是「全面更好」，失效模式是**反的**

| 参数 | IGBT 模块 | 压接式 IGBT |
|---|---|---|
| 功率密度 | 低 | **高** |
| 可靠性 | 中等 | **高** |
| 成本 | 中等 | **高** |
| **失效模式** | **开路** | **短路** |
| 简易维修 | **+** | − |
| 散热器安装 | **+** | − |
| 缓冲器需求 | − | − |
| **热阻** | **大** | **小** |
| **开关损耗** | **低** | **中等** |
| 导通损耗 | 中等 | 中等 |
| 门级驱动 | 中等 | 中等 |
| 制造商 | 英飞凌/西门康/三菱/ABB/富士 | **西码/ABB** |
| 中等额定电压 | **3.3 / 4.5 / 6.5 kV** | **2.5 / 4.5 kV** |
| 最大额定电流 | 1.5 / 1.2 / 0.75 kA | **2.3 / 2.4 kA** |

**这张表的价值在最后三行与前两行的冲突**：

- 压接式**热阻小**（双面冷却）→ 同样芯片能出更大电流（2.3–2.4 kA vs 1.5 kA）✓
- 但压接式**开关损耗更高**（中等 vs 低）→ **双面冷却省下的热阻，被开关损耗吃了**。这与 `66 · I.5`「MRI 堆叠」、`64 · I.5`「洗碗机 MOSFET 压降低但总损耗高」是同一类陷阱：**只看一个参数会选错**。
- **失效模式相反**：模块**开路**（故障点自行隔离，安全）；压接式**短路**（故障点把母线短死，必须靠外部熔断）。**这是选型的隐藏变量** —— 压接式的「高可靠性」指的是「无键合线、无焊点」，但**失效后果更危险**。
- 电压档：模块覆盖 3.3/4.5/6.5 kV，压接式只到 2.5/4.5 kV → **中压以上（6.5 kV）压接式没有货**，这不完全是技术原因，也是市场原因（西码/ABB 的产品线选择）。

> **可迁移判据**：选压接式之前必须回答「**短路失效怎么隔离**」。没有熔断器/爆炸开关设计，压接式的高可靠性不能兑现。

### I.5 ★ HERIC 与「10 % 负载仍要 95 %」——可再生能源的独有要求

| 拓扑 | 10 % 负载 | 100 % 负载 | 功率上限 | 器件 |
|---|---|---|---|---|
| **HERIC 单相** | **95 %** | **97 %** | 11 kW | 4 + **2 只续流 IGBT** |
| 三相 VSI | — | **97 %** | 30 kW | 6 |
| 商业 NPC（富士） | — | **97–98.5 %** | 1 MW（4×250 kW） | 4 只/模块 |

**为什么 HERIC 要额外加 2 只 IGBT 做续流？** p330：「在**续流期间 IGBT-1~IGBT-4 被关闭以隔离光伏板**」。这是**无变压器拓扑的漏电流问题**：光伏板对地有寄生电容，共模电压高频跳变会驱动漏电流。HERIC 用两只额外的 IGBT 在续流期把 H 桥与电网**断开**，让共模电压不跳变。

→ **这 2 只 IGBT 不承担功率传输，只承担「隔离」。** 它们的价值不在效率表里，在**安规认证**里。**这是本层唯一「器件用来解决 EMI/漏电流而不是解决功率」的案例。**

**「10 % 负载仍 95 %」的可再生能源特殊性**：

| 应用 | 典型负载剖面 | 效率取点 |
|---|---|---|
| 牵引（`62`） | 长期 60–100 % 额定 | 额定点 |
| 医疗 ICD（`65`） | 占空比 `3.9×10⁻¹⁰` | **不算效率，算能量** |
| 家电（`64`） | 间歇、短时满载 | 额定点 + 待机 |
| **光伏 / 风电** | **长期 10–40 % 额定**（辐照/风速分布） | **10 % 点与 100 % 点同权** |

→ **判据：效率必须报「负载剖面加权」，不能报单点。** 光伏逆变器若在 10 % 点掉到 90 %，全年发电量损失远大于额定点从 98 % 提到 99 %。

### I.6 反向阻断 IGBT 的工艺解法：为拓扑改终端

p335 是全章唯一的**器件结构 vs 拓扑**耦合：

```
常规 IGBT：N+ 缓冲层（field stop）+ 对称/非对称终端
反向阻断 IGBT：去掉缓冲层 → 必须重新设计边缘终端
      ↓
问题：划片切割穿过终端区 → 高泄漏电流
      ↓
解法 A：薄片 + 边缘深 P+ 扩散，划片槽置于 P+ 区内 → 600 V 双向
解法 B：背面 V 形切口，P+ 隔离扩散做在 V 形槽表面 → 1200 V 对称
```

- 解法 A 的代价：**长时间高温扩散循环**（深 P+ 需要 `>1000 ℃`、数十小时）
- 解法 B 用**背面 V 形切割**规避长扩散，富士已报 1200 V 对称阻断

→ **这是 `57-chip-design-termination` 的补充章节：常规终端讲「怎么阻断一个方向」，这里讲「阻断两个方向要付什么代价」。**
→ **工程含义**：反向阻断 IGBT 的**芯片面积比同电压非对称型大**（终端占位更宽），这正是 I.1 里「导通损耗降了但开关损耗涨了」的物理来源之一。

### I.7 ★ 波浪能：把一台大机器拆成 N 台小机器

波浪能这一节书里给了十几个项目名，但**只有两个有器件级数据**：

| 项目 | 结构 | 单机 | 台数 | 总额定 | 电气特征 |
|---|---|---|---|---|---|
| **OSPREY（苏格兰 1997）** | 振荡水柱 + 威尔斯涡轮 | 500 kW | **4** | 2 MW | 4 套独立 IGBT 变流器 + 反并联逆变器 → 50 Hz |
| **波龙（丹麦 2003）** | 越堤蓄水池 + 16 台涡轮 | 380 kW | **16** | 6.08 MW | 690 V 变频 → VSC → 50 Hz 690 V → 升压 11/13 kV |

**OSPREY 的四个设计判据（p345，全章最细的控制策略）**：

1. 每台发电机**独立运行**以取各自最高效率
2. 任何给定海况下，**调整发电机转速**以提取最大能量
3. **波浪小时维持低转速以减少损耗**
4. 大浪脉冲下按 **150 % 额定转矩吸收 60 s**

→ **第 4 条是「过载能力」的罕见量化**：`1.5 × 额定转矩持续 60 s`。对照 `56 · SOA`，这是**短时过载而非短路**，落在 SOA 的热限制区而不是电限制区。**做波浪/潮汐变流器选型时，IGBT 的 `I_C` 要按 1.5× 连续 60 s 校核结温，不是按峰值电流。**

**为什么都是「多台小机器」？** 因为波浪能的单点俘获功率与**波浪周期**成正比，装置尺度受波长限制（几十米），单机做不大。→ 这**不是设计选择，是物理约束**。而**多台小机的电气后果与 `65 · I.4` MRI 多桥相移、`66 · I.2` 群马 8 组相移完全同构**：**用 N 台低额定、低频率的变换器，通过相移合成高频率、大功率的等效输出**。这是本层的第三条主线（见 §接口）。

**两个正文没说的结论**：

1. **地热 4.79 是全场最低，比天然气还便宜 27.8 %**（`4.79/6.63 = 0.722`）。但正文对这点的处理是零——只写「太阳能和风能正在变得有竞争力，但仍高于天然气」。**为什么？因为本书的视角是 IGBT 市场，不是能源经济。**
2. **装机量排序与 LEC 排序几乎无关**：地热 39 GW、光伏 139 GW（2013）、风电 282 GW（2012）。**最便宜的装机最少，最贵的装机最多。**

→ **判据（本层的第五根选型轴）：IGBT 市场规模由「可复制性 × 装机增速」决定，不由 LEC 决定。**
   - 地热便宜但**不可复制**（需板块边界/火山带），装机只能缓慢线性增长
   - 光伏贵但**可复制到任何屋顶**，装机指数增长
   - → 器件厂该投的是「增速」，不是「度电成本」
   - **这条判据可迁移到任何「器件-系统」产业链的市场判断**：不要用下游的单位经济性推上游的出货量，要用**下游的可复制性**。

**成本结构上的第二个发现**：光伏/风电/地热/水力的**可变 O&M = 0**（燃料免费），而煤/气/生物质的可变 O&M 占 30–50 %。→ **可再生能源的 LEC 几乎全部由「资金成本」决定**（光伏 11.45/13.00 = **88 %**）。所以**利率比器件价格更能左右光伏的 LEC** —— 这是 I.9 里「逆变器占比恒定」的另一面。

### I.9 ★★ 逆变器占比恒定 8.3 %：器件降本在系统成本里被稀释

| 项目 | 1998 | 2013 | 倍数 |
|---|---|---|---|
| 光伏系统 | 12 美元/W | 3 美元/W | **4.0×** |
| 逆变器 | 1 欧元/W | 0.25 欧元/W | **4.0×** |
| **逆变器占比** | **8.33 %** | **8.33 %** | **不变** |

**两组数字的降幅完全一致（都是 4.0×）**，这不是巧合，是**同一根学习曲线**。p349 原话「逆变器的成本仍然**低于太阳能光伏总成本的 10 %**」。

→ **残酷但真实的推论**：**IGBT 降价 50 %，光伏系统的 LEC 只降 4 %。** 器件厂在光伏链里的议价权**天然弱**，因为它的成本占比只有 8 %，且降幅与下游同步。
→ **对照 `63 · 减裸片面积降本`**：`63` 讲的是「器件内部怎么降本」，这里讲的是「器件降本在系统里被稀释」。**两件事必须分开看，否则会高估器件降本的战略价值。**
→ **例外**：在**小功率分布式**（户用 5 kW）场景，逆变器占比高于 8.3 %（因为支架/线缆/许可的固定成本被摊薄得更慢）。书中给了「住宅 5 kW / 商用 100 kW」的分界，但**没给这两个点的逆变器占比**。→ 缺口（B7）。

### I.10 波浪/潮汐/地热的「低密度」事实

| 能源 | 全球可开发量 | 已装机 | 器件级数据 |
|---|---|---|---|
| 波浪 | **2 TW** | 十几个示范项目，最大 2 MW | 仅 OSPREY / 波龙 |
| 潮汐 | 未给 | Rance 240 MW、始华湖 **254 MW**、SeaGen 1.4 MW | 无（只给 690 V VSC） |
| 地热 | **39 GW 已装**（24 国） | 美国 3 GW / 菲律宾 1.9 GW / 印尼 1.2 GW | 2 kHz 载波、480 V/60 Hz、双极异步机 |
| 水力 | 3427 TWh（2010，占全球 **16 %**） | 三峡 22.5 GW、伊泰普 14 GW、古里 10.2 GW | HVDC 用 8 kV/2 kA 晶闸管 → VSC |

**潮汐的唯一优势是「可预测」**：p347「与风力或太阳能发电相比，潮汐发电的优势是具有**功率的稳定性**，这是由月球绕地球轨道的规律一致性造成的」。
→ **对 IGBT 的意义**：可预测 = 不需要大容量储能，变流器可以按**基荷**设计（长期满载），效率取点在额定点而非 10 % 点。**这与 I.5 的光伏/风电正好相反。**
→ **判据补充：负载剖面的「可预测性」决定变流器的设计取点。** 光伏/风电 → 宽负载；潮汐/地热/水电 → 窄负载。

### A1.3 海上风电五方案对照（p340，欧洲实装）

| 方案 | 拓扑 | 电压 | 功率 |

**并网要求**（可作验收清单）：THD **<3 %**、频率偏移 **<5 %**、功率因数 **>0.9**。

## S · 步骤（可再生能源 IGBT 选型 7 步）

```
① 定源型：DC（光伏/燃料电池）还是变频 AC（风/浪/潮）？
   → DC 省掉整流桥；变频 AC 必须背靠背或双馈

② 定母线电压：三相全桥 V_dc ≈ 1.35 × V_line，再乘 1.15 余量 → ≈ 1.55 × V_line
   单相 230 V → 360 V（HERIC 实测口径）

③ 算两条电压约束，取大者：
   a) 宇宙射线限：V_rating ≥ 1.65 × V_dc          （表 15.2/15.3）
   b) 关断过冲限：V_rating ≥ 2.0–2.2 × V_dc        （`61` / `64` A2.3）
   → 长寿命、高利用率场景（风/光/牵引）常常 a) 先撞线

④ 定拓扑级数：
   V_dc ≤ 1 kV → 2 级；V_dc > 1 kV → 3 级 NPC 或 NPC 派生
   3 级时器件按「半母线」选，但注意 2×V_dc/V_line ≈ 1.635

⑤ 定效率取点：按负载剖面加权，不是单点
   光伏/风电：10 % 与 100 % 同权（HERIC：95 % / 97 %）
   潮汐/地热/水电：单点（长期满载）

⑥ 决定是否上反向阻断 / CSI：
   ΔP_cond = ?  ΔP_sw = ?  净差 = ?  器件数省几个？
   → 只报净差不做决策；BOM 与可靠性才是决策变量

⑦ 封装形式：模块（开路失效、可现场更换）vs 压接式（短路失效、需熔断器）
   → 双面冷却的红利会被更高的开关损耗抵掉一部分
```

`7.20+0.41+0.00+0.20 = 7.81`，表列 `8.45`。回原页（p349）确认四列数字无误。→ **只能引用分项，不能引用 8.45 这个总数**；若必须用总数，须标注「与分项差 0.64，原因不明」。

**B2｜表 15.2 内部混了两套口径**
`1.55 族`（= `√2×1.1`）与 `1.20 族`（整 1.2），同一张表两个来源。→ **逐行查，不插值、不外推。** 外推请用 `V_dc = 1.35 × V_line × 1.15`。

**B3｜表 15.3 的 `V_dc` 是单管承压，不是母线电压**
书正文说「每个 IGBT 必须承受一半的 DC 总线电压」，表头只写「标称直流母线电压」。**表头与正文口径不一致**。本层按 `2×V_dc/V_line = 1.635` 七行闭合判定为「单管承压」。→ **引用时必须写明「V_dc 指单管承压（半母线）」，否则读者会算错一倍。**

**B4｜表 15.4「缓冲器需求」两列都是「−」**
与「压接式在高 di/dt 下需要 RC 缓冲」的通用认识冲突。→ 该行**存疑，不作判据**。其余行与正文「压接式热阻小、电流大、可靠性高」一致，可用。

**B5｜「双馈获得 3 % 效率提升」没有基准**
未说明是「相对全变换的绝对百分点」还是「相对自身损耗的百分比」。本层按「绝对百分点」复算得 2.25，差 0.75。→ **只能作方向性引用。**

**B6｜p325「风力发电每年增长 30 %，在 2012 年有超过 280 兆瓦的发电量」——单位错**
同页后文（p336）明确「2012 年底已达到 **282 GW**」。→ **`280 兆瓦` 应为 `280 GW`**，`兆瓦` 是译/排错误。

**B7｜逆变器占比 8.33 % 是「大系统」口径**
p349 的 `12→3 美元/W` 与 `1→0.25 欧元/W` 是整体市场均价。**户用 5 kW 系统的逆变器占比高于 8.33 %**（固定软成本摊薄更慢），书未给该点数值。→ **不能用 8.33 % 推户用项目。**

**B8｜光伏效率 12–18 % 是 2013 年口径**
书给的「平均效率 12–18 %」「理论极限 33.7 %（Shockley-Queisser）」在 PERC/TOPCon/HJT 之后已被大幅超越。→ **只能作历史参照，不能作当前选型依据。**

**B9｜双馈的故障穿越（LVRT）完全未涉及**
这是 DFIG 在现行并网导则下的**核心约束**（定子直连，电网跌落时转子过流需 Crowbar 保护）。本章只讲稳态效率，**不能据此判定双馈优于全变换**。→ 实际选型必须补 LVRT 章节。

**B10｜「海上风电交越点 100 km」是 2015 年前口径**
p338 给「典型的交越点为 **100 km**」（AC vs DC 传输）。随柔直（VSC-HVDC）成本下降，该点已显著后移。→ 只能作量级参考。

**B11｜所有图/曲线不可读数**
图 15.23（风电装机）、15.48（光伏价格）、15.49（光伏 LEC）、15.51（风电成本）均为趋势图，**只有正文给出的点值可用**（1998 年 12 美元/W、2013 年 3 美元/W 等）。

**B12｜波浪/潮汐的项目数据是「已建/已沉没」混合，不能当装机量**
p344 明说 OceanLinx 的原安装「在极度汹涌的海洋中**沉没了**」。→ 该节只能作**拓扑与器件数量**的参考，不能作产业规模依据。
