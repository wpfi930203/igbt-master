## I · 骨架（本模块的 8 个逻辑块）

### I.0 ★ 全书唯一「市场选择胜过技术指标」的完整案例

这不是一段历史轶事，是**一条可迁移的技术路线判据**：

| 环节 | MCT（落选方） | IGBT（胜出方） |
|---|---|---|
| 1986 美国联合小组（DoD + EPRI）资助 | **独家被选中** | 未获资助 |
| 被选中的理由 | 锁存四层结构 → **低通态压降** | — |
| 致命短板 | **缺 IGBT 的正/反向 SOA**；GTO 类结构需庞大缓冲器；无晶体管式电流控制 | 正/反向 SOA 完整、可电流控制 |
| 制造可行性 | **「制造设备的技术困难」→ 商业化失败** | 与功率 MOSFET **工艺兼容** |
| 资金 | 数千万美元（政府） | 零政府资助 |
| 结局 | 商业化失败 | 消费/工业市场**自举成功** → 国防 2003/2004 年反过来采纳 |

**判据（本模块最值钱的一句话）**：
> 选器件不能只看「额定点上的通态压降」，要看 **① 安全边界（SOA）是否覆盖故障工况**、**② 工艺是否能复用现有产线**。
> MCT 的通态压降更低是事实，但它在**短路/反偏这两个出事的时候没有边界**，且**造不出来**。这两条任何一条都足以否掉一个更"先进"的器件。

**跨源呼应**：`56-soa-latchup`（SOA 的物理机理）与 `62-app-industry`（GTO→IGBT 的替换判据）在本条上合成一条线：**SOA 不是参数表里的一行，是器件能不能进工程的准入证。**

### I.1 PEBB：本层唯一给出「控制时域分层」的地方

| 层级 | 时域 | 责任 |
|---|---|---|
| 门驱动器 | **< 10 μs** | 开关瞬态、保护（DESAT/软关断） |
| 电路拓扑控制器 | **10 μs – 1 ms** | PWM 调制、电流环 |
| 负载控制器 | **1 ms – 1 s** | 转矩/速度环 |
| 系统控制器 | **> 1 s** | 能量管理、任务调度 |

- **单元粒度**：`<100 kW` = 一整台三相逆变器；`100 kW – 1 MW` = **单相**
- **PEBB 的输出是「软件」**（p300 原话）——这不是修辞，是**把差异从硬件挪到配置**的商业模式
- 三代演进：PEBB-1 五端口（2 入 + 3 出）→ PEBB-2 加封装级 EMI/互连/传感器约束 → PEBB-3 双面冷却 + 分布式控制
- 商用落地：ABB PowerPak3 **600 kV·A** 水冷；PM1000 **0.5 MW**

**工程含义**：`门驱动 < 10 μs` 这个数把「保护动作必须在开关周期内完成」写成了架构约束——**保护不属控制层，属驱动层**。这与 `main` 层「DESAT 消隐 + 软关断」的时限讨论同源。

### I.2 ★★ 表 14.1「效率最高的拓扑输了」——本层第四根选型轴：噪声

| 拓扑 | 总重/kg | 磁性物重/kg | 体积/m³ | 效率 | 判决 |
|---|---|---|---|---|---|
| **多电平逆变器**（二极管钳位） | **3850** | 3060 | **7.6** | **97.6 %** | ✅ 选它 |
| 循环变流器 | 9820 | 2405 | 11.13 | **98.7 %** | ❌ 淘汰 |
| 串联低压（9 级） | 13700 | 6311 | **21.4** | **99.3 %** | ❌ 淘汰 |

**为什么效率最高的两个都输了**：

| 拓扑 | 淘汰理由（原文） | 量化 |
|---|---|---|
| 循环变流器 | 「功率因数低 + 严重的转矩波动 → **难以实现安静的操作**」 | 转矩波动 **100 % 转速时 1 % → 50 % 转速时 25 %** |
| 串联低压 | 「为电动机电流创建最佳波形，但具有**很大的重量和尺寸**」 | 21.4 m³ vs 7.6 m³ = **2.82 倍** |

多电平自身的代价：转矩波动 **全速 0.42 % → 50 % 转速时 2 %**（仍是循环变流器的 1/12.5）。

**这条轴的独立性**：`62` 给的是「频率/功率等级」轴，`64` 给的是「成本阶梯」轴，`65` 给的是「精度」轴——**本模块补上第四根：声学噪声**。海军的权重里，静音 > 效率（98.7 % 输给 97.6 %）、体积效率 > 波形质量。

**IGCT vs IGBT 同页判决**：IGCT 每周期 **>20 J** 开关损耗 vs IGBT **<10 J**；IGCT 需**大内置栅驱 + 缓冲器**，IGBT **小栅驱、无缓冲**。→ 同 I.0 的判据：**外围电路复杂度是权重很高的否决项。**

### I.3 ★★ 可靠性定量：式 14.2–14.7 + 表 14.4–14.7

**这是本层唯一的完整失效模型。** 结构 = 浴盆曲线（早期失效筛选掉 → 恒定失效率段定义为寿命 → 磨损段）。

**主要失效模式（p320）**：① 管芯绝缘击穿/漏电 ② 管芯上焊线失效（热循环 → 铝焊丝剥离 → **串联电阻↑ + 电流均匀性恶化 → `V_CE` 增大**）③ 芯片焊料失效（负载循环 → **热阻↑ → 结温↑ → 失效**）

**失效率模型（式 14.2）**：
```
λ_IGBT = λ_b·IGBT · π_Tj · π_A · π_S · π_E      [失效数 / 10⁶ h]
```
| 因子 | 表达式 | 取值 |
|---|---|---|
| `λ_b·IGBT` | — | **0.133**（中等功率 IGBT 模块） |
| `π_Tj` | `exp[−2114·(1/(T_j+273) − 1/298)]`（式 14.3） | `T_j` 单位 ℃；**注意内嵌了 298 K 基准** |
| `π_A` | — | **0.7**（开关应用） |
| `π_S` | `4.5×10³ · exp(3.1·V_DC/V_Rated)`（式 14.4） | **`V_DC/V_Rated` 越高越差** |
| `π_E` | — | **13**（机载/空中） |

**寿命模型（式 14.5 / 14.6）**：
```
N_fWB = k_Tj · (ΔT_j)^k_ΔTj · exp( k_Tj' / (T_j + 273) )     键合线
N_fSJ = k_Tc · (ΔT_c)^k_ΔTc · exp( k_Tc' / (T_c + 273) )     焊点
其中 k_Tj = 9830、k_ΔTj = −5、k_Tj' = 1124；k_Tc = 9830、k_ΔTc = −5、k_Tc' = 337
```
→ **`k_ΔT = −5` 意味着 ΔT 减半 → 循环寿命 ×32**。这是全书对「降 ΔTj 的价值」给出的最硬的一个指数。

**四组对照（IFT 表 14.4–14.7，EUPEC FS450R12KE3 六管模块，更多电动飞机场景）**：

| 对照 | 变量 | λ/10⁻⁶h | MTTF/h | 寿命/h |
|---|---|---|---|---|
| **表 14.4** 调制方式 | D-PWM | 1.45 | 690,000 | **458,000** |
| | S-PWM（连续正弦） | **2.12** | 472,000 | **12,000** |
| **表 14.5** 开关频率 | 20 kHz | 1.45 | 690,000 | **458,000** |
| | 30 kHz | **1.81** | 552,000 | **37,000** |
| **表 14.6** 器件数 | 单管 | 1.45 | 690,000 | 458,000 |
| | **双管并联** | **2.52** | **397,000** | **10,323,000** |

**读法（三种都反直觉，必须逐条讲清）**：
1. **D-PWM → S-PWM：寿命从 458,000 h 崩到 12,000 h（−97.4 %）**，失效率只涨 46 %。→ **失效率涨一点点，寿命可能塌一个数量级** —— 因为寿命是磨损段的积分，对它最敏感的是 `ΔT_j`（式 14.5 的 −5 次幂）。
2. **20 → 30 kHz：寿命 458,000 → 37,000 h（−91.9 %）**，同样是失效率涨 25 %、寿命塌 12 倍。→ **PWM 频率每抬 50 %，磨损寿命掉一个数量级**。这就是「为什么电机驱动不敢随便提频」的定量答案。
3. **★ 双管并联：λ 更差（1.45→2.52，+74 %）、MTTF 更差（690k→397k，÷1.74），但寿命好 22.5 倍（458k→10,323k h）**。
   → **这是全书唯一把「降额 vs 器件数」这对矛盾量化到同一个表里的地方**：并联让**每颗管子的 ΔTj 减半**（式 14.5 的 −5 次幂 → ×32 上限），代价是**系统级失效率按器件数线性叠加**。
   → **判据**：**「可维修、可更换」的系统选并联**（磨损寿命才是瓶颈）；**「不可维修、失效率决定任务成败」的系统不要并联**（MTTF 才是瓶颈）。潜艇/机载属于后者，消费类属于前者。

**表 14.7 系统级（含无源件）**：

| 部件 | λ/10⁻⁶h | MTTF/h | 寿命/h |
|---|---|---|---|
| IGBT 模块 | 1.45 | 690,000 | 458,000 |
| **电容**（8 个薄膜） | **1.07** | 937,000 | **125,000** |
| 电感（三相） | 0.012 | 83,333,000 | 2,153,000 |
| **功率级合计** | **2.532** | **395,000** | **125,000** |

→ **结论**：**「IGBT 和电容器是限制可靠性的主要部件」**。电容的 λ 是 IGBT 的 74 %，**寿命却只有 IGBT 的 27 %** —— 电容的 MTTF 好看（937k > 690k），但**磨损寿命最差**。**又一个「MTTF 与寿命指向相反」的实例，与表 14.6 同型。**

### I.4 固态断路器的「时间尺度阶梯」

| 器件 | 故障后断流时间 | 相对于 IGBT |
|---|---|---|
| IGBT 固态断路器 | **< 20 μs** | 1× |
| IGBT 双功能开关 DFS（50 A） | 40 μs（截止） | 2× |
| SABT 设计指标 | **< 250 μs** 响应「降到 90 % 标称」 | 12.5× |
| 晶闸管（等过零，60 Hz） | **最长 8 ms** | **400×** |
| IGCT | 开关慢 IGBT **6 倍**，但仍比机械断路器快 **900 倍** | — |

- **SABT 必须「先断后合」**（避免两路电源短路）；70 % 标称值时判为故障
- DFS 实测：`V_CE = 1.5 V`（**已含反向阻断串联二极管**）；50 A 时损耗 **80 W**；「IGBT 的导通压降是晶闸管的**两倍**，但切换时间仅为 SCR 版的 **10 %**」
- **IGCT vs IGBT 的分工判决**（p307）：IGCT 用于**上游中等电流**，IGBT 用于**下游小电流** —— 因为 IGCT「不能制约故障时的负载电流」
- 直流断路器实测额定：**4.5 kV / 900 A** 模块，两个 IGBT 串联 + MOV 钳位

**与 `62 · I.8` 的区别**：那里比的是**单次开关**（晶闸管 10 ms vs IGBT 0.2 μs = 50,000×），这里比的是**故障后等过零**（8 ms vs 20 μs = 400×）。**同一个物理，两种口径，报数时必须说清是哪一个。**

### I.5 ★ 潜艇静音驱动：级联 H 桥的「电压等级分工」

- 单相绕组 = **三级 H 桥串联**：**两级 1400 V + 一级 700 V = 3500 V**，输出 **2400 V 线对中性线**
- **高压级跑准方波（低频）｜低压级跑 PWM（高频）** —— 原文理由：「PWM 级 IGBT 需要的**阻断电压低**」
- 效率：**满载 94 %，10 % 负载 76.4 %**
- 前级：三相移相变压器 → 同步整流器（IGBT 以 **10 kHz** PWM 工作，兼做谐波抑制 + 直流电压调节）

**同构证据（本层第三次）**：`65 · I.4` MRI 堆叠三桥 = **800 V @ 31.25 kHz + 400 V @ 62.5 kHz**。两条完全独立的应用，同一解法：**把开关频率压在低压级、把电压应力压给高压级**。

**可靠性实测（本层唯一在役长周期数据）**：英国皇家海军 2000 年，**4 个模块 / >110,000 电气周期 / 相当于 25 年 × 5 艘潜艇全部开关次数 / 零故障**；热循环 **50–65 ℃ 查键合线、75 ℃ 查焊点**（对应 `main` 层 6.7 节的分温区判据）。

### I.6 串联均压（本层唯一「多管串联」的工程解法）

**式 14.1**：
```
R_B = (0.9·n·V_CES − V_S) / [ ΔI_CES · (n − 1) ]
```
- `V_CES` = 每管耐压（如 1.2 kV）；`V_S` = 电源电压（8 kV）；`ΔI_CES` = **各管漏电流之差**（如 10 mA）；`n` = 串联数（10）
- 分子 `0.9·n·V_CES` 的含义：**每管只用到耐压的 90 %**（降额 10 %）
- **动态均压不靠电阻，靠驱动同步**：EXB840 光隔离驱动，**5 ns 内同步 10 只 IGBT 的栅驱** → **动态均压是「驱动时序问题」，不是「无源网络问题」**

**两个应用场景的差异**（同一公式）：
| 场景 | 母线 | 器件 | 关键约束 |
|---|---|---|---|
| 等离子镜（p318） | **8 kV**、30 A、500 μs @ 10 Hz | 1996 商用 **1.6 kV**，n ≥ 10 | 「1996 年可用的商业 IGBT 额定值仅为 1.6 kV」 |
| 磁控管雷达电源（p316） | **11 kV**、峰值 1200 A、上升 150 ns | n = 10，平均 150 W | 「闸流管的电流上升率更高，但**抖动大得多**；上升时间差异不影响发射器性能」 |

→ **同一条式，两种矛盾**：等离子镜的矛盾是**静态漏电流不均**（所以要 `R_B`），磁控管的矛盾是**动态开关不同步**（所以要 5 ns 同步驱动）。**必须先分清是静态还是动态不均，再决定加电阻还是加驱动。**

## A2 · 本地复算

### A2.1 式 14.1 代入原书数据 → **书给的「10 kΩ」算不出来**

代入 `n=10, V_CES=1.2 kV, V_S=8 kV, ΔI_CES=10 mA`：
```
R_B = (0.9×10×1.2e3 − 8e3) / (10e-3 × 9)
    = (10800 − 8000) / 0.09
    = 2800 / 0.09 = 31,111 Ω ≈ 31 kΩ
```
**书说「10 kΩ 左右」，实算 31 kΩ，差 3.1 倍。**

反推：要得到 10 kΩ，需要 `ΔI_CES ≈ 31 mA`，或 `V_CES = 1.6 kV`（`(0.9×10×1.6e3−8e3)/0.09 = 71 kΩ`，更远），或 `n = 7`（**负值 −7.3 kΩ，不成立**）。

**同页矛盾（更强的证据）**：p318 原文说「基于 **1996 年可用的商业 IGBT 额定值仅为 1.6 kV**，至少需要 10 个 IGBT 串联产生所需的 8 kV 脉冲」——但式 14.1 的算例代入的是 **1.2 kV**。若用 1.6 kV，`0.9×n×1.6 kV ≥ 8 kV` 只需 **n ≥ 6**（`8/(0.9×1.6)=5.56`）；若用 1.2 kV，则需 **n ≥ 8**（`8/(0.9×1.2)=7.41`）。**「10 个」对两种耐压都不是最小值，说明原文没做降额计算，或 n=10 是按别的约束（如余量、可用性）定的。**

→ **结论：式 14.1 的形式可信（分子 `0.9nV_CES − V_S` 物理意义清楚，分母 `ΔI·(n−1)` 也对），但同一段里 `V_CES` 取 1.2 还是 1.6 kV、算出的 10 kΩ 与 31 kΩ 不自洽。→ 引用时只抄公式，不抄算例；算例必须自己重算。**

### A2.2 `π_Tj` 的基准被写进式子里 → **不能按"相对 T_j"读**

式 14.3 撕开看是 `exp[−2114·(1/(T_j+273) − 1/298)]`——`298` 即 **25 ℃ 基准**，藏在式子内部。

| `T_j` / ℃ | 25 | 50 | 75 | 100 | 125 | 150 |
|---|---|---|---|---|---|---|
| `π_Tj` | **1.000** | 0.690 | 0.480 | 0.335 | 0.235 | 0.168 |

→ **`T_j` 25 → 125 ℃，`π_Tj` 降到 0.235（÷4.26）**。反过来 `T_j` 比 25 ℃ 低时 `π_Tj > 1`。
**纪律**：`λ_IGBT` 的输出单位是「每 10⁶ 小时的失效数」，**绝对值和 25 ℃ 基准绑定**；跨文献比 λ 时必须核对对方用的是不是同一基准温度（Arrhenius 型公式最常见的踩坑点，见 `34 §12.2` 量纲纪律的同类）。

### A2.3 `π_S` 的量级不成立（式 14.4 有问题）

按式 14.4 字面 `π_S = 4.5×10³ · exp(3.1·V_DC/V_Rated)` 代入：

| `V_DC/V_Rated` | 0.5 | 0.667 | 0.8 | 1.0 |
|---|---|---|---|---|
| `exp(3.1·ratio)` | 4.71 | 7.91 | 11.9 | 22.2 |
| `π_S` | **21,200** | 35,600 | 53,600 | **99,900** |

**两个硬矛盾**：
1. **量级不对**：`λ_b = 0.133`，若 `π_S ≈ 2×10⁴`（连 `π_Tj·π_A·π_E` 一起算），`λ` 会是 10³–10⁵ /10⁶h；而表 14.4–14.7 的 `λ` 全部落在 **1.45–2.53**。**差 3–5 个数量级。**
2. **方向对但杠杆荒谬**：`ratio` 从 0.5 到 1.0（电压应力翻倍），`π_S` 只涨 **4.7 倍**；而 `ratio` 从 1.0 降到 0.5（降额一倍）应带来显著可靠性收益，这里只换来 4.7 倍。对比 MIL-HDBK-217 同型模型的典型电压应力因子（`ratio` 0.5→1.0 往往跨 1–2 个数量级），**这个杠杆偏软**。

**可能的三处错**：
- `4.5×10³` 应为 `4.5×10⁻³`（→ `π_S` 落在 0.009–0.1，与 `λ_b` 同量级，**最可能**）
- 指数符号应为负（`exp(−3.1·ratio)`，但这样 `ratio` 越大越好，物理反了）
- 括号内应为 `(1 − V_DC/V_Rated)`

→ **判定：式 14.4 不可定量。只保留定性方向「电压应力比例越高、失效率越高」，不得代入求 `λ`。** 登记见 B2。

### A2.4 表 14.4–14.7 的内部一致性（三向验证）

**① MTTF ≡ 1/λ 严格成立**（这证明 λ 与 MTTF 同一口径）：

| λ | `1/λ×10⁶` | 书给 MTTF | 相对误差 |
|---|---|---|---|
| 1.45 | 689,655 | 690,000 | 0.05 % |
| 2.12 | 471,698 | 472,000 | 0.06 % |
| 1.81 | 552,486 | 552,000 | 0.09 % |
| 2.52 | 396,825 | 397,000 | 0.04 % |
| 2.532（表 14.7 合计） | 394,945 | 395,000 | 0.01 % |
| 1.07（电容） | 934,579 | 937,000 | 0.26 % |
| 0.012（电感） | 83,333,333 | 83,333,000 | 0.0004 % |

→ **全部闭合到 0.3 % 以内。λ 与 MTTF 是同一份数据的两种写法，不存在「不同置信度口径」。**

**② 表 14.7 的加法闭合**：`1.07 + 0.012 + 1.45 = 2.532` ✓（与书给合计一致，**说明三类部件的失效率是直接相加**，即串联可靠性模型）

**③ 但「寿命/h」不闭合**：
```
功率级寿命 125,000 h = 电容寿命 125,000 h（取最短板 ✓）
但 IGBT 寿命 458,000 h > 功率级 125,000 h → 一致
电感寿命 2,153,000 h → 一致
```
→ 表 14.7 的寿命列是**串联系统取最小**，逻辑自洽 ✓。

**④ 表 14.4/14.5/14.6 的寿命列则不自洽**：

| 表 | 单管基准寿命 | 另一列寿命 | 比值 | 问题 |
|---|---|---|---|---|
| 14.4 | 458,000（D-PWM） | 12,000（S-PWM） | 2.6 % | 只给结果不给 ΔTj，**无法复算** |
| 14.5 | 458,000（20 kHz） | 37,000（30 kHz） | 8.1 % | 同上 |
| 14.6 | 458,000（单管） | **10,323,000**（双管） | **2253 %** | 同上 |

→ **三张表的「寿命/h」列全部无法用式 14.5/14.6 复算**，因为书**没给对应的 `ΔT_j`**。→ 只能读**相对趋势**，不读绝对值（登记 B3）。

**⑤ 表 14.6 的「双管 λ = 2.52」对不上「2×1.45 = 2.90」**：
- 若按串联模型：两管 λ 相加 = 2.90
- 书给 2.52 → **意味着并联后单管的 λ 从 1.45 降到 1.26**（`λ_单/管 = 2.52/2`）
- `1.26/1.45 = 0.869` → `π_Tj` 若按式 14.3 折算，等价于结温从某个 `T` 下降到 `T'` 使 `exp` 项降至 0.869

**复算**：`π_Tj` 比 0.869 → `−2114(1/(T') − 1/(T)) = ln0.869 = −0.1404` → 若 `T = 125 ℃`（`1/398`），解得 `1/(T'+273) = 1/398 + 0.1404/2114 = 0.0025126 + 0.0000664 = 0.002579` → `T' = 114.8 ℃`。
→ **即「并联把结温从 125 ℃ 降到 114.8 ℃，降 10.2 K」，与 `π_Tj` 的 0.869 完全对上。** → **表 14.6 内部自洽，且这个 10.2 K 的降温幅度是本章唯一可反推出的热设计指标。**（**前提：假设 `λ_b`、`π_A`、`π_S`、`π_E` 都不变，只是 `T_j` 变——这与「并联降应力」的物理一致，可信。**）

### A2.5 跨模块校验：`k_ΔT = −5` 的杠杆

式 14.5 的 `(ΔT_j)^(−5)`：

| `ΔT_j` 变化 | `N_f` 倍数 |
|---|---|
| 减半（×0.5） | **×32** |
| −20 %（×0.8） | **×3.05** |
| +10 %（×1.1） | **×0.62**（寿命 −38 %） |

→ **与 `main` 层「降 ΔTj 是封装可靠性第一杠杆」的定性说法，这里是定量的**：`ΔT_j` 每降 10 %，循环寿命涨 1.69 倍。
→ **同时与 `65 · A2.4` 形成对照**：那里 `J_C` 必须连占空比一起报，这里 `ΔT_j` 必须连「测试温区」一起报（键合线 50–65 ℃、焊点 75 ℃ 是两个不同温区）。

### A2.6 ICD 式占空比复核（与 `65 · A2.4` 对齐，纳入本模块作为跨章一致性检查）
潜艇/机载/脉冲负载的「峰值电流能力」都不能直接当连续电流用：
- ABB 模块：**5 μs 打 12 kA** vs 连续 **2000 A** = **6×**
- 若按 12 发/分、每发 9 ms 计（轨道炮）：占空比 `1.8×10⁻³`，等效连续 = 峰值 × 该占空比
→ **纪律：报「脉冲电流能力」必须同时报脉宽与重复频率**（与 `65 · B6` 同一条）

## E · 触发场景（什么时候翻这一篇）

1. 用户问「**器件选型该看什么指标**」「为什么某个更先进的器件没成」→ **I.0**（SOA + 工艺可行性两条否决线）
2. 用户问「**并联能不能提高可靠性**」→ **I.3 表 14.6**（λ 更差、MTTF 更差、寿命好 22.5 倍 → 先问「瓶颈是失效率还是磨损寿命」）
3. 用户问「**PWM 频率能不能提**」「**调制方式怎么选**」→ **I.3 表 14.4/14.5**（寿命对频率和调制方式的敏感度是数量级级的）
4. 用户做**多管串联**的均压设计 → **I.6 + A2.1**（先分静态/动态；静态用 `R_B`、动态用 ns 级同步驱动；**不要抄书里的 10 kΩ 算例**）
5. 用户问「**为什么低负载效率低**」→ **I.5**（潜艇级联驱动 10 % 负载 76.4 % vs 满载 94 %，差 17.6 个点，与 `61` 的轻载损耗结构同源）
6. 用户问「**电机驱动的噪声从哪来**」→ **I.2**（转矩波动是拓扑属性：循环变流器 25 % @50 % 转速 vs 多电平 2 %）
7. 需要**系统级 FMEA/可靠性预算** → **I.3 表 14.7**（含无源件才是真系统；薄膜电容寿命最短板）
8. 需要**串联器件的驱动时序指标** → **I.6**（5 ns 同步是硬指标，不是「尽量快」）

## S · 步骤（可直接执行的作业流）

**S1｜器件选型否决清单（用 I.0 的判据）**
① 写清失效工况（短路电流、反偏电压、di/dt/du/dt）→ ② 查 SOA 图是否覆盖（RBSOA/SCSOA）→ ③ 查工艺是否与现有产线兼容 → ④ 两条任一不过，**无论通态压降多低都否决** → ⑤ 再比通态/开关损耗。

**S2｜并联决策（用 I.3 表 14.6）**
① 定义系统瓶颈：任务期内「能接受几次失效」还是「必须跑到 N 年」→ ② 若瓶颈是**失效率/MTTF** → **不并联**（λ 按 2.5 而不是 1.45 计）→ ③ 若瓶颈是**磨损寿命** → 并联，但必须实测 `ΔT_j` 降到多少（参考 A2.4 ④ 的反推法：`π_Tj` 比 → 温降 K 数）→ ④ 报数时必须**同时给 λ、MTTF、寿命三个**，单给一个都是误导。

**S3｜可靠性预算（用 I.3 表 14.7）**
① 列出所有部件（IGBT / 电容 / 电感 / 驱动 / 连接器）→ ② 各自 λ 相加（串联模型）→ ③ `MTTF = 10⁶/λ_total` → ④ **寿命取最小值，不取 MTTF** → ⑤ 找最短板（本例是薄膜电容，125,000 h）→ ⑥ 改设计优先改最短板。

**S4｜串联均压设计（用 I.6 + A2.1）**
① 定 `n`：`n ≥ V_S/(0.9·V_CES)` **并留余量**（书用 n=10 而算得只需 7.4 → 余量 35 % 是工程惯例）→ ② 静态均压电阻：`R_B = (0.9nV_CES − V_S)/[ΔI_CES·(n−1)]`，**`ΔI_CES` 必须取实测漏电流差**（书用 10 mA 是示意）→ ③ 动态：驱动同步 ≤ 5 ns（EXB840 级）→ ④ 验证：通断瞬间示波器看各管 `V_CE` 是否均分。

**S5｜脉冲负载折算（用 I.7 + A2.6）**
① 峰值电流 / 脉宽 / 重复频率三件套 → ② 算占空比 → ③ 等效连续 = 峰值 × 占空比（热等效需按瞬态热阻曲线修正，**不是简单线性**）→ ④ 与连续额定比：ABB 案例是 6× → ⑤ 模块选型按**峰值 + 热积累**双约束。

## B · 边界（诚实登记，11 条）

**B1｜式 14.1 的算例自相矛盾（31 kΩ vs 书的「10 kΩ」）**
见 A2.1。同页 `V_CES` 在正文里是 **1.2 kV**，而上页说商用器件是 **1.6 kV**；且 n=10 对两种耐压都不是最小值。→ **公式可用，算例不可抄。**

**B2｜式 14.4 `π_S` 的量级差 3–5 个数量级（最严重的一项）**
按字面 `4.5×10³·exp(3.1·ratio)` 算，`ratio=1.0` 时 `π_S = 99,900`，乘 `λ_b = 0.133` 后 `λ` 落在 10³–10⁵，**而表 14.4–14.7 的实测 λ 是 1.45–2.53**。
→ 三处可能错：① `4.5×10³` 应为 `4.5×10⁻³`（最可能）② 指数符号 ③ 括号应为 `(1 − ratio)`。
→ **结论：只保留定性方向「电压应力比例越高越差」，不得代入求 `λ`。**

**B3｜表 14.4/14.5/14.6 的「寿命/h」列无法复算**
书未给对应 `ΔT_j`，式 14.5/14.6 的 `k_ΔT = −5` 无法代入。→ 只读相对趋势（S-PWM 崩 97 %、30 kHz 崩 92 %、并联涨 22.5×），**不读绝对值**。

**B4｜表 14.4/14.5/14.6 的「MTTF」与「寿命」定义关系不明**
`1/λ` 与 MTTF 严格闭合（A2.4 ①），但「寿命/h」与 MTTF 的比值在四组里从 0.66 变到 26.0。**书未定义「寿命」是「到磨损失效的时间」还是「某分位数」**。→ 只能在同表内横向比，不能跨表比。

**B5｜「MCT 缺 SOA」无定量**
原文只说「MCT 缺乏 IGBT 在正向和反向安全工作区中可用的特征」，**未给 RBSOA 曲线、未给短路耐受时间**。→ 「为什么选 IGBT」的第一因只能定性陈述。

**B6｜`π_E = 13` 仅适用机载**
原文「如对于空中、在飞机上其为 13」。**地面/舰载的 `π_E` 书未给。** → 不得外推。

**B7｜`π_A = 0.7`（开关应用）只有一个取值**
未给「线性应用」「脉冲应用」的对应值。而本章 14.8 通篇讲脉冲电源，**却没有给脉冲应用的 `π_A`** —— 这是本章的结构性缺口。

**B8｜表 14.1 的原始语境是「超导电机」方案**
美国超导公司（AMSC）评估的三个拓扑是为**超导电动机/发电机**做的，`98.7 %/99.3 %` 的效率数字含超导机器的高效率红利，**不能直接搬到常规电机**。

**B9｜「110,000 电气周期 = 25 年 × 5 艘潜艇」的分母是推出来的**
书未给单艘潜艇的开关次数/年。→ 该等式只能当「量级示范」，不能当换算系数。

**B10｜图与曲线一律不引**
图 14.17（潜艇噪声谱）、图 14.35（浴盆曲线）、图 14.9（CBEMA 曲线）、图 14.2（控制分层时标）均为**示意图**，无刻度可读。→ 只引用正文给出的数字。

**B11｜数据年代**
全章数据止于 2012–2014（参考文献最晚 2014）。**MCT 已经不存在，PEBB 的 600 kV·A 已被后续产品超越，SiC 在舰载/机载的渗透完全未涉及。** → 本章只能用作**方法论与判据来源**，不能用作**当前器件能力来源**。
