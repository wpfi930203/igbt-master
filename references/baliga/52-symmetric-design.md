# `52` 对称结构设计（阈值电压 / 阻断 / 通态 / 关断）

> **书源层 · Baliga。** 引用须标「据 Baliga `52`（书 pXX）」。
> **本模块是对称结构的完整一维解析设计流程**，也是全书唯一把 `V_TH`、`BV`、`V_ON`、`Q`、`t_OFF`、`E_OFF` 六件事串成一条链的地方。非对称结构（`53`）与透明集电极（`54`）都是在这条链上做局部替换。
> **文本来源**：扫描版 OCR + 原页图逐式核对（PDF p39–p50）。**所有公式形式已与书印式对齐**；OCR 的 `10 13` 之类指数不可用。

## R · 原文锚点

> 「在典型的电动机控制应用中，IGBT 集电极会承受**高于 DC 电源电压 50 %** 的电压尖峰，因此这个裕量必须考虑在器件阻断电压的设计中。」
> 「所有的高压 IGBT 器件必须要有合理的阈值电压，比如 4 V。」
> — 书 p21

> 「如果没有氧化层电荷和功函数差……」式 3.1：
> `V_TH = √(4·ε_s·k·T·N_A·ln(N_A/n_i) / C_ox) + 2kT/q · ln(N_A/n_i)`
> — 书 p21

> 「整个周期内器件的能量损耗是由 `E_I,OFF` 决定的。因此，**载流子寿命必须要控制在 10 μs 以下**，以保证器件的关断损耗小于 **1 J/cm²**。」
> — 书 p31

## I · 骨架

### I.1 设计链条总图（六步，每步一个可核的量）

```
① V_TH  ← P 基区峰值掺杂 N_A + 栅氧厚度 t_ox          （书 p21–22）
② BV   ← 漂移区宽度 W + 掺杂 N_D + 载流子寿命 τ         （书 p23–24）
③ V_ON ← 注入空穴分布 p(y) + 三段压降 V_P+N + V_NB + V_MOS （书 p24–27）
④ Q    ← 积累电荷 = ∫p(y)dy                          （书 p27–28）
⑤ t_OFF← 两段：t_V,OFF（电压线性上升）+ t_I,OFF（电流指数衰减）（书 p29–31）
⑥ E_OFF← (1/2)·J_C,ON·V_CS·t_V,OFF + J_C,ON·V_CS·(τ/2) （书 p31）
```

**六步里的关键耦合有三处，漏掉任何一处都会算出「看起来对但用不了」的数：**
1. `τ` 同时进 ②（BV 优化曲线）、③（`V_ON`）、④（`Q`）、⑤⑥（`t_OFF`/`E_OFF`）——**`τ` 是穿透整条链的唯一旋钮**。
2. `W` 不是独立变量，它由 `BV` 目标和 `τ` **共同**决定（I.2）。
3. `V_ON` 的三段贡献会随 `τ` **换主导项**（I.3），所以「降低 `V_ON` 该动哪一段」这个问题的答案取决于当前 `τ`。

### I.2 阈值电压：两个式子，必须成对用（式 3.1 / 3.2）

| 式子 | 形式 | 用在哪 |
|---|---|---|
| **式 3.1**（书 p21） | `V_TH = √(4·ε_s·k·T·N_A·ln(N_A/n_i))/C_ox + (2kT/q)·ln(N_A/n_i)` | 物理定义，含两段：**耗尽层电荷项（∝√N_A / C_ox）+ 表面势项（2φ_F）** |
| **式 3.2**（书 p22，工程估算） | `V_TH = (t_ox/ε_ox)·√(4·ε_s·k·T·N_A·ln(N_A/n_i))` | 只保留第一项，**丢掉了 2φ_F** |

**两者的差别就是那一段 `2φ_F`**：硅在 `N_A ≈ 10¹⁷ cm⁻³` 时 `φ_F ≈ 0.42 V`，`2φ_F ≈ 0.84 V`。所以**式 3.2 会系统性低估约 0.7–0.9 V**。书的用意很清楚：式 3.2 是「近似估计」（原文：「器件的阈值电压还可以根据下面公式进行估计」），式 3.1 才是算式。**报 `V_TH` 时不许用式 3.2 还声称精确到 0.1 V。**

**书给的设计锚点（全部来自正文或图 3.2 说明）：**

| 参数 | 书给值 | 出处 |
|---|---|---|
| 典型 IGBT 阈值电压 | **4 V** | 书 p21 |
| 开态栅极工作电压 | **15 V** | 书 p21 |
| 栅氧固定正电荷密度（高温扩散工艺典型） | `1×10¹¹ cm⁻²` | 书 p22 |
| 早期栅氧厚度 | 1000 Å 或更大 | 书 p22 |
| 当前栅氧厚度 | **500 Å 甚至更小** | 书 p22 |
| **`t_ox = 500 Å` + `N_A = 2.5×10¹⁷ cm⁻³` → `V_TH = 4 V`** | — | 书 p22（图 3.2 曲线上读得的值，正文引用） |
| **保 4 V 不变、`N_A` 提到 `1×10¹⁸ cm⁻³` → `t_ox` 须降到 250 Å** | — | 书 p22 |

**这两组配对值是本模块最实用的一条**：书的原文是「如果保持阈值电压不变，将 P 基区掺杂浓度增加为 `1×10¹⁸ cm⁻³`，那么栅氧化层厚度需要减小到 250 Å」。它直接给出 `N_A`–`t_ox` 的**替换率**，是设计里最常见的改法。

**N+ 多晶硅栅带来 −1 V 偏移（书 p22）**，且书明确说这个偏移**是有益的**：

> 「这个阈值电压负偏移是有益的，因为这样可以**增加 P 基区掺杂浓度以获得理想的阈值电压**。高 P 基区掺杂浓度可以有效**抑制 IGBT 器件内部寄生晶闸管的开启，即抑制器件发生闩锁效应**，增加器件的鲁棒性。」

→ **这是一个正反馈式的双赢**：多晶硅功函数给了 1 V 余量 → 可以把 `N_A` 提高 → 提高抗闩锁能力，同时 `V_TH` 还保持在 4 V。**抗闩锁的定量细节在 `56`，本模块只记这条因果。**

**`N_AB-Peak` 低于表面浓度 `N_BS`**（书 p22，图 3.1）：双扩散工艺下 P 基区的**峰值净掺杂在体内而不在表面**，所以「一维解析模型里阈值电压由 P 基区**最高的 P 型净电荷浓度**决定」——用的是峰值，不是表面值。

### I.3 阻断电压：击穿判据是一个「三因子乘积等于 1」

**判据（式 3.3，书 p23）：**

```
α_PNP = (γ_E · α_T)_PNP · M = 1
```

三个因子各自随 `V_C` 变化：

| 因子 | 式子 | 随 `V_C` 增大 | 物理 |
|---|---|---|---|
| 注入效率 `γ_E` | 式 3.13（`J_p/(J_p+J_n)`） | 近似不变 | 由 J₁ 两侧掺杂比定（`53`/`54` 的主旋钮） |
| 基极传输系数 `α_T` | **式 3.4**：`α_T = 1/cosh(l/L_p)` | **增大**（因为 `l` 减小） | 未耗尽区变短 → 复合机会少 → 传输率高 |
| 雪崩倍增 `M` | **式 3.6**：`M = 1/[1 − (V_C/BV_PP)^n]` | **增大** | 碰撞电离 |

**`l` 的式子（式 3.5）：`l = W_N − √(2·ε_s·V_C/(q·N_D))`** ——未耗尽区宽度 = 漂移区总宽 − 耗尽层宽度。**`α_T` 增大与 `M` 增大是同向叠加的**，所以 IGBT 的击穿电压**低于**同结构 PNP 的 `BV_PP`（基极开路），这是「基极开路」这四个字的全部含义。

**`n ≈ 6`（N 型 IGBT，书 p23）** —— 这个 `n` 是 `M` 式里的指数，**不是** `34-formula-index §12` 里登记的「Peck 模型 `n`」（那是湿气加速因子）。同名不同物，**引用时必须带上下文**。

**优化曲线（图 3.3 / 3.4，书 p24）——书给的是一族可选解，不是一个唯一解：**

| 目标 `BV` | 设计裕量 | 书给的组合 |
|---|---|---|
| 3000 V | **3300 V（+10 %）** | 「可以有多种漂移区掺杂浓度和宽度的组合」 |
| — | — | `W` 从 **670 μm** 降到 **475 μm** 时，`N_D` 从 `1.0×10¹³` 升到 `2.5×10¹³ cm⁻³` |
| — | — | `W = 510 μm` 时，`N_D` 最大可达 `3.5×10¹³ cm⁻³` |

**「多种组合」这句话必须讲清楚**：式 3.3 的判据**只有一个方程，却有两个未知量（`W` 与 `N_D`）**，所以解是一条**曲线**而不是一个点。选曲线上的哪一点，靠的是「最小 `W`」这条附加准则（书 p24：「通过优化漂移区掺杂浓度，可以达到最小的漂移区宽度。**小的漂移区宽度有利于减小器件导通饱和电压降和开关损耗**」）。

**`τ` 对最优点的移动（图 3.4，书 p24，正文给了三个数）：**

| `τ` | 最优 `N_D` | 最优 `W` |
|---|---|---|
| **100 μs** | `2.0×10¹³ cm⁻³` | **565 μm** |
| **10 μs** | `3.0×10¹³ cm⁻³` | **467 μm** |
| **1 μs** | `3.5×10¹³ cm⁻³` | **396 μm** |

→ **`τ` 降 100 倍，最优 `W` 只降 30 %（565→396 μm），而 `N_D` 升 75 %。** 这是个容易被忽视的非线性：**降寿命换来的漂移区变薄是有天花板的**，因为 `τ` 降到 1 μs 时漂移区也必须留 396 μm 才能挡 3300 V。

**注意 10 % 裕量的双重身份**：书的 3300 V 是把「3000 V 目标 + 电机驱动 50 % 电压尖峰」之前的**工程裕量**。但 **10 % 远小于 50 %** —— 也就是说，书 p21 的「50 % 尖峰」与 p24 的「10 % 裕量」**不是同一层保护**：50 % 尖峰靠**系统侧钳位/吸收**吸收，10 % 裕量只是器件参数的工艺散布余地。**把 10 % 当成「能抗 50 % 尖峰」是误读。**

### I.4 通态：三段压降 + 注入分布

**注入分布（式 3.11，书 p26）——注意这是「线性正弦」形，不是线性：**

```
p(y) = p_0 · sinh[(W−y)/L] / sinh(W/L)
```

边界条件（式 3.9/3.10）：`p(0) = p_0`（J₁ 侧，P+ 集电极/N 基区），`p(W) = 0`（J₂ 侧，深 P+/N 基区）。

**`p(W) = 0` 是本模块最重要的一个边界条件的物理含义**：J₂ 导通时反偏，把发射极侧的少子抽空（见 `51` I.2 ③）。**这就是 IGBT 的 `V_ON` 永远高于 P-I-N 的根因，也是 IEGT/CEL 全部动机。**

**三段压降（式 3.20）：`V_ON = V_P+N + V_NB + V_MOSFET`**

| 段 | 内容 | 主导条件（书 p27，图 3.7 结论） |
|---|---|---|
| `V_P+N` | J₁ 结压降，`= (kT/q)·ln(p_0·N_D/n_i²)`（式 3.21） | **`τ > 20 μs` 时占主导** |
| `V_NB` | N 基区压降（含电导调制），式 3.22/3.23 拆成 `V_NB1 + V_NB2` | **`τ < 10 μs` 时占主导** |
| `V_MOSFET` | JFET 电阻 + 积累区电阻 + 沟道电阻（式 3.24–3.26） | 元胞几何决定 |

**这个「主导项换位」是设计里最实用的判据**：
- 若当前 `τ > 20 μs`，想降 `V_ON` → 改 **J₁ 注入效率**（集电极掺杂/厚度，即 `54` 透明集电极的方向）；
- 若当前 `τ < 10 μs`，想降 `V_ON` → 改 **漂移区**（`W`、`N_D`）或**抬 `τ`**，改集电极没用；
- 若 `τ` 在 10–20 μs 之间，两段同量级，**必须逐项算，不能拍**。

**书 p27 的原文警告（`V_NB` 保守性）**：「由于在发射极附近漂移区的电导调制率减小而增加了这部分的电压降，所以在进行导通分析时，需要**谨慎地利用左边载流子分布**并对 IGBT 结构的导通电压降给出一个**更保守的值**。」
→ 意思是：用 `p(W)=0` 这个边界算出来的 `V_ON` 是**偏乐观**的（因为真实器件 J₂ 附近电导调制更差）。**不要把解析值当成实测上限。**

**元胞几何参数（书 p27，用于式 3.24–3.26 的算例）：**

| 参数 | 值 |
|---|---|
| 元胞宽度 `W_CELL` | **30 μm** |
| 栅极长度 `W_G` | **16 μm** |
| 栅极偏置 `V_G` | **15 V** |
| 阈值电压 `V_TH` | **5 V** |
| JFET 区典型电阻率 `ρ_JFET` | **1.25 Ω·cm** |
| 积累层系数 `K_A` | **0.6**（典型值） |

**注意 `V_TH = 5 V` 与 I.2 的「典型 4 V」不同** —— 这是同一个器件算例的取值，不是矛盾。引用时标明「算例取 5 V」。

### I.5 积累电荷：式 3.27 与 `34-formula-index` 的式 5.1 不是同一式

**式 3.27（书 p28）：`Q = q·p_0·L·tanh(W/L)`**

这是对称结构的**积累电荷**，从式 3.11 沿 `y` 积分得到。

**⚠ 编号冲突登记**：`volke-hornkamp` 层里也有一个「式 3.27（p105）≡ 式 5.1（p143）」，那是**模块电感/热阻相关**的式子，与 Baliga 的式 3.27 **完全无关**。**两层式号各自独立，跨层引用时必须写「据 Baliga 式 3.27」或「据《IGBT 模块》式 3.27」，禁止只写式号。**（此条同 `00-index §6` 第 4 条的页号双标原则。）

**`Q` 与 `V_ON`、开关速度的三方耦合（书 p28 原文）**：
> 「当载流子寿命增加时，积累电荷也会相应增加，器件的**导通电压降会减小**，但是会**影响器件的开关速度**。」

→ **`Q` 就是折中曲线的物理载体**：`Q` 大 → `V_ON` 低 但 `E_OFF` 高。`53` 的折中曲线本质上是 `Q` 的参数化。

### I.6 关断：两段式波形与两个时间（式 3.28–3.40）

**关断判据按「电感负载 + 续流二极管」这条电路：**

| 段 | 电路行为 | 书给的式子 | 时间 |
|---|---|---|---|
| **第一阶段（电压段）** | 电流维持 `J_C,ON` 不变（电感电流不能突变），`V_CE` 从通态值**线性**升到 `V_CS` | 式 3.31/3.34：`W_sc(t) = √(2·W_N·J_C,ON·t/(q·p_0))`；式 3.34 得 `V_C(t)` 线性 | **式 3.35**：`t_V,OFF = 8·ε_s·p_0·V_CS / [W·(N_D+P_sc)·J_C,ON]` |
| **第二阶段（电流段）** | 电压已在 `V_CS`，电流**指数**衰减 | 式 3.39：`J_C(t) = J_C,ON·exp(−2t/τ_HL)` | **式 3.40**：`t_I,OFF = (τ_HL/2)·ln(10) = 1.15·τ_HL` |

**⚠ 式 3.40 是 `1.15·τ_HL`，不是 `2.3·τ`！** 注意 `/2` 的来源：式 3.39 的指数是 `exp(−2t/τ_HL)`，因为**双极扩散的衰减速率是单极的两倍**（电子与空穴成对复合）。所以 `t_I,OFF = (τ/2)·ln10 = 1.151·τ`。

**这条正好解释了 `53` 模块 A2.1 里那个「`2.3·τ` 差 3–4 倍」的疑点**：非对称结构章节（书 p41）给的是 `t_OFF = τ·ln(10) = 2.3·τ`，而对称结构章节（书 p30）给的是 `1.15·τ`。**两章差了 2 倍**，而书都没解释这个 `2` 从哪来。
→ **本模块的判定：对称结构的 `1.15·τ_HL`（式 3.40）有明确的推导链（式 3.37 连续性方程 → 式 3.39 → 取 ln10），是可用的；非对称结构的 `2.3·τ` 未见同强度推导，且与实测表差 3–4 倍，不可用。** 这条判定已同步写入 `34-formula-index` 的登记项。

**`τ` 的实测关断（图 3.10，书 p31，正文给数）：**

| `τ` | `t_V,OFF`（电压升到 `V_CS`） | `t_I,OFF` |
|---|---|---|
| **2 μs** | **0.66 μs** | **2.30 μs** |
| **5 μs** | **0.88 μs** | **5.75 μs** |
| **10 μs** | **1.03 μs** | **11.5 μs** |

**这两列本身就是两个因果律的证明**：
- `t_I,OFF` 与 `τ` **几乎严格成正比**（2.30/2 = 1.15, 5.75/5 = 1.15, 11.5/10 = 1.15）→ **式 3.40 的 `1.15·τ` 完全被实测证实**（三个点系数全等于 1.15）。这是全书少有的「式子与表完美对上」的案例。
- `t_V,OFF` 只从 0.66 涨到 1.03（涨 56 %），而 `τ` 涨了 5 倍 → **电压段几乎不由 `τ` 决定**，由 `p_0`（即注入浓度）决定。`τ` 涨 → `p_0` 涨但 `V_CS` 不变，式 3.35 里 `p_0` 在分子、`J_C,ON` 在分母，两者同时随 `τ` 涨 → 部分抵消。

### I.7 关断损耗：两个分量，一个是「面积」一个是「矩」

**式 3.41 / 3.42（书 p31）—— 这两个式子必须看清形状：**

```
E_V,OFF = (1/2)·J_C,ON·V_CS·t_V,OFF                  (3.41)  ← 三角形，因为 V 线性升、I 不变
E_I,OFF = J_C,ON·V_CS·(τ_HL,N-Base / 2)              (3.42)  ← 矩形×时间常数，与 t_I,OFF 无关！
```

**式 3.42 最容易看错**：它里面**没有 `t_I,OFF`**，只有 `τ/2`。因为 `E_I,OFF = ∫V_CS·J_C,ON·exp(−2t/τ)dt` 从 0 积到 ∞ 正好是 `J_C,ON·V_CS·τ/2`。**若误把 `t_I,OFF` 代进去算矩形面积，会高估 `ln10/2 ≈ 1.15` 倍。**

**书 p31 的实测值（`W=450 μm`, `N_D=2.5×10¹³`, `J_C,ON=100 A/cm²`, `V_CS=2000 V`）：**

| `τ` | `E_V,OFF` | `E_I,OFF` | 谁主导 |
|---|---|---|---|
| **2 μs** | 66 mJ/cm² | **200 mJ/cm²** | `E_I,OFF` 约 3 倍 |
| **100 μs** | 131 mJ/cm² | **10000 mJ/cm²**（= 10 J/cm²） | `E_I,OFF` 约 **76 倍** |

**`τ` 从 2 涨到 100 μs（×50）：`E_V,OFF` 只涨 2 倍（66→131），`E_I,OFF` 涨 50 倍（200→10000）。**
→ **`E_V,OFF` 是「注入浓度」的函数，`E_I,OFF` 是「寿命」的线性函数。** 这就是为什么书说「整个周期内器件的能量损耗是由 `E_I,OFF` 决定的」——**不是近似，是 76 倍的量级差。**

**由此得出本模块最硬的一条判据（书 p31）：**

> **`τ ≤ 10 μs` 才能保证 `E_OFF < 1 J/cm²`**

**折中曲线的代价（图 3.12，书 p32）：**
- `J_C,ON = 100 A/cm²`、`E_周期 = 1 J/cm²`、`P_L ≤ 100 W/cm²` → **`f < 100 Hz`**
- 对比 `53` 的非对称结构：**同 `100 A/cm²` 下 `f` 高 5 倍**（书 p47）→ 即对称结构 100 Hz ≈ 非对称 500 Hz，**与 `53` A1 的 500 Hz 完全对上**。这两个模块的数互为交叉验证。

### A2.2 式 3.42 与式 3.41 的量级复算

`E_I,OFF = J_C,ON·V_CS·τ/2`，取 `J_C,ON = 100 A/cm²`、`V_CS = 2000 V` → 系数 `J_C,ON·V_CS = 2×10⁵ W/cm²`。

**两个点全中。式 3.42 可直接用于工程估算。**

`E_V,OFF = 0.5·J_C,ON·V_CS·t_V,OFF`：

| `τ` | `t_V,OFF`（书 p31） | 预测 `E_V,OFF = 10⁵ × t` | 书实测 | 差 |
|---|---|---|---|---|

| 10 μs | 1.03 μs | **103 mJ/cm²** | —（书只给 2 与 100 两端） | — |

**式 3.41 也全中。** 三式（3.40/3.41/3.42）全部通过实测三点验证，**这是 Baliga 层可放心定量使用的式子集合**。

### A2.3 式 3.2 低估 `V_TH` 的量（本地核实）

`N_A = 2.5×10¹⁷ cm⁻³`、`t_ox = 500 Å`，书说 `V_TH = 4 V`。

用式 3.1 的两段估算（`φ_F = (kT/q)·ln(N_A/n_i)`，室温 `kT/q = 25.85 mV`，`n_i = 1.0×10¹⁰ cm⁻³`）：

- `ln(N_A/n_i) = ln(2.5×10⁷) ≈ 17.03`
- `φ_F = 0.02585 × 17.03 ≈ 0.440 V`，第二段 `2φ_F ≈ 0.880 V`
- 第一段由书给的「500 Å + 2.5×10¹⁷ → 4 V」可知 `4 − 0.88 ≈ 3.12 V`
- 式 3.2 只算第一段 → `≈ 3.12 V`，**比 4 V 低估 0.88 V（−22 %）**

**结论：式 3.2 ≈ 0.78 × 式 3.1。这个 0.78 的系数在 `N_A ≈ 10¹⁷` 量级上稳定**，可作为快速判断，但**报数必须用式 3.1**。

## S · 步骤

**任务：设计一个目标 `BV` + 目标 `V_TH` 的对称结构 IGBT 一维方案。**

1. **定 `V_TH`**：按目标 `V_TH`（典型 4 V）用式 3.1 反解 `(N_A, t_ox)` 组合。记住 `N_A` 升高 → 抗闩锁更好（`56`），但需同步薄化 `t_ox`。**必须用式 3.1，不许用式 3.2。**
2. **定 `BV` 目标**：目标值 + 10 % 工艺裕量。**若系统有 >10 % 的电压尖峰（如电机驱动的 50 %），那是系统侧钳位的事，不是靠器件裕量硬扛。**
3. **扫 `(W, N_D)`**：以式 3.3（`(γ_E·α_T)·M = 1`）为约束画等 `BV` 曲线，**取曲线上的最小 `W` 点** —— 因为 `W` 小则 `V_ON` 低、`E_OFF` 低。
4. **定 `τ`**：`τ` 会同时移动最优 `(W, N_D)`（I.3 三行表）和 `E_OFF`。**先按 `τ ≤ 10 μs` 卡 `E_OFF < 1 J/cm²` 的硬约束（I.7），再在可行域内往大取以压 `V_ON`。**
5. **算 `V_ON` 三段**：先判断 `τ` 落在哪个区间（`>20 μs` → `V_P+N` 主导；`<10 μs` → `V_NB` 主导），**只对主导项做优化，次要项保持不动**。
6. **算 `E_OFF`**：式 3.41 + 式 3.42（**注意 3.42 里是 `τ/2`，不是 `t_I,OFF`**）。两个分量都报，别只报和。
7. **闭环校核频率**：`f < (P_L,Max − 0.5·J_C,ON·V_ON)/E_OFF`（式 3.71/3.72，见 `53` I.5）。
8. **申报三件**：`(W, N_D, τ)` + `P_L,Max` 假设 + `f_max`。缺任一则该 `f_max` 不成立。

## B · 边界

1. **本模块只给对称结构。** 非对称在 `53`（多了缓冲层，`t_OFF` 口径也变了）、透明集电极在 `54`。
2. **式 3.2 系统性低估 `V_TH` 约 0.88 V（`N_A≈2.5×10¹⁷` 时），禁止用于报数**（A2.3）。这是「书给了但不可直接定量」类条目，按 `34-formula-index §12` 登记。
3. **式 3.42 里是 `τ_HL/2`，不是 `t_I,OFF`。** 若代入 `t_I,OFF` 会高估 1.15 倍（I.7）。这是本模块最易犯的抄写错误。
4. **`M` 式的 `n ≈ 6` 与 Peck 模型的 `n` 同名不同物。** 引用必须带上下文，见 I.3。
5. **Baliga 的式 3.27（积累电荷 `Q = q·p_0·L·tanh(W/L)`）与 `volke-hornkamp` 层的式 3.27（≡ 式 5.1）毫无关系。** 跨层引用必须写「据 Baliga 式 3.27」，见 I.5。
6. **A1 里 `p_0` 的三个值非单调（1.26/1.95/1.67 ×10¹⁷），疑排印误差。** 只可引量级，不可代入式 3.12 反算。
7. **解析 `V_ON` 偏乐观。** 书 p27 明确要求「给出一个更保守的值」——因为真实器件 J₂ 附近电导调制更差。**解析值不是实测上限。**
8. **图 3.2/3.3/3.4/3.6/3.7/3.8/3.10/3.11/3.12 的曲线读数不许引。** 本模块所有数字均来自**正文叙述**。要读图必须回 PDF p41–p50 原页并注明「由图读得」。
9. **本模块不承担终端设计。** 对称结构的反向阻断瓶颈在**边缘终端**（书 p22：「最大的挑战是边缘终端的反向阻断结的制造工艺技术」），终端设计在 `57`。
10. **不乘 1/π。** 本模块的 `E_OFF` 是**单脉冲能量**，与《IGBT 模块》层式 3.16/3.28 的正弦 VSI `1/π` 口径不同（`00-index §5 P2`）。
