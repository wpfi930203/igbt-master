# `59` 门驱动电路七级演化

> **书源层 · Baliga。** 引用须标「据 Baliga `59`（书 pXX）」。
> **一句话定位**：第 7 章给的是**门驱动的一个分类法 + 一条演化轴**。轴只有一条：**「用一个固定栅电阻」→「按开关阶段动态改变栅电阻/栅电压」**。它给出 6 个可引的定量收益，其中 **两级门驱动「过冲 −60 %」** 和 **数字门驱动「5 A 摆率」** 最硬。

> **章节实际范围**：第 7 章正文 **p129–p135**（7 节 + 小结），**只有 7 页**，是全层最短的一章。原计划的「九拓扑」实为 **7 节 / 7 种拓扑**（`00-index §3` 已更正）。

## I · 骨架

### I.1 关断波形的两段：一个物理分界（整章的地基）

**IGBT 关断 = `t_d`（延时）+ `t_f1`（下降）+ `t_f2`（拖尾）**（书 p129 图 7.1）。

| 段 | 由谁决定 | 能不能用驱动改 |
|---|---|---|
| `t_d` + `t_f1` | **栅电阻 `R_G`**（「可以看成是具有恒定电容的 RC 时间常数模型」，书 p129） | ✅ **能** |
| **`t_f2`（拖尾）** | **漂移区少子寿命**（与 A/B/C 分类绑定） | ❌ **完全不能** |

**器件三分类（书 p129，可直接引）**：

| 类 | `t_off` |
|---|---|
| **A** | **15 μs** |
| **B** | **1 μs** |
| **C** | **0.25 μs** |

**缩短 `t_f2` 的唯一办法**：「通过增加**电子辐射**减少 IGBT 结构漂移区的载流子寿命」（书 p129–130）—— **与 `57` I.5 的寿命控制完全对上**。

> **这条分界是整章最重要的工程判断，也是本模块对「驱动能不能救拖尾」这个高频问题的正式回答**：
> **驱动只能改 `t_d + t_f1`，`t_f2` 一个字都改不了。** 想压拖尾只能动器件（降 `τ`）。而 `t_d + t_f1` 与 `R_G` 的关系在 `100 Ω → 10 kΩ` 范围里是「幂律」（图 7.2 的双对数轴，`t_f1` 从约 1 μs 涨到约 10 μs），**不是线性**。
> **与 `54` 的定量一致**：`54` 给出透明集电极 `t_I,OFF = 0.105·τ`，正是「`t_f2` 只由 `τ` 决定」的定量表达。**两章独立得到同一结论，可互相校核。**

**`R_G` 的下界（本节唯一可量化的「小」之一）**：`R_G` 太小 → `di/dt` 太大 → 关断过压 / 开通反恢复过冲。书在本章反复说「增加栅电阻可以降低 `di/dt`，**但这会导致功耗的显著增加**」（p130、p132、p133 三处重复）—— **这是全章的权衡主轴**。

### I.2 非对称门驱动：最小的有效改动（书 p130）

**结构**：`R_on` 与一个**二极管串联**（开通路径），`R_off` 单独（关断路径）。
**效果**：`di/dt`（开通）由 `R_on` 定；关断速度由 `R_off` 定（「这个电阻被用来释放 IGBT 栅输入电容中储存的电荷」）。

> **为什么叫「非对称」**：因为开通与关断走了**不同的电阻**。代价是**两个方向仍然只有一个自由度** —— 你只能分别设 `R_on`、`R_off`，但**在每个方向内部还是固定的**。这正好是下一步（两级/AGVC）要突破的地方。

### I.3 两级门驱动：先快、再慢、再快（书 p130，唯一给了「−60 %」的拓扑）

**要解决的问题**：硬开关关断时，`L_σ`（**DC 链路电容电感 + 模块内总线电感**，书 p130 明确列出这两项）上的 `di/dt` 造成过压 → 器件雪崩击穿。
**矛盾**：加 `R_G` 降 `di/dt` → 损耗显著增加。

**机理链（书 p130，图 7.4）**：

```
① T1、T2 都导通 → 快速放电（此时 dV/dt 快，但 dI/dt 还没开始降）
② 集电极电压升到齐纳二极管 D_Z 的击穿电压 → 电流流经 C 触发单稳态触发器
③ 单稳态在短时间内关断 T2 → 只剩大电阻 R_G2 → dI/dt 变小（压住过冲）
④ 短时间后 T2 再导通 → IGBT 更快截止（把拖尾段剩余时间缩到最短）
```

**收益：过冲电压 −60 %，同时保持低开关损耗**（书 p130 引 [4]）。

> **这个拓扑的关键设计变量是「齐纳击穿电压」**：它决定**什么时候从「快」切到「慢」**。切早了多损失损耗，切晚了过冲已经发生。**书没给这个电压怎么选**，只给了「按 `V_CE` 触发」这个原则。**这是本章最大的一个「知道原理但拿不到设计值」的空洞。** 见 B 段。

### I.4 有源栅电压控制（AGVC）：不动电阻、动电压（书 p131–132）

**原理**：在开关期间施加**两级栅极电压**，而不是两级栅电阻。

**开通侧（图 7.6，`di/dt` 控制）**：
```
V_GS → 中间电平 V_G1/V_G2/V_G3 → 保持 T_IM → 再升到 V_GS(on)
```
| 规则 | 内容 |
|---|---|
| 中间电平**必须 > `V_TH`** | 否则沟道没开，方法失效 |
| `T_IM` **必须够长** | 要「足以完成反激二极管的反向恢复过程」 |
| **降低中间电平 → `di/dt` 增大** | ⚠ **注意方向与直觉相反** |

> **⚠ 「降低第一步的栅极电压可以增加导通时的 `di/dt`」这句（书 p132 原话）方向要小心**：原文在 p131 图 7.6 的说明里写「降低 IGBT 导通期间的 `di/dt` 可减少由反激式二极管反向恢复引起的电流过冲」，p132 又说「**降低**第一步使用的栅极电压可以**增加**导通时的 `di/dt`」。**两句方向相反。**
> 本模块判定：**图 7.6 的物理是「中间电平越低 → 沟道电流越小 → 二极管恢复电流的峰值越低」**，因此应理解为**「降低中间电平可以降低（或延后）电流过冲」**。p132 那句「增加 `di/dt`」**很可能是「降低 `di/dt`」的印刷/翻译错误**（与 p131 的表述直接冲突）。**→ 引用时必须同时给出两句，不得只引一句。**登记 `00-index §6.4` 第 17 项**。**

**关断侧（图 7.7，`dV/dt` 控制）**：
```
① V_GS 接地 → 空间电荷区形成 → V_CE 开始上升（初始段「逐渐增加」）
② 在 V_CE 开始快速上升之前 → V_GS 回到中间电平 → 保持 T_IM → 再降到 0
```
| 规则 | 内容 |
|---|---|
| 中间电平**必须 < `V_TH`** | ⚠ **与开通侧相反** |
| `T_IM` **必须够长** | 要「足以让集电极电压达到电源电压」 |
| **减小中间电平 → `dV/dt` 减小** | — |

**AGVC 的代价（书 p132，本节的诚实项）**：「这增加了导通和截止状态转换持续的时间，从而在 IGBT 中产生更大的开关损耗。**然而，这些损耗小于那些通过使用较大的栅极电阻实现 `di/dt` 与 `dV/dt` 的减小所产生的损耗。**」

> **这句话是 AGVC 存在的全部理由，而且它是一个「相对比较」的结论**：AGVC 比「加电阻」好，但**不比「什么都不做」好**。**所以 AGVC 的适用场景是「必须限 `dV/dt`」的场合**，不是「想省损耗」的场合。

### I.5 可变栅电阻驱动：三个时间窗三个电阻（书 p132–133）

**关断侧（图 7.8 / 7.9）—— 本节最实用的一条，因为它是纯时序设计**：

| 时段 | 期望 `R_G` | 目的 |
|---|---|---|
| `t_1 → t_2` | **低**（`R_1`） | 让栅压**快速**降到平台电压 `V_GP` |
| `t_2 → t_3` | **高**（`R_2`） | 减小 `dV/dt` 与 `di/dt`（压过冲） |
| `t_3 → t_4` | **低**（`R_1`） | 让栅电容**继续放电**（把剩余电荷抽干） |

**实现（图 7.9）**：用一个晶体管 `T_3` 的**开/关**在 `R_1`（低）与 `R_2`（高）之间切换，由**比较器 + 延时**控制。
**收益**：「该方法**减小了集电极电压中的最大值（`V_M`）**」（书 p133）。

**开通侧（图 7.10）**：同样的三段结构，目的是压**反激二极管反向恢复引起的 `I_M`**。
**关键规则（书 p133，本书少有的「操作级」结论）**：
> 「为了在不显著增加导通功耗的前提下减小集电极电流过冲，**除了在 `t_2 → t_3` 这段时间（即栅极平稳阶段期间），栅极电压在导通期间始终保持着高的上升速率**。」

→ **翻译成设计语言：只在「平台期」这一刻用大电阻，其他时间都用小电阻。** 因为**平台期是 `di/dt` 与 `dV/dt` 实际发生的窗口**，其余时间加大电阻纯属浪费损耗。**这是全章把「什么时候该慢」讲得最清楚的一句。**

**两级电路版本（书 p133）**：「一个用于调节低压和高压之间栅电阻的两级电路[8]也被使用以获得与减小 IGBT 截止期间的瞬态电压过冲同样的好处。」（**无数据**。）

### I.6 数字门驱动：把 `di/dt` 和 `dV/dt` 变成任意波形（书 p133–134）

**做法**：用**电阻分压器**持续监测 `V_CE` 与 `V_GE`，用**电流探头**监测 `I_C` → 全部送进 **FPGA（微控制器）** → 产生想要的栅控信号。

| 指标 | 值 |
|---|---|
| 栅极电流 | **摆率高，可达 5 A** |
| 能力 | 「保持 `di/dt` 与 `dV/dt` 的**任意期望组合**」 |
| **硬限制** | **D-A / A-D 转换器的延时 → 只能用于「开关跳变慢于几微秒」的 IGBT** |

> **「5 A 摆率」这个数要读清楚**：它指**驱动器的输出能力**（能快速给栅极充放电），**不是「`di/dt` 能到多高」**。5 A 与 `Q_G` 相除才是 `dV_GS/dt`。**引用时不许把 5 A 说成 `di/dt`。**
> **「几微秒」这个限制是本章对数字驱动最锋利的一句**：它意味着**数字门驱动天然不适合高频硬开关**（现代 IGBT 的开关跃变常在 100–500 ns 量级）。**它的战场是「大功率、低频率、需要精细波形」的场合。**
> **与厂商层 `47` 的数字驱动对照**：`47` 讲的是**可编程驱动的功能块与配置项**；本章讲的是**「用 FPGA 闭环」这个架构的上限在哪**。**两者并列，不互相替代。**

### I.7 短路下的驱动：本章唯一与 SOA 对接的地方（书 p135）

**机理链**：
```
负载短路 → I_C 升到稳态值几倍
  → 若直接关断故障电流通路 → di/dt 极大
  → L_σ 上过压 → V_CE 超过击穿电压 → 超出 RBSOA
```
**解法**：**检测到故障后改变栅极电阻**，在短路条件下减小关断期间的 `di/dt`（书 p135 引 [12][13][14]）。

> **这条与 `56` I.7 的 RBSOA 判据串起来**：`56` 式 4.25/4.26 给出 `BV_RBSOA = 5.34×10¹³/(N*)^{3/4}`，`N*` 随 `J_C` 上升而 **`BV` 下降**。短路时 `J_C` 是稳态的几倍 → `BV` 已经降低；此时再加 `L_σ·di/dt` 过压 → **两个方向同时挤压**。**所以短路软关断不是「优化」，是 RBSOA 唯一可行的出路。**
> **厂商层 `31`（软关断）与本章的关系**：本章只说「改变栅电阻」这个原理，**不给软关断的两段式栅压时序、不给软关断时间常数** —— 那些在 `31`/`47`。**本章是原理，`31` 是实现。**

### I.8 演化轴（本模块归纳，书未集中成一句）

| 级 | 拓扑 | 自由度 | 书页 | 关键成本 |
|---|---|---|---|---|
| **0** | 单一 `R_G` | 1（一块电阻） | 7.1 | 无 |
| **1** | **非对称**（`R_on` / `R_off`） | **2**（两个方向各一个） | 7.2 | 一个二极管 |
| **2** | **两级**（齐纳触发切换） | 3（+ 切换时刻） | 7.3 | 单稳态 + 齐纳 |
| **3** | **AGVC**（两级栅压） | 4（+ 中间电平值） | 7.4 | 电平源 |
| **4** | **可变栅电阻**（三时间窗） | 5（+ 三段时序） | 7.5 | 比较器 + 延时 |
| **5** | **数字门驱动**（FPGA 闭环） | 任意波形 | 7.6 | **ADC/DAC 延时 → 只能用于 >几 μs** |

> **这张表的读法**：**每上一级，自由度 +1，但代价从「元件」变成「时间」**。最后一级的代价是**延时**，而延时直接杀掉了高频应用。**所以「越先进越好」在这里不成立 —— 分级越高，适用带宽越窄。**
> **这是本模块最重要的一句话，书没有说**：**门驱动的先进程度与开关频率是反向的。** 选型时先看 `t_sw`，再看要不要上高级拓扑。

## A1 · 案例：1200 V / 600 A 模块的关断过冲治理路线

**前提（本模块设定，非书给值）**：`V_DC = 800 V`、`L_σ = 40 nH`（模块 + 母线）、`I_C = 600 A`、要求 `V_CE,peak ≤ 1000 V`（即过冲 ≤ 200 V）。

**预算**：`ΔU = L_σ·di/dt ≤ 200 V` → **`di/dt ≤ 200/40×10⁻⁹ = 5 kA/μs`**。

**三级方案对比**（书中给出的机制，数值为本模块代入）：

| 方案 | 机制 | 所得 | 代价 |
|---|---|---|---|
| **① 只加大 `R_G`** | 全段 `di/dt` 都降 | `di/dt` 可控 | **损耗「显著增加」**（书 p130 原话，未给数） |
| **② 两级驱动** | 只在 `V_CE` 过齐纳后降 `di/dt` | **过冲 −60 %**（书报） | 需要齐纳电压与单稳态宽度两个设计值（**书未给**） |
| **③ 可变栅电阻** | 只在平台期 `t_2→t_3` 用大电阻 | `V_M` 减小（书报，无百分比） | 需要比较器阈值 + 延时 |

→ **书唯一给了百分比的只有 ②（−60 %）。** 其他两级的收益书只给定性。**这是本章的诚实边界：能选拓扑，但不能做定量预算。**

## A2 · 本地复算

### A2.1 「过冲 −60 %」意味着什么（可解析）

若原始过冲是 `200 V`（本模块设定），`−60 %` → **剩 80 V**。
反过来：**如果设计要求是「过冲 ≤ 200 V」，那么不加驱动的原始过冲可以是 `200/0.4 = 500 V`** —— 即 `di/dt` 可以做到 `500/40×10⁻⁹ = 12.5 kA/μs`。
→ **两级驱动把「可用 `di/dt`」放大了 2.5 倍**，而**开关损耗与 `di/dt` 正相关** → 这是它「同时保低损耗」的定量解释。
> **注意：`−60 %` 是书引文献 [4] 在特定模块上的结果，不是普适系数。** 换 `L_σ`、换模块会变。

### A2.2 数字驱动的「几 μs」限制与典型开关时间的对照

| 器件类型 | 典型 `t_sw` | 数字驱动可用？ |
|---|---|---|
| 高频硬开关（20 kHz 以上） | 100–500 ns | ❌ **不可用**（延时 > `t_sw`） |
| 中频（1–5 kHz） | 1–3 μs | ⚠ 边缘 |
| 大功率低频（50–500 Hz） | 10–100 μs | ✅ 可用 |

→ **书的「几微秒」限制把数字驱动锁在「大功率低频」这一格**，这正是 HVDC / 牵引 / 大型传动。**与 `68`（电力传输）/`61`（轨道）的应用章一致。**
> 表中的 `t_sw` 范围是本模块按行业常识给的，**不是书给值**。

### A2.3 AGVC 两个「中间电平」的方向对立（结构自洽检验）

| 侧 | 中间电平 vs `V_TH` | 物理理由 |
|---|---|---|
| **开通** | **> `V_TH`** | 必须让沟道真的开起来，二极管才能完成恢复 |
| **关断** | **< `V_TH`** | 必须让沟道已经关掉，`V_CE` 才会上升；此时栅压只起「减缓」作用 |

→ **两条规则不是笔误，而是同一个物理的两面**：中间电平的唯一作用就是「把沟道放在一个受控的中间态」，开通时需要沟道有电流、关断时需要沟道已无电流。**这个对照可以用来校验转写正确性：若你看到的写法两侧都是「>」或都是「<」，就是抄错了。**

## E · 触发场景

| 场景 | 用哪一段 |
|---|---|
| 「拖尾能不能用驱动压下来」 | **I.1：不能。`t_f2` 完全与 `R_G` 无关**，只能降 `τ`（接 `57` I.5、`54`） |
| 「`R_G` 加大能降多少过冲」 | I.1：书只说「显著增加损耗」，**未给数**；反向用两级驱动才有 `−60 %`（I.3） |
| 「A/B/C 类是什么意思」 | I.1：`t_off` = **15 / 1 / 0.25 μs** 三档 |
| 「开通和关断能不能分别调」 | I.2：**能，`R_on` / `R_off` 分开**（二极管串联在开通路径） |
| 「要压 60 % 过冲怎么做」 | I.3：**两级驱动（齐纳触发 + 单稳态）**，书报 `−60 %` 且保低损耗 |
| 「AGVC 和两级驱动差在哪」 | I.3 vs I.4：两级驱动改**电阻**，AGVC 改**栅压电平**；**AGVC 的中间电平开通要 >`V_TH`、关断要 <`V_TH`** |
| 「什么时候该用大栅阻」 | I.5：**只在平台期（`t_2→t_3`）**。其余时间用大电阻纯浪费损耗（书 p133 原话） |
| 「数字驱动能不能上 20 kHz」 | I.6 + A2.2：**不能**，ADC/DAC 延时限制在「>几 μs」；5 A 是**驱动电流能力**不是 `di/dt` |
| 「短路时驱动怎么保护」 | I.7：**检测到故障后加大 `R_G`**，减小关断 `di/dt`；与 `56` 的 RBSOA 一起看 |
| 「门驱动越先进越好吗」 | **I.8：不。** 分级越高，适用带宽越窄（数字驱动被延时锁死在低频大功率） |
| 「怎么选驱动拓扑」 | I.8 表：先看 `t_sw`，再定级；书只对「两级驱动」给了定量收益 |

## S · 步骤

**任务：给一个具体应用选门驱动拓扑并定关键参数。**

1. **先算 `t_sw` 与开关频率**。这一步决定你能不能上高级拓扑（I.8 / A2.2）。**`t_sw` 在 100–500 ns 量级 → 停在第 1–2 级；`t_sw` > 几 μs → 才考虑数字驱动。**
2. **分两段看关断**：`t_d + t_f1` 归驱动；`t_f2` 归器件。**若 `t_f2` 占比大，先回去换器件（`54`/`57`），不要在驱动上折腾。**
3. **至少做到非对称**（`R_on ≠ R_off`）—— 这是零成本的自由度（只多一个二极管）。
4. **算过压预算**：`ΔU = L_σ·di/dt`，其中 `L_σ` **必须含「DC 链路电容电感 + 模块内总线电感」两项**（书 p130 明确列出）。求出允许的 `di/dt`。
5. **若纯 `R_G` 满足不了**，升到**两级驱动**（齐纳阈值 + 单稳态宽度）。**这是唯一有 `−60 %` 定量背书的方案。**
6. **若要更细**，用**可变栅电阻**：只在平台期切大电阻（书 p133 的规则），并配比较器 + 延时。
7. **AGVC 只在「必须严格限 `dV/dt`」时上**（如长电缆电机端的反射过压）。**记住它的代价是转换时间变长、损耗变大**（书 p132）。
8. **短路保护单独设计**：故障检测后加大 `R_G` 软关断；**驱动侧的软关断时间常数转 `31`/`47`**。
9. **回查 `56`**：任何降低 `di/dt` 的措施都会**延长开关时间 → 增大 `E_off`**，与 `56` 的 SCSOA 时间窗要一起核。

## B · 边界

1. **本章只有 7 页，不给任何驱动的电气设计值。** `DESAT` 消隐时间、软关断电流源大小、`R_G` 功率与温升、驱动功率计算、隔离耐压**一律转 `30`/`31`/`47` 与 `references/infineon/`**。
2. **只有「两级驱动 −60 % 过冲」一个定量收益**（书 p130 引 [4]）。AGVC 与可变栅电阻的收益**书只给定性描述**，**不能编百分比**。
3. **p131 与 p132 关于开通侧 `di/dt` 的方向表述互相矛盾**（I.4 末）：p131 说「降低中间电平可降低 `di/dt`」，p132 说「降低中间电平可**增加** `di/dt`」。**本模块判定 p132 为印刷/翻译错误，但引用时必须两句并列。登记 `00-index §6.4` 第 17 项。**
4. **两级驱动的齐纳击穿电压怎么选，书未给。** 只给「按 `V_CE` 触发」的原则（I.3 末）。
5. **单稳态触发器的宽度怎么选，书未给。** 只说「在短时间内关断 T_2」，无量化。
6. **「5 A 摆率」是驱动电流能力，不是 `di/dt`**（I.6）。二者不可混用。
7. **A/B/C 三分类（15/1/0.25 μs）是 1980 年代 GE 产品的历史分类**（书 p129 引 [2][3]），**不是现代 IGBT 的规格体系**。现代器件的 `t_off` 由 datasheet 给。**引用时必须标明这是历史分类。**
8. **图 7.2 的数量级（`t_f1` 从约 1 μs 涨到约 10 μs，`R_G` 从 100 Ω 到 10 kΩ）是本模块从图中读得**，按 `00-index §6` 第 2 条**不可当精确值**；只能引「幂律关系、非线性」这个结论。
9. **本章的 `L_σ` 定义（DC 链路电容电感 + 模块内总线电感）与 `13`（书源一吸收电路）的 `L_σ1 + L_σ2 + L_σ3` 分解口径不同** —— 本章不区分「能否被吸收电容削减」。**做吸收电容设计时必须用 `13` 的口径，不能套本章的 `L_σ`。**
10. **`[8]` 的两级电路、`[9]` 的分段驱动、`[12]` 的闭环驱动都只提到名字，无数据**，本模块不展开。
11. **不承担「驱动拓扑的实现成本」评估**（IC 价格、元件数、PCB 面积）。书只点名了 `UCC27531`、`M81738FP`、`TLP700HL` 三个商品型号（书 p135），**未给任何参数**，本模块不引其性能。
12. **本章不出现在 `E_OFF` 的任何算法里** —— 本章的「损耗增加」都是定性的，**不给能量**。
