# `53` 非对称结构与损耗折中曲线

> **书源层 · Baliga。** 引用须标「据 Baliga `53`（书 pXX）」。
> **本模块是全书设计问题的中心。** 若只能记一件事：**IGBT 的设计不是一个「最优结构」，而是在一条 `E_周期`–`V_ON` 曲线上选工作点。** 非对称结构、透明集电极（`54`）、乃至所有后续章节的默认背景都压在这条曲线上。
> **文本来源**：扫描版 OCR + 原页图目视核对。公式形式已逐式回原页图（PDF p51–p68）确认；**带上下标的数值必须回原页读，OCR 的 `10 13` 之类不可用。**

## R · 原文锚点

> 「如果因封装原因器件的能量损耗需要限制在 100 W/cm² 以下，那么器件的工作频率需要低于 500 Hz，以保证每个周期内能量损耗低于 0.2 J/cm²。同样在开态电流密度为 100 A/cm² 的条件下，**非对称结构 IGBT 器件的工作频率可以高于对称结构 IGBT 器件 5 倍**。这也是非对称结构 IGBT 器件更多地被应用在电动机驱动应用中的原因。」
> — 书 p47

> 「需要指出的是，在**载流子寿命为 10 μs 和缓冲层掺杂浓度为 5×10¹⁷ cm⁻³** 的组合下，器件能量损耗和导通电压降获得了最佳折中。
> 「器件的耗散功率需要限制在 **200 W/cm²** 以下，以保证结温低于 **125 ℃**。」
> — 书 p47 / p49

## I · 骨架

### I.1 非对称结构改了什么（一句话）

**对称结构在背面只有 P+ 集电极；非对称结构在 P+ 与 N⁻ 漂移区之间插入一层 N 缓冲层（场停止层）。**

| | 对称结构 | 非对称结构（本模块） |
|---|---|---|
| 背面叠层 | P+ / N⁻ 漂移区 | P+ / **N 缓冲层** / N⁻ 漂移区 |
| 阻断时电场形状 | 三角形，峰值在背面 P+/N⁻ 结，**穿到漂移区全宽** | **梯形**（缓冲层把电场「顶住」），峰值仍在背面结但电场不穿通 |
| 同样 BV 所需漂移区厚度 | 厚（全宽都要承担电压） | **薄**（只需承担到饱和前的部分） |
| 同 BV 的 `V_ON` 与 `E_OFF` | 高 | **低**（漂移区短 → 存储电荷少 → `E_OFF` 小） |
| 代价 | — | 缓冲层多一道外延工序；**反向阻断能力基本丧失** |

**这个取舍必须讲清**：非对称结构省下的通态与开关损耗，是用**反向阻断能力**换来的。凡是需要双向阻断（交流侧直接串接、电流源型变流、部分矩阵变换器）的场景，非对称结构不能用。

### I.2 三个物理环节（决定 `V_ON`）

`V_ON` 在书里被拆成**三段相加**（式 3.55–3.58）：

```
V_ON = V_P+N_BL  +  V_B  +  V_MOSFET
       ↑J1 结压降    ↑漂移区体压降   ↑MOS 沟道压降
```

| 环节 | 由什么决定 | 设计自由度 |
|---|---|---|
| `V_P+N_BL`（J1 结） | 缓冲层表面空穴浓度 `p_NB(0)`，受**缓冲层掺杂**控制；掺杂越高 → 注入效率 `γ_E` 越低 → 该段压降**升高** | 缓冲层掺杂 `N_NB` |
| `V_B`（漂移区） | 电导调制强弱；漂移区内空穴分布 `p(y)` 由 **载流子寿命 `τ`** 与漂移区宽度 `W` 共同决定 | 少子寿命 `τ`（电子辐照/退火）、`W` |
| `V_MOSFET`（沟道） | 元胞结构（平面/沟槽）、栅压、`J_C,ON` | 元胞设计（见 `51`/`52`） |

**电导调制的强弱由「缓冲层注入」决定，不是由「漂移区本身」决定**——缓冲层在这里起的是**注入效率调节阀**的作用，不只是场停止层。这是非对称结构能同时压 `V_ON` 和调 `E_OFF` 的机理根源。

### I.3 关断时间的因果链（本模块最反直觉的一条）

关断电流波形按式 3.62–3.69 分两段，两段有**完全不同的控制变量**：

| 段 | 物理含义 | 由谁决定 | 书 p43 实测（`τ` = 2/5/10 μs） |
|---|---|---|---|
| `t_V,OFF` | 电压上升段（电流仍接近通态值） | **缓冲层掺杂 + 缓冲层厚度** | **0.615 / 1.06 / 1.40 μs** |
| `t_I,OFF` | 电流拖尾段（电压已建立后的电流下降） | **缓冲层内的载流子寿命** | **0.77 / 1.92 / 3.83 μs** |

**因果分离（书 p43 三组数据实测支撑）：**

1. **加厚缓冲层**（10 → 20 → 30 μm）→ `t_V,OFF` = 1.06 → 0.679 → 0.434 μs（**减半**），而 `t_I,OFF` **恒为 1.92 μs 不动**。
   → 因为拖尾段是缓冲层内的存储电荷在复合，厚度不改复合速率；而电压段由缓冲层的电荷量支撑，厚度直接改电荷量。
2. **加高缓冲层掺杂**（1.0 → 3.0 → 5.0 ×10¹⁷ cm⁻³）→ `t_V,OFF` = 1.06 → 0.648 → 0.424 μs，`t_I,OFF` = 1.92 → 0.821 → 0.523 μs，**两段同降**。
   → 掺杂同时减少缓冲层电荷总量并压缩其有效寿命。

**工程含义**：**如果拖尾是问题，改缓冲层厚度没用，只能降寿命；如果电压上升段是问题，加厚/加掺杂缓冲层最快。** 这一条能直接判掉很多「先加厚缓冲层试试」的错误方向。

### I.4 折中曲线的三个自由度

按书 p47–p49（图 3.35–3.38）的顺序，同一族曲线被三个旋钮分别推动：

| 旋钮 | 变化方向 | 结果（书 p47–p49） |
|---|---|---|
| **载流子寿命 `τ`** | 10 → 5 → 4 → 3 → 2 μs（递减） | 曲线**向右上抬**（同 `V_ON` 下 `E_周期` 变大）→ **寿命越长越好，直到最佳点** |
| **缓冲层厚度** | 10 → 20 → 30 → 40 → 50 μm | 曲线**向左下移**（同 `V_ON` 下 `E_周期` 变小）→ 越厚越好，但缓冲层厚 = 漂移区有效变短，会牺牲 BV |
| **缓冲层掺杂** | `J_C,ON` 100 / 50 / 25 A/cm²（改掺杂实现） | 开态电流密度**减半** → 工作频率**约翻倍**（`900 Hz` → `4000 Hz` → `10 kHz`） |

**最佳折中**：`τ = 10 μs` + `N_NB = 5×10¹⁷ cm⁻³`（书 p47 明写）。注意 10 μs 已是测试序列里**最长**的，这说明**书给的最佳值落在测试区间的边界上**——它不是一个真正的内部极大点，往后还有多少空间本书没给。

### I.5 器件设计 → 系统选型：`P_L` 与 `f_max`（式 3.71 / 3.72）

书的最后一步是把器件曲线接到**系统约束**上，两条式子必须成对使用：

```
P_L = 0.5 · J_C,ON · V_ON  +  E_OFF · f          (3.71)
f_max = ( P_L,Max − 0.5 · J_C,ON · V_ON ) / E_OFF  (3.72)
```

| 项 | 含义 | 书给的数 |
|---|---|---|
| `0.5·J_C,ON·V_ON` | 通态损耗（**0.5 是 50 % 占空比**，原文「忽略导通损耗」指忽略开关瞬态期间的导通损耗） | — |
| `E_OFF · f` | 每周期开关能量 × 频率 = 单位面积开关损耗功率 | — |
| `P_L,Max` | 散热能力上限 | **200 W/cm²**（对应 `T_j < 125 ℃`） |

**这是 IGBT 选型的唯一硬闭环**：`f_max` 不是芯片属性，而是 `(散热能力 − 通态损耗) / 开关能量` 的函数。同一个芯片，散热从 200 W/cm² 降到 100 W/cm²，`f_max` 直接掉一半。**任何「这颗管子能跑到多少 Hz」的答案，不写散热假设就是没答。**

## A1 · 案例：3000 V 非对称 IGBT 的完整设计点

**书 p47–p50 给出的基准器件**（图 3.35–3.39 共用这套参数）：

| 参数 | 值 |
|---|---|
| 阻断电压 | 3000 V |
| 集电极电压（测试） | 2000 V |
| 开态饱和电流密度 `J_C,ON` | 100 A/cm² |
| 漂移区宽度 `W` | 280 μm |
| 漂移区掺杂 | `1×10¹³ cm⁻³` |
| 缓冲层厚度 | 10 μm |
| 缓冲层掺杂 | `1×10¹⁷ cm⁻³`（基准） |

**书从这套参数推出的系统级结论（逐条对照，不要混用）：**

| 约束 | 条件 | 结论 | 出处 |
|---|---|---|---|
| `E_周期 ≤ 0.2 J/cm²`，`P_L ≤ 100 W/cm²` | 基准结构、`P_L` 限 100 W/cm² | **`f < 500 Hz`** | 书 p47 |
| 同上，改 `τ = 10 μs` + `N_NB = 5×10¹⁷` | `E_周期 ≤ 0.1 J/cm²` | **`f` 可达 1000 Hz** | 书 p47 |
| 同上，与**对称结构**比 | `J_C,ON = 100 A/cm²` | **`f` 高 5 倍** | 书 p47 |
| `P_L ≤ 200 W/cm²`（`T_j<125 ℃`），式 3.72 | `J_C,ON = 100 A/cm²`、`N_NB = 1×10¹⁷` | **`f_max = 900 Hz`** | 书 p50 |
| 同上 | `J_C,ON = 50 A/cm²`、`N_NB = 2×10¹⁸` | **`f_max = 4000 Hz`** | 书 p50 |
| 同上 | `J_C,ON = 25 A/cm²` | **`f_max = 10 kHz`** | 书 p50 |

**注意 500 Hz 与 900 Hz 的差别不是矛盾，是两组不同约束**：前者 `P_L ≤ 100 W/cm²` 且按折中曲线读图得 `E_周期 ≤ 0.2 J/cm²`；后者 `P_L ≤ 200 W/cm²` 用式 3.72 反解。**引用时必须带约束，只报频率数字就是错的。**

**第三条结论值得单独记**：`J_C,ON` 从 100 → 25 A/cm²（降 4 倍），`f_max` 从 900 Hz → 10 kHz（升 11 倍）——**不是线性的**，因为 `E_OFF` 本身随电流密度下降超线性。但代价是**芯片面积要放大约 4 倍**才保住同样的电流等级（书 p49 明写）。这就是「高频」与「硅面积」的直接兑换率。

## A2 · 本地复算

### A2.1 `t_OFF = 2.3 · τ_p,NB` 的复算与边界（式 3.69）

书 p41 给出：**`t_OFF = τ_p,NB · ln(10) = 2.3 · τ_p,NB`**。

代入书 p43 的实测 `τ` 序列：

| `τ_p,NB` | 式 3.69 预测 `t_OFF` | 书 p43 实测 `t_V,OFF + t_I,OFF` | 偏差 |
|---|---|---|---|
| 2 μs | 4.6 μs | 0.615 + 0.77 = **1.385 μs** | 预测大 **3.3 倍** |
| 5 μs | 11.5 μs | 1.06 + 1.92 = **2.98 μs** | 预测大 **3.9 倍** |
| 10 μs | 23.0 μs | 1.40 + 3.83 = **5.23 μs** | 预测大 **4.4 倍** |

**结论：式 3.69 与书自己的表对不上，偏差 3.3–4.4 倍，且偏差随 `τ` 增大而增大。不许把 2.3·τ 当定量公式用。**

原因（可判定的）：
- 式 3.69 的定义是**电流从通态值衰减到 10 % 的时间**（`ln 10` 来自 90 % 衰减），属**纯拖尾段**的定义；
- 书 p43 表里 `t_I,OFF` 的测量窗口按惯例是**从 90 % 到 2 %**（与 `34-formula-index` 登记的 `Q_rr` 窗口一致），分母不同；
- 且 2.3·τ 假设**单一时间常数**，而实际缓冲层内 `p(y)` 是双曲正弦分布（式 3.62–3.69 组），不是单指数。

→ **本模块的立场：`2.3·τ` 只能作量级估算（σ 内 3–4 倍），凡是要写进规格书的 `t_OFF`，必须实测。**

### A2.2 式 3.72 的复算（用书 p50 三个点反验）

`f_max = (P_L,Max − 0.5·J_C,ON·V_ON) / E_OFF`，取 `P_L,Max = 200 W/cm²`。

**书没给逐点的 `V_ON` 与 `E_OFF`**，只能做**反向一致性检查**——用书报的 `f_max` 反推要求的 `E_OFF`：

| `J_C,ON` | 书报 `f_max` | 若 `V_ON` 取图 3.38 读数的量级 2.0 V | 反推所需 `E_OFF ≤` |
|---|---|---|---|
| 100 A/cm² | 900 Hz | 通态项 `0.5×100×2.0 = 100 W/cm²` | 余 100 / 900 = **0.111 J/cm²** |
| 50 A/cm² | 4000 Hz | 通态项 `0.5×50×2.0 = 50 W/cm²` | 余 150 / 4000 = **0.0375 J/cm²** |
| 25 A/cm² | 10 kHz | 通态项 `0.5×25×2.0 = 25 W/cm²` | 余 175 / 10000 = **0.0175 J/cm²** |

反推出的 `E_OFF` 从 0.111 → 0.0375 → 0.0175 J/cm²，与图 3.38 曲线在同一 `V_ON` 下随 `J_C,ON` 下降而下降的趋势**方向一致**；数量级也与书 p45 给的「`τ=10 μs` 时 `E_OFF ≈ 141+? mJ/cm²`」同量级（0.1 J/cm² 级）。**这只是一致性检查，不是复现——`V_ON` 是我从图上取的量级，不是书给的数。**

### A2.3 一条可直接用的判据：`E_OFF` 的反算上限

由式 3.72 直接得工程判据（**这是本模块最该被记住的可执行式**）：

```
E_OFF ≤ ( P_L,Max − 0.5·J_C,ON·V_ON ) / f
```

给定「散热能力 `P_L,Max`」「工作点 `J_C,ON`、`V_ON`」「目标频率 `f`」三项，就能反推**允许的最大单脉冲关断能量**，再去芯片 datasheet 对照。反过来，datasheet 的 `E_off` 一定，`f` 的上限立刻锁死。

## S · 步骤

**任务：给一个「BV + 频率 + 散热」约束下的非对称 IGBT 选设计点。**

1. **先锁约束的三角**：`BV`（决定 `W`、`N_D`）、`P_L,Max`（散热能力，W/cm²）、`T_j,max`。三个缺一个，后面全是猜。
2. **定漂移区**：按 `BV` 给 `W` 与 `N_D`（书基准点：3000 V → `W = 280 μm`、`N_D = 1×10¹³ cm⁻³`）。阻断设计细节在 `52`。
3. **定缓冲层**：厚度 10 μm 起步（书基准），掺杂 `1×10¹⁷` 起步。要压 `t_V,OFF` → 加厚或加掺杂；要压 `t_I,OFF` → **只能降寿命**（I.3）。
4. **选载流子寿命 `τ`**：这是折中曲线的主旋钮。书的最佳点是 `τ = 10 μs` + `N_NB = 5×10¹⁷`，但**该点落在测试区间边界**，实际应做 `τ` 扫描（电子辐照剂量 + 退火）取曲线膝点。
5. **查折中曲线定工作点**：在 `E_周期`–`V_ON` 图上画当前设计点，与「最佳折中曲线」（图内虚线）比距离。距离大 = 设计有改进空间。
6. **闭环校核频率**：用 A2.3 的 `E_OFF ≤ (P_L,Max − 0.5·J_C,ON·V_ON)/f`。不满足 → 回第 4 步降 `τ`，或降 `J_C,ON`（要同时接受面积放大）。
7. **申报时写全三件**：设计点参数（`W`、`N_D`、`N_NB`、缓冲层厚度、`τ`）+ `P_L,Max` 假设 + 由式 3.72 得出的 `f_max`。**三者缺任一，这个 `f_max` 不成立。**

## B · 边界

1. **本模块不覆盖阻断电压设计本身。** `BV` 与 `W`/`N_D` 的定量关系在 `52`（对称）与本章 3.3.1（非对称），本模块只引用结论。
2. **式 3.69（`2.3·τ`）与实际表差 3.3–4.4 倍，禁止定量使用**（A2.1）。这是**「书给了但不可直接用」**类条目，按 `34-formula-index §12` 的口径登记，引用时不许写「据式 3.69 计算得 `t_OFF = …`」。
3. **图 3.34–3.39 的曲线读数不可引。** 本模块引用的所有数字都来自**正文叙述**或**表**；图只用于确认曲线族的方向（左移/右移/上抬）。要从图上读具体值，必须回 PDF p65–p68 原页目视并注明「由图读得」。
4. **OCR 在本书公式区系统性丢失负号与上下标。** 例：`1×10⁻¹³` 被识别成 `1×10 13`、`10¹⁷` → `10 7`。本模块所有指数形式均以原页图核对为准；**未见原页的一律不写。**
5. **书未给缓冲层厚度厚化的阻断电压代价。** I.4 说「越厚越好，但会牺牲 BV」，而**牺牲多少书没给数**——凡要定量，须自行做阻断仿真，不许外推。
6. **本层不乘 1/π。** 折中曲线的 `E_周期` 是**单脉冲能量**，与 `volke-hornkamp` 层式 3.16/3.28 的正弦 VSI `1/π = 0.3183` 口径**不同**。把两者混算会得出差 3.14 倍的结论。并列登记见 `00-index §5 P2`。
7. **`P_L` 式（3.71）忽略导通瞬态期间的损耗**，原文如此。`0.5` 系数是 **50 % 占空比**假设；占空比一变，该系数必须改——书没给一般式，只有这一特例。
