## I · 骨架

### I.1 为什么要封装：三个理由（书 p117）

1. **电气** —— 半导体器件需要电流端口；
2. **热** —— 通态与开关损耗产生的热必须散出以维持结温；
3. **环境隔离** —— 防湿度、腐蚀、电荷导致的长期退化。

**演化谱系（书 p117，本节唯一的时间线，值得整段记住）**：

```
分立三端口（TO-220 型）
  → 芯片 + 续流二极管合成三端口（逆变器用）
  → 功率模块：单臂 → 整 H 桥 → 六管三相（6 IGBT + 6 FWD）
  → 驱动与控制电路一并集成 = IPM
```

> **这条线的驱动力不是「技术更好」，而是「系统级寄生电感与元件数」**：每多一个外置连接，就多一段互感。**读懂这条线要看电感，不是看封装外形。**

### I.2 分立封装：焊料的六条硬约束（书 p117–118）

**式 6.1 之外的定量内容全在焊料这一节，且都是可引的硬数**：

| 约束 | 数值 | 理由 |
|---|---|---|
| 焊料熔点**下限** | **≥ 160 ℃** | 芯片结温典型高达 150 ℃，须防「正常工作二次熔化 + 裸片脱落」 |
| 焊料熔点**目标** | **≈ 200 ℃** | 兼顾「低到减小 CTE 失配应力」与「高到不重熔」 |
| 共熔合金 | **单一熔点**（固相线 = 液相线） | 非共熔合金有「可塑相」区，**该温度范围必须尽可能窄** |
| 其余要求 | **低弹性模量**（吸收热应力）、**高热导率**（导热至铜底）、**低电阻率**（减小焊料层压降） | — |
| 背面金属化 | **Ti-Ni-Ag / Cr-Ni-Ag / Al-Ti-Ni-Ag** | **Ti、Cr、Al 作欧姆接触（接触电阻典型 < 10⁻⁶ Ω·cm²）；Ag 层促焊料浸润；其余金属层作阻挡层** |
| 无铅化 | **2006 年欧盟禁铅** | — |

> **「Ti/Cr/Al 的接触电阻典型值小于 `10⁻⁶ Ω·cm²`」这个数在书里是一句话带过的，但它是本层唯一的「芯片背面欧姆接触」定量数据**，与书源一的 DBC/AMB 侧参数不重叠，可放心引。**注意原页是 `10⁻⁶` 量级**（OCR 丢指数，已核）。

### I.3 BGA：四个定量收益（书 p119–120）

**分立封装三个缺点的因果（书 p119，这句是全章封装批判的总纲）**：
1. 引线键合 → **串联电阻 + 串联电感**；
2. 引线键合 → **限制芯片可靠性**；
3. 引线键合 → **限制散热**（热量只能从底部/集电极散出 → 「相当大的热阻」）。

**BGA 的做法**：发射极与栅极的**铝线键合换成球格阵列**，焊点置于**约 1 mm 见方**的衬垫上；**焊点下金属（UBM）= Ti/Ni/Ag，位于铝金属镀层之上**。
**回流焊**：**250 ℃**（高于焊帽熔点 221 ℃、低于焊锡球 Sn/Pb 的 268 ℃），**还原性气氛 96 % N₂ / 4 % H₂** 防氧化。

| 收益 | 数值 | 出处 |
|---|---|---|
| 通态电压降 | **−20 %** | 书 p120 |
| 串联电阻 | **−30 %** | 书 p120 |
| 双面散热热阻（预计） | **−30 %** | 书 p120 |
| 规格 | 「小得多」的芯片级封装 | 书 p119（定性） |

> **−20 % 的 `V_ON` 是本章最容易被误读的数**：它**不是**芯片变好了，而是**发射极串联的铝线电阻被 BGA 消除了**。按 `56`/`58` 的口径，`V_Module = V_Chip + R_CC'+EE'·I`（书源一 `34` 的端子值/芯片值区分），**BGA 改的正是 `R_EE'`**。→ **这条与 `34` 的「端子值 vs 芯片值」纪律直接对接**，是本章对封装工程师最有用的一条。

### I.4 基本功率模块：五个子系统与各自的硬指标（书 p120–122）

**结构链条**：基板 → 陶瓷衬底 → 芯片（IGBT + FWD）→ 引线键合互连 → 端子 → 硅凝胶 → 塑料外壳。

**① 基板（书 p120–121）—— 四项硬指标 + 一项工艺指标**：

| 指标 | 要求 |
|---|---|
| 热导率 `λ` | **> 150 W/(K·m)** |
| 表面光洁度 | **< 2 μm** |
| 弯曲性 | 「可复原的弯曲性」（与散热层紧密接触） |
| CTE | 须与绝缘陶瓷匹配 |
| 抗张/挠曲强度 | 足够高以可塑型/弯曲 |
| 密度 `ρ` | **要小**（减重） |

**典型材料：37 % Al / 63 % SiC，60 % Cu / 40 % C**（金属基复合材料）。
> **⚠ OCR 把前者读成「37 % 铝 / 76 % 碳化硅」，原页为 `37 % 铝 / 63 % 碳化硅`；`60 % 铜 / 40 % 碳` 正确。** 已核。

**② 陶瓷（书 p121）—— 三种材料的三维对比，本节最值钱**：

| 材料 | 热导率 | CTE | 成本 | 定位 |
|---|---|---|---|---|
| **Al₂O₃** | 最低 | **与 Si 严重失配** | **最低**、技术最成熟、易金属化加工、无毒 | 最常用；**大功率不合适** |
| **AlN** | **比 Al₂O₃ 高约 6 倍** | 与 Si 更匹配 | **贵 4 倍** | 大功率首选 |
| **Si₃N₄** | 较高 | **与 Si 十分匹配** | **贵 2 倍** | **更适合「无基板」时作独立衬底** |

> **三个「贵」的关系是本表的关键**：`AlN = 4×Al₂O₃`、`Si₃N₄ = 2×Al₂O₃`。→ **Si₃N₄ 的价格正好在中间，而它的 CTE 匹配最好** —— 所以「无基板模块」选 Si₃N₄ 不是偶然（书 p121 原话：「氮化硅更适合于在没有基板的情况下作为独立衬底」）。
> **注意：本层给的是「倍数」不是「绝对值」，不能换算成元/kg。**

**③ 双焊料的三温度窗口（书 p121，本节最硬的工程约束）**

| 层 | 焊料 | 熔点 |
|---|---|---|
| **芯片 → 陶瓷**（先做，高熔点） | 96.5 % Sn / 3.5 % Ag | **≈220 ℃** |
| **陶瓷 → 基板**（后做，低熔点） | 92.5 % Pb / 5 % Sn / 2.5 % Ag | **≈180 ℃** |
| 差值 | — | **≥ 40 ℃**（否则组装陶瓷时芯片会脱落） |
| 组装全程最高温度 | — | **< 350 ℃** |

> **`40 ℃` 这个差值是**顺序决定的**：后一道工序的峰值温度必须低于前一道焊料的固相线，否则芯片会「浮起来」。而且组装全程 < 350 ℃ 封死了「用高温焊料换可靠性」的路 —— 这正是后来**银烧结（>200 ℃ 仍稳定）**要解决的问题，**但烧结不在本书范围**（见 B 段）。
> **书里 96.5Sn/3.5Ag 在 p121 写作「96.5 % 锡/2.5 % 银」（OCR 也说「96.5 % 锡/2.5 % 银」），与 p118 表 6.1 的 `96.5 % Sn / 3.5 % Ag` 不一致。按表 6.1 取 `3.5 % Ag`**（表 6.1 已回原页核对）。**这是本层的第 2 处书内自相矛盾。**

**④ 互连与封装材料**
- 铝线：**电阻率 `2.65×10⁻¹⁰ Ω·cm`**（书 p121，已回原页；OCR 丢负号）；楔形键合适配大直径导线；
- **密封剂（书 p122）**：硅凝胶 / 环氧 / 聚氨酯 / 腈纶；要求 **介电强度 > 250 V/mil**、**固化不收缩**（否则拉断导线）、**热循环不开裂**；**硅凝胶因高纯度、高化学稳定性、低毒性、柔软（减小对芯片与导线应力）成为最常用**；
- **外壳**：终端的爬电与**高压电弧放电**必须考虑。

**⑤ 寄生电感（书 p122，两个可直接引的数）**

| 对象 | 寄生电感 |
|---|---|
| **24 mm / 20 mil 单根铝线** | **10–16 nH** |
| **S 形端子 → L 形端子** | **约 −50 %** |

> **这两个数连起来是本模块最有用的工程判断**：**一根普通铝线就有 10–16 nH**。按 `13`（书源一吸收电路）的口径，`U_spike = L_σ·di/dt`，在 `di/dt = 5 kA/μs` 下 15 nH 就是 **75 V** 过压 —— **而这只是一根线**。所以「多根并联 + 缩短路径 + L 形端子」不是优化项，是必选项。**这是本层唯一能与书源一 `13` 的 `L_σ` 直接相加的定量桥梁。**

### I.5 扁平压接：用「没有键合线」换可靠性（书 p122–123）

**做法**：芯片集电极侧焊在钼基板上；发射极侧用**带钼接触板的压力触点**（不焊，压接）；**唯一保留键合的地方是栅电极**（从侧面引出）。**选择钼的理由：CTE 与硅接近。**

**书给的两个实例**：

| 实例 | 配置 | 能力 |
|---|---|---|
| 图 6.6 | **11 个 IGBT + 5 个 FWD** | **1800 A / 2.5 kV** |
| 图 6.7（带修复技术） | **9 个 IGBT + 3 个 FWD**，每芯片 **20 mm × 20 mm** | **1000 A / 2.5 kV** |

**芯片修复技术（书 p123）—— 本节最有价值的工程方法**：

```
单个 20×20 mm 大芯片 → 划分为 36 个单元，每单元自带栅极与发射极接触区
  → 测试找出「栅源短路」的单元
  → 用聚酰亚胺层的图形：把失效单元的发射极与所有单元发射极相连 + 把失效单元的栅源短路
  → 剩下的单元继续工作
```

**定量规则（书 p123，可直接引）**：
- **每个单元可在超过芯片额定电流 20 % 的状态下工作**；
- → **36 个单元中可以去除 4 个缺陷单元**（`1/0.8 = 1.25`，`36/1.25 = 28.8` → 至少 29 个完好即可；36−29 = 7 个可去？**书说 4 个，按 20 % 过载反推是 7 个**）。

> **⚠ 这里书给的「4 个」与「20 % 过载」的反推不自洽**：36 单元、每单元允许 +20 % → 总电流不变的条件下可缺 `36×(1−1/1.25) = 7.2` 个。**书给 4 个，偏保守 44 %。** 本模块按书报值 4 引用，**但必须知道反推给的是 7，书可能留了额外裕量（或「20 %」指的是别的口径）。**留在本章 `B5`，不入登记表**（这是本层反解推断，不是书内两数冲突）。**
- **该模块热阻比传统引线键合模块小 40 %**（书 p123）；
- 该思想已扩展到 **4.5 kV** 模块（工业/牵引/电力传输）；
- **另一条路**：用**熔丝**自动隔离栅源短路的 IGBT（书 p123 引 [8]）。

### I.6 无基板模块：一个几何换热的定量例子（书 p123–124）

**动机**：减重减成本 → 去掉金属基板，DCB 直接装散热板。**但去掉基板后机械强度不够 → 必须加厚 DCB → 热阻剧增。** 这是「减重必有代价」的典型。

**书给的解法与数（图 6.8，可直接引）**：

| 方案 | 陶瓷厚度 | 铜厚度 | 热阻 |
|---|---|---|---|
| 传统 | **0.635 mm** | **0.25 mm** | 基准 |
| **新** | **0.32 mm** | **0.5 mm** | **减小 2 倍（即 −50 %）** |

**原理（书 p123 原话）**：「铜比陶瓷（氧化铝）基片具有更好的导热性」→ **把厚度从陶瓷移到铜上，热量更易横向铺开后向下传导**。
> **这是一个「不是靠新材料、只靠调厚度」的改进**，而且书给的是「热阻减小两倍」这种模糊表述（是 −50 % 还是 ÷2？中文里「减小两倍」= 变成 1/3 还是 1/2 有歧义）。**本模块按「减半（−50 %）」理解，与 `λ_Cu/λ_Al₂O₃ = 400/24 ≈ 17` 的物理一致（热阻主要在陶瓷层）。** 见 B 段。

**EV/HEV 应用（书 p124）**：**650 V / 300 A**，非对称结构，**晶圆厚度仅 70 μm**；薄片在两面加焊点时**容易弯曲**；已有 **200 kV·A** 承载能力的集成 70 μm 器件无基板模块。

### I.7 IPM：从 DIP 到智能功率单元（书 p124–126）

**三代演化（书 p124）**：分立封装 → PCB 搭建 → 功率芯片集中到单模块（保护电路在 PCB 上）→ **功率 + 控制保护芯片封在一起**（面向制冷、空调、洗衣机等低功率）。

**DIP 型（书 p124–125）**：

| 项目 | 值 |
|---|---|
| 额定 | **3–30 A / 600 V** |
| 热阻 | **3 A → 4.5 ℃/W；30 A → 1 ℃/W** |
| 衬底 | 直接键合铜（DBC） |
| 集成内容 | IGBT + FWD + 无源器件 + 控制芯片 + **HVIC（高压电平移位）** |

> **「3 A 时 4.5 ℃/W、30 A 时 1 ℃/W」是本章唯一给出「热阻随电流连续变化」的数据对**。它说明**小电流封装的热阻几乎全在封装，不在芯片** —— 电流越小，芯片面积越小，封装热阻占比越高。**这与 `15`/`27`（书源一热路）里「`R_th,JC` 由封装决定、与芯片面积弱相关」的直觉一致，但给出了斜率。**
> **HVIC 的工程价值（书 p126）**：对桥式上管做电平移位，**消除光耦**。→ 这是「IPM 为什么便宜」的根因：**省掉 6 个光耦 + 6 路隔离电源**。

**智能功率单元（IPU，书 p126）**：面向 EV/HEV，含 **DC-DC 变换器 + 预驱动器 + DC 连接电容 + 片上电流/温度传感器**。
**关键革新**：**电解电容换成固态电容，体积只有 1/10**；**电容靠近 IGBT → 寄生电感减小 → 开关过冲电压更小**。
> **「电容靠近 IGBT」这一条与 I.4 ⑤ 的 10–16 nH 直接对应** —— 这就是封装级解决 `L_σ` 的办法。**注意它与 `13`（书源一吸收电路）是同一物理问题的两个层面：`13` 在模块端子外加吸收电容（受 `L_σ3` 天花板限制），IPU 是把电容搬进模块内（绕过 `L_σ1+L_σ2`）。** 见 B 段。
> **`SEMiX` 系列用弹簧触点替代键合线**（书 p126，只提了一句，无数据）。

### I.8 可靠性：式 6.1（本模块唯一可代数、且全章价值最高的式子）

**两个失效机理（书 p127）**：

| 机理 | 起因 | 自加速机制 |
|---|---|---|
| **焊点空洞** | 芯片与 DBC 陶瓷 **CTE 不同 → 剪应力** | 空洞变大 → **阻碍散热 → 芯片温度更高 → 空洞更大** |
| **引线键合脱离** | 热循环 | **一条断 → 其余电流增大 → 加速其余脱离**（书 p127 原话：「隐性」） |

> **两个机理的共同点是「正反馈」** —— 这是本章最本质的洞察：**IGBT 模块的可靠性失效不是线性的，是自加速的**。所以「剩余寿命」不能按线性损耗外推。
> 与书源一 `28`（功率循环）的对照：`28` 给的是 `ΔT_j` / `T_m` / `t_on` 的多参数模型与 AQG 324 的试验矩阵；**本章的式 6.1 是单参数（只 `ΔT`）的极简式**。**两者必须并列：式 6.1 用于「快速排序/量级判断」，`28` 用于「认证判据」。**

**式 6.1（书 p127，已回原页确认）**：

```
N_f = a · (ΔT)^(−n)
```

| 参数 | 值 | 来源 |
|---|---|---|
| `a` | **`1.04×10¹⁵`** | 单一铝线键合的功率循环试验平均 |
| `n` | **5.36** | 同上 |
| `ΔT` | 热循环中的温度漂移 | — |
| 模型基础 | **双金属模型 + 塑性应变 Coffin-Manson** | 书 p127 |

**书报的 MTTF 三点（书 p127，可直接引）**：

| `ΔT` | 书报 MTTF |
|---|---|
| **20 K** | **100 年** |
| **30 K** | **18 年** |
| **40 K** | **5 年** |

**牵引应用的两个背景数（书 p127）**：
- 车辆牵引要求「**30 年工作时间故障率 < 100 FIT**」；
- **有轨电车每年 52 周 × 每周 130 h → 模块须经受 300 000 次循环**（书引 [16]）。

**钼缓冲层的定量收益（书 p127）**：`Si` 与 `Mo` 的 CTE 分别为 **`3×10⁻⁶ /K`** 与 **`5×10⁻⁶ /K`**（书原文，已回原页；OCR 丢负号）→ 接近 → 热应力减小；**每芯片尺寸定制为 `2.15 cm × 2.15 cm`；在 10 000 次、`ΔT = 70 K` 的功率循环后器件性能无变化**。

## A1 · 案例：把式 6.1 用在一个具体使命剖面上

**使命剖面（书 p127 引 [16] 的有轨电车例）**：每年 `52 × 130 = 6760 h`，须 300 000 次循环 → **平均每 `6760×3600/300000 ≈ 81 s` 一次循环** → 折算「每小时约 44 次循环」。

**任务：给定 `ΔT = 30 K`，用书报 MTTF = 18 年，反推该剖面下 18 年对应多少次循环。**

`18 年 × 300 000 次/年` …… **⚠ 书没说「300 000 次/年」，只说「必须经受 300 000 次循环」。**
→ 若按「300 000 次 = 全寿命」，则 `ΔT=30 K` 下书报 18 年对应 **300 000 次**；由式 6.1：`N_f = 1.04×10¹⁵ × 30^(-5.36) = 1.258×10⁷` 次。
→ **`1.258×10⁷` 次 与 `3×10⁵` 次相差 42 倍。** 这说明：**式 6.1 的 `N_f` 是「单一铝线键合」的失效周期数，而 MTTF 是「整模块（含许多键合）」的平均无故障时间** —— 两者的桥接方式书未给（「该模型可以被应用于含多个 IGBT 模块的平均无故障时间分析，每个模块包含许多引线接合」，但没有给并联/串联的统计式）。

→ **结论：式 6.1 的 `a`、`n` 可用于「相对比较」（同一模块不同 `ΔT` 的寿命比），不可用于「绝对寿命预测」**，因为「从 `N_f` 到 MTTF」缺一个未给出的统计桥。见 B 段。

## A2 · 本地复算

### A2.1 式 6.1 的「指数 5.36」在本模块内的自洽性检验

**⚠ 先验：`MTTF` 与 `N_f` 的关系书未给，故不能用 MTTF 比值直接验式子。** 改为**反查书自身的 MTTF 比值是否与 `N_f` 比值一致**：

| 对比 | 式 6.1 预测的 `N_f` 比值 | 书报 MTTF 比值 | 偏差 |
|---|---|---|---|
| 20 K → 30 K | `(20/30)^(−5.36) = **8.79**` | `100/18 = **5.56**` | 预测降得更快（1.58 倍） |
| 30 K → 40 K | `(30/40)^(−5.36) = **4.67**` | `18/5 = **3.60**` | 预测降得更快（1.30 倍） |
| 20 K → 40 K | `(20/40)^(−5.36) = **41.1**` | `100/5 = **20.0**` | 预测降得更快（2.05 倍） |

→ **式 6.1 的 `n = 5.36` 与书报的三个 MTTF 点系统性不一致，且方向一律是「式子比书报数值更陡」。**
**可能解释（本模块推断）**：`MTTF ≠ N_f`，中间有一个随 `ΔT` 变化的因子（例如循环频率、占空比、多键合并联的统计最小寿命）。**书没有给这个因子。**
→ **落地判定：式 6.1 的 `n = 5.36` 只能用于「同一实测数据集内的相对斜率校验」，不能用来从一个已知寿命点外推到另一个 `ΔT`** —— 用 20 K 的 100 年外推 30 K，会得到 `100/8.79 = 11.4` 年（书报 18 年），**低估 37 %**。**这是本模块最重要的复算结论，且它是负面的。** 登记 `00-index §6.3` 第 7 项（「同一事实两个数」族）。

### A2.2 表 6.1 的塑性区域自洽（已闭合）

`液相线 − 固相线`：`190−183=7` ✅、`266−183=83` ✅、`280−275=5` ✅、`180−180=0` ✅、`221−221=0` ✅。**五条全中。这是表 6.1 抄写正确性的判据。**

### A2.3 无基板模块「热阻减小两倍」的量级验证

书给的几何：陶瓷 `0.635 mm → 0.32 mm`（**减薄约 2 倍**），铜 `0.25 mm → 0.5 mm`（**加厚 2 倍**）。
`λ_Al₂O₃ = 24`、`λ_Cu = 400` W/(K·m)（表 6.3）。
单层热阻（面积归一）`R = d/λ`：
- 陶瓷：`0.635×10⁻³/24 = 2.65×10⁻⁵`；`0.32×10⁻³/24 = 1.33×10⁻⁵`
- 铜：`0.25×10⁻³/400 = 6.25×10⁻⁷`；`0.5×10⁻³/400 = 1.25×10⁻⁶`

| 方案 | 陶瓷 + 铜 = 总（K·m²/W） |
|---|---|
| 传统 | `2.71×10⁻⁵` |
| 新 | `1.46×10⁻⁵` |

→ **比值 1.86，接近书说的「减小两倍」**（若是 −50 % 即比值 2.0）。
**结论：书这句「热阻减小两倍」在「铜+陶瓷」两层串联的简化模型下，物理上成立（1.86 vs 2）。**
> **注意这个复算做了两个简化**：① 忽略铜的横向铺开（实际会更好）；② 忽略焊料层与界面。**所以 1.86 是保守下界，与书报的「2 倍」方向一致、量级吻合。** **这是本模块唯一一个「书给的定性表述被定量复现」的例子。**

### A2.4 24 mm 导线的电感与过压的换算

`L = 15 nH`（取 10–16 的中值）、`di/dt = 5 kA/μs` → `U = 15×10⁻⁹ × 5×10⁹ = 75 V`。
→ 在 1200 V 母线上是 **6 %** 的过压；在 600 V 母线上是 **12.5 %**。
> 这个换算是本模块自设的 `di/dt`，**不是书给值**；只用于说明「单根线的电感不可忽略」这个量级。

## S · 步骤

**任务：从应用规格选封装形态并定关键几何。**

1. **先按电流/电压划形态**（书 p128 总结）：**`1–10 A / 600–1200 V` → 分立（TO-220/TO-3PN、TSON-8、SOP-8）**；更大 → 模块；家电紧凑 → DIP；EV/HEV → IPM/IPU。
2. **定热阻预算**：分立 `≈1 ℃/W`；DIP 按电流插值（`3 A→4.5`、`30 A→1`）；模块按 `−40 %`（扁平压接）/`−50 %`（无基板）相对传统折算。**别忘脉冲工况要乘 `Z_thjc`（图 6.3 的占空比曲线）。**
3. **定焊料体系**：满足「熔点 ≥160 ℃ + 目标 200 ℃ + 塑性区尽量小」，模块必须**双焊料且差 ≥40 ℃**。**共熔优先**（表 6.1 的 `96.5Sn/3.5Ag` 与 `71Sn/25Bi/4Ag` 塑性区均为 0）。
4. **定互连**：铝线按表 6.2 查载流，**不要按截面积外推**；**掺 1 % Mg**；发射极多根并联且**均匀分布**（书 p99「避免小尺寸金属线、保留垂直电流路径」）。
5. **算寄生电感**：`n` 根线并联 → `L/n`（近似）；端子形状 `S → L` 再 −50 %。**与 `13` 的 `L_σ` 预算相加时，务必区分「模块内」与「模块外」。**
6. **选陶瓷**：大功率 → `AlN`；无基板 → `Si₃N₄`；成本优先 → `Al₂O₃`（但**不用在大功率**）。
7. **定灌封**：硅凝胶（柔软、高纯、低毒）；**要求介电强度 > 250 V/mil**；**固化不得收缩、热循环不得开裂**。
8. **寿命判据**：**只用式 6.1 做相对比较**（同模块不同 `ΔT`），**不许从一个 `ΔT` 的实测寿命外推到另一个 `ΔT`**（A2.1）。认证口径转 `28`。
9. **大芯片时考虑修复方案**（I.5）：36 单元 + 聚酰亚胺，或熔丝隔离。
