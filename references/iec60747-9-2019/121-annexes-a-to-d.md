# 121 · IEC 60747-9:2019 规范性附录 A–D（V_CE(sus) 测量 / 电感负载关断 / FBSOA 两法 / 管壳不破裂）

> **层归属**：IEC 60747-9:2019 标准层；门：**A**（器件与应力），跨 **G**（极限值评估方法）与 **H**（损坏性试验边界）
> **页引用**：用 Annex A–D 附录号。条文见 §6.3 引用与 Annex 详述；本文件为附录层的整合视图。
> **R·原文锚点**

## R·原文锚点
- **Annex A**：`V_CE(sus)`（集电极-发射极维持电压）测量法——在指定 I_C、T_j 下测维持电压，用于 SOA 上边界与雪崩/维持特性确认。
- **Annex B**：电感负载关断电流法（inductive load turn-off current method）——测关断过程 I_C 上升/拖尾与关断安全工作边界，是 §6.3 开关测量的补充实现。
- **Annex C**：**FBSOA（正向偏置安全工作区）两法**——① 直流 FBSOA（DC SOA，由 R_BS(ON) 与 T_j(max) 限制的最大 I_C-V_CE 矩形区）；② 脉冲/瞬态 FBSOA（由 E_off 与热容量限制的脉冲边界）。两法给出不同时间尺度的安全工作包络。
- **Annex D**：管壳不破裂（case non-rupture）要求——**仅给出设计/结构要求，不提供试验方法**。

## I·骨架
1. **V_CE(sus) 与 SOA 关系**：维持电压是 FBSOA 上边界电压参考；低于 V_CES 但高于额定工作电压，表征器件从导通到阻断的维持点。
2. **FBSOA 双时间尺度**：DC FBSOA（稳态热限制）与脉冲 FBSOA（瞬态能量限制）必须分别给出，应用层取工况对应包络（正弦 VSI 用脉冲包络）。
3. **管壳不破裂红线（与国标层一致）**：Annex D **无试验方法**，只陈述要求。任何「管壳不破裂试验」若引本附录即**越权引用**——该判定须由封装结构/机械标准或厂商规范给出，本层不提供测试程序。

## A1·案例
应用工程师画 FBSOA 曲线，只画了 DC 矩形区。→ 标准 Annex C 要求**同时给脉冲 FBSOA**；若单管用于秒级过载（非稳态），DC 包络过保守、脉冲包络才正确。漏脉冲包络会限制器件可用能力或反之过载失效。

## A2·本地复算
- FBSOA 边界复算：DC 区 I_C(max) ≈ (T_j(max)−T_c)/(R_th(j-c)×V_CE)（受 R_BS(ON) 与二次击穿限制）；脉冲区由 E_off 积分能量与热容定。两区交点须落在厂商 datasheet SOA 图内。
- V_CE(sus) 实测值应 ≥ 标称 V_CES 的某百分比（见 Annex A 判据），低于则维持特性退化，预警雪崩能力损失。

## E·触发场景
- 画/审核单管 SOA 曲线（应用设计 E 门）进 Annex C 取 FBSOA 两法。
- 关断特性测量/双脉冲法补充进 Annex B。
- 涉及「管壳不破裂」判定时进 Annex D，**仅取要求、转封装/机械标准，禁止引本层做试验**。

## S·步骤
1. SOA 设计：先 Annex A 取 V_CE(sus)，再 Annex C 画 DC + 脉冲 FBSOA 双包络。
2. 关断测量：Annex B 电感负载法补充 §6.3 开关测量。
3. 管壳不破裂：仅引用 Annex D 要求，试验程序转 IEC 60191 / 厂商规范。

## B·边界
- **Annex D 管壳不破裂＝无试验方法**，引用即越权（与国标层 C1 红线同源）。
- FBSOA 两法不可相互替代（时间尺度不同）。
- 模块级 SOA 不属本部分（AQG 324 / IEC 60747-15）。

## 接口
- 上游：119（§6.3 开关/热阻测量，Annex 为补充实现）、118（SCSOA/RBSOA 与 FBSOA 构成完整 SOA 体系）。
- 跨层：国标层 115（IDT 2007 Annex A–D，对照修订；国标 C1 同样标「附录 D 无试验方法」）；门 E（应用 SOA 设计）；门 H（SOA 失效机理）；封装层 B 门（管壳/机械结构）。
