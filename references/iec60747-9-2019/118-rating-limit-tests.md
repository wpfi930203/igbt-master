# 118 · IEC 60747-9:2019 额定值（极限值）试验（§6.1–6.2：通则 / 六项额定值试验 + 表 1 + SCSOA/RBSOA）

> **层归属**：IEC 60747-9:2019 标准层；门：**G**（可靠性与认证），跨 **A**（RBSOA/SCSOA 应力考核）
> **页引用**：用 §N.N 标准条款号。§6.1 = 通则；表 1 = 验收判据；6.2.1–6.2.6 为各项额定验证；6.2.10 = SCSOA。
> **R·原文锚点**

## R·原文锚点
- §6.1 General：额定值验证按 **S（DC 法）/ R（AC 法）/ X（特殊法）** 三类工况进行；具体每项用哪类见 §5.2 标注。
- **Table 1**：额定值验证验收判据表，含 **RB-IGBT / RC-IGBT** 的额外判据行（2019 相对 2007 的重要扩展）。
- §6.2.1–6.2.6：V_CES、V_CEO、V_CER/V_CEV、V_ECS、栅极 I_GES、温度额定（T_j、T_stg）验证条件。
- **§6.2.10 SCSOA（短路安全工作区）**：双情形（single-pulse / repetitive）+ **25% 爬流规则**（short-circuit current 在指定脉冲宽度内不得超过额定值的 125%，即留出 25% 裕度判据）。
- RBSOA（反向偏置 SOA）：由 V_CES 与 I_CM/I_CRM 及安全工作边界定义，限值曲线由厂商在 datasheet 给出，标准给出验证原则。

## I·骨架
1. **S/R/X 三法对应**：
   - **S（DC）**：直流偏置下测截止/漏电流，验证电压额定（如 V_CES 下 I_CES ≤ 上限）。
   - **R（AC）**：工频交流偏置（如 50/60 Hz 正弦峰）验证，模拟实际交流工况的瞬时过压。
   - **X（特殊）**：脉冲/特殊波形（如短路脉冲）验证，用于 SCSOA、开关应力类。
2. **Table 1 验收判据**：每项额定对应「验证法 + 条件 + 允许最大漂移/失效判据」。RC/RB 型额外增加反向项判据（如 V_RM 下 I_RM）。
3. **SCSOA 双情形 + 25% 规则**：
   - 情形 A（单次短路）：t_sc 内 I_sc 不超 I_CM，结温升不超 T_j(max) 余量；
   - 情形 B（重复短路）：累计热循环不引发参数漂移超 Table 1 判据；
   - **25% 爬流规则**：测得的短路峰值电流 I_sc 须 ≤ 1.25 × 器件额定短路能力（即实测不得超过声明值的 125%，否则判失效）——这是 2019 版给出的明确量化判据。

## A1·案例
某 1200 V/200 A IGBT 单管短路测试，实测 I_sc(peak)=260 A，datasheet 声明 I_sc=200 A。→ 260/200=1.30 > 1.25，**违反 25% 爬流规则，判废**。若只按「没烧穿」定性判合格会漏判。

## A2·本地复算
- SCSOA 裕度复算：声明 I_sc=200 A，允许上限 = 200×1.25 = 250 A；实测 260 A → 超 10 A（相对上限超 4%）→ 失效。复算务必用「声明值×1.25」作上限，而非声明值本身。
- RBSOA 边界：V_CE 工作点 ≤ V_CES 且 I_C ≤ I_CM（脉冲）/ I_CRM（重复），两轴交点须在厂商 SOA 曲线内。

## E·触发场景
- 单管型式试验做额定值验证时进本层 §6.1–6.2，按 Table 1 取判据。
- 短路能力评估/失效分析（H 门）查 SCSOA 双情形与 25% 规则。
- 来料检验判废判定：先 116（术语）→ 117（额定值）→ 本层（验证+判据）→ 120（接收可靠性）。

## S·步骤
1. 按 §5.2 确定每项额定用的验证下标（S/R/X）。
2. 取 Table 1 对应行判据（注意 RC/RB 型增行）。
3. 执行 §6.2.x 测试，记录实测。
4. SCSOA：分单次/重复两情形，按 25% 规则判 I_sc ≤ 1.25×声明值。
5. 漂移超 Table 1 或烧穿即判废。

## B·边界
- S/R/X 是「验证工况分类」，不是三个不同电压值（常见误读，见 116 A2）。
- 25% 规则是 SCSOA 专用判据，不套用于 RBSOA/FBSOA（后两者由曲线 + 厂商声明定）。
- 模块（多芯片）不属本部分，短路判废走 AQG 324 层。
