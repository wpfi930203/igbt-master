# 119 · IEC 60747-9:2019 特性测量方法（§6.3：VCEsat / VGE(th) / 电容 / 栅荷 / 开关能量 / 热阻双法）

> **层归属**：IEC 60747-9:2019 标准层；门：**F**（测量），跨 **C**（6.3.16 热阻两法）与 **D**（双脉冲法）
> **页引用**：用 §N.N 标准条款号。§6.3.1–6.3.16 覆盖导通/关态/电容/栅荷/开关/热阻测量。
> **R·原文锚点**

## R·原文锚点
- §6.3.1–6.3.5：关态参数（V_CE(sus)、I_CES/I_CEO/I_CER/I_CEV、I_GES）、导通参数（V_CE(sat)、V_GE(th)、g_fs）测量。
- §6.3.6–6.3.8：电容 `C_ies/C_oes/C_res` 测量，规定 **LC 解耦条件**（器件与仪表间须低感连接，去耦避免振荡）。
- §6.3.9–6.3.11：栅电荷 `Q_G/Q_ge/Q_gc` 测量。
- **§6.3.12–6.3.13 开关能量积分窗（关键）**：
  - `E_on` 积分窗 = 从 **V_GE 升至 10%** 到 **V_CE 降至 2% V_CC**；
  - `E_off` 积分窗 = 从 **V_GE 降至 90%** 到 **I_C 降至 2% I_CM**。
  - 与「恒流近似 1.0」无关——**正弦 VSI 开关损耗系数 1/π=0.3183**（见封装/应用层纪律），本标准的积分窗只定义「开窗边界」，不替代工况折算。
- §6.3.14–6.3.15：反向恢复 `Q_rr/t_rr`、正向恢复 `V_FRM/t_fr`（RC/RB 型）。
- **§6.3.16 热阻双法**：用 **V_CE** 或 **V_GE(th)** 作为温度敏感参数（TSP）测 `R_th(j-c)` / `Z_th(j-c)`，两法择一，须在校准温度区间线性。

## I·骨架
1. **导通损耗测量**：V_CE(sat) 在指定 I_C、V_GE、T_j 下测；V_GE(th) 用恒流法（如 I_C 小值取 V_GE）。
2. **电容/栅荷**：小信号法，须满足 LC 解耦（低感连接）避免自激；C_ies 在 V_CE 偏置、V_GE=0 测。
3. **开关能量**：**双脉冲法（DPT）** 是标准实现；积分窗严格按 §6.3.12/6.3.13 的 10%/2% 边界，漏窗会系统性高估/低估 E_on/E_off。
4. **热阻双法**：TSP 选 V_CE 或 V_GE(th)；V_CE 法需较大测试电流（影响小信号区），V_GE(th) 法灵敏度高但需标定斜率 dV_GE(th)/dT_j。

## A1·案例
DPT 测 E_off 时，有人把积分窗取到「I_C 到 0」。→ 标准 §6.3.13 是到 **2% I_CM** 即止（尾电流阶段能量很小且窗口定义统一可比）；取到 0 会引入尾电流噪声、跨器件不可比。应回到 10%/90%/2% 边界。

## A2·本地复算
- 热阻双法一致性：同一颗器件用 V_CE 法得 R_th=0.42 K/W，用 V_GE(th) 法应落在 ±10% 内；偏差大说明 TSP 标定区间不当或接触热阻混入。换算到 Foster→Cauer（封装层）误差量级须单独评估。
- 损耗折算：标准只给「单脉冲积分能量」；正弦 VSI 工况总损耗 = Σ(单脉冲 E)×f_sw×(1/π)，不可把 E_on/E_off 直接当周期平均（见门 C/D 纪律）。

## E·触发场景
- 建单管损耗模型 / 仿真取数时进本层 §6.3 取测量定义，确保与 datasheet 口径一致。
- 热阻实测（K 系数、结构函数 JESD51-14）先过本层 §6.3.16 定 TSP 法与 R_th(j-c)。
- DPT 设备验收：用 §6.3.12/6.3.13 积分窗定义校验采集脚本开窗是否正确。

## S·步骤
1. 选定被测参数 → 对应 §6.3.x。
2. 满足该条前置条件（偏置、温度、LC 解耦）。
3. 开关类用 DPT，按 10%/90%/2% 边界开窗积分。
4. 热阻类定 TSP（V_CE 或 V_GE(th)），线性区标定后测 R_th/Z_th。
5. 记录测量法版本（2019）以便与旧版数据对照。

## B·边界
- 积分窗是「能量开窗边界」，不是「损耗工况折算系数」——正弦工况 1/π 系数来自应用层，不可混用。
- 端子值 ≠ 芯片值：R_th(j-c) 是芯片结到壳，壳到散热器另算（封装层 / JESD51 系列）。
- RC/RB 型才测反向恢复/正向恢复；标准 IGBT 不测。

## 接口

- 下游：120（接收可靠性，Table 2 接收判据用到实测特性）。
