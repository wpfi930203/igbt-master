# 113 · GB/T 29332 特性测量方法（§6.3：VCEsus / VCEsat / 阈值 / 漏电 / 电容 / 栅荷 / 内阻 / 开关能量 / 热阻，式(1)–(8)）

> **层归属**：国标层（references/gb29332/）；门：**F**（测量），跨 **C**（6.3.13 热阻两法）与 **D**（双脉冲法）
> **页引用**：PDF = 标准页 + 8。§6.3.1–6.3.13 = 标准页 19–34（PDF p27–42）。

> **R·原文锚点**
- p19（式 1）：Lmin = (Vcc2 − Vcc1) × toffn / (0.1×IC)——「这保证 IC 在 toff 期间的减少量不超过 10%」
- p27（6.3.11.4）：Eon「为 VCE×IC×dt 的积分。积分时间 ti 自 VGE 上升至其 **10%** 的时刻起，至规定的 VCE 低值（电源电压 Vcc 的 **2%**）的时刻止」
- p33（6.3.13.1.4 式 5）：Rth(j-c) = (Tj − Tc2) / (VCE4 × IC2)

> **I·骨架**（本模块回答：每个特性的标准测量法、电路要点与积分/计算口径）
1. **VCE,sus**（6.3.1，图 11/12）：脉冲饱和→关断经电感扫描；Vcc2＋串联二极管构成钳位单元；**式(1) 定 Lmin**（toff 期间电流衰减 ≤10%）；判定二选一：钳位下轨迹由 B→C 不越过 BC 线左侧，或无钳位时轨迹在 B 点附近有效变向；初试先**降压验证钳位有效**。条件含 VCE,sus 三种第三下标（VCERsus/VCESsus/VCEXsus）。
2. **VCEsat**（6.3.2，图 13）：窄脉冲供流防自热（「测量期间 DUT 中不应产生显著的热耗散」）；条件＝温度+VGE+IC。
3. **VGE(th)**（6.3.3，图 14）：定 VCE，升 VGE 至 IC 达规定低值，读该点 VGE。
4. **截止/漏电流**（6.3.4/6.3.5，图 15/16）：ICES/ICER/ICEX 直流法/交流法（交流法 50/60 Hz 源）；IGES 在 C-E 短路下测。
5. **三电容**（6.3.6–6.3.8，图 17–19）：电容表 CM＋隔直 L1/L2＋测频旁路 C1/C2；**条件式：1/ωL«|yie|、ωC»|yie|（输出同式对 yoe）**——即隔直支路阻抗远小于端口导纳、旁路电容阻抗远小于端口导纳；程序＝先定频后接 DUT；6.3.8 的 Cres 路径还要求 R 不太大。
6. **QG 栅电荷**（6.3.9，图 20/21）：恒流 IG 注入至 VGE 达规定值，**式(2) QG = ∫i(t)dt = IG×(t−t0)**；监测 t0→t1 的 VCE 与 VGE。
7. **rg 栅极内阻**（6.3.10，图 22）：LCR 表**零位法**，串联电容/电阻模式；ωC1»Coes、ωC1»|yie| 条件；C-E 短路下测。
8. **Eon/Eoff 双脉冲**（6.3.11/6.3.12，图 23–26）：电感负载＋续流二极管 D；**Eon 窗＝VGE 升至 10% → VCE 降至 2%Vcc；Eoff 窐＝VGE 降至 90% → IC 降至 2%ICM**；耗散功率＝开关频率×单脉冲能量；开通用双脉冲（第二脉冲考核），关断保证 DUT 完全饱和；**注：若续流二极管与 IGBT 同封装，测量电路须选相同特性的二极管**。
9. **Rth/Zth 热敏参数两法**（6.3.13，图 27–31）：**方法 1** 小电流 VCE 为热敏参数——式(3) αVCE=(VCE1−VCE2)/(T2−T1)；加热至热平衡后切断大电流 IC2，紧接测 VCE5；式(4) Tj=Tc1+(VCE3−VCE5)/αVCE；式(5) Rth=(Tj−Tc2)/(VCE4×IC2)；**方法 2** VGE(th) 为热敏参数——式(6) Ct=|(VGE(th)1−VGE(th)2)/(T2−T1)|（V/K）；式(7) Tj=Tc1+(VGE(th)3−VGE(th)4)/Ct；式(8) Rth=(Tj−Tc2)/(VCE×IC2)；Zth 由切断 IC2 后冷却曲线**逐点**按式(5)/(8) 算；两法均要求「测量管壳温度的基准点」作规定条件。

> **A1·案例**（标准自带的判定素材）
- Eon/Eoff 积分窗对照（p29/30）：Eon 起点 10%VGE（开通过程起点）、终点 2%Vcc（电压完全换相）；Eoff 起点 90%VGE、终点 2%ICM（含拖尾到 2%）——**四条窗沿全不同**，自建测量脚本须逐条对齐。
- Lmin 算例口径（式 1）：toffn 用**关断延迟+下降**的标称值代入；除以 0.1 即「允许 10% 衰减」——IC=100 A、Vcc2−Vcc1=400 V、toffn=1 µs → Lmin=4 mH。
- αVCE 标定两点法（式 3）：Ti/T2 两点须均达热平衡再读数（「测量前必须达到热平衡」），线性区间取点，不看单点斜率。

> **A2·本地复算**
- 式(5) 自检：分母 VCE4×IC2＝切断前稳态加热功率 P（VCE4 是**加热态**压降）——若误用 VCE3（小电流态）会差数量级；与封装层 78「热阻测量用加热功率」口径一致。
- 方法 2 的 Ct 量纲（式 6）：VGE(th) 温度系数典型 −5～−10 mV/K；式(7)/(8) 中分母用 VCE×IC2（非 VGE×IC2）——阈值电压只做温度计，功率账仍走 VCE。
- 电容测量条件式复核（6.3.6.3）：GB 版前言已勘误方向（|yi_e|»ωC1 更正为 ωC1»|yie|）——引用旧版 IEC 文本时注意此条编辑修正。

> **E·触发场景**
- 搭 VCE,sus 试验台 → 式(1) 定 Lmin＋「先降压验钳位」步骤。
- 写自动开关能量测量脚本 → 对齐四条积分窗沿（6.3.11.4/6.3.12.4）。
- 热阻测试选热敏参数 → 方法 1（VCE）常规；方法 2（VGE(th)）适合 VCE 平台被封装寄生淹没的场合；与 AQG Annex II.A 的 VCE(T) 法交叉引用。
- 三电容测值与 datasheet 对不上 → 先查隔直/旁路条件式与「先定频后接 DUT」顺序。

> **S·步骤**（完整特性测量清单的最短执行序）
1. 静态四件：VCEsat（窄脉冲）→ VGE(th) → ICE（三口径）→ IGES。
2. 动态两件：双脉冲法测开通族（td(on)/tr/ton/Eon）与关断族（td(off)/tf/toff/tz/Eoff）。
3. 小信号三件：Cies/Coes/Cres（条件式校验）→ QG（恒流法）→ rg（LCR 零位法）。
4. 热一件：方法 1 或 2 标定热敏系数→加热→切断→读 Tj→算 Rth；要 Zth 就录冷却曲线逐点算。
5. 极限值延伸：VCE,sus（式 1 台架）按 6.3.1 判定。
6. 每项按 §6.3 各条「规定条件」清单打勾（温度/VCE/VGE/IC/频率五件套）。

> **B·边界**
- 本模块是**方法条文转述**，判废以标准原文＋详细规范为准。
