# 11 · 逆变器设计：电压等级、母线、吸收与基本公式（第 13 章）

> 来源：书页 341–362（PDF 353–374），**主干精读**（13.3–13.6、13.9、13.13）。
> 本章补的是"选型"这一环最实用的东西：**电源电压 → 母线电压 → 模块电压等级**的对应表，以及母线杂散电感与吸收电容的定量关系。

## R · 原文锚点

> 「除了其他因素外，直流母线电压决定了宇宙射线（见第 14 章 14.8 节）引起的功率半导体器件失效率，同时也决定了其在特定阻断电流下的长期稳定性。」【书 p343】

> 「当选择功率半导体器件时，需要根据直流母线电压和安全裕度 s₂ 估算器件的电压等级。如果杂散电感较小，安全裕度可设为 50 %，而中等杂散电感时则设为 60 %。」【书 p343】

> 「在实际工作必须确保功率半导体器件（IGBT 及续流二极管）承受的电压不超过其最大阻断电压。除了直流母线电压外，器件的开关过程会产生过电压 U_peak，由直流母线电压 U_DC 和换流路径中杂散电感的压降 ΔU 组成。」【书 p346】

## I · 骨架一：电压等级的三步推（式 13.1–13.3）

```
第 1 步  母线电压（交流输入）
  U_DC = √2 · U_nom,RMS · ( 1 + s1/100 )        (13.1)

第 2 步  母线电压（直流输入）
  U_DC = U_nom,DC · ( 1 + s1/100 )              (13.2)

第 3 步  器件阻断电压
  U_CES = U_DC · ( 1 + s2/100 )                 (13.3)
         s2 = 50 %（杂散电感小）
         s2 = 60 %（杂散电感中等）
```

> **s1 与 s2 是两笔不同的钱**：s1 是**电网/输入容差**（母线本身就偏高），s2 是**开关过冲**（器件额外要扛）。
> 常见错误是把两者合并成一个"1.5 倍系数"，结果要么过设计、要么漏掉过冲。

## I · 骨架二：表 13.1——直接把电源接到模块型号上

| 电源电压 U_nom | 直流母线电压 | 首选 IGBT 电压等级（两电平） |
|---|---|---|
| **230 V_RMS** | 360 V | **600 V** |
| **400 V_RMS** | 620 V | **1.2 kV** |
| **750 V_DC** | 900 V | **1.7 kV** |
| **690 V_RMS** | 1.07 kV | **1.7 kV** |
| **1.0 kV_RMS** | 1.56 kV | **2.5 kV** |
| **1.5 kV_DC** | 1.80 kV | **3.3 kV** |
| **2.3 kV_RMS** | 3.58 kV | **6.5 kV** |
| **3.0 kV_DC** | 3.60 kV | **6.5 kV** |

**三条读表要点**：
1. **690 V 与 750 V_DC 都落在 1.7 kV**——这是风电/光伏/工业传动的密集区，也是 1.7 kV 模块出货量最大的原因
2. **1.0 kV_RMS 跳到 2.5 kV**：620 V 母线用 1.2 kV 只剩 1.94 倍裕度，而 3.58 kV 母线用 3.3 kV 只有 1.08 倍——**3.3 kV 挡在 2.3 kV_RMS 场合必须用三电平**，否则裕度不足
3. 表末注明：「**三电平逆变器 IGBT 的电压等级可以减半**」→ 这也是 3.3 kV/6.5 kV 场合三电平流行的原因

## I · 骨架三：直流母线电容——容量、串并联与平衡电阻

**容量量级**：「大多在 **100 μF～1 mF** 之间」（电解电容为主，有时薄膜电容）。

**串联必须均压**：
- 母线电压高时需多只串联。串联时「必须在电容两端并联均压电阻保持电容电压平衡（对称），从而避免某个电容承受过高的电压」
- 两种结构（图 13.3）：**共用平衡电阻**（电容数量增加时自动趋向平衡，最好情况不需要额外电阻；缺点：某只短路则与之相对的电容承受全部电压）vs **独立平衡电阻**（某支路损坏不致整机失效；缺点：增加电阻、空间与成本）

**平衡电阻计算（式 13.5，引 Cornell Dubilier）**：
```
R_B ≈ ( 2·U_C − U_DC,max ) / ( 0.0015 · C · U_C )

U_C ：电容的最大设计电压（V）
U_DC,max ：直流母线最大电压（V）
C ：电容值（F）
```

**寿命约束**（书强调，且常被忽略）：
- 电解电容寿命由**最高环境温度 + 纹波电流**共同决定
- 「输入整流器和输出功率半导体器件的开关都在母线电容中产生纹波电流并使其发热。工作温度接近或高于最高芯温都会导致电容提前失效」
- 化成电压决定氧化层厚度 → 决定额定电压；也限制下限温度（电解液电阻随温度降低）
- 书给了厂商在线工具（Cornell Dubilier、Epos AlCap），说明**电容选型本来就是"用工具算寿命"，不是查表**

## I · 骨架四：吸收电容——只在"改不了杂散电感"时才用

**过压构成（式 13.6）**：
```
U_peak,noSnubber = U_DC + ΔU_noSnubber
                 = U_DC − L_σ,noSnubber · di/dt        (13.6)

L_σ,noSnubber = L_σ1,DC,ESL + L_σ2,DC + L_σ3,Module
```

**决策顺序（书给的，很重要）**：
1. 先设法**降低结构杂散电感**（母线叠层、并排铜排/铝排、最短路径连接电容与器件）
2. 「如果无法通过降低结构的杂散电感，保证半导体器件的开关过电压低于其允许电压，那么吸收电容就值得考虑」
3. 选 **MKP 型（金属聚丙烯）薄膜电容**，它对电解质缺陷有**自愈能力**
4. **代价要认**：「吸收电容会增加成本并降低系统的寿命，所以最好不用吸收电容」

> 第 4 条是本书最"老工程师"的一句话：吸收电容是**降低系统寿命**换器件安全。它在故障能量上做加法，不是在效率上做加法。

**母线结构的三条硬要求**：
- 保证 DC+ 与 DC− 的导体包围面积尽可能小
- 选 **低 ESL** 的电容
- 用铜薄板或铝薄板叠层，**并联薄片通过最短路径把电容与器件连起来**
- 若模块有多个 DC+/DC− 连接点：**电流必须均匀分布**，「电流严重不对称可能导致模块端子温度过高，并使 IGBT 模块内部的电流分布不对称」

## I · 骨架五：驱动级布局的四种方案（图 13.9/13.10 有实测）

| 方案 | 优点 | 缺点 |
|---|---|---|
| a) 附带驱动级模块 | 定义所有模块设计；**低寄生效应**；保护功能效果好 | 机械灵活性差 |
| b) 适配板 + 驱动核心板 | 机械灵活；**开关特性几乎不受电缆长度影响**；保护效果好；适合并联 | 增加零件数目 |
| c) 模块与驱动级分离（**<15 cm**） | 机械灵活 | 对开关特性影响有限；集电极电缆需足够绝缘 |
| d) 模块与驱动级分离（**>15 cm**） | 机械灵活 | **明显影响开关特性**；保护功能降低；集电极电缆需足够绝缘 |

**图 13.10 的实测结论**（三条曲线对比）：
- `1` = 适配板与驱动核分离、距离 <15 cm
- `2` = 分离、距离 >100 cm
- `3` = 驱动级通过 100 cm 电缆连到辅助发射极端子

→ 曲线 2、3 的 E_on/E_off 与 V_CE 波形显著劣化。**"15 cm"是这个实测给出的分界**，不是经验口号。

## I · 骨架六：三相逆变器基本公式（13.13，可直接代入）

**输入整流**（忽略二极管与串联阻抗压降）：
```
U_DC,max = √2 · U_LL,Grid                        (13.35)
I_avg    = (120°/360°) · I_DC = (1/3) · I_DC     (13.36)
I_RMS    = (1/√3) · I_DC                          (13.37)
```

**输出逆变**：
```
P_el       = √3 · U_LL,Load · I_Load · cosφ      (13.38)   cosφ>0 电动 / <0 发电
Û_Load     = √(2/3) · U_LL,Load                   (13.39)
Û_Load     = (1/2) · m · U_DC                     (13.40)   m = 调制系数
U_LL,Load  = (√3/(2√2)) · m · U_DC                (13.41)
```

**直流母线**：
```
P_DC = P_el / η_inv                               (13.42)
I_DC = (3/(2√2)) · (U_LL,Load·cosφ / η_inv) · I_Load      (13.43)
I_DC = (π√3/(3√2)) · (U_LL,Load·cosφ / (U_LL,Grid·η_inv)) · I_Load   (13.44，计及输入整流)
```

> 式 13.41 是**反推母线电压**的关键：给定所需输出电压与调制比，就能算出最低母线电压；反过来给定母线电压，就能算出最大可输出电压。**这两者是选模块电压等级的上游约束**（接表 13.1）。

## A1 · 案例：690 V 风电网选 1.7 kV，到底够不够（本地复算）

**第 1 步：母线电压（式 13.1）**

```
U_DC = √2 × 690 × (1 + s1/100) = √2 × 690 × 1.10 = 975.8 × 1.10 = 1073 V
```
对照表 13.1 的「690 V_RMS → 1.07 kV」，**吻合**——说明书里这张表反推的 s1 就是 **9.6–10 %**（230 V→360 V、400 V→620 V、1.0 kV→1.56 kV 三行同样吻合）。

**第 2 步：器件等级（式 13.3）**

| s2 | U_CES 需求 | 1.7 kV 够不够 |
|---|---|---|
| 50 %（Lσ 小） | 1073 × 1.50 = **1610 V** | 够，裕量 90 V（**5.6 %**） |
| 60 %（Lσ 中等） | 1073 × 1.60 = **1717 V** | **差 17 V，不够** |

→ 反解：1073 V 母线上，1.7 kV 能给的 s2 上限 = 1700/1073 − 1 = **58.4 %**。

**这条是 690 V 系统最容易踩的坑：它正好卡在「50 % 够、60 % 不够」的分界上。** 同一只 1.7 kV 模块，换个封装就可能从「够」变「不够」——因为 s2 从来不是拍脑袋定的，它由 Lσ × di/dt 决定。

**第 3 步：把 s2 落到 Lσ 上（式 13.6）**

允许的过冲 ΔU = 1700 − 1073 = **627 V**。

| 封装（表 2.2） | Lσ | di/dt 上限 = 627 V / Lσ |
|---|---|---|
| 62 mm / EconoDUAL™3 | 20 nH | **31 A/ns** |
| IHM 二代 | 6 nH | **105 A/ns** |
| 34 mm | 30 nH | **21 A/ns** |

→ 「1.7 kV 够不够」的答案**不在电压表里，在 di/dt × Lσ 的乘积里**。这三个数就是给 Rg 设下限（限制 di/dt）的物理依据，而不是「Rg 大一点更保险」。

**第 4 步：如果改三电平**

表 13.1 注明「三电平 IGBT 的电压等级可以减半」。每管稳态承压 1073/2 = **537 V**，用 1.2 kV：
537 × 1.60 = **859 V** < 1200 V，裕量 **40 %** → 宽裕。

→ 690 V 风电场上「两电平 1.7 kV / 三电平 1.2 kV」两条路线并存，取舍点不在器件本身，而在**拓扑成本（多一倍器件与驱动）vs 器件成本（1.7 kV 更贵且 Lσ 要求更严）**。

> 全部数值由书内式 13.1 / 13.3 / 13.6 与表 13.1 / 表 2.2 代入算出，属**本地复算**；**s1 = 9.6–10 % 是从表 13.1 反推的假设值**（书中未直接给 s1 数值），三电平的 859 V 按「电压等级减半」定性说明外推——**书中未给三电平对应表**，这两项不能当书内数据引用。

## E · 触发场景

- 「690 V 电网选什么模块？」→ 表 13.1：母线 1.07 kV → 1.7 kV
- 「2.3 kV 电网能不能用 3.3 kV 两电平？」→ 母线 3.58 kV，3.3 kV 只剩 1.08 倍，不够；用三电平（电压等级可减半）
- 「要不要加吸收电容？」→ 先算式 13.6 的过压，再看能否改母线结构；吸收电容降系统寿命
- 「驱动板离模块多远可以？」→ 15 cm 是实测分界；>15 cm 必须做适配板或驱动核心板
- 「母线电容怎么串联均压？」→ 式 13.5 算 R_B，并核算纹波电流与芯温
- 「母线电容选多大？」→ 100 μF~1 mF 是量级；真正的约束是纹波电流与寿命，用厂商工具算

## S · 步骤（从电网到模块型号的选型链）

1. **定电网/母线**：交流用式 13.1，直流用式 13.2，s1 按容差
2. **算所需输出**：由式 13.38–13.41 反推最低母线电压与调制比余量
3. **定器件等级**：表 13.1 查档，再用式 13.3 校核过冲（s2=50/60 %）
4. **核宇宙射线**：母线电压越高、海拔越高，失效率越高（接 `05-reliability-life.md`）
5. **设计母线**：叠层、低 ESL、对称、多端子均流；算 L_σ,noSnubber
6. **判吸收**：式 13.6 过压是否超 RBSOA；先改结构，再考虑 MKP
7. **定布局**：驱动距离 ≤15 cm；超过则上适配板/核心板
8. **算损耗与温升**：接 `scripts/igbt_loss.py` 与 `igbt_thermal.py`
