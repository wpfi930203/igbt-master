# 38 · 损耗的解析式族：模块压降里有多少是封装的（第 3.1–3.5 节）

> 一句话：**同一个 datasheet 标称的 `U_CE(sat)` 里，有一截不是芯片的 —— 是键合线 + 端子 + 内部铜排。** 第 3 章给了两个可以直接拆开它的式子（式 3.8 / 3.22），而全技能此前没有任何地方用到。同一个 1/π 也是在这里：**开关损耗的平均值系数不是 1，是 0.3183**。
>
> 本模块覆盖 **3.1–3.5**（正向特性、开关过程、损耗解析式、栅极电荷与密勒平台）。**能量窗口 E 的积分边界（式 3.1–3.3）与 `Q_rr` 的另一套边界见模块 `23`；短路/阻断/雪崩（3.6–3.8）见模块 `26`；3.9–3.10 见模块 `17`**，不重复。

## R · 原文锚点

> 「如果没有给出芯片级的 `U_F`，而只是给出了模块级的压降，就需要通过计算得到芯片级的压降。要做到这一点，**需要从模块压降 `U_F,Module` 中减去模块电阻 `R_CC'+EE'` 的压降**，模块电阻通常在数据手册中给出。」【书 p95，式 3.8】

> 「`U_F,Chip = U_F,Module − R_CC'+EE' · I_F`」【书 p95，式 3.8】

> 「`U_CE,Chip = U_CE,Module − R_CC'+EE' · I_C`」【书 p101，式 3.22】

> 「`P_cond,1 = ½[U_CE0·î/π + r·î²/4] + m·cosφ·[U_CE0·î/8 + (1/3π)·r·î²]`」【书 p102，式 3.24】

> 「`P_on,1 = (1/π)·f_sw·E_on(I_nom,U_nom,T_vj)·(î/I_nom)·(U_DC/U_nom)`」【书 p104，式 3.26，脚注「适用于正弦电流」】

> 「`P_sw,1 = P_on,1 + P_off,1 = (1/π)·f_sw·[E_on + E_off]·(î/I_nom)·(U_DC/U_nom)`」【书 p106，式 3.29，脚注「适用于正弦电流」】

> 「`E_rec(î) = E_rec(I_nom,T_vj)·(0.45·î/I_nom + 0.55)`」【书 p99，式 3.17】

> 「**积分边界范围是 `U_R` 的 10% 和 `I_RRM` 的 2%**。最终，二极管的开关损耗 `P_sw,D` 等于 `E_rec` 乘以开关频率 `f_sw`。」【书 p99】← **这是恒流口径**，与式 3.16/3.26 的 1/π 差 π 倍，见骨架三

> 「`I_G = I_Driver + I_GC = I_Driver + C_GC · dU_CE/dt`」【书 p107，式 3.32】

> 「**沟槽型 FS IGBT 不能通过降低外部驱动电阻增加 `dU_CE/dt`。** 在正常工作状态下，沟槽栅 IGBT 的关断更软，而且电压过冲更小。」【书 p108，3.5.4 节结论】

> 「在低于 20 ℃ 时，从图 3.23 中可以看出，**NPT IGBT 和 FS IGBT 会从 PTC（正温度系数）转为 NTC（负温度系数）**。」【书 p103】

## I · 骨架一：封装压降分解 —— 式 3.8 / 3.22

书在讲二极管正向特性（p95）和 IGBT 正向特性（p101）时，**各给了一次同一个式子**：

```
U_F,Chip   = U_F,Module   − R_CC'+EE' · I_F      (3.8)   ← 二极管
U_CE,Chip  = U_CE,Module  − R_CC'+EE' · I_C      (3.22)  ← IGBT
```

`R_CC'+EE'` 是**端子 C 到芯片 C'、芯片 E' 到端子 E** 的路径电阻 —— 也就是**键合线 + DBC 铜层 + 端子焊点**这一整段封装内互连。

**为什么这一式对封装工程师比对齐片工程师更重要**：datasheet 上的 `U_CE(sat)`、`V_F` **一律是端子测的**，包含封装。而所有热仿真、芯片选型、寿命评估用的都是**芯片值**。两者之间差的这一截，恰好是**你负责的那部分**：

```
P_封装 = R_CC'+EE' · I²
```

它是**纯焦耳热、全在封装内部、且不像芯片那样有面积可以摊薄**。

> **这一式在书里是"用来说明怎么反推芯片值"的工具，但反过来读更有用：它是封装损耗的唯一解析入口。** 全书没有第二处给出这个分解。

### 本地复算：这一截到底占多少

取算例 B 的器件参数（`[假设]`：`U_CE0=1.05 V`、`r_CE=3.2 mΩ`、`R_CC'+EE'=0.4 mΩ`）：

| 量 | 峰值瞬时（566 A） | 调制平均（I_rms=262.6 A） |
|---|---|---|
| 芯片 `U_CE0·I` | 594 W | 157.7 W |
| 芯片 `r_CE·I²` | 1025 W | 220.7 W |
| **封装 `R_CC'+EE'·I²`** | **128 W** | **27.6 W** |
| 合计 | 1748 W | 406 W |
| **封装占比** | **7.3 %** | **6.8 %** |

> `[推断]` 0.4 mΩ 是常见 1.7 kV / 1000 A 模块的量级，**不是书里的数**（书只给公式、不给典型值 —— 因为这一项本该查具体模块 datasheet 的 `R_CC'`、`R_EE'` 分项；`34-formula-index §12` 的 11 项「书未给 / 不可直接用」里也没有它，那里管的是"系数"，这里管的是"数据"）。

**7 % 这个数会让人低估封装改动的价值 —— 这是本模块最想纠正的一个直觉。** 见下面 A1。

## I · 骨架二：通态损耗的解析式，以及 `m` 与 `cosφ` 怎么进来

书的做法分两步：**先写积分式，再给出"假设正弦 + 假设半周期导通"后的闭式**。

| 器件 | 积分式（通用） | 闭式（正弦、半周期导通） | 书页 |
|---|---|---|---|
| 二极管 | `P_cond,D = (1/T)∫u_F·i_F·τ(t)dt`（3.9） | `½[U_F0·î/π + r_T·î²/4] + m·cosφ·[U_F0·î/8 + (1/3π)·r_T·î²]`（3.11） | p95 |
| IGBT | `P_cond,1 = (1/T)∫u_CE·i_C·τ(t)dt`（3.23） | `½[U_CE0·î/π + r·î²/4] + m·cosφ·[U_CE0·î/8 + (1/3π)·r·î²]`（3.24） | p102 |

其中导通占空比 `τ(t) = t_on/T = ½(1 + m·sin(ωt+φ))`（式 3.10，p95）。**两式形式完全一样**，只是 `U_F0/r_T` 换成 `U_CE0/r`。

### 与 `igbt_loss.py` 的对应关系（已核对一致）

脚本里写的是"先算电流分量、再乘 `U_CE0`/`r_CE`"，展开后**与式 3.24 逐项相同**：

```
I_avg = î·(1/(2π) + m·cosφ/8)          ← ½·î/π = î/(2π)  ✓
I_rms = î·√(1/8 + m·cosφ/(3π))         ← ½·î²/4 = î²/8   ✓
P_cond = U_CE0·I_avg + r_CE·I_rms²
```

> **这条一致性是上一轮"π 倍事故"的现场证据**：同一段代码里，**通态走的是正弦口径（分母里有 π），开关却用了恒流口径（没有 π）**。骨架三就是要补这个缺口。

**两个常被忽略的边界**（书 p95 明说）：
1. 式 3.24 只在 **`U_CE0`、`r` 是该结温下的值** 时成立 —— 温度系数 30–50 %，用 25 ℃ 的数会系统性低估。
2. 式 3.24 假设 **半周期导通**。三电平、交错、以及带死区的大电流工况下，实际导通角不是 180°，`m·cosφ` 那一组修正项会偏。

## I · 骨架三：开关损耗的那个 `1/π` —— 四种系数与两次误用

这是本模块最值钱的一条，也是全技能此前唯一一个**把结论方向算反**的地方。

```
P_sw,IGBT = (1/π)·f_sw·(E_on + E_off)·(î/I_nom)·(U_DC/U_nom)      (3.29, p106)
P_sw,D    = (1/π)·f_sw·E_rec·(î/I_nom)·(U_DC/U_nom)                (3.16, p99)
```

### 1/π 从哪来

正弦电流 `i(t)=î·sin(ωt)`，单个器件**只在半个工频周期里有显著开关损耗**（另半周期由对管承担）。对**整个**工频周期取平均：

```
P_sw = (1/2π)·∫₀^π f_sw·E(î·sinθ)dθ
     = (1/2π)·f_sw·E(î)·[−cosθ]₀^π
     = (1/2π)·f_sw·E(î)·2
     = (1/π)·f_sw·E(î)          ← 0.3183
```

### 三种系数，只有一个对得上"正弦 VSI 单管"

| 系数 | 取值 | 什么时候对 | 什么时候错 |
|---|---|---|---|
| **`1/π`** | **0.3183** | ✅ **正弦电流、2 电平 VSI、算单个器件的平均损耗**（书 式 3.16/3.26/3.28/3.29） | 恒流/斩波时会**低估 π 倍** |
| `1` | 1.0000 | ✅ **恒流/斩波/单脉冲**（书 p99 那句"`E_rec` 乘以 `f_sw`"） | 正弦 VSI 时**高估 π 倍** |
| `2/π` | 0.6366 | 器件**全周期**都承担开关损耗时（极少数拓扑） | 用在半桥单管上**高估 2 倍** |
| `1/2π` | 0.1592 | ❌ 无适用场景 | 把"半周期导通"又除了一次，**低估 2 倍** |

> **这不是"精度差异"，是能不能得出正确结论的问题**：π 倍足以让一个 143.7 ℃ 的设计被算成 224.9 ℃，从"灰色带"翻成"FAIL"。

### 式 3.16 的完整形态（含 `E_rec` 的非线性）

式 3.16 本身只做 U/I 线性缩放，但书紧接着把 `E_rec` 对电流的非线性补进去，得到**可直接手算的近似式**：

```
P_sw,D = (1/π)·f_sw·E_rec(I_nom,T_vj)·(0.45·î/I_nom + 0.55)·(U_DC/U_nom)    (3.18)
```

> **书自称这两个近似「这种方法存在 20 % 的偏差」**（p99、p104 各说一次）。这是**书自己给的误差棒**，引用时必须带。

## I · 骨架四：`E_rec` 的 0.55 偏置 —— 轻载省不出你以为的那么多

式 3.17：`E_rec(î) = E_rec(I_nom)·(0.45·î/I_nom + 0.55)`。

把 `î → 0` 代进去：**`E_rec(0) = 0.55·E_rec(I_nom)`**。也就是说，**电流降到零，反向恢复能量只降 45 %，还剩 55 %。**

| `î/I_nom` | 式 3.17 给出 | 线性缩放会给 | 线性缩放的低估倍数 |
|---|---|---|---|
| 0.0 | 0.550 | 0.000 | ∞ |
| **0.1** | **0.595** | 0.100 | **5.95×** |
| 0.25 | 0.663 | 0.250 | 2.65× |
| 0.50 | 0.775 | 0.500 | 1.55× |
| 1.00 | 1.000 | 1.000 | 1.00× |

**物理解释**（书 p97–p98 讲的机理）：反向恢复电荷由两部分组成 —— **耗尽层电荷（与正向电流无关）+ 等离子体电荷（正比于正向电流）**。前者在零电流下依然存在，所以 `Q_rr`、`E_rec` 有一个**不随电流下降的底**。

**三个后果**：
1. **轻载效率差是物理必然**，不是设计缺陷。10 % 负载时二极管的开关损耗是额定的 **59.5 %**，不是 10 %。
2. **降载救不了全部开关损耗**。算例 B 里降载 20 %，开关损耗只降 20 %，而通态的电阻项降 36 % —— 这也是为什么降载 20 % 只买回 45 K 而不是 58 K。
3. **待机损耗、轻载温升、以及"最小负载"要求**，都要按 0.55 的底算，不能按线性。

## I · 骨架五：开通"塌陷"与关断"过冲"是同一式子的两个方向

```
开通：U_CE = U_DC − L_σ·di_C/dt        (3.25, p103)   ← 电压被"抽走"
关断：U_CE,max = U_DC + L_σ·di_C/dt    (3.27, p105)   ← 电压被"顶上"
```

> **式 3.27 与式 5.1（p143）是同一个判据的两次印刷**，不是两个不同的式子。引用时统一写"式 5.1 ≡ 式 3.27"。

`L_σ` 不是"只造成过冲"的负面因素 —— 它**同时**让开通时的器件承受电压低于母线。两者幅度相等：

| 同一 `di/dt` | `L_σ·di/dt` | 器件实际承受 |
|---|---|---|
| 30 nH × 20 A/ns（算例 C 参数） | **600 V** | 开通时 1073 − 600 = **473 V**；关断时 1073 + 600 = **1673 V** |

`[推断]`（按式 3.25/3.27 直接代入，非书内读数）

**这条"对称性"有三个工程含义**：

1. **`E_on` 不能用"母线电压 × 电流 × 时间"估** —— 开通期间器件根本没看到母线电压。硬要这么估，会高估 `E_on`。
2. **开通是"借钱"，关断是"还钱"**，还的时候用 SOA 余额支付。所以"提高 di/dt 提升效率"永远是一笔**拿耐压换损耗**的交易。
3. **吸收/钳位电路只作用于关断那一半** —— 它对开通的"塌陷"无能为力，这也是为什么缓冲电路对 `E_on` 帮助有限（模块 `32`）。

## I · 骨架六：密勒平台 —— 式 3.32 决定 `du/dt`

```
I_G = I_Driver + I_GC = I_Driver + C_GC · dU_CE/dt      (3.32, p107)
```

平台期间（图 3.29 的 CD 段）栅压恒定，**没有电流进 `C_GE`，全部栅极电流都走 `C_GC`**。移项：

```
du/dt = I_GC / C_GC
```

**两个可算的量**：

| 想要 | 需要 | 本地复算（`C_GC=1 nF`、`Q_GC=1.5 μC`，`[假设]`） |
|---|---|---|
| `du/dt = 5 kV/μs` | `I_GC = C_GC·du/dt` | 1 nF × 5 kV/μs = **5 A** |
| 平台长度 | `t_plateau = Q_GC/I_G` | 1.5 μC / 5 A = **300 ns** |

> **5 A 的栅极电流**是个反直觉的数：它解释了为什么"想快"不是换个 2 A 驱动器就够，而往往要上 10 A 级 —— 也解释了模块 `30` 的 `R_G,min ≥ 2√(ΣL_G/C_GE)` 为什么是硬约束（大电流 + 小 `R_G` 必然激励 `L_G`-`C_GE` 振荡）。

**沟槽栅 vs 平面栅的分野**（书 p107–108）：平台之后，**沟槽栅 IGBT 出现一段"不受控"的斜坡** —— 因为栅压已低于阈值，内部 MOS 通道关闭，负载电流只能靠漂移区剩余载流子维持。这直接导出骨架七的结论。

## I · 骨架七：拖尾电流与母线电压**反向**，且沟槽栅不可控

### (a) 母线越低，拖尾越明显

图 3.28（p105，Trench-FS IGBT，同温度）：

| `U_DC` | 拖尾 `I_CZ` | 书给的机理 |
|---|---|---|
| 500 V | **几乎没有** | 空间电荷区几乎扩展到整个漂移区 → 没有残留载流子形成拖尾 |
| 300 V | 明显 | 空间电荷区缩小，残留载流子开始贡献 |
| 250 V | **最明显** | 同上，更甚 |

> **反常点**：直觉是"电压低 → 损耗小"。**对拖尾这一项，恰恰相反。** 低压大电流应用（储能 PCS、低压变频、48 V 级）的 `E_off` 拖尾分量比高压应用更重，不能套用高压 datasheet 的曲线形状。

**书同时给了反面代价**：FS/Trench-FS 在**高**母线时拖尾消失得太快 → 接近**硬关断** → 强振荡 → EMI。所以"没有拖尾"不等于好事。

### (b) 沟槽栅：**降 `R_G` 换不到 `du/dt`**

> 「沟槽型 FS IGBT **不能**通过降低外部驱动电阻增加 `dU_CE/dt`。……沟槽栅 IGBT 的关断更软，而且电压过冲更小。」【书 p108】

| 器件 | 降 `R_G` 的效果 | 原因 |
|---|---|---|
| **平面 NPT** | `du/dt` 上得去（图 3.30 中曲线可调） | 平台后电流仍受栅控 |
| **沟槽 FS** | **`du/dt` 基本不动**（图 3.30 陡降段与 `R_G` 无关） | 平台后 MOS 通道已关断，电流由漂移区载流子决定，**不受栅极控制** |

**工程含义（这条最实用）**：
- 想在沟槽 FS 器件上"靠减小 `R_G` 提高 `dv/dt` / 降 `E_off`"，**做不到** —— 平台之后那段不受控。
- 但**沟槽 FS 的过冲天然更小**，所以低 `R_G` 的收益主要落在**缩短平台**（`t_plateau = Q_GC/I_G`）而不是拖尾。
- **不要拿平面 NPT 的 `R_G`-波形对应关系去推沟槽器件的波形** —— 这是 datasheet 里看不到、只有实测才显形的一条。

## I · 骨架八：20 ℃ 的 PTC→NTC 转折 —— 低温的第三重危险

图 3.23（p103）：给定 `I_C` 与 `U_GE` 时，`U_CE(sat)` 随温度先降后升，**转折点在 20 ℃**。

| 温度区 | 温度系数 | 含义 |
|---|---|---|
| **> 20 ℃** | **PTC**（正） | 热了电流往别处跑 → **自动均流**、抑制热点 |
| **< 20 ℃** | **NTC**（负） | 热了电流更集中 → **正反馈**、热点易形成 |

书的机理：低温下发射极效率很低，P 型集电区掺杂浓度低、半导体表面载流子浓度很低，**P 集电区与背面金属之间的电阻影响增大**；低于 20 ℃ 时这个效应开始主导。

> **这是"冷更危险"的第三条腿**：① 低温阻断电压下降（图 3.34，−50 ℃ 时 `U_CES` 只剩 87.7 %，模块 `16`）；② 低温小电流更易射频振荡（模块 `02`、`23`）；③ **低温下并联失去自均流机制**（本条）。
>
> **③ 对封装/系统最有杀伤力**：多芯片模块在**冷启动 / 低温存储后首次上电**时，芯片间 `V_CE(sat)` 的微小差异会被 NTC 放大，而不是被拉平。→ **低温工况的并联降额不能套用常温的式 8.1**（模块 `08`）。

## A1 · 本地复算：为什么"只占 7 %"的封装损耗值得单独改

**背景**：骨架一算出封装内互连只占通态损耗 6.8–7.3 %。按这个比例，把铝线换铜线（电阻降到 1/1.48，模块 `14`/`25`）只省 2–3 % 的总损耗 —— **看起来不值得做**。

**但书 p57 给的实测对照是**：600 A、12 × 500 μm 键合线，**铝 325 ℃ vs 铜 200 ℃，降 125 K**。

**两个数放在一起就是本模块的核心论点**：

```
总损耗占比：7 %  →  换铜只省 ~2 %（26 W 级）
局部温度：  −125 K（325 ℃ → 200 ℃）
```

**为什么不成比例？** 因为键合线的**散热路径极差**：

| 部件 | 损耗密度 | 散热能力 | 结果 |
|---|---|---|---|
| 芯片 | 高 | 好（整面贴 DBC，`R_th` 低） | 温升可控 |
| **键合线** | 中 | **差（只有两端焊点导热，线身靠灌胶/气）** | **局部温度最高** |

> `[推断]` 这是"损耗占比 ≠ 温升占比"的通用原因：**局部温度 = 损耗密度 × 局部热阻**，而总损耗占比只是"损耗密度 × 体积"的积分。**用总占比判断封装改动价值，会系统性低估那些"体积小、热阻大"的部件 —— 键合线、焊层、端子正好都是。**

**判据（可直接用于设计评审）**：
- 评估任何封装改动时，问的不该是"这能省多少总损耗"，而是"**这能把哪个节点的局部温度降多少**"。
- 反过来：**总损耗下降 ≠ 可靠性提升**。烧结银把失效点从键合线迁到芯片/焊层（模块 `25`，34000 → 62000 周次）就是这个道理 —— 不是"损耗降了"，是"最热的那一点换位置了"。

## A2 · 本地复算：轻载时 `E_rec` 被低估 5.95 倍

**场景**：某 UPS/充电机在 **10 % 负载**下做效率标定，工程师按"电流线性缩放"估二极管开关损耗。

```
线性缩放：E_rec(0.1·I_nom) = 0.10 · E_rec(I_nom)
式 3.17： E_rec(0.1·I_nom) = (0.45×0.1 + 0.55) · E_rec(I_nom) = 0.595 · E_rec(I_nom)
低估倍数：0.595 / 0.10 = 5.95×
```

**后果链**：
1. 轻载效率被高估 → 能效认证（如 80 PLUS 的 10 % 负载点）可能不达标；
2. 轻载时若仍按"损耗很小"设计散热，**局部热点在轻载下反而更突出**（因为芯片自身损耗降了，但二极管的底还在）；
3. 双向变换器在**轻载反向**时，二极管承担的比例上升，这个 0.55 的底影响更大。

> **书自己给的误差是 20 %**（p99），指的是 `E_rec` 随电压的线性缩放；**"随电流线性缩放"的误差不在那 20 % 里**，是另一个数量级的错。两者别混。

## A3 · 跨文件复盘：π 倍事故

`worked-examples.md` 算例 B 的开关损耗漏了 `1/π`，导致 `P_sw` 从 689.5 W 算成 2166 W，`T_j` 从 143.7 ℃ 算成 224.9 ℃，**结论从"灰色带"翻成"FAIL"**。

完整复盘（含"为什么没人发现"的三条原因）在 **`worked-examples.md` B⑧**，此处只留判据：

> **当估算结果"看起来保守"时，正是最该核系数的时候。** 保守的错误不触发告警，只会安静地改变你的决定。

## S · 步骤：从 datasheet 到一份可交的损耗账

1. **确认电压/电流口径**：datasheet 的 `U_CE(sat)`、`V_F` 是**端子值**。若要芯片值，先查 `R_CC'+EE'`，用式 3.8/3.22 减掉。若 datasheet 没给 `R_CC'+EE'` → **写"未给"，不许自己编**（`34-formula-index §12`）。
2. **确认温度**：`U_CE0`、`r_CE`、`E_on/E_off` 必须是**工作结温**下的值。25 ℃ 的数直接代入＝系统性低估 30–50 %。
3. **确认波形口径**：正弦（VSI）用 `1/π`；恒流（斩波）用 `1`。**在报告里写明用了哪个**，并写出式子编号（3.16/3.26/3.28/3.29 或 p99 文字）。
4. **确认电流分布**：用式 3.24 的 `I_avg`/`I_rms`，**不要用 `î/2` 或 `î/√2` 代替** —— 带 `m·cosφ` 的修正项不是小数（本算例 `I_avg` 从 `î/π`=180 A 修正到 150 A）。
5. **开关损耗加误差棒**：`±30 %`（书 p99/p104 的"20 % 偏差" + 积分窗差异）。写成 `689 ± 207 W`，不要写 `689 W`。
6. **反算一次 `P_sw` 的量级**：用 `P_sw/P_cond` 的比值交叉检查。本算例 689/378 = **1.8** —— 高压大电流高频下 `P_sw > P_cond` 是正常的；若得到 `P_sw/P_cond > 5`，先怀疑系数。
7. **写清"不能用在哪"**：见 B 段。

## B · 边界（这一篇不能用到哪）

1. **式 3.24 不适用于非正弦电流**。方波驱动、BLDC 六步换相、以及带大幅纹波的 DC-DC，`I_avg`/`I_rms` 都要自己积分，不能套 `m·cosφ` 那组修正。
2. **`R_CC'+EE'` 书里没有任何典型值**。本模块的 0.4 mΩ 是 `[假设]`。真实值必须查具体模块 datasheet，且**它随温度上升**（铜 +0.4 %/K），高温下这一项的占比会比常温算出来的高。
3. **式 3.8/3.22 只减掉了"电阻性"压降**。它不含芯片与互连之间的**接触电阻/焊层**贡献 —— 若焊层有空洞，实际 `U_CE,Module` 会高于"芯片 + `R_CC'+EE'·I`"，差额就是焊层劣化的电学指纹（可作 PFMEA 的监控量，但**书未给判据**）。
4. **`1/π` 只在"单个器件、正弦、半桥"下成立**。模块里 6 个开关管的**总**开关损耗是单管的 2 倍（上下桥臂各半周期），不要拿单管的 `1/π` 结果乘以 6 去估整模块。
5. **图 3.28 的拖尾-母线关系是 Trench-FS 的**。PT/NPT 的拖尾机理不同（少子寿命控制），不能照搬。
6. **式 3.17 是书给的经验拟合（0.45/0.55）**，不是物理推导。不同厂家 `E_rec`-电流曲线的偏置不一样（有的接近线性），**引用前用该器件 datasheet 的两点值验证一次**。
7. **图 3.23 的 20 ℃ 转折是"给定 `I_C` 与 `U_GE`"下的**。大电流下转折点会移动；且它是 NPT/FS 的共性，**不是所有 IGBT 技术都有**。
8. **本模块不含 E 的积分窗口定义**。`E_on` 用 `I_C 10 % → U_CE 2 %`、`E_off` 用 `U_CE 10 % → I_C 2 %`、`E_rec` 用 `U_R 10 % → I_RM 2 %`（式 3.1–3.3，书 p91）—— 定义与跨厂可比性在模块 `23`，**引用 E 值前必先去那里确认窗口**。
