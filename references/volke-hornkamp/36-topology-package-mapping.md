# 36 · 拓扑 → 封装参数的映射：客户给了拓扑，你的模块规格怎么定（第 11 章 × 第 5/13/25/27 章综合）

> 一句话：**同一个 3.3 kV / 20 nH 的模块，在两电平 VSI（母线 1.8 kV）里判 PASS，在 Z 源（升压 2×）里判 FAIL 差 400 V** —— 差别不在模块，在拓扑。所以"我这个模块行不行"这个问题**必须带拓扑才能回答**。
>
> 本模块是**跨章综合**，不是第 11 章的复述：第 11 章的拓扑结论在 `35-converter-topologies.md`，本模块只做一件事——把拓扑翻译成模块规格书上的字段。

## R · 原文锚点

> 「对于这类电路拓扑，**除了选择电压等级外，IGBT 封装外壳的绝缘等级非常重要**。」【书 p297】

> 「为了满足各种各样的需求，**生产商提供了相同电压级别但绝缘等级不同的模块**。」【书 p297】

> 「三电平逆变器的一个设计准则就是尽可能地降低寄生电感，尤其是**降低 T_1b 和 VD_1 的换流通路上的杂散电感**。」【书 p299】

> 「由于无法在市场上买到反向阻断 IGBT，所以**只能采取分立元件的解决方案**。」【书 p299】

> 「与传统的 VSI（包括换流期间由于寄生杂散电感导致的过电压）相比较，**IGBT 的阻断电压将升高**。……输出电压为 400 V 和输入电压为 100 V，**必须使用 U_CES = 1.7 kV 的 IGBT 来取代 1.2 kV 的 IGBT**。」【书 p303】

> 「因为只有三分之一的开关通过电流，所以**热阻会上升**。」【书 p304】

> 「`U_term,max = U_CES + L_σCE·di_C/dt`」【书 p142，式 5.1】

> 「手册给的 R_th,ch 是按 **d = 50–100 μm、λ = 1 W/(m·K)** 的假定算的」【书 p117，见模块 27】

## I · 骨架一：模块规格书九个字段，谁决定它

这是本模块的核心表。**左边一列是你要写进规格书的东西，右边一列是它的真正决定者**——凡是"决定者"写着"拓扑"的字段，都不能用"同功率同电压的别家产品"来对标。

| # | 规格书字段 | 真正的决定者 | 拓扑以什么方式决定它 | 依据 |
|---|---|---|---|---|
| 1 | **U_CES（电压等级）** | 拓扑 + 母线 + L_σ·di/dt + 低温 | 两电平要扛全母线；三电平只扛 ½U_DC；Z 源扛"高于母线" | 式 5.1 / p297 / p303 |
| 2 | **I_C（电流等级）** | 拓扑 + 过载倍数 | 伺服 2~6× 过载；斩波器因 100 Hz 开关损耗低可小一档 | p305 / p286 |
| 3 | **U_iso,module（绝缘等级）** | **接地点 + 散热器电位** | 中性点接地 → 3.3 kV；未接地 → 6.5 kV（同为 3 kV 母线） | p297 |
| 4 | **R_th,jc** | 拓扑的**导通占位** | DMC 的 0Hz VSI 只 1/3 开关导通 → 有效热阻上升 | p304 |
| 5 | **L_σCE（内部杂散电感）** | 拓扑的换流通路 | 三电平要压 T_1b/VD_1 换流通路；Z 源靠它决定过压 | p299 / p303 |
| 6 | **封装形态**（模块/分立） | **器件可得性** | CSI 需反向阻断 → 买不到 RB-IGBT → 只能分立 | p299 |
| 7 | **基板/底板配置** | 拓扑的热流路径 | 伺服要 2~6× 过载 → 要大 Z_th,jc → 多带铜基板 | p305 |
| 8 | **键合负载周次能力** | 使命剖面（拓扑决定） | 伺服要求"达到十年或更长的使用寿命" | p305 |
| 9 | **驱动 DC-DC 绝缘** | 与 #3 联动 | 3.3 kV 模块配**加强** 10.2 kV 驱动（非标准 6 kV） | p297 |

**读法**：#1/#3/#5 三个字段**完全由拓扑决定**，且**互相耦合**（改拓扑会同时改三个）。#4/#7/#8 由拓扑 + 使命剖面共同决定。#2/#6/#9 是拓扑的间接后果。

## I · 骨架二：八类拓扑 × 六个关键字段（现场速查）

| 拓扑 | 器件电压基准 | 绝缘等级依据 | L_σ 敏感度 | 热阻敏感点 | 形态倾向 | 书页 |
|---|---|---|---|---|---|---|
| **PIM/CIB 整流级** | √2·U_LL | 按母线 | 低（二极管） | 浪涌时键合脚 | 模块（集成） | p282–286 |
| **AFE** | U_DC × 1.1~1.2（升压模式） | 按母线 | 中 | FWD 浪涌耐受弱 | 模块 | p287 |
| **维也纳 / 三电平整流** | **½U_DC** | 按母线（三电平） | **高**（换流通路） | 器件数减半 | 模块（3 个即可） | p288–289 |
| **Buck/Boost DC-DC** | 母线或输出 | 按母线 | 中 | 单管集中 | 分立/模块均可 | p290–292 |
| **两电平 VSI** | **U_DC**（全母线） | 按母线 | 中 | 开关损耗 | 模块（主流） | p294–296 |
| **多电平 NPC/FCML** | **½U_DC** | **接地点决定（3.3 vs 6.5 kV）** | **高** | 换流通路 | 模块（600/650 V 半桥） | p297–299 |
| **CSI** | 高（含负压） | 按母线 | 中 | 恒定母线电流 | **只能分立** | p299 |
| **Z 源** | **高于母线** | 按母线 + 短路态 | **极高** | 短路态通态损耗 | 模块 | p300–303 |
| **DMC / IMC** | 线电压（双向） | 按母线 | 中 | **0Hz VSI 局部热集中** | 模块（IMC）/ 特殊 | p303–305 |

**用法**：客户说"我用的是三电平"，你不要立刻按"⅓ 母线电压"选器件——先问第 3 列"绝缘等级依据"，因为三电平的绝缘等级可能比器件电压等级高一倍（骨架三）。

## I · 骨架三：三个"拓扑 → 规格"的典型错配事故

### 错配 1：把"器件电压等级"当成"绝缘等级"

**现象**：客户用 3.3 kV 模块做 3 kV 母线三电平，器件电气上够（1.5 kV + 余量），但绝缘型式试验不过。

**原因**：p297 的两种配置 —— 中性点接地（散热器同电位）→ 绝缘要 3.3 kV 就够；**中性点浮地** → 绝缘要 **6.5 kV**。器件电压等级没变，绝缘等级翻倍。

**处置**：规格书上 **U_CES 与 U_iso 必须是两个独立字段**，询价时分别写。看到"3.3 kV 模块"不能默认绝缘也是 3.3 kV 档。

### 错配 2：用"母线电压选耐压"忽略拓扑抬升

**现象**：Z 源项目按母线 566 V 选了 1.2 kV，样机炸。

**原因**：p303 明说"与传统的 VSI（包括换流期间由于寄生杂散电感导致的过电压）相比较，IGBT 的阻断电压将升高"，必须 1.7 kV。

**处置**：任何"非常规拓扑"（Z 源、矩阵、电流源、多电平飞跨）在选耐压前，必须先把**该拓扑特有的电压基准**写出来，再套式 5.1。判据是：**稳态母线只是起点，不是依据**。

### 错配 3：把 R_th,jc 当模块常数

**现象**：DMC 项目按 R_th,jc 算结温合格，实测局部过热。

**原因**：p304 的 0Hz VSI —— 只有 1/3 的开关通过电流，**热阻上升**。R_th,jc 是"全芯片均匀发热"条件下的定义值，局部导通时这个定义不成立。

**处置**：凡"导通占位不均"的拓扑（DMC/IMC、CSI 的部分导通段、多电平的死区分布），R_th 都要按**实际导通芯片面积占比**修正，或直接实测该工况的 Z_th。这与模块 27 的"R_th,ch 按 d=50–100 μm 假定"是同一类错误——**用平均值回答局部问题**。

## A1 · 书内可查的两个映射实例

### 实例 1：三电平的三种模块实现方式（图 11.31，p299）

书给了同一台三电平半桥的**三种模块组合**，这是"拓扑 → 封装形态"最直接的映射：

| 方案 | 构成 | 器件数 | 特点 |
|---|---|---|---|
| a | **四个分立 IGBT 模块 + 一个双二极管模块** | 5 | 最灵活，L_σ 最大 |
| b | **两个 IGBT 半桥模块 + 一个双二极管模块** | 3 | 折中 |
| c | **一个斩波器模块（IGBT/D）+ 一个 IGBT 半桥模块** | 2 | L_σ 最小，机械最简 |

书还补了一条时间线：**"大约从 2008 年起，厂商开始提供 600 V 或 650 V 电压等级的三电平半桥模块，也就是说一个三相三电平逆变器仅用三个模块就可以实现"**，目标是"简化机械设计的同时**减小由杂散电感产生的关断过电压**"（p299）。

→ **这是"封装形态随拓扑演进"的实证**：不是先有标准模块再套拓扑，而是拓扑倒逼出专用模块（三电平半桥模块）。对封装厂的启示：**新拓扑是模块新品类的入口**。

### 实例 2：伺服驱动的"封装三要求"（p305）

书对伺服驱动给了三条**直接指向封装**的要求：

1. "伺服驱动中的功率半导体需要具有很强的过载能力，**一般要承受 2~6 倍的额定电流**"（p305）
2. "为了在几分之一秒到几秒内完成响应，最重要的是具有**足够大的热容量 Z_th,jc**"（p305）
3. "在这类应用中，**大多数的 IGBT 模块采用带铜基板的模块**。而且，**IGBT 的键合点需要具有很高负载周次能力**，从而能够保证其达到十年或更长的使用寿命"（p305）

**三条合起来就是一份规格书**：过载倍数 → I_C；大 Z_th,jc → 带铜基板；高负载周次 → 键合工艺等级 + 寿命目标。这是全书里**唯一一处把"应用 → 三个封装参数"直接写死的地方**，可以直接当报价依据。

## A2 · 三组本地复算（均为脚本实跑）

> 用 `scripts/igbt_book_budget.py terminal` 实跑，同一模块（3.3 kV / 20 nH / 5 kA/μs）在三种拓扑下的判据。
> 复算命令附在每个小结末尾，可自行验证。

### A2-1 同一模块，VSI 里 PASS

```
U_CES = 3300 V，L_σ = 20 nH，di/dt = 5 kA/μs → L·di/dt = 100 V
两电平 VSI，母线 1800 V
  U_bus + L·di/dt = 1900 V  → 占耐压 58 %
  [PASS]  扣掉尖峰后仍余 1400 V（42 %）
```

### A2-2 同一模块，Z 源里 FAIL

```
同一模块，Z 源升压 2× → 母线 3600 V
  U_bus + L·di/dt = 3700 V  → 占耐压 112 %
  [FAIL]  静态裕量 -300 V，扣尖峰后 -400 V
```

**结论**：**从 PASS 到 FAIL，唯一变化是拓扑把母线从 1800 V 抬到 3600 V。** 这就是为什么"我这个 3.3 kV 模块能不能用"必须带拓扑问。差额 400 V 无法靠"降 di/dt"补（要把 5 kA/μs 降到 3 kA/μs 才省 40 V），只能升耐压等级。

```bash
python scripts/igbt_book_budget.py terminal --uces 3300 --lsig 20e-9 --didt 5e9 --u-bus 1800
python scripts/igbt_book_budget.py terminal --uces 3300 --lsig 20e-9 --didt 5e9 --u-bus 3600
```

### A2-3 3 kV 母线：两电平只剩 6 % 裕量

```
两电平 VSI，母线 3000 V，同一模块
  U_bus + L·di/dt = 3100 V  → 占耐压 94 %
  [PASS]  但扣掉尖峰后仅余 200 V（6 %）
```

**这条正好印证书 p297 的选择逻辑**：3 kV 母线做三电平，单管只扛 1.5 kV，配 3.3 kV 器件裕量充裕（1600/3300 = 48 %）；做两电平，3.3 kV 器件只剩 6 %，**必须上 6.5 kV**。所以"三电平"的存在理由在 p298 写得很清楚：*"由于无法获得高阻断电压的半导体器件，因此设计三电平逆变器是有必要的"*。

**再叠低温**：`--temp-derate 12.3` 后 U_CES 降到 **2894 V**，3100 V 立刻变成 **107 % → FAIL**。同一台设备，**夏天过、冬天不过**——这就是模块 16 那条"低温最危险"的工程后果。

**更值钱的是脚本反解出的那个负数**：`反解允许 di/dt = (2894 − 3000)/20e-9 = −5.30 kA/μs`。

> **负的允许 di/dt 意味着"即使 di/dt = 0 也不够"**——母线 3000 V 本身已经超过低温下的 2894 V 耐压。此时任何"降 di/dt、加缓冲、放缓开关"的措施全部无效，**唯一出路是升耐压等级或降母线**。
>
> 这条判据值得做成习惯：**看到反解出负数，立即停止调参数，回头改选型。**

```bash
python scripts/igbt_book_budget.py terminal --uces 3300 --lsig 20e-9 --didt 5e9 --u-bus 3000
python scripts/igbt_book_budget.py terminal --uces 3300 --lsig 20e-9 --didt 5e9 --u-bus 3000 --temp-derate 12.3
```

## E · 触发场景

1. **客户只给"功率 + 母线电压"，问你要什么模块** → 先要拓扑，否则骨架一的 9 个字段里 3 个定不了
2. **同一型号在 A 客户合格、B 客户不合格** → 查骨架三错配 1（接地点/绝缘等级）
3. **"这个模块能不能替代那个模块"** → 过骨架二，确认两个拓扑的电压基准与 L_σ 敏感度是否同档
4. **新拓扑项目（Z 源/矩阵/CSI/多电平）报价** → 强制走骨架三错配 2，先写拓扑特有电压基准
5. **客户投诉"局部过热、整体温度正常"** → 查骨架三错配 3（导通占位不均 → 有效 R_th 上升）
6. **模块新品立项** → 看 A1 实例 1：三电平半桥模块是"拓扑倒逼出的新品类"，这是产品线机会

## S · 步骤

**把客户拓扑翻译成模块规格，六步**：

1. **锁定拓扑族**（骨架二表的第 1 列），记录书页。
2. **写拓扑特有的电压基准**：U_DC / ½U_DC / 高于母线。**不许直接填母线电压**。
3. **套式 5.1 定耐压**：`U_term,max = U_bus + L_σ·di/dt`，L_σ 取表 2.2 封装级值；再叠低温 `--temp-derate`。两点都过才定档（`worked-examples.md` 算例 C 的教训：25 ℃ 过、−50 ℃ 不过）。
4. **单独定绝缘等级**：问接地点 + 散热器电位 + 驱动 DC-DC 标准/加强；按 `U_iso,Tra > 2·U_Module/√2 + 1000 V` 双向验算（模块 35 的 A2-2）。
5. **核对热与寿命**：过载倍数 → Z_th,jc 要求；导通是否均匀 → R_th 是否需要修正；使命剖面 → 选模型（多段小摆幅 vs 少次大摆幅，见算例 A）。
6. **落成规格书**：按骨架一的 9 个字段逐项填，**#3 绝缘与 #9 驱动绝缘必须单独成行**，并在备注里写"依据：【书 p297】/【拓扑：X】"。

## B · 边界

1. **本模块是跨章综合，不是书内章节**。书里没有"拓扑 → 模块规格"这张表，它是把第 11 章（拓扑）、第 5 章（datasheet/式 5.1）、第 2 章（绝缘）、第 14 章（寿命）四处的结论拼起来的。**凡表中标"依据"为多个书页的，都是本技能的整合，不是书的原话。**
2. **绝缘公式的适用口径必须核**。`U_iso,Tra > 2·U_Module/√2 + 1000 V` 出自图 11.29（p298），书未给出它的标准出处与适用电压范围。**用于正式设计前必须核 IEC 60664 与客户规范**，本技能只保证"书上确实这么印"。
3. **拓扑对 R_th 的修正没有公式**。`34-formula-index.md §12` 明确列了"R_th(j-c) 典型值"是书未给项；"导通占比修正 R_th"书更未给。骨架三错配 3 只给**定性方向**（局部导通 → 有效 R_th 上升），**不给系数**，必须实测或仿真。
4. **八类拓扑的表是 2012 年的判断**。Z 源之后的派生拓扑（qZSI、SL-qZSI）、SiC 混合方案、以及 2012 年后出现的新多电平变体均未覆盖。p307 只提到碳化硅二极管"有一定的应用前景"。
5. **本章不解决"该用分立还是模块"**。书只在 CSI 那一处给了明确答案（因买不到 RB-IGBT 只能分立，p299）。其余场合的分立/模块分界见模块 19（UPS 分界）与模块 17（封装谱系），本模块只用不重复。
6. **A2 的三组复算共用同一组假设**（20 nH、5 kA/μs）。真实模块的 L_σ 见表 2.2（34 mm 30 / 62 mm 20 / EconoDUAL3 20 / IHM G1 10 / IHM G2 6 / PrimePACK3 10 nH），di/dt 由 R_G 决定（模块 30）。**换假设必须重跑，不许外推。**
