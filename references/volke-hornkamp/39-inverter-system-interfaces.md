## I · 骨架一：吸收电容先要问"砍得掉哪一段"

书 p346 给的过电压是两段相加，不是一段：

```
U_peak,noSnubber = U_DC + ΔU_noSnubber = U_DC − L_σ,noSnubber · di/dt      (13.6)
```

关键在图 13.5 的**环路分解**（p347）：

| 环路 | 组成 | 加吸收电容后 | 能不能砍 |
|---|---|---|---|
| `L_σ1,DC_ESL` | 直流母线电容的 ESL | → 被 `L_σ4,Snubber` 替代 | ✅ 能 |
| `L_σ2,DC` | 母排/直流母线导体（除电容 ESL 外的全部寄生电感） | → 被 `L_σ4,Snubber` 替代 | ✅ 能 |
| `L_σ3,Module` | **IGBT 模块内部**的全部寄生电感 | **仍然在里面** | ❌ **砍不掉** |

所以式 13.7 的不等式两边同时减去 `L_σ3,Module`，得到一个**纯工程判据**：

```
L_σ4,Snubber  <  L_σ1,DC_ESL + L_σ2,DC          (13.7 化简)
```

**这一条是全节最实用的东西**：吸收电容支路自己的电感，必须**小于母线侧那两段之和**，才可能降低过电压。它经常不成立——小 MKP 电容本体 ESL 很低，但**引线长度、安装方式、到端子的连接**会把它拉回去。这也是书 p347 强调"吸收电容最好能直接安装在 IGBT 模块上，这样电容与 IGBT 之间连线包围的面积最小"的原因。

由此得到一条对封装侧最直接的结构性结论：

> **模块内电感 `L_σ3` 是吸收电容的天花板。**当 `L_σ3` 已经在总电感里占大头时，"再加一个电容"这条路的上限就被锁死了，唯一有效动作是换低感封装（表 2.2：34 mm 30 nH / EconoDUAL3 20 nH / IHM G1 10 nH / IHM G2 6 nH / PrimePACK3 10 nH，见 `14-interconnect-lowinductance.md`）。

## I · 骨架二：式 13.9 的量纲不成立（本文最重要的一条）

书 p347 给的吸收电容值是：

```
C_Snubber ≈ L_σ,total · I_peak / (U_CE,peak − U_DC)²          (13.9，书印)
```

**量纲检查**：法拉 `F = A·s/V`；电感 `H = V·s/A`。

```
书印式：(V·s/A)·A / V²  =  s/V      ← 不是法拉
应为  ：(V·s/A)·A² / V² =  A·s/V = F  ✓
```

**分子少了一个 `I_peak`。** 这不是"精度问题"，是**照抄会小 1000 倍**（`I_peak = 1000 A` 时正好 1000 倍）。

**更硬的内部证据**：同一页的式 13.11 是

```
U_osc,peak ≤ √( (L_σ1,DC_ESL + L_σ2,DC) · I_C² / C_Snubber )     (13.11)
```

式 13.11 的量纲是对的（`H·A²/F = V²`）。把它反解，令 `U_osc,peak = ΔU = U_CE,peak − U_DC`：

```
C_Snubber = L_σ · I_C² / ΔU²        ← 正是能量守恒 ½CU² = ½LI²
```

**同一页两个式子互相矛盾，式 13.11 反推出的才是对的。** 所以式 13.9 的 `I_peak` 上标丢失（本书有丢上标的先例：p61 把 `10⁸ V/m` 印成 `10⁶ V/m`），可以判为**排印缺陷**，但这个缺陷会让读者算出的电容小三个数量级。

**本地复算（`[假设]` L_σ=50 nH、I_peak=1000 A、U_CE,peak=1700 V、U_DC=1100 V）**：

| 口径 | C_Snubber | 式 13.10 得 f_osc | 可实现性 |
|---|---|---|---|
| 书印式（分子 `I_peak`） | **139 pF** | **60.4 MHz** | ❌ 小于 MKP 自身 ESL 的作用量级，物理上无意义 |
| 能量守恒（分子 `I_peak²`） | **139 nF** | **1.91 MHz** | ✅ 与工程实际 0.1–2.2 μF MKP 同量级 |

60 MHz 这个数本身就是反证：IGBT 的开关 `du/dt` 频段在 MHz 以下，谐振跑到 60 MHz 说明 LC 组合不成立。

**引用纪律**：报告里要写吸收电容值，写「按 `C = L_σ·I_peak²/ΔU²`（能量守恒，与书式 13.11 自洽）」，**不要写"据书式 13.9"**。

## I · 骨架三：吸收电容的取舍是真实的，不是"加了就好"

书在同一节里给了两条方向相反的话，必须并列读：

| 位置 | 原话 | 含义 |
|---|---|---|
| p346 正文 | 「如果无法通过降低结构的杂散电感，保证半导体器件的开关过电压低于其允许电压，那么吸收电容就值得考虑」 | **前置条件**：先试着降电感 |
| p348 脚注② | 「通常，吸收电容会增加成本并**降低系统的寿命**，所以最好不用吸收电容」 | **代价**：增加成本、降系统寿命 |

这不是矛盾，是**决策顺序**：`降 L_σ`（改母排/换低感封装）→ 仍然过压 → 才上吸收电容。与 `32-soft-switching-snubber.md` 的结论一致，两处可互相印证。

**选型边界（p348，全部是硬条件）**：

| 条件 | 书给的数 |
|---|---|
| 电容电压等级 | **≥ 半导体器件与直流母线的电压等级** |
| 1.2 kV 模块 / 母线 <800 V 的常规配法 | 电容标称**不低于 1 kV**（留 >200 V 余量） |
| 温度影响 | 电容标称电压**随温度升高而下降**；工作温度较高时标称电压**必须高于** 1 kV |
| 电流 | **不得超过**供应商手册标注的 `I_RMS` 与最大脉冲负载 |
| 类型 | **MKP 金属聚丙烯薄膜**（对电解质缺陷有自愈能力） |
| 位置 | **直接安装在 IGBT 模块上**（连线包围面积最小） |
| ESL | 必须低于 `L_σ1 + L_σ2`（见骨架一判据） |

p348 脚注③还给了 MKP 自愈的机理与代价：金属膜局部击穿时电弧使涂层汽化、穿透点蒸汽压力使电弧熄灭，形成小孔，**略微降低电容容量**——这是"自愈"不是"无损"。

## I · 骨架四：驱动布局——四种方案与三种布局的实测

书 p349 图 13.9 给了四种布局，各自的优缺点原文照录：

| 方案 | 结构 | 优点 | 缺点 |
|---|---|---|---|
| **a) 附带驱动级模块** | 驱动级与模块一体 | 定义所有模块设计；**低寄生效应**；**保护功能效果良好** | —（无缺点列出） |
| **b) 适配板 + 驱动核心板** | 母板上留适配板，驱动核经双绞线/屏蔽电缆连 | 机械灵活性好；**开关特性几乎不受电缆长度影响**；保护功能效果良好；适合并联 | **增加零件数目** |
| **c) 模块与驱动级分离（<15 cm）** | 分离安装 | 机械灵活性较好 | **对开关特性的影响有限**；集电极电缆对其他部件需足够绝缘能力 |
| **d) 模块与驱动级分离（>15 cm）** | 分离安装 | 机械灵活性较好 | **对开关特性的影响明显**；集电极电缆对其他部件需足够绝缘能力 |

**图 13.10 的实测**（p349）：三条曲线分别对应
- **1** = 驱动适配板和驱动核分离，**距离小于 15 cm**
- **2** = 驱动适配板和驱动核分离，**距离大于 100 cm**
- **3** = 驱动级通过 **100 cm 长的电缆**与 IGBT 模块的辅助端子相连

书只给波形、没给数字，**但波形方向是明确的：方案 3（经 100 cm 电缆接辅助端子）的 `E_on`、`E_off` 明显最大，且 `U_CE` 出现更明显的振荡。** 注意方案 2（分离 >100 cm）反而与方案 1 接近——**说明关键不是"分离多远"，而是"栅极回路有没有被长电缆串进去"**。这是一个容易被忽略的读图结论：把驱动核放远、但用合适的适配板走线，比用长电缆直连辅助端子要好得多。

**p350 给了两个反向代价**（驱动级贴着模块不全是好处）：

1. 模块**辅助端子温度可能接近 PCB 极限温度**，并升高 PCB 附近电子器件的环境温度；
2. 模块内部**大电流产生磁场**，尤其**关断短路电流时**，磁场会耦合到 PCB 上的电子器件并导致故障。

> 这两条对封装设计的含义：**模块顶部温度场与杂散磁场分布，是"能不能把驱动贴上去"的决定因素**，而不是机械空间。短路关断那一瞬是磁场最恶劣的时刻。

## I · 骨架五：电机电缆——`U_motor = 2·U_inverter` 是硬结论

这一节和第 13 章其他部分不同：**它算的不是模块承受的应力，而是模块制造出来的应力打到哪里去了。** 但对封装侧仍有两条直接含义（见 B 段）。

**第一步：`du/dt` 由母线电压除以固定时间常数得到（式 13.12）**

```
du/dt ≈ U_DC / 150 ns          (13.12)
```

书把这 150 ns 称为"开关时间的暂取中间值"，并明说"根据实际情况，这个时间可能增大或减小"。**这是典型值，不是规格值。**

表 13.4 与该式完全自洽（本地复算，偏差 <1.5 %）：

| 线电压 | 直流母线电压 | 表 13.4 印 `du/dt` | 式 13.12 复算 | 偏差 |
|---|---|---|---|---|
| 230 V / 1~ | 325 V | 2.2 kV/μs | 2.17 kV/μs | 1.5 % |
| 400 V / 3~ | 565 V | 3.8 kV/μs | 3.77 kV/μs | 0.9 % |
| 690 V / 3~ | 975 V | 6.5 kV/μs | 6.50 kV/μs | 0.0 % |

→ **表 13.4 是式 13.12 的直接产物，可以直接引用；但要记住它假设了 150 ns。**

**第二步：电缆参数（式 13.13–13.15）**

```
L'_cable = μ0·( ln(2a/d) + 0.25 ) / (2π)        [μH/m]      (13.13)
C'_cable = 2π·ε0·εr / ln(2a/d)                  [pF/m]      (13.14)
Z_cable  = √( L'_cable / C'_cable )             [Ω]         (13.15)
```

书给 `Z_cable` 的工程区间：**50–75 Ω**。

本地复算（`[假设]` a=10 mm 导体间距、d=2 mm 导体直径、ε_r=4.0）：

```
L' = 0.511 μH/m, C' = 96.6 pF/m → Z_cable = 72.7 Ω   ✓ 落在 50–75 Ω
```

**第三步：反射（式 13.16–13.18）**

```
U_ref = U_inverter · (Z_motor − Z_cable)/(Z_motor + Z_cable)      (13.16)
```

电机阻抗远高于电缆阻抗 → 式 13.16 简化为 `U_ref = U_inverter`（式 13.17），于是

```
U_motor = U_inverter + U_ref = 2 · U_inverter       (13.18)  ← 电机端承受两倍母线电压
```

| 母线 | 电机端峰值 |
|---|---|
| 325 V | **650 V** |
| 565 V | **1130 V** |
| 975 V | **1950 V** |

**第四步：什么时候会发生全反射（式 13.19）**

```
v_pulse = 1 / √(L'_cable · C'_cable)      (13.19)
```

书给 ≈ **150 m/μs**。本地复算 ε_r=4.0 得 142 m/μs、ε_r=2.3 得 188 m/μs —— 与 150 m/μs 同量级。

书给的经验判据原文是「**如果从逆变器到电机的脉冲电压传播速度大于脉冲上升时间的 50 %，就会产生全反射电压**」，并在 p352 补充「**当电缆超过 15 m 左右时，就可以观测到这种波形**，且随电缆变长而增强」。把它写成可算的形式：

```
d_critical = 0.5 · t_r · v_pulse
```

| ε_r | v_pulse | `t_r`=150 ns 时的临界长度 |
|---|---|---|
| 4.0 | 142 m/μs | **10.7 m** |
| 2.3 | 188 m/μs | **14.1 m** |

→ 与书说的"15 m 左右"吻合。**注意这个临界长度随 `t_r` 线性缩短**：换成更快的器件（`t_r` = 50 ns）就变成 3.6–4.7 m——**快器件把电缆长度的容忍度直接砍掉 2/3**。

**后果（p351–352）**：电机绝缘承受反复的 2 倍过压；更隐蔽的是**移位电流经电机轴承**，导致轴承电蚀。图 13.11 的仿真实测（560 V 母线、长电缆、80 μH/10 nF 分段模型）：电机端 `U_motor` 峰值明显超过母线电压，并在换向沿后出现 -0.3 kV 级的负向振荡。

**对策（p351 四条，p355 三条滤波器）**：逆变器输出端串联电抗器、电机侧串联电抗器、电机侧并联吸收电容、增加低通滤波器（`du/dt` 滤波器）。

## I · 骨架六：EMI 滤波——差模/共模的物理来源与三个位置

**差模与共模的定义（图 13.12，p353）**：

| 模式 | 路径 | 来源（p352 原文） |
|---|---|---|
| **差模（对称）** | 去与回在同一对导体上流动 | 电缆中的差模电流**源于 IGBT 与二极管的开关行为**，低频时引起电流上升时间较长 |
| **共模（不对称）** | 去与回经地构成回路 | 电缆中的共模电流**由开关时的 `du/dt` 与耦合电容共同作用**产生 |

> 一句话：**差模是"电流换向"产生的，共模是"`du/dt` 对地充电"产生的。**两者对策不同（`C_X` vs `C_Y` + 共模扼流圈），混用无效。

**三个滤波位置与各自的设计式**：

| 位置 | 元件 | 设计式 / 关键数 |
|---|---|---|
| **电源（输入）滤波器** | `L_A/L_B/L_C` 差模扼流圈 + `C_X` + `C_Y` + 压敏电阻 | 式 13.20：`X_L = 2π·f_grid·L`，`U_K = I_N·X_L·√3`；**设计目标 `U_K/U_N ≈ 4 %`**；400 V → `U_K = 16.1 V` |
| **直流母线滤波器** | `L_DC` **共模**扼流圈（同一磁芯上两个相同线圈）+ `C_X` + `C_Y` | **对称电流下磁通互相抵消，只呈现约 `L_DC` 的 1 % 漏感**；不对称电流时才起作用 |
| **输出滤波器** | `du/dt` 滤波器 / 正弦波滤波器 / 输出扼流圈 | 电感压降计算方式与电源滤波器相同；**必须防止饱和，电感值尽量恒定** |

**式 13.20 的反解（本地复算，`U_N`=400 V、`U_K`=16.0 V、50 Hz）**：

| `I_N` | `X_L` | `L` |
|---|---|---|
| 50 A | 184.8 mΩ | **588 μH** |
| 100 A | 92.4 mΩ | **294 μH** |
| 200 A | 46.2 mΩ | **147 μH** |
| 400 A | 23.1 mΩ | **74 μH** |

→ 电流翻倍、电感减半：**输入扼流圈的成本几乎完全由 `I_N` 决定**，这是 4 % 电压降目标直接推出来的。

**"1 % 漏感"这条最容易被误用**：它说的是**共模扼流圈对对称（差模）电流只呈现 1 % 的电感**，所以它**不影响**直流母线里的对称工作电流，只抑制不对称成分。反过来说，**如果故障是不对称的（对地短路），这个扼流圈才开始起作用**——但那时它就是个串联电感，会拖慢故障电流上升、影响熔断器与短路保护的配合（见 `22-fuse-modulation.md`）。

## A1 · 案例：1700 V 模块 + 30 m 电机电缆，到底该改哪一头

**需求**：975 V 母线的 690 V 风机泵类变频器，IGBT 模块 1700 V，用户现场电机电缆 **30 m**（远超书说的 15 m）。问：先动吸收电容，还是先动输出滤波？

**输入与假设**：
- 母线 975 V，`du/dt` 按表 13.4 = **6.5 kV/μs**（`[书 p350]`）
- 电缆：`[假设]` ε_r=4.0、a=10 mm、d=2 mm → `L'`=0.511 μH/m、`C'`=96.6 pF/m、`Z_cable`=**72.7 Ω**
- 模块内电感 `L_σ3`：`[假设]` 62 mm 封装 **20 nH**（`[书 p47 表 2.2]`）
- 母排 + 电容 ESL `L_σ1 + L_σ2`：`[假设]` **30 nH**
- 关断 `di/dt`：`[假设]` 5 kA/μs

**第一步：模块端子电压（先把模块这一头算清）**

```
L_σ,total = L_σ1 + L_σ2 + L_σ3 = 30 + 20 = 50 nH
L_σ·di/dt = 50e-9 × 5e9 = 250 V            （50 nH × 5 kA/μs）
U_term    = 975 + 250 = 1225 V
```

1700 V 器件的静态裕量：`1700 − 1225 = 475 V`（占耐压 72 %）。**模块这一头没问题。**
（复算：`python scripts/igbt_book_budget.py terminal --uces 1700 --lsig 50e-9 --didt 5e9 --u-bus 975`）

**第二步：吸收电容能砍多少**

加了吸收电容后 `L_σ` 变成 `L_σ4 + L_σ3`。最佳情况 `L_σ4 → 0`：

```
U_term,min = 975 + 20 nH × 5 kA/μs = 975 + 100 = 1075 V
```

→ **最好情况也只降 150 V**（1225→1075），而且需要 `L_σ4 < 30 nH`（骨架一判据）——这要求电容几乎贴装在端子上。**而 1225 V 本来就在 1700 V 以内**，所以对这个工况，**吸收电容是纯成本、纯降寿命（p348 脚注②），不该装。**

**第三步：电缆那一头才是真问题**

```
d_critical = 0.5 × 150 ns × 142 m/μs = 10.7 m
实际 30 m = 2.8 × d_critical    → 必然全反射
U_motor = 2 × U_inverter ≈ 2 × 975 = 1950 V（未计振荡过冲）
```

→ **电机绝缘承受近 2 kV 的反复脉冲**。按 IEC 60034-17 / NEMA MG1 的常规分级，这已经落在需要 `du/dt` 滤波器或加强绝缘的区间（`[L4 行业实践，非本书内容]`）。

**第四步：结论**

| 动作 | 对模块端子的收益 | 对电机端的收益 | 判定 |
|---|---|---|---|
| 加吸收电容 | 1225 → 1075 V（−150 V，**本来就合格**） | **0** | ❌ 不做 |
| 加输出 `du/dt` 滤波器 | 0（甚至因反射轻微恶化） | 把 1950 V 与 6.5 kV/μs 压下来 | ✅ **做这个** |
| 缩短电缆到 <10 m | 0 | 消除全反射 | ⚠ 现场通常做不到 |

**这个案例的通用形态**：**同一个"过压"问题，可能在模块端、也可能在负载端；吸收电容只在模块端有效，而且在模块端本来合格时完全无用。**先算清楚应力落在哪个界面，再选器件——这是骨架一~六合起来的唯一结论。

## A2 · 案例：`L_σ3` 占大头时，吸收电容的上限在哪

**问题**：如果模块内电感是 34 mm 封装的 **30 nH**（`[书 p47 表 2.2]`），母排 + 电容 ESL 只有 20 nH，吸收电容还值得装吗？

**推理**：

```
L_σ,noSnubber = 20 + 30 = 50 nH
L_σ,withSnubber,min = 0 + 30 = 30 nH        （L_σ4 理想为零）
改善上限 = 30/50 = 40 %
```

`di/dt` = 5 kA/μs 时：`ΔU` 从 250 V 降到 150 V，**只省 100 V**。

**若换成 62 mm 封装（20 nH）**：`L_σ` 从 50 → 40 nH，`ΔU` 200 V。
**若换成 IHM G2（6 nH）**：`L_σ` 从 50 → 26 nH，`ΔU` 130 V。

**结论**：`L_σ3/L_σ,total` 就是"吸收电容能改善的比例上限"的倒数。**当 `L_σ3` ≥ 50 % 时，任何吸收电容方案都只能拿到不到 50 % 的改善**，而代价是成本 + 系统寿命（p348 脚注②）。这就是"低感封装 > 吸收电容"的定量依据——**书没有把这句话写出来，是从图 13.5 的环路分解直接推得的 `[推断]`**。

|---|---|

## S · 步骤（四个界面的检查顺序）

1. **先分界面**：这颗过压/过热/失效，应力是在**模块端子**、**驱动回路**、**电机侧**、还是**电网侧**？四个界面的对策互不替代。
2. **算模块端子**：`U_term = U_DC + L_σ·di/dt`，`L_σ` 按图 13.5 三段分解。**分开写 `L_σ3` 和 `L_σ1+L_σ2`**，不要只写总和。
3. **判吸收电容是否在射程内**：`L_σ3 / L_σ,total` ≥ 50 % → 直接跳到"换封装"；否则先查 `L_σ4 < L_σ1 + L_σ2`。
4. **算 `du/dt`**：`U_DC / 150 ns`（表 13.4 直接查），并记住 150 ns 是典型值不是规格值。
5. **算电缆临界长度**：`d = 0.5·t_r·v_pulse`，`v_pulse` 按电缆 ε_r 取 142–188 m/μs。实际长度 > 2 倍临界 → 必须加输出滤波。
6. **分差模/共模**：共模源头是 `du/dt` × 耦合电容；对策是 `C_Y` + 共模扼流圈，`C_X` 对共模无效。
7. **记录引用的口径**：吸收电容用能量式（不引式 13.9）；`du/dt` 引表 13.4 并注明 150 ns 假设。

## B · 边界（这一节必须读）

1. **13.8 不是空档，是纯转引。**p350 全文只有两句：「电气间隙和爬电距离由通用标准和专用标准定义，详见第 2 章 2.8 节，其中内容也适用于逆变器设计」。**本节没有任何独立数据**，爬电数值一律回 `13-materials-insulation.md`（表 2.3）与 `35-converter-topologies.md` 的绝缘链。
2. **式 13.9 不要用。**量纲不成立（分子缺 `I_peak`），与同页式 13.11 矛盾。用 `C = L_σ·I_peak²/ΔU²`。这是本文最需要传递的一条。
3. **图 13.10 只有波形，没有数字。**书没给三种布局的 `E_on`/`E_off` 具体值，只能定性说"方案 3 最大"。任何"驱动布局使损耗增加 X %"的说法都必须注明是自己测的。
4. **`du/dt ≈ U_DC/150 ns` 是典型值。**书原文"开关时间暂取中间值 150 ns，根据实际情况这个时间可能增大或减小"。器件越快，`du/dt` 越大、电缆临界长度越短。**用 datasheet 的 `t_r`/`t_f` 算，不要一律套 150 ns。**
5. **式 13.18 的 `U_motor = 2·U_inverter` 是"电机阻抗 >> 电缆阻抗"的极限值**，实际因电机与电缆阻抗比、PWM 脉宽与传播延迟的相互作用会低于 2 倍，但**振荡过冲可能使它超过 2 倍**。这个式子给的是**上界量级**，不是精确峰值。
6. **电缆 `L'`/`C'` 依赖具体结构与 ε_r。**本文的 0.511 μH/m / 96.6 pF/m 是 `[假设]` a=10 mm、d=2 mm、ε_r=4.0 的结果，只用于验证式子自洽；**实际必须查电缆厂参数或实测**。
7. **书没给吸收电容的"典型值表"。**本文的 0.1–2.2 μF MKP 是行业量级 `[L4]`，不是书里的数。**不许写成"据《IGBT 模块》"**。
8. **"共模扼流圈漏感 1 %"不等于"共模阻抗 1 %"。**1 % 是**对对称电流**呈现的电感比例；对共模电流它呈现的是全电感。引用时不要把这句当"扼流圈没用"。
9. **驱动器贴装的"辅助端子高温"与"磁场耦合"书只给定性描述**（p350），没有任何温度或磁场数值。要用于设计必须自己测。
