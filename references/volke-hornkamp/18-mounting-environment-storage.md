## R · 原文锚点

- 硅脂粘度「如果粘度**过低**，可能导致连接**分离**。如果粘度**过高**，硅脂**无法完全地在空隙内散开**，从而接触面也无法紧密连接……其结果是**无法建立金属直接连接**，且热阻 R_th,ch 也不尽如人意」【书 p276】
- 直接冷却「直接冷却模块大多数采用**镀镍铜基板**或者在基板的**底部安装针翅扰流片**……在这两种情况下，**基板直接和冷却系统的冷却液接触**」【书 p276】
- 「如果使用**合成的（塑料的）冷却器**，基板需要和**大地零电位**连接起来以满足 **EMC** 的需求。特别是，**公共地非常有利于 IGBT 模块并联连接**」【书 p276】
- 密封「很多密闭方案倾向于采用 **O 形密封垫片**而不是平垫片……**O 形**密封垫片，根据类型不同，可以在拧紧螺栓前**预装在凹槽中**。在实际工作时，**冷却回路的液体对密封垫片施压**，从而实现密封」【书 p277】
- 平垫片的失败链「用平垫片的话，就完全依靠螺栓来实现密封……**螺栓安装点附近的压力最大**，相应的平垫片承受的压力也最大，而**安装螺栓之间的压力最低**，可能导致模块基板因受力而产生**轻微的扭曲**。最坏的情况是模块基板**扭曲严重，导致冷却液溢出**」【书 p277】
- 后果升级「最严重的情况可能导致 **DCB 断裂，产生短路或电气连接断裂（开路）**」【书 p277 脚注】
- 防护等级「通常 IGBT 模块的防护等级为 **IP00**，比如，面对固体异物接触（意外连接）或水的渗透，其**不能提供任何防护措施**」【书 p278】
- 硫化「有些物质可能**穿过（扩散）使用的硅胶**和 DCB 的铜发生反应。比如，**硫化氢（H₂S）**就属其中一种物质。硫化氢会**腐蚀镀铜层**，从而可能导致**开路或短路**……因为腐蚀会**形成一些晶体结构，从而缩小两个个体之间的间距**」【书 p278】
- 盐雾「典型的例子就是**含盐空气的污染，会腐蚀模块的连接端子**。刚开始电源、PCB 或直流母线对模块**接触电阻的影响并不明显**。当然，**腐蚀绝不能演变成机械失效**」【书 p279】
- 储存「目前模块公认的最长储存时间**不得超过两年**。而且储存环境条件不能超过以下值（**IEC 60721-3-1 1K2** 标准明确了储存条件）：最低环境温度 **5 ℃**；最高环境温度 **40 ℃**；最低相对湿度 **5 %**；最高相对湿度 **85 %**；**不得出现凝露、淋雨和结冰**」【书 p279】
- 振动「还需要**从总体上设计系统**。根据安装结构，可能产生**共振**从而**损坏整个系统**。所以增加额外的**安装支撑**也是至关重要的」【书 p278】

## I · 骨架：压力路径的四个下游后果

安装扭矩本身是电气参数（见 `04-installation-measurement.md`）。本篇讲的是**压力施加错了之后，失效会出现在哪里**：

```
螺栓扭矩
  ├─ 压力不足/不均 ──→ 硅脂未铺展 → 无金属直连 → R_th,ch ↑（不是裂纹，是热阻）
  ├─ 边缘过压     ──→ 基板弯曲 → DCB 受拉 → 陶瓷断裂 → 短路/开路（不可逆）
  ├─ O 形圈缺失   ──→ 冷却液沿间隙渗入 → 漏液/腐蚀
  └─ 接地缺失     ──→ 塑料冷却器悬浮 → EMC 超标 + 并联环流
```

### 三种密封方案的本质差别

| 方案 | 密封力来自 | 失效模式 | 判别方法 |
|---|---|---|---|
| **O 形圈（装凹槽）** | **冷却液自身压力**把圈压向槽壁，螺栓力只做初始定位 | 圈老化/切口 → 渗漏 | 拆检看圈是否有永久压痕、切口 |
| **平垫片 + 螺栓** | **只有螺栓力** | 螺栓间区域压力不足 → 基板弯曲 → 漏液，极端时 DCB 断裂 | 用**支撑垫圈**（书图 10.10b）限制垫片过度压缩 |
| **直接冷却（无基板/针翅）** | O 形圈 + 基板自身刚度 | 基板变形 → 与冷却腔贴合不良 → 局部热点 | 压力试漏 + 热成像看基板温度均匀性 |

**书里给的关键动作**：安装时**使用支撑垫圈**，防止垫片在螺栓点被过度压缩，从而保证密封区域内**高度一致、基板形变最小**（书 p277，图 10.10）。这是"基板 ±8 μm"（见 `04-installation-measurement.md`）在装配层的落地手段。

## A1 · 案例：H₂S 为什么要穿过硅胶才能腐蚀铜

这是本书最容易被低估的一段（书 p278–279，图 10.13 给出 DCB 铜走线被硫化氢腐蚀的实物）。

链条是：
1. 模块是 **IP00**，硅胶只是**胶结构**、不是密封壳体；
2. H₂S 从环境**扩散穿过硅胶**（硅胶对气体不是屏障）；
3. 到达 **DCB 铜走线/镀层**，生成**硫化物晶体**；
4. 晶体生长**缩小导体间距** → 短路；或腐蚀耗尽镀层 → 开路。

三个工程推论：

- **"灌了胶就是密封"是错的**。硅胶解决的是绝缘与机械保护，**不解决气体渗透**。要挡 H₂S 只能靠模制外壳或系统级密封（书明确说"不透气的密封壳体（塑模封装）效果最好"）。
- **失效形态是"间距缩小"而不是"变薄"**，所以早期电测（绝缘电阻）可能无明显变化，直到爬电距离不够才突然击穿。这与 `13-materials-insulation.md` 的"PD 是累积损伤"同属**潜伏型**失效。
- **现场环境必须写进 PFMEA 的"环境"栏**：含硫环境（橡胶厂、造纸、地热、污水处理、部分矿区）与含盐空气（沿海、海上风电）是两类不同的化学攻击，前者打内部、后者打端子。

## A2 · 案例：直接冷却模块的三个装配细节

书 p276 给了直接冷却（基板底面直接接触冷却液）的三条硬约束：

1. **散热器要开孔**——因为基板直接与冷却液接触，水路必须从上方引入并在基板周围形成密封腔；
2. **塑料冷却器必须把基板接大地**——否则整个模块悬浮，EMC 不过；而且**公共地有利于并联**（多模块并联时地电位一致，减少环流）；
3. **密封靠 O 形圈而非平面压紧**——因为直接冷却的腔体压力由泵提供，平面垫片在这种压力下会形成"螺栓点高压、中间低压"的弯曲。

对应检查动作（可直接进 `checklists/`）：
- 装配后**压力试漏**（按厂商规定压力与保压时间，书未给数值，需查安装手册）；
- 拆检时看**O 形圈压痕是否连续闭合**，断口处即渗漏路径；
- 塑料冷却器方案必测**基板-大地阻抗**与**共模噪声**。

## E · 触发场景

- 客户现场**漏液**/基板变形/DCB 断裂 → 先查密封方案（O 形圈 vs 平垫片）与是否用支撑垫圈，再查扭矩。
- 客户问「灌胶了为什么还会腐蚀」→ H₂S 扩散链，指出硅胶不是气密屏障。
- **沿海/海上/化工/地热**项目 → 盐雾打端子、H₂S 打 DCB，两套防腐要求不能混。
- 讨论**并联均流** → 提醒公共接地对并联的影响（书 p276）。
- 库存超过 2 年、或仓库无温湿度控制 → 引 IEC 60721-3-1 **1K2**（5–40 ℃、5–85 %RH、不凝露）与"最长 2 年"。
- 运输振动导致失效 → 三轴振动 + 系统共振 + 额外支撑（书 p278，图 10.11/10.12）。

## B · 边界

- **书中没有给数值门槛**：试漏压力、保压时间、支撑垫圈规格、振动谱（GRMS/频率范围）、盐雾小时数——这些必须在**厂商安装手册**（书引用的是 Infineon EconoDUAL™3 Mounting Instruction AN 2006）或 **IEC 60068-2-52 / IEC 60721** 里取。本文不编造。
- 书 p279 只引了 **IEC 60721-3-1**（储存），**运输**对应的是 60721-3-2、**使用**对应 60721-3-3，本书未展开，引用时需自行补齐。
- "最长储存 2 年"是**书作者的行业公认值**（原话"公认的"），不是标准条文；若客户合同另有规定，以合同为准。
- 本篇**不覆盖**焊接式端子（超声焊/激光焊）的工艺窗口——那属于 `14-interconnect-lowinductance.md`。

## 补 · 第八轮补充（第 10 章 p271–p279 全章复核）

> 来源：第八轮精读书页 p271–p279（第 10 章 机械安装指导 全章，注：原预判 p280–p286 属第 10 章不成立，第 10 章止于 p279，p280 起为第 11 章）。

### 散热器四条验收（全章仅此四条，无第五条）

1. **表面粗糙度 ≤10 μm，但不得磨光至过低**（书 p274–p275，反直觉）：过光使硅脂颗粒无法进入表面空隙、界面留隙，反而**热阻增大**；需要的是「适度粗糙 + 匹配」，不是越光越好。
2. **表面平整度 ≤50 μm**（书 p274）。
3. 散热器（及模块基板）**无损坏、无污染**（书 p274）。
4. 安装前用**无尘布 + 异丙醇或乙醇**清理（书 p274）。

### TIM 与储存三条

- **导热硅脂涂层厚度 50–100 μm**（齿形抹刀法实测，书 p274）。
- **储存条件**（IEC 60721-3-1 1K2，书 p279）：温度 **5–40 ℃**、相对湿度 **5–85 %RH**、**最长 ≤2 年**；且须密闭、温度可控、无冷凝/淋雨/结冰。

### 硅脂只涂基板不涂散热器（与很多现场做法相反）

- 书 p273 脚注② 明确规定：硅脂**必须涂在模块基板上，绝对不能直接涂在散热器上**——否则堵塞螺丝安装孔、影响螺栓安装扭矩。

### 平垫片必须配支撑垫圈

- 书 p277：平垫片完全靠螺栓压紧，液压力不增密封，压力分布极不均——**螺栓处压力最大、螺栓之间压力最低** → 基板轻微扭曲 → 最坏情况冷却液溢出（极端致 DCB 断裂开路）。
- 防范措施：**加装支撑垫圈**，防止垫片局部过度压缩，保证密封区高度一致、基板形变最小。

### 扭矩 / 安装顺序 / 压力分布图读数（切片核查）

- **扭矩数值**：书 p272/275/278 反复要求「遵守厂商数据手册的最小/最大扭矩」，但**本册未给任何 N·m 值**，须查厂商安装手册。
- **安装顺序**：要求按厂商「紧固顺序」；高粘度硅脂采用「初紧—暂停待铺展—终紧」两步法（书 p275，脚注①），**无具体螺栓序列图/分步力矩表**。
- **压力分布图**：书 p277 图 10.10 定性显示「螺栓点高压、中间低压」的弯曲趋势，但**无具体压力数值读数**，本篇不补数字。
