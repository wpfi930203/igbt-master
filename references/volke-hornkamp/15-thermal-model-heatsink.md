# 15 · 热模型、TIM 与散热器（第 4 章蒸馏）

> 来源：4.1.3 热辐射（书 p124–125）、4.1.4 对流（书 p125）、4.2 材料与导热（书 p126–128）、4.3 热模型（书 p131–133）、4.4 散热器（书 p136–138）。
> 本模块补的是 `scripts/igbt_thermal.py` 缺的那一层：**每段 Rth 的量级从哪来、哪些假设会错**。

## R · 原文锚点

> 「在功率半导体器件的散热中热辐射的作用不大。然而对于非接触温度测量则大不相同。因为所有的测量过程都基于热辐射原理，所以发射因子 ε 非常重要……否则，IGBT 芯片的铝表面只有约 **0.02** 的发射因子，这样想要像图 4.14 中测量芯片温度将不可能或很难。」【书 p125】

> 「连续网络模型（Cauer 模型）：根据 IGBT 模块的实际物理层和材料直接建立模型……所需 RC 组合的数目取决于预期模型提供的分辨率。局部网络模型（Foster 模型）：根据实际的物理层和材料**没有关系**，适合通过计量测定热阻和阻抗。」【书 p131】

> 「对于有基板的模块，可以认为基板上热的横向传导导致约 **5 %** 的误差。」【书 p133】

> 「冷却系统的时间常数越大，对 IGBT 模型的影响越小；冷却系统时间常数越小，如水冷系统，对 IGBT 模型的影响越大。」【书 p133】

## I · 骨架：热链的每一段，都有一个「书上给了量级」的填法

### 1. 先排除辐射——除了做红外测温的时候

**发射率表（书 p124–125）**：

| 材料 | 表面 | ε |
|---|---|---|
| 铜 | 抛光 | **0.05** |
| 铜 | 氧化 | **0.60** |
| 玻璃 | 平坦 | 0.94 |
| FR4 PCB | — | 0.94 |
| 铁 | 镀锌 | **0.03** |
| 漆 | 平坦 | **0.90** |
| 阻焊剂 | — | 0.94 |
| 锡 | 抛光 | **0.07** |
| **硅 / 铝（芯片表面）** | — | **≈ 0.02**（书 p125） |

**三个工程结论**：
1. 抛光金属 ε 极低（0.03–0.07）→ **红外测温必须先涂黑**，否则读数是「环境反射」不是表面温度
2. 氧化/涂漆能把 ε 拉到 0.6–0.9 → 老旧发黑的散热器反而「看起来更热」
3. 散热器做辐射优化没意义：翅片间距太窄，**只能与相邻翅片互相辐射**（书 p137）；且「辐射散热比例不与对流表面积成比例增加」

### 2. 对流：散热器热阻的修正因子

`P_th,α = α · A · ΔT`（式 4.14，书 p125），α 单位 W/(m²·K)。

**强制风冷 vs 自然对流**（图 4.26，书 p137，经验曲线）：

| 风速 | 修正因子 f |
|---|---|
| 0 m/s（自然对流） | **1.0** |
| 2 m/s | ≈ **0.4** |
| 5 m/s | ≈ **0.25** |
| 10 m/s | ≈ **0.20** |

`R_th,forced = f · R_th,convection`（式 4.22，书 p137）

> 「速度越快……直到达到某个平衡点，这时无法把更多的热能随着吹来的空气消散掉，且热阻达到一个值，基本上与空气的速度无关。」【书 p137】
>
> → 这就是「风扇加到 10 m/s 也压不下去」的物理解释：**收益在 5 m/s 之后基本封顶**。

**液冷的选型点**（图 4.27，书 p138）：不是查散热器参数，而是**求交点**——
- 冷却回路压降随流量**上升**（近似指数）
- 水泵压降随流量**下降**
- 两条曲线的**交点才是工作点**；只看散热器 Rth-流量曲线选泵，一定选错

### 4. 热模型：Cauer 和 Foster 不是「两种画法」，是两种用途

| | **Cauer（连续网络）** | **Foster（局部网络）** |
|---|---|---|
| 依据 | 实际物理层与材料 | **与物理层无关**，纯拟合 |
| 需要什么 | 精确材料参数，尤其**横向传热参数** | 只需测量 Rth / Zth |
| RC 对数 | 取决于预期分辨率 | **通常 3–6 对** |
| 能做什么 | 可拆到「每层多少 K」 | 只能算总 Zth(t) |
| 用在 | 热设计、结构优化 | 数据手册、实时结温估算 |

`Z_th,jc(t) = Σ r_i · (1 − e^(−t/τ_i))`（式 4.20，书 p133）

`T_j(t) = P(t) · Z_th,jc(t) + T_c(t)`（式 4.21，书 p133）

**四条会算错的假设**：
1. **横向导热误差**：有基板模块约 **5 %**；无基板模块「误差会明显增加」（有源面积减小、无横向传导）——书 p133
2. **参考点选择**：有基板模块用 T_c（基板）；无基板模块只能测 T_h（散热器，传感器放在 TIM 下 1–2 mm），得到的是 Z_th,jh 不是 Z_th,jc
3. **反解散热器 Rth**：只有 **t ≫ 5τ** 时，Z_th 里才只剩散热器项；此时减去 TIM 的 R_th 才能得到 R_h
4. **时间常数匹配**：水冷时间常数小 → 对 IGBT 模型影响大；强制风冷时间常数大 → 影响小

### 5. TSEP 校准：一个会骗人的细节

校准方法（书 p131–132）：
- 外部热源加热被测模块，通**很小的测量电流 I_ref**，记录饱和压降 U_CEsat 或 U_F
- **I_ref ≈ I_nom / 1000**（书 p132 原文：典型值大约是 1/1000）
- 不同温度下重复 → 得到 `U_CEsat = f(T_j, I_ref)` 曲线
- 测量时：先恒定功率跑到稳态 T_j，再把电流降到 I_ref，查曲线

> **书里最重要的一条脚注**（书 p132）：
> 「通常，现代 IGBT 的饱和电压表现为**正温度系数**。此图中出现**负温度系数**的原因是**采用的电流很小**。在温度不同时，只有负载电流达到一定的水平，正温度系数的特性才会表现出来。」
>
> → **用小电流测 TSEP，看到的是负温度系数，这与「IGBT 是正温度系数」的常识矛盾，但不是错。** 校准曲线的斜率符号取决于 I_ref 的量级。若把负载电流下的正温度系数直接套到小电流校准上，符号会反，算出来的结温会朝错误方向走。
>
> 这条对 `scripts/igbt_thermal.py` 的直接含义：**TSEP 法必须自带校准曲线，不能假设一个 mV/K 的通用系数**。

### 6. TIM：两种结构的 Rth 网络不一样

**图 4.25（书 p136）给了两种拓扑**：

```
a) 导热垫片： R_th,BasePlate — R_th,TIM — R_th,HeatSink         （串联）
b) 导热膏  ： R_th,BasePlate — [R_th,TIM ∥ R_th,Metal-Metal] — R_th,HeatSink
                                ↑ 金属直接接触的并联通路
```

→ **涂硅脂时存在「金属-金属直接接触」的并联通路**，所以「硅脂越薄越好」不是线性关系：涂太薄，接触面积不足、金属-金属通路也建立不起来；涂太厚，硅脂层主导。**存在一个最优厚度**，不是越薄越好。

**TIM 的失效形态（图 4.17，书 p130）**：长期工作后底板上出现**变干区域**与**抽空区域**（pump-out）。
- PCM（相变材料）熔点可调 **60–80 ℃**，λ 可达 3–4 W/(m·K)，不含硅
- 但 PCM 与散热器之间**无法形成金属-金属接触**，界面热阻相对较高

**可选 TIM 数据（表 4.6，书 p130）**：

| 名称 | 材料 | λ（W/m·K） |
|---|---|---|
| AOS MicroFaze A | 铝箔 | **0.02** |
| AOS MicroFaze K | 聚酰亚胺 | **0.03** |
| Bergquist Hi-Flow | PCM | **1 ~ 4** |
| Denka HittiPlate | 铝箔或铜箔 | **4** |

## A1 · 案例：加风到底还能买到多少 K，5 % 误差值多少寿命（本地复算）

**第一笔账：风冷收益的封顶量化**

取示例量级：自然对流 R_th,convection = **0.30 K/W**、模块总损耗 P = **600 W**（示例值，非书内数据）。
按式 4.22 `R_th,forced = f · R_th,convection` 与图 4.26 的 f：

| 风速 | f | R_th（K/W） | ΔT_h-a = 600 W × R_th | 比上一档多买到 |
|---|---|---|---|---|
| 0 m/s | 1.00 | 0.300 | **180 K** | — |
| 2 m/s | 0.40 | 0.120 | **72 K** | **−108 K** |
| 5 m/s | 0.25 | 0.075 | **45 K** | −27 K |
| 10 m/s | 0.20 | 0.060 | **36 K** | **−9 K** |

→ 0→2 m/s 买到 **108 K**；5→10 m/s（风量翻倍）只买到 **9 K**。
**「再加一档风扇」必须先换算成 K，再换算成风扇功率与噪声**——这是书说「达到平衡点后热阻基本与风速无关」的量化版本。到 5 m/s 以后，正确的动作是改散热器几何或改 TIM，不是加风。

**第二笔账：5 % 横向导热误差进了寿命公式**

书 p133：「有基板的模块，可以认为基板上热的横向传导导致约 **5 %** 的误差」。

- 若 ΔT_jc = 60 K，5 % → **3 K**；
- 把 3 K 当成 ΔTj 的偏差送进 Coffin-Manson / Bayerer（指数取 4.4）：

| 情形 | 算式 | 后果 |
|---|---|---|
| 计算值偏低（真值 63 K，用了 60 K） | (63/60)^4.4 = **1.24** | 寿命被**高估 24 %** |
| 计算值偏高（真值 60 K，用了 63 K） | (60/63)^4.4 = **0.81** | 寿命被**低估 19 %** |

→ **一个「可以认为只有 5 %」的假设，落到寿命上是 ±20~25 % 的摆动。** 所以寿命报告里的 ΔTj 必须写清来源（Foster 拟合 / 实测 Zth / 是否修正横向导热），只写一个数就是在隐藏 20 % 的不确定度。

> R_th 与 P 为示例量级，结论只依赖 f 曲线形状；5 % → 4.4 次方的换算为本地复算，**指数 4.4 取 Bayerer 模型的典型量级，具体项目必须用所选模型的实测指数**；5 % 是「模型误差」而非「ΔTj 误差」，此处按最保守方式直接当 ΔTj 偏差处理。

## E · 触发场景

| 症状/任务 | 用本模块 |
|---|---|
| 红外测得芯片温度明显偏低/不可信 | ε 表 + 芯片 Al 面 ε≈0.02 + 必须涂黑 |
| 「风扇再加一档还有没有用」 | 修正因子 f 曲线（5 m/s 后基本封顶） |
| 液冷系统选泵/定流量 | 求压降曲线与泵曲线交点，不是查 Rth 表 |
| Foster 参数算出的 Tj 与实际差很多 | 5 % 横向导热误差 + 时间常数匹配 + 参考点选错 |
| 反解散热器 Rth | t ≫ 5τ 条件 |
| TSEP 校准曲线斜率符号不对 | I_ref ≈ I_nom/1000 与温度系数符号的关系 |
| 硅脂涂布厚度评审 | 图 4.25b 的并联金属-金属通路 |
| 长期运行后 Rth 缓慢上升 | 图 4.17 的变干/抽空 + PCM 的取舍 |

## B · 边界

1. **图 4.26 的修正因子是「例子」**（书原文用词），不是通用曲线；不同翅片几何差异很大。它只能用来判断「加风还有没有收益」的量级，不能直接算 Rth。
2. **λ / CTE 表是 20 ℃ 附近的值**。硅与焊料的 CTE 随温度强烈非线性（书 p126 明说「多数材料的 CTE 不是线性的，只能在参考温度内定义」）——**跨 200 K 的循环不能直接用 20 ℃ 的表值**。
3. 书没有给 **Rth(j-c) 的行业典型值**（因封装而异太大），也没有给 TIM 厚度的最优值。这两项必须查具体 datasheet 或做 DOE。
4. 本文引用的 λ/CTE 与 `13-materials-insulation.md` 中的同一材料有差异（书内不一致），详见该文件末节。**做热-机械耦合计算时，两个模块的取值必须统一，否则应力与热阻互不自洽。**
5. 发射率表是**特定表面处理**下的值，氧化程度不同差异很大；红外测量应以「同批同表面处理的参考试片」现场标定，而不是查表。
