# 02 · 射频振荡：三类振荡的判据与处置（第 9 章全章蒸馏）

> 来源：第 9 章「射频振荡」，书页 265–270，**逐页精读**（PDF 277–281）。
> 这是本技能原先完全空白的一块，也是模组并联后「莫名其妙炸管」的常见真因。

## R · 原文锚点

> 「如果反馈存在相移，系统的放大倍数会增大（正反馈）并可能最终导致振荡。IGBT 内部的寄生电容如密勒电容……和模块内的杂散电感提供了反馈路径。这里形成的 LC 振荡电路包括一个三通容性耦合电路，称作科尔皮兹振荡器。」【书 p265】

> 「IGBT 关断过程中，集-射极电压变化率 duCE/dt 通过密勒电容 CGC 反馈到栅极。……因此，被关断的集电极电流 IC 越大，产生的位移电流 iGC 就越大，这也就容易理解了。当半导体并联连接时，这种正反馈可能引发振荡。」【书 p267】

> 「可以在模块内通过放置附加键合线的方式来避免模块内并联半导体之间的振荡。这主要是改变谐振回路中寄生参数的影响，从而避免振荡。」【书 p269】

## I · 骨架：IGBT 是一个反相放大器，加反馈就成振荡器

```
        ┌──────── CGC（密勒电容，反馈路径）────────┐
        │                                          │
   UG ──┴──► [IGBT 反相放大] ──► UC ──► 负载/母线
                    │
               Lσ（模块内 + 外部连接）
```

**成立条件**：反相放大 + 相移反馈（CGC 与 Lσ 构成的 LC）+ 环路增益 ≥ 1。
书中给出的等效电路是 **Colpitts（科尔皮兹）** 型——三个电容（CGC / CGE / CLE）串并联分压，电感 Lσ 谐振。

**这一句是整章的价值所在**：振荡不是「干扰」，是**电路拓扑的固有属性**。
只要 CGC、CGE、Lσ 的组合落在某个区间，任何驱动电阻都只是把增益压下去，不是消除。

### 9.1 为什么会振：三个反馈路径

1. **密勒电容 CGC**：duCE/dt 通过它注入栅极，形成位移电流 iGC = CGC · duCE/dt
2. **模块内杂散电感 Lσ**：键合线 + 端子 + 内部布线，构成谐振电感
3. **CGE**：与 CGC 组成容性分压，决定反馈系数

书中明确指出：**IC 越大，iGC 越大**，所以大电流关断最容易振；**并联时正反馈可能引发振荡**——这解释了为什么「单管测试好好的，并联就振」。

### 9.2 短路振荡：SC1 vs SC2

- **SC1**（硬短路，如端子直接短接）：短路电流建立后立刻振，10–20 MHz，栅极电压上能直接看到
- **SC2**（较软短路）：在退饱和阶段振，>10 MHz，此时 VCE 上升

**为什么必须分开**：两者的处置方向不同。SC1 主要靠**内部栅极电阻**压；SC2 更多与 **duCE/dt** 相关。

### 9.3 关断振荡：密勒平台末尾的正反馈

机制链条：关断 → duCE/dt 上升 → iGC = CGC·duCE/dt 注入栅极 → 栅极电压被抬起 → IGBT 又被开通一点 → 电流变化 → 更强反馈。

**这解释了「关断时的栅极电压为什么会翘起来」**——不是干扰耦合，是密勒反馈。

### 9.4 拖尾电流振荡：PETT 机理（最反直觉的一类）

这是唯一**不能靠改布局根治**的一类。

- **BARITT 机理**：一个 PN 结正偏、另一个反偏，外加电压达穿通电压时空间电荷区连通，电流急剧上升；载流子渡越时间与 LC 谐振相互作用，形成**等效负微分电阻**
- **PETT（等离子提取时间）机理**：空间电荷区**没有**延伸到另一个 PN 结，N 区剩余载流子未被复合、转化为载流子；电流由进入空间电荷区的载流子形成
- **判据**：负微分电阻 > 谐振回路中等效正电阻 → 振荡

**书中的关键限定**：「从原理上来说，任何具有双极特性的半导体都可能发生 PETT 振荡。因此，IGBT 和二极管都可能产生振荡。」【书 p268】

→ 所以拖尾振荡可能来自**续流二极管**，而不是 IGBT 本身。判错对象就会一直在 IGBT 上找原因。

### 处置措施（书中给出的四项，按优先级）

| # | 措施 | 作用机理 | 代价 |
|---|---|---|---|
| 1 | **调整内部栅极电阻** | 降低环路增益 | 书中明说「即使不会完全消除振荡也会减少振荡」——不是根治 |
| 2 | **筛选低 CGC / 高 CGE 的芯片** | 削弱反馈、增强容性分压 | 需要芯片级参数筛选能力，一般封装厂做不到 |
| 3 | **优化模块内部布局** | 减小反馈回路、防止反馈进入模块应用端 | 需改 DBC 布线，影响寄生电感与均流 |
| 4 | **附加键合线** | 改变谐振回路寄生参数，专门用于**并联芯片之间**的振荡 | 需在模块内加线，影响工艺与成本 |
| 5 | 提高栅-射极门槛电压 UGE(TO) | 限制振荡 | 改变器件特性，通常不可行 |

> 注意书中把第 4 项专门用于「模块内并联半导体之间」的振荡——这是**并联设计**与**振荡**的交叉点，
> 优化布局（图 9.3、9.4）在实验中直接把振荡消掉了。

## A1 · 案例（书中实验）

**案例 1：模块布局对 SC1 短路振荡的影响**（图 9.3，书 p267）
- a) 优化布局：短路电流建立后，栅极电压有轻微台阶，无高频振荡
- b) 未优化布局：同一时刻出现明显 10–20 MHz 振荡，VGE 被反复抬起

**案例 2：布局对关断特性的影响**（图 9.4，书 p268)
- a) 未优化：关断沿后段出现振荡，VCE 与 IC 同步振荡
- b) 优化：关断沿干净，无振荡

**案例 3：附加键合线消除拖尾振荡**（图 9.8，书 p269）
- 同一模块，仅在并联芯片间加键合线 → 200–500 MHz 的拖尾振荡消失
- 这证明该振荡是**回路寄生参数**问题，不是芯片缺陷

## E · 触发场景

- 「关断时栅极电压翘起来，是不是驱动受干扰了？」→ 先算 iGC = CGC·duCE/dt
- 「短路测试时示波器上全是毛刺，是探头问题吗？」→ 看频率，10–20 MHz 是 SC1 真实振荡
- 「并联后一台好一台炸」→ 查并联芯片间的振荡（附加键合线）
- 「关断后 1–2 μs 有一串高频，是 IGBT 还是二极管？」→ 200–500 MHz 大概率是 PETT，可能是二极管
- 「加了 Rg 还是有振」→ 正常，Rg 只降增益；要根治得改布局或加键合线

## S · 步骤（振荡诊断五步）

1. **测频率**：用高带宽探头（≥500 MHz）测 VGE、VCE、IC，读出振荡频率
2. **查表定位**：10–20 MHz / >10 MHz / 10–50 MHz / 200–500 MHz → 对照上表确定类别
3. **确认时机**：短路建立后 / 退饱和 / 密勒平台末尾 / 关断后 5 μs 内
4. **分离对象**：换一个同型号二极管重测，判断振荡源是 IGBT 还是 FWD
5. **按类处置**：SC1/关断 → 内部 Rg + 布局；并联振荡 → 附加键合线；PETT → 换器件或改回路阻抗

## B · 边界

- 书中数据来自**特定厂商的 3.6 kA 级模块**（24 个 IGBT + 二极管并联，书 p265），频率区间可迁移，**绝对幅值不可迁移**
- 未给出 CGC / Lσ 的定量判据（没有「环路增益 < 1」的算式），只能定性判断
- PETT 振荡的**抑制方法书中只给了「加键合线」一条**，工程上还有改门极驱动、加 RC 吸收等，本书未覆盖
- **第 8 章「并联和串联」本次仅取目录，未精读**——并联的静态/动态均流细则不在本笔记内，不要从本笔记推断并联设计规则

### 四档频段分诊表（本篇最可直接用的东西）

| 频段 | 出现场景 | 成因 | 处置方向 |
|---|---|---|---|
| **10–20 MHz** | SC1（恒定短路电流建立后极短时间，书 p266 表 9.1） | 栅极电压上可观测明显振荡；敏感项为**低 U_CE / 高 U_GE** | 增大内部 Rg（即使不能完全消除也会减少）、提升 U_GE(TO)、优化内部布局压缩反馈回路 |
