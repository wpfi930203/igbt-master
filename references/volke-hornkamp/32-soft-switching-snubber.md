# 32 · 软开关与缓冲电路：什么时候值得付这个代价（第 7.10–7.11 节）

> 一句话：缓冲不是"省损耗"的魔法，而是把损耗搬个地方；在 IGBT 上，先降杂散电感，再谈缓冲。

## R · 原文锚点

> 「IGBT 下一次导通时，通过电阻 R_snubber 消耗缓冲电容存储的能量；因此 IGBT 的最小开通时间由 RC 网络时间常数 τ = R_snubber·C_snubber 决定。」【书 p243】

> 「降载缓冲电路不是当前 IGBT 的主流技术；电力电子制造商多年前就为不同的应用提供了优化设计的 IGBT 和二极管。使用缓冲电路只应作为一种补充。」【书 p244】

> 「由于 IGBT 与吸收二极管之间 RCD 网络的振荡，无法简单直接使用 U_CEsat 监控；因此若采用缓冲电路，必须重新评估短路保护策略。」【书 p244】

> 「保持 I_C 为零或接近零 → 零电流开关（ZCS）；保持 U_CE 为零或接近零 → 零电压开关（ZVS）。」【书 p245】

## I · 骨架一：缓冲的两类目标与电路形态

缓冲要解决的是两个**不同**的问题，不能混为一谈：

| 目标 | 限制的应力 | 典型电路形态 | 书页 |
|---|---|---|---|
| 限制 du/dt（开通/换流尖峰） | 电压上升率、米勒误导通 | **RC 缓冲**（并联 R+C） | p243 |
| 限制关断过压 | 关断时的 U_CE 过冲 | **RCD 缓冲**（二极管+RC）或**钳位** | p243 |
| 吸收关断能量 | 关断损耗 / SOA 裕量 | RCD（含能量回收变体，拓扑复杂） | p243 |

电路形态对应代价：RC 缓冲在每个开关周期都经 R 放电；RCD 增加一只吸收二极管，关断时经二极管给 C 充电，下个开通时再经 R 放掉。图 7.25 给出 RC、RCD-1、RCD-2 三种，原理上"其他变体可行甚至可回收能量，但拓扑复杂"。

## I · 骨架二：缓冲的代价账（这是核心判据）

缓冲**不创造效率**，它做三件事，全是代价：

1. **把损耗从器件搬到电阻**：每次关断搬进 C 的能量，下次开通时 100% 在 R_snubber 上烧掉，IGBT 开通损耗反而增加（电容放电电流流过 IGBT）。
2. **体积与成本**：缓冲电容电压等级须 ≥ 直流母线最大电压（p243），大电压下是很贵的薄膜电容。
3. **高频下的环路问题**：设计不当会在直流母线产生**寄生振荡**，使 IGBT 超出 SOA（p243）；匹配参数要同时压住开通电流 < 2·I_nom（p243）。

设计约束（书给的，可操作）：
- 开通侧 τ = R_sh2·C_sh2 必须小于最小导通时间，取最小导通时间 = 3~5τ（否则电容没放完，下次关断降载失效）
- R_sh2 ≥ U_DC/(2·I_nom)，否则开通电流过大超 SOA

## I · 骨架三：软开关（ZVS/ZCS）对 IGBT 的适用边界

IGBT 有**拖尾电流**——这是和 MOSFET 的根本区别，决定了软开关对 IGBT 是"半截子"方案：

- **ZVS（U_CE≈0 时开通）**：能消除**开通**损耗与开通 di/dt 应力，但**关断拖尾仍在**，关断损耗没解决。
- **ZCS（I_C≈0 时开关）**：理论上消开通+关断损耗，但 IGBT 的拖尾电流意味着"电流过零关断"实际仍要硬扛一部分拖尾；且 ZCS 拓扑常需串联 LC 谐振网络，IGBT 在 f_sw=f0 时电流过零开关，f_sw>f0 呈感性、f_sw<f0 呈容性（p245）。

结论句式：**对 IGBT，软开关消开通不消拖尾；拿 ZCS 当"零损耗"是误解。**

## I · 骨架四：谐振/准谐振拓扑的代价

谐振拓扑（附加 LC 网络，工作于 f0 附近）的代价：

1. **环流**：谐振网络始终存在环流，导通损耗增加。
2. **电压/电流应力升高**：被动开通时压降会高于标称饱和电压，直到漂移区充满载流子（p245）；实测被动开通过冲约 25V，约 1μs 后才降到标称值，VD3 峰值约 70A（p246）。
3. **控制复杂**：f_sw 与 f0 的关系决定 ZCS/ZVS 能否成立，偏离即失配。

## I · 骨架五：什么时候不该用缓冲（优先级判据）

**先看 A，再谈 B**——这是本章最该记住的工程判据：

1. **先把杂散电感做小**：换流回路的 L_σ 降下来，du/dt 与关断过压自然缓解，"降载缓冲电路不是主流技术，只应作为补充"（p244）。
2. **只在以下情形付缓冲的代价**：① 无缓冲时过压超出器件阻断裕量/SOA；② dv/dt 超出器件能力导致米勒误导通；③ 器件本身未针对低杂散电感回路优化。
3. **采用缓冲后必须重做短路保护**：U_CEsat 监控因 RCD 振荡失效，要换策略（p244）。

## A1 · 案例（书中实例）

书里给了仿真实例与实测，数值全抄：

**图 7.26 简化仿真模型（p244）**
- DC 源 560V / 1mF；负载 1mH / 100mΩ；栅极电阻 4.7Ω / 4.7Ω
- **匹配好（图 7.26b）**：L_shr1=2.2μH，R_shr1=4.7Ω，C_shr2=33nF，R_shr2=47Ω
- **匹配不当（图 7.26c）**：L_shr1=2.2μH，R_shr1=10Ω，C_shr2=100nF，R_shr2=1Ω（反例，易产生寄生振荡）

**谐振实测（p246，图 7.28）**
- 被动开通过程电压过冲约 **25V**，约 **1μs** 后降到标称值

- LC 谐振频率本例设定 **f0=25kHz**；仿真开关频率取 25/28/23kHz 对应过零/感性/容性三种工况（p245）

## A2 · 案例（本地复算）

> 本地复算。以下数值由书中公式代入算出，假设项不能当书内数据引用。

第 7 章的软开关缓冲**未给 C_s 的设计公式**；第 13.6 节的母线吸收电容虽给式 13.9，但**分子缺 `I_peak`、量纲不成立**（见 `34-formula-index §12.2` 与模块 `39` 骨架二）。两处都拿不到可直接用的设计式。故此处用任务给定假设算"缓冲电阻要烧多少功率"，并与"省下的 E_off"对比。

**给定假设**：
- C_s = 1μF（=1×10⁻⁶ F）——注：此为任务设定的演示值，书里匹配好的实例仅 33nF / 100nF 量级，1μF 是特意放大以便看量级
- U_clamp = 1200V（钳位电压）
- f_sw = 4kHz
- 假设被缓冲 IGBT 在 1200V 关断下的 E_off ≈ 10mJ/次（代表性量级，书本章节未给具体 E_off，**纯假设**）
- 假设无缓冲时该过压应力对应的"可省损耗"≈ E_off 量级（即缓冲能消除的只是过压附加损耗，不大于 E_off）

**每关断搬走的能量**：
```
E = 0.5 · C_s · U_clamp²
  = 0.5 × 1×10⁻⁶ × (1200)²
  = 0.5 × 1×10⁻⁶ × 1,440,000
  = 0.72 J / 次
```

**缓冲电阻上的平均功率**：
```
P_buffer = E · f_sw = 0.72 × 4000 = 2880 W = 2.88 kW
```

**与"省下的 E_off"对比**：
```
P_saved = E_off · f_sw = 10×10⁻³ × 4000 = 40 W
P_buffer / P_saved = 2880 / 40 ≈ 72 倍
```

**净收益条件（假设写明）**：
- 缓冲**不节能量**——它把 0.72J/次 从 IGBT 搬到电阻，系统总损耗净增。2.88kW 是纯增量，远大于"省下"的 ~40W。
- 所以**正常工况下缓冲永远净亏**。它买的是**可靠性**：只有当"无缓冲时关断过压超出器件阻断裕量或 dv/dt 超出器件能力"时，才值得付这 2.88kW。
- 若把 C_s 降到真实量级（如 10nF）：E=0.5×10×10⁻⁹×1.44×10⁶=0.0072J，P_buffer=28.8W，才与 E_off 量级相当——说明**真实缓冲电容应在 nF 级**，1μF 只用于看量级。
- 结论句式：**缓冲不是"回本"工程，是"买 SOA 裕量"的保险；先把 L_σ 做小比加缓冲更划算。**

## E · 触发场景

- 「客户要加 RC 缓冲来降损耗」→ 告诉他缓冲不降总损耗，只搬迁损耗，先看杂散电感
- 「IGBT 关断尖峰老超压」→ 先查换流回路 L_σ，再决定要不要 RCD 钳位
- 「能不能上 ZVS 把损耗做没」→ IGBT 有拖尾，ZVS 只消开通，关断拖尾仍在
- 「谐振拓扑效率更高吧」→ 有环流、应力高、控制复杂，对 IGBT 未必划算
- 「加了缓冲短路保护怎么配」→ U_CEsat 监控失效，必须重评短路策略
- 「4kHz 下 1μF 缓冲电阻要多大功率」→ 2.88kW，纯增量，正常工况别加

## S · 步骤（要不要上缓冲的决策七步）

1. **测 L_σ**：先量换流回路杂散电感，算无缓冲时的 du/dt 与过压
2. **判 SOA**：过压/du/dt 是否超出器件阻断裕量与米勒阈值——**不超就别加**
3. **选形态**：限 du/dt 用 RC；限关断过压用 RCD / 钳位
4. **定 C_s**：按 nF 量级起算（书无公式，靠经验+仿真），电压等级 ≥ 母线最大电压
5. **定 R**：R_sh2 ≥ U_DC/(2·I_nom)；τ = R·C 满足最小导通时间 = 3~5τ
6. **算功耗**：P_buffer = 0.5·C_s·U_clamp²·f_sw，确认散热与体积可接受
7. **重做保护**：缓冲后 U_CEsat 监控失效，改短路保护策略

## B · 边界

- **C_s 没有可直接用的设计式**：第 7 章软开关缓冲只给定性判断（"须足够电压等级""其他变体可行"）与实例值 33 nF/100 nF（p244）；第 13.6 节吸收电容给了式 13.9，但**分子缺一个 `I_peak`、量纲不成立**（照抄小 1000 倍），必须改用能量式 `C = L_σ·I_peak²/ΔU²`。见 `34-formula-index §12.2`、模块 `39` 骨架二。
- A2 中的 E_off≈10mJ、C_s=1μF 均为**任务假设**，非书内数据；书里缓冲实例 C_s 为 33nF/100nF（p244）
- 谐振/准谐振的"效率提升"书里只给定性，**无定量环流损耗数据**
- "降载缓冲非主流技术"是书出版时的结论，须按当前器件（低杂散电感优化型）复核
- 被动开通 25V 过冲是特定实测示例（p246），非通用限值
