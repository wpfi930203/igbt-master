# 27 · 传热三通道与热阻链的定义（第 4 章）

> 一句话：datasheet 的 R_th,ch 是别人按假定算的，不是你的接触热阻。

## R · 原文锚点

> 「R_th,jc（结→基板）、R_th,ch（基板→散热器）、R_th,ha（散热器→周围介质）」——热阻链的三段式定义，每段配热容与热阻抗。【书 p118–119】

> 「制造商按式 4.2 计算 R_th,ch：假定 d=50~100 μm、λ=1 W/(m·K)。数据手册中 R_th,ch 只能作参考，实际用户参数完全不同。」【书 p134】

> 「与散热片水冷、强制风冷或对流冷却相比，由辐射引起的热传导效应几乎可以忽略不计。」【书 p124】

> 「Foster 模型与实际的物理层和材料没有关系，适合计量测定；Cauer 模型根据模块实际物理层和材料直接建模。」【书 p131】

## I · 骨架

### 骨架一：传热三通道，先分清哪条通道扛活

| 通道 | 物理式 | 适用 | 结论 |
|---|---|---|---|
| 导热 | P_th,C = λ·A·ΔT/d；R_th = d/(λ·A)（式 4.2/4.3，书 p119–120） | 固体/液体、有介质 | 主导；λ 跨度极大 |
| 对流 | P_th,α = α·A·ΔT = α·A·(T_hs−T_cool)（式 4.14，书 p125） | 气体/液体、需流动 | **本章只给定性，未给 α 数值** |
| 辐射 | P_th,s = ε·σ·A·(T⁴−T₀⁴)，σ=5.67×10⁻⁸（式 4.13，书 p124） | 真空/空气均可 | 相对风冷/水冷可忽略 |

**导热 λ 量级对比（表 4.3，书 p127–128；完整表见 `15-thermal-model-heatsink.md`）**：
空气 0.0261 ≪ Al₂O₃ 25 / Si 100 / AlN·AlSiC 180 / Al 220 / Cu 380 / Ag 429；TIM 0.5–6、膜 0.01–4。
→ 空气夹层 λ 比任何 TIM 低 1–2 个数量级，是 TIM 存在的唯一理由【书 p127–129】。

**对流 α**：书只定义 α 为「传热系数（W/(m²·K)），取决于几何、流速、材料」，**未给自然/强制/液冷的具体 α 区间**【书 p126】。α 量级与风速修正因子见 `15-thermal-model-heatsink.md`，本篇不重复。

**辐射 ε**：抛光铝/芯片 Al 面 ε≈0.02，氧化或涂黑可到 0.6–0.9（表见 `15-thermal-model-heatsink.md`）【书 p124–125】。结论：散热器辐射优化无意义，只在红外测温（ε 决定读数）时必须考虑。

### 骨架二：热阻链的定义与 R_th,ch 的隐含假定

链：结 →（R_th,jc）→ 基板 →（R_th,ch）→ 散热器 →（R_th,ha）→ 环境；每段配 C_th 与 Z_th【书 p118–119】。

**R_th,ch 是陷阱段**：书 p134 明确——datasheet 的 R_th,ch 由厂商假定「d=50~100 μm、λ=1 W/(m·K)」按式 4.2 算出（示例 0.30 K/W per IGBT）。你手上的 TIM 厚度、λ 都不同，**datasheet 的 R_th,ch 不是你的 R_th,ch**，必须按自己 TIM 重算（见 A2）。

### 骨架三：Foster vs Cauer 的数学差别 + 从 Z_th 反推

| | Foster（局部网络） | Cauer（连续网络） |
|---|---|---|
| 数学形式 | Z_th(t)=Σ r_i(1−e^(−t/τ_i))（式 4.20） | 物理层逐级 RC 串联 |
| 对应材料 | 否，纯曲线拟合 | 是，每层一个 R、C |
| 需要输入 | 仅测量点 | 精确材料参数，含横向传热 |
| RC 对数 | = 测量点数，通常 3–6 | 取决于建模分辨率 |
| 反解单层 | 不能（参数无物理意义） | 能 |

**从 Z_th 反推稳态 R_th**：取 t > 5τ（99.3% 终值，书 p121–122）曲线读数，此时 Z_th≈R_th；再减已知/设定的 TIM R_th，得散热器段 R_th【书 p133】。（图 4.21 的 r_i/τ_i 小字表读不清，不转录；反推只需曲线读数。）

**结温标定陷阱**：I_ref ≈ I_nom/1000 小电流测 U_CEsat，曲线 0.70 V@20℃ → 0.40 V@190℃（负温度系数）【书 p131–132】。与「IGBT 正温度系数」矛盾——书 p132 脚注：小电流所致，负载电流到一定水平才转正。校准斜率符号取决于 I_ref 量级。

## A1 · 案例（书中实例）

书 p134 实例：厂商按 d=50~100 μm、λ=1 W/(m·K) 由式 4.2 算 R_th,ch，图 4.22 示例值 **0.30 K/W（per IGBT）**。书明确此值仅作参考。

## A2 · 本地复算

> 本地复算。以下数值由书中公式代入算出，假设项不能当书内数据引用。

用式 4.2 R_th = d/(λ·A)，取 λ=1 W/(m·K)，假设 A=1 cm²（本地假设）：

- d=50 μm=5×10⁻⁵ m：R_th = 5×10⁻⁵ / (1×10⁻⁴) = **0.50 K/W**
- d=100 μm=1×10⁻⁴ m：R_th = 1×10⁻⁴ / (1×10⁻⁴) = **1.00 K/W**

**结论**：50μm 与 100μm 端点相差 **2 倍**（0.50 vs 1.00 K/W），R_th 随厚度**线性**变化，厚度翻倍热阻翻倍。

**为什么「多涂硅脂会更凉」是错的**：
- 涂厚：TIM 越厚 R_th 越大→更热，不是更凉。
- 涂太薄：留不下连续膜，模块-散热器间出现**空洞**（空气 λ=0.0261，比 TIM 低 1–2 个数量级），局部热阻反而飙升。
- 两个方向都有代价：太厚直接增大 R_th，太薄靠空洞增大 R_th；最优是刚好填满空隙、不堆积。具体厚度取决于平面度与涂布工艺，书未给最优值。

## E · 触发场景

- 「datasheet 的 R_th,ch 能直接套吗」 → 不能，按自己 TIM 重算（骨架二）
- 「我算的接触热阻比手册大这么多」 → d/λ 假设不同（A2）
- 「Foster 参数能拆出每层温度吗」 → 不能，纯拟合，换 Cauer（骨架三）
- 「Z_th 曲线怎么读出稳态 Rth」 → t>5τ 减 TIM（骨架三）
- 「标定时 U_CEsat 随温度降，IGBT 不是正温度系数吗」 → 小电流负系数（骨架三）
- 「辐射要不要算进散热」 → 相对风冷/水冷可忽略（骨架一）
- 「TIM 涂越厚越凉吗」 → 错，厚度线性增阻（A2）

## S · 步骤

1. 先定通道：结→散热器以**导热**为主，辐射先排除（除非红外测温）。
2. 列热阻链 R_th,jc / R_th,ch / R_th,ha，标注每段来源（书/实测/假设）。
3. 对手册 R_th,ch：**不采纳**，写自己 TIM 的 d、λ、A 假设。
4. 用式 4.2 算自己的 R_th,ch（A2 方法），比手册值大/小多少。
5. 选模型：分层物理 → Cauer；拟合 datasheet Z_th → Foster（3–6 对）。
6. 反推稳态 Rth：取 Z_th 曲线 t>5τ 读数，减 TIM 段。
7. 标定用 I_ref≈I_nom/1000，记录 U_CEsat 曲线，斜率符号以小电流为准。
