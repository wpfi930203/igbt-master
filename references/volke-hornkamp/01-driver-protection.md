# 01 · 驱动回路与七类保护（第 6 章蒸馏）

> 来源：《IGBT 模块：技术、驱动和应用》第 6 章，书页 151–220。
> 本笔记覆盖 **6.6.3 栅极引线电感 / 6.7 保护措施 / 6.8 逻辑功能** 的精读部分（书 p186–195）。

## R · 原文锚点

> 「如果栅极驱动不是脉冲，则功率使半导体持续导通发热。……由于极板引线电感，栅极将被逐渐增大的栅极电流充电。」【书 p187】

> 「如果 UCEsat 测量电路检测到 UCEsat 超过了先前设定的参考电压，测量电路认为产生了故障就会关 IGBT 栅极驱动单元或者向微控制器报错。」【书 p188】

> 「只要集电极处的电位超过了某一特定电压临界值 UCE，单向的 TVS 二极管 VD1 就会导通且通过电流。这时 VT2 开通，IGBT 被关断。」【书 p195】

## I · 骨架：驱动回路是三个寄生参数的博弈

驱动设计不是选一个 Rg 就完事，是三件事同时定：

```
栅极回路  ──┬── Rg（开关速度 / 损耗 / dv/dt）
            ├── LσG（栅极引线电感：影响开通延时与振荡）
            └── CGC（密勒电容：反馈路径，振荡与串扰的根）
```

**关键认知（书中反复出现的判据）**：这三种参数没有「越小越好」。
- Rg 小 → 开关快、损耗低，但 dv/dt 高 → 电压尖峰、EMI、串扰、振荡风险
- LσG 小 → 延时短、波形干净；但它是**与 Rg 串联的等效阻抗**，改动它会同时改变开通与关断
- CGC 小 → 反馈弱、不易振荡；但 CGC 由芯片结构与 VCE 决定，选型时几乎不可调

### 6.5 耦合电容：驱动器的第三个寄生量（书 p180–181，图 6.35）

前面三个寄生参数都在**栅极回路**里；耦合电容不在回路里，它从**整机地**上绕回来。

书 p180 给的式子（6.16）：

```
I_CM = C_couple · du/dt
```

- 只要存在**动态电位差**（开关系统的 du/dt），耦合电容就生效；
- 每个开关动作都让模块对散热器/机壳的电位跳变，位移电流经 C_couple 串进驱动与信号地；
- 这就是「IGBT/二极管/MOSFET 与冷却装置绝缘、并通过绝缘体相互绝缘」的物理原因——**绝缘不是为耐压，同时也是为切断 I_CM**。

两个可直接引用的量级（书 p180）：

| 指标 | 书中数值 | 用法 |
|---|---|---|
| 栅极驱动器可承受的最大 du/dt | 多数厂家给「无故障运行最高 **30 kV/μs**」 | 实际系统很少超过，但**超过时不是驱动器坏，是共模电流导致误触发/门锁** |
| 信号传输 + DC-DC 的耦合电容 | **每通道不能超过 22 pF** | 选光耦/数字隔离器/隔离电源时的硬指标 |

**工程含义**：把 22 pF 与 30 kV/μs 代进式 6.16，单通道 I_CM 上限约 **0.66 A 的位移电流尖峰**量级——它不走栅极回路，直接注到驱动参考地上。所以「加了 Rg 还是振」「偶发直通」「换个隔离电源就好了」这类问题的第三个怀疑对象，就是这个 C_couple。

### 6.6.3 栅极引线电感的真实影响（书 p187，图 6.43）

书中给出的机制比「电感拖慢开关」更细：

| 驱动方式 | LσG 的作用 |
|---|---|
| 双极性 ±15V | 电感只是延缓，开关速度基本不变，整个过程只多一次延时 |
| 单极性 0/15V | 开通**只会延迟，速度不变**；原因是初始阶段栅极电流全用来给 CGE 充电 |
| 0/15V + 较大 LσG | 栅极电压越过 UGE(TO) 后，栅极电流才达最大值；**关断速度不变** |

结论：**LσG 主要卖的是延时，不是速度**；但 d i/dt 与 d v/dt 会随 LσG 增大而增大（图 6.43c/d），关断延时也随之增加。这与「加电感就变慢」的直觉相反，是容易误判的地方。

### 6.7 保护：先分清「保护什么」

书中把保护按**被保护对象**分开，而不是按电路名字分：

| 保护 | 保护对象 | 触发量 | 动作 |
|---|---|---|---|
| UCEsat 监控（DESAT） | IGBT 自身（过流/短路） | VCE 退出饱和后上升 | 关断驱动 / 报 MCU |
| 集-射极钳位（有源钳位） | IGBT 自身（关断过压） | VCE 超过 TVS 击穿值 | 经 TVS 注入栅极 → 开通 VT2 → 软关断 |
| 栅极钳位 | 栅极氧化层 | VGE 超限 | 钳位到安全电平 |
| 欠压锁定 UVLO | 驱动能力 | VCC 跌落 | 封锁输出，防止欠驱动导致线性区发热 |
| 软关断 / 两级关断 | 短路电流 | 故障信号 | 降 di/dt，避免关断过压 |
| 最小脉冲抑制 | 逻辑正确性 | 脉宽 < 阈值 | 抑制窄脉冲，防直通 |
| 死区 / 半桥互锁 | 桥臂直通 | 上下管同时导通命令 | 强制插入死区 |

### 6.7.1 DESAT 的电路本质（书 p188，图 6.44）

书里用一张**扩展的输出特性图**讲清了 DESAT 为什么成立：

- 正常：IGBT 在饱和区，VCE = VCEsat，很低
- 过流到约 **4×Inom**：IGBT 退出饱和，VCE 急剧上升，直到接近母线电压
- 判据：VCE > Uref → 故障

电路的三个必备件：
1. **恒流源 Idesat** 给盲区电容 **Cbl** 充电（这样才不会被 VCE 的直流电平「灌满」而失效）
2. **Cbl** 提供**消隐时间**（blanking time），避开开通瞬间 VCE 尚未下降的窗口
3. **Uref** 比较器 + 故障锁存

**书中点明的一个易漏细节**：IGBT 关断时，Cbl 通过驱动器内部电路迅速放电，所以下次开通时 Cbl 处于确定的初始状态。若驱动器没有这个放电通路，第二次开通的消隐时间会漂移。

### 6.7.2 有源钳位的两条路径（书 p195，图 6.52）

书给了两种拓扑，区别在**反馈到哪**：

| 拓扑 | 反馈路径 | 特点 |
|---|---|---|
| a) 直接反馈到栅极 | TVS → 栅极 | 快，但容易在钳位期间引起振荡 |
| b) 反馈到驱动控制与栅极 | TVS → 驱动级 VT2 → 栅极 | 可控，能配合软关断 |

原理：VCE 超过 TVS 击穿值 → VD1 导通 → 电流注入 → VT2 开通 → IGBT 被（软）关断。
**注意**：书中特别说明「有源钳位」这个术语在本书中专用于集-射极钳位，不用于其他阻尼电路。写报告时别混用。

## A1 · 案例（书中实例）

1. **单极性 0/15V 驱动的开通延迟**（图 6.43a）：同样 Rg，LσG 大的版本开通沿整体右移，但上升斜率不变——如果只看「开关变慢」会误判成 Rg 太大。
2. **DESAT 的 4×Inom 边界**（图 6.44）：450A/1.2kV 器件的输出特性族显示，VGE=15V 时电流到 ~1800A 才明显退出饱和。这意味着 **Uref 设得太低会在正常过载时误报**。
3. **有源钳位的双 TVS**：单向 TVS 只能抑制正向峰值，双向 TVS 才能同时抑制正反向——反向尖峰（如续流二极管恢复）需要双向。

## S · 步骤（驱动与保护联调）

1. **定短路预算**：从 tSC（数据手册）倒推允许的检测+关断总时间
2. **设消隐**：Cbl × Uref / Idesat = 消隐时间；必须 > 开通瞬间 VCE 下降时间，且 < tSC 余量
3. **定 Uref**：取「额定电流下 VCEsat 上限」的 3–5 倍，且低于 4×Inom 时的 VCE
4. **选钳位**：先算关断尖峰 VCE,pk = VDC + Lσ·di/dt，再定 TVS 电压（留 10–15% 余量到 VCES）
5. **定软关断**：短路关断必须降 di/dt，两级关断的第二级 Rg 通常取第一级的 3–10 倍 `[推断，需实测]`
6. **验证**：双脉冲测开关损耗与尖峰 → 短路试验（用等效电感限流）测 tSC 余量 → 温升复测

## B · 边界

- 本章讲的是**分立驱动电路**，不涉及数字隔离器/集成驱动 IC 的内部实现
- DESAT 在 **SiC MOSFET** 上需要改判据（无饱和区），本书不覆盖
- 有源钳位的 TVS 选型依赖具体 Lσ，书中未给通用数值
- 本笔记读了 6.5 / 6.6.3 / 6.7 / 6.8 的部分页；**6.2 信号传输、6.6.2 栅-射极外接电容、6.4.2–6.4.3（DC-DC 与欠压锁定）未精读**
- 22 pF / 30 kV/μs 是**元件与驱动器级别的限值**，不含客户系统的母排与散热器耦合面积；实际 I_CM 必须由整机结构决定，不能只用这两个数反推
