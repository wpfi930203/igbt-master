# 22 · 熔断器协调与调制算法（第 13.11–13.12 节）

> 来源：13.11「熔断器」（书 p355–357，逐页精读）、13.12「调制算法的影响」（书 p357–359）。
> 这两节在书里相邻，看起来是两个话题，其实回答同一个问题：**系统级的选择（保护器件、调制方式）如何变成器件级的应力**。
> 对封装可靠性工程师的意义：**同一只模块，换个调制算法，ΔTj 就变了，寿命跟着变——而 datasheet 一个字都不会提。**

## R · 原文锚点

> 「熔断器是用于阻断半导体电流最后的保护措施。因为熔断器的 I²t 值高于 IGBT 的 I²t 值，所以不能保护 IGBT。」【书 p356】

> 「当超过设定的 I²t 值时（设计负载）时，导体就会熔断从而阻断电流。」【书 p356】

> 「熔断器断开后两端工作电压不能高于熔断器额定电压；电弧电压或者开关电压不能高于电力半导体的额定电压；熔断器的熔断 I²t 值必须低于整流二极管或晶闸管的 I²t 值。」【书 p357】

> 「DPWMMIN：在采样时间内，选择三相系统中相电压幅值最小的电压作为参考电压，其相关相将不再调制，也就是说相应的电力电子器件不动作。这种算法实际上是忽略了 U₀ 矢量，因而开关损耗下降，**但是逆变器底部 IGBT 的通态损耗会上升**。」【书 p358】

> 「由于 DPWM 算法可以降低开关损耗，所以可以适当增大电力电子器件的开关频率 f_sw……图 13.20 中 DPWM 算法的开关频率经校正后有所增加，**K_f 值取 2/3**。」【书 p359】

## I · 骨架一：熔断器不是用来保护 IGBT 的（这是本节最反直觉的一句）

书 p356 的因果关系必须读准：**熔断器的 I²t 高于 IGBT 的 I²t**，所以在 IGBT 烧毁之前熔断器不会动作。这不是选型失误，而是物理现实——IGBT 芯片面积小、热容小，短路耐受只有几微秒；熔断体的热容远大于芯片。

所以正确的分工是：

| 保护对象 | 由谁保护 | 熔断器的角色 |
|---|---|---|
| **IGBT** | 驱动器的**退饱和检测/软关断**（见 `01-driver-protection.md`） | **保护不了**，只做后备 |
| **整流二极管 / 晶闸管**（输入侧） | **aR 熔断器**（I²t 可比） | 真正的保护器件 |
| **整机 / 母线 / 电缆** | 熔断器 + 断路器 | 阻止故障扩大与二次失效 |

> 记住一句：**熔断器保护的是「系统不被一个已经坏掉的管子拖死」，不是「管子不被烧」。** 这句话能省掉大量与客户的责任争论。

## I · 骨架二：四类熔断器与一套字母代码

**按用途分四类**（书 p356）：

| 代号 | 名称 | 用在哪 |
|---|---|---|
| **UR** | 超快速熔断器（半导体熔断器） | 整流二极管、晶闸管 |
| **HH** | 高压大功率熔断器 | 中高压电网 |
| **NH** | 低压大功率熔断器 | 低压电网（图 13.17 的典型结构） |
| **GS** | 电器熔断器 | 熔断器内置于电器设备 |

**按分断能力分两类**：**a**（部分分断能力，只能分断 ≥ 额定电流的某倍数）/ **g**（全分断能力，从最小熔断电流到额定分断电流都能分断）。

**按保护对象分**（工程上真正要背的）：`gL`（线路）、`aM`（电动机回路）、**`aR`（半导体）**、`gR`（半导体全分断）、`gB`（矿用）、`gTr`（变压器）。

→ **选型只认 `aR` / `gR`**，其余是配电侧的事。图 13.17 的结构要点：陶瓷外壳 + **石英砂**填充（提高散热能力、帮助熔断时灭弧）+ 镀银/镀锡铜导体（降电阻）。

## I · 骨架三：四条判据，其中一条的方向最容易记反

书 p357 给的四条，逐条对应一个物理量：

```
① U_工作(断开后) ≤ U_额定                                              ← 绝缘
② U_电弧 ≤ U_半导体额定                                               ← 过压
③ I²t_熔断 < I²t_器件（对整流二极管/晶闸管）                          ← 热
④ 有滤波电路时，短路电流仍须足够大使熔断器熔断                          ← 灵敏度
```

**第 ③ 条的方向必须分清对象**：

| 保护谁 | I²t 关系 | 为什么 |
|---|---|---|
| 整流二极管 / 晶闸管 | 熔断器 I²t **<** 器件 I²t | 熔断器先断 → 器件活下来 |
| IGBT | 熔断器 I²t **>** 器件 I²t | 器件先炸 → 熔断器只做隔离 |

**同一条判据、两个相反方向，因为器件热容差两个数量级。** 这也是本书内部看起来「自相矛盾」（p356 说高于、p357 说低于）的真正原因——见本文末「附」。

**第 ④ 条是最容易漏的**：加了输出滤波器（图 13.16）后，滤波器电容/电感会限制故障电流上升率，**短路电流可能达不到熔断器的最小熔断值** → 熔断器「该断不断」，故障持续到模块炸。这条在带 long cable 或 du/dt 滤波器的场合尤其常见。

## I · 骨架四：调制算法改变的不是效率，是**应力的分布**

书 p357–358 的分类（CPWM 族 vs DPWM 族）：

| 族 | 算法 | 特点 |
|---|---|---|
| **CPWM**（连续） | SPWM、SVPWM、THIPWM（三次谐波注入） | 每相每周期都开关；**开关损耗大**，但输出畸变小 |
| **DPWM**（不连续） | DPWMMIN、DPWMMAX、DPWM3、GDPWM（DPWM0/1/2，相移 0、π/6、π/3） | 每相在一个基波周期内有 **120° 不开关**；开关损耗降，**但某一只管的通态损耗上升** |

书 p358 的关键句（DPWMMIN）：**「开关损耗下降，但是逆变器底部 IGBT 的通态损耗会上升。」**
DPWMMAX 对称：**「逆变器顶部 IGBT 的通态损耗上升。」**

→ **这是对封装可靠性最要紧的一句**：DPWM 并不是「让所有管子都轻松 1/3」，它把损耗从「三相均摊」变成「特定位置的管子承担更多」。落到寿命上，**六只芯片的 ΔTj 不再相同**——而这正好是「同一模块内不同芯片寿命差异」的一个系统性来源，与工艺缺陷无关。

## I · 骨架五：K_f = 2/3 ——唯一可直接用的数字

书 p359：DPWM 省下开关损耗后可以提频，**校正系数 K_f = f_sw,CPWM / f_sw,DPWM = 2/3**，即 **DPWM 可用 1.5 倍的开关频率**而开关损耗持平。

书同时给了 HDF（谐波失真因子）的解析式（式 13.21–13.24，**p359**，源于 A. M. Hava 等）与图 13.20 的曲线族，并说明 DPWM 的 HDF 要乘 K_f² 修正（式 13.26–13.29，**K_f 取 2/3**，即开关频率可提到 1.5 倍）。

> **HDF 四式的定量定位（v2.7.0 结案，原「排版不清」的判断已撤回）**：p359 原图放大 2 倍后**系数清晰可辨**，问题不在看不清，而在**代入后不闭合**。逐点比对图 13.20 的结果分三档：
>
> | 式 | m=0.3 算/图 | m=0.6 算/图 | m=0.9 算/图 | 判定 |
> |---|---|---|---|---|
> | 13.21 SPWM | 0.085 / 0.105 | 0.209 / 0.320 | 0.345 / 0.520 | ✅ 系数成立，但 m 口径差一个 `4/π`（拟合 c=1.25 ≈ 4/π=1.273） |
> | 13.22 SVPWM | 0.083 / 0.100 | 0.192 / 0.285 | 0.257 / 0.390 | ✅ 同上 |
> | 13.23 DMIN | **0.366** / 0.090 | **0.928** / 0.235 | **1.235** / 0.110 | ❌ 偏 3–10 倍，缩放救不回 |
> | 13.24 DMAX | **0.311** / 0.090 | **0.514** / 0.235 | **−0.060** / 0.110 | ❌ m≥0.7 变负，物理不可能 |
>
> **工程口径**：**HDF 一律读图 13.20**。要用解析式，只用 13.21/13.22，并显式写明 m 乘了 `4/π` 折算。**这是本模块唯一留白的定量项**，留白的理由现在是量化的，不再是「看不清」。

## A1 · 案例：换调制算法 = 零成本的寿命杠杆？（本地复算）

**第 1 步：总损耗降多少**

DPWM 每相一个基波周期内 120° 不开关，三相轮换 → 全网开关次数约为 CPWM 的 **2/3**（书 p359 的 K_f = 2/3 是同一事实的另一面）。

设开关损耗占总损耗比例 k，则：

```
P_DPWM / P_CPWM = (1 − k) + (2/3)·k = 1 − k/3
```

| k（开关损耗占比，示例） | 总损耗降幅 |
|---|---|
| 30 % | 10 % |
| **50 %** | **16.7 %** |
| 70 % | 23.3 % |

**第 2 步：折算成 ΔTj 与寿命**

同一 R_th、同一散热条件，ΔTj 近似正比于损耗。取 k = 50 %、原 ΔTj = 60 K：

- ΔTj → 60 × 0.833 = **50 K**
- Coffin-Manson（n = 4.4）寿命比 = (60/50)^4.4 = **2.23×**

→ **只改调制算法（不换材料、不改封装），寿命可以翻倍以上。** 这就是为什么 `19-application-profiles.md` 里「同一只模块在不同应用剖面寿命差 5~10 倍」不是玄学：**工况与算法都在动 ΔTj。**

**第 3 步：为什么不能说「所以 DPWM 更好」**

书 p358 已经给了反例：DPWMMIN 让**底部 IGBT 的通态损耗上升**。均摊算出的 16.7 % 是**总损耗**，不是**每只管子的损耗**。

逐管核之后可能出现：
- 顶部管：开关损耗 −33 %、通态不变 → **变凉**
- 底部管：开关损耗 −33 %、通态 +x % → **可能变热**

→ **结论必须写成两句**：① 系统总损耗下降、整机效率上升；② **某一只芯片的 ΔTj 可能上升**，寿命核算必须按「最热的那只」做，不能按平均值。

> 损耗占比 k、ΔTj = 60 K、n = 4.4 均为**示例/典型取值**，不是书内数据；本书只给了「DPWM 降开关损耗但抬高特定管通态损耗」的定性结论与 K_f = 2/3 这一个定量系数。**任何项目都必须用实测损耗（双脉冲 + 量热/电学法）逐管核算。**

## E · 触发场景

| 症状/任务 | 用本模块 |
|---|---|
| 客户问「为什么加了熔断器模块还是炸了」 | 熔断器 I²t > IGBT I²t，本来就保护不了（p356）；IGBT 靠 DESAT |
| 输入整流管频繁击穿 | 查 aR 熔断器的 I²t 是否 **<** 整流管 I²t，以及电弧电压判据 |
| 加了输出滤波器后熔断器不断 | 第 ④ 条：故障电流达不到最小熔断值 |
| 同一模块里总有某一只芯片先坏 | 先排除 DPWM 的**位置性损耗偏移**（顶部/底部），再谈工艺 |
| 想靠改调制算法提寿命 | 可以，但要**逐管**核 ΔTj；均摊值会骗人 |
| 「DPWM 能提多少开关频率」 | K_f = 2/3 → 1.5 倍（p359），但 HDF 要用图 13.20 核 |
| 选熔断器只看额定电流 | 四条判据缺一不可；I²t 与电弧电压才是半导体侧的关键 |

## S · 步骤（熔断器 + 调制算法的联合校核）

1. **定保护对象**：IGBT（靠驱动）还是整流管（靠熔断器）——先分清，再选 I²t 方向
2. **查四条判据**：额定电压、电弧电压、I²t 方向、滤波后的最小熔断电流
3. **定熔断器类别**：半导体侧只用 `aR` / `gR`；配电侧另算
4. **确认拓扑**：图 13.18 的三种接法（输入侧 aR / 输入 gG + 输出 aR / 母线 gRL）
5. **定调制算法**：CPWM（畸变小）还是 DPWM（损耗低）——按客户对 THD 的要求定
6. **逐管算损耗**：DPWM 下区分顶部/底部管，不能均摊
7. **回填寿命**：用最热那只的 ΔTj 走 `05-reliability-life.md` 的七步；对比 CPWM 与 DPWM 两套结果

## B · 边界

1. **书没有给任何熔断器 I²t 数值、也没有给 IGBT 的 I²t 曲线**——只有判据。实际选型必须用厂商的 I²t-时间曲线与器件的短路耐受曲线逐点比。
2. **HDF 绝对数值不采信解析式**（13.23/13.24 代入发散，13.21/13.22 差 4/π 口径，见骨架五）；定量一律读图 13.20。
3. 13.12 只讲到「CPWM 比 DPWM 开关损耗大、DPWM 输出电流畸变大」这一层；**书未给两类算法在具体工况下的损耗差百分比**，本模块的 k 值是示例假设。
4. 调制算法的实现细节（载波频率、死区补偿、过调制）**不在本节范围**，书也未展开。
5. 熔断器的**老化与降额**（环境温度、安装方式、频繁涌流）书未涉及——这部分须查 IEC 60269 系列与厂商手册。

## 附 · 书内一处「看起来矛盾」的口径（必须分清对象）

- 书 p356：「熔断器的 I²t 值**高于** IGBT 的 I²t 值，所以不能保护 IGBT」
- 书 p357：「熔断器的熔断 I²t 值**必须低于**整流二极管或晶闸管的 I²t 值」

→ **两句都对，对象不同**：前者说 IGBT（小热容、微秒级短路耐受），后者说输入侧整流管/晶闸管（大热容、毫秒级浪涌耐受）。写报告时若把两句混引，会得出「熔断器 I²t 要高于器件」这种致命结论——**这就是为什么本模块把「方向」单独列成一张表。**
