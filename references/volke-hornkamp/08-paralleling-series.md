# 08 · 模块并联与串联（第 8 章）

> 来源：书页 247–263（PDF 259–275），**主干精读**（8.1–8.3，含表 8.1、式 8.1–8.4）。
> 本章补的是技能里「温度系数决定并联命运」这个心智模型缺的**量化落地**：降额因子怎么算、哪些参数真正决定均流、双脉冲怎么验证并联。

## R · 原文锚点

> 「对于 IGBT 并联连接，无论是静态特性还是动态特性最主要的问题是要保证模块之间的均流。曾经认为静态均流对模块的并联非常重要，但是随着新一代芯片的应用，静态均流问题不再是主要问题，而动态均流成为制约模块并联的障碍。」【书 p248】

> 「为了不超过模块的静态电流容量，两个 IGBT 并联的总标称电流（1756A）小于他们单独工作的标称电流（2000A）。」【书 p249】

> 「总而言之，通过 8.2.2 节所述直流母线调整方法和隔离控制，可以实现最佳的电流匹配。如果遵守上述规则，就不太需要过去常用的 IGBT 并联降额方法。」【书 p259】

## I · 骨架一：为什么并联，以及并联的真正瓶颈

**三个动因**（书的分类，比"电流不够就并"细）：
1. **没有所需电流等级的模块**——例：需要 5 kA，而 1.7 kV 级最大标称 3.6 kA
2. **封装限制了电流**——「目前 62mm IGBT 模块的最大电流为 900A」；**换封装也不行**时只能并联
3. **特定机械结构 / 大批量生产的封装可用性**——结构定了，只能用小模块并

**瓶颈已经换位**：静态均流（正温度系数 + 工艺一致性改善）不再是主要矛盾，**动态均流才是**。这句话决定了并联设计评审的重心。

## I · 骨架二：表 8.1——哪些参数影响静态、哪些影响动态

这是全章最有操作价值的一张表。图例：`○` 无影响、`+` 有影响、`++` 主要影响。

| 参数 | 静态均流 | 动态均流 |
|---|---|---|
| **DC 母线杂散电感** | ○ | **++** |
| AC 输出电感 | + | + |
| **温度** | **++** | **++** |
| **饱和压降 U_CEsat** | **++** | ○ |
| **栅-射极阈值电压 U_GE(TO)** | ○ | **++** |
| AC 输出电阻 | **++** | ○ |
| DC 母线电阻 | **++** | ○ |
| 栅极驱动电压 U_GE | + | + |
| **栅极开通和关断延迟时间** | ○ | **++** |
| **栅极回路电阻** | ○ | **++** |
| **栅极回路电感** | ○ | **++** |
| 磁场影响 | ○ | + |

**读法**（这是表的用法，书里靠正文串起来）：
- 只有 **温度** 一列是 `++/++`——所以**散热设计同时决定静态和动态均流**，"先均温再均流"不是口号
- `U_CEsat` 管静态、`U_GE(TO)` 管动态，**两者互不替代**：挑同批次（同 U_CEsat）解决静态，但动态还得靠栅极回路对称
- 三个 `○/++` 的（DC 母线杂散电感、延迟时间、栅极回路 R 与 L）说明：**动态均流几乎完全是布线与驱动问题，不是芯片问题**

## A1 · 算例：两台 1000 A 模块并联，只能当 1756 A 用

**条件**（图 8.1，Tvj=125 ℃）：U_CE0=1.10 V；模块 A：U_CEsat,typ=2.35 V @1000 A；模块 B：U_CEsat,max=2.80 V @756 A。

**机理**：并联时 U_CE 被强制相等 → **U_CEsat 低的那个承担更多电流**。线性化输出特性后交点给出 1000 A / 756 A。

**降额因子**（式 8.1）：

```
δ_der = ( 1 − I_tot / (n · I_nom) ) × 100 %

两台：δ = (1 − 1756/(2×1000)) × 100 % = 12 %
三台：δ = (1 − (1000+756+756)/(3×1000)) × 100 % = 16 %
```

> **注意三台的算法**：假设"一个工作在典型值、另两个工作在最大值"——**这是最坏情况原则，不是统计期望**。所以 16 % 是上界，不是典型值。
> 反过来说：**看到"并联降额 12 %"就照抄进设计，等于默认了两个模块分别是 typ 和 max**，这在实际配对的模块里通常过于保守。

## I · 骨架三：静态均流的四个动作（按性价比排序）

1. **同日期条码**：同一条码的模块内部芯片来自同一批晶圆 → U_CEsat 天然接近。书中把它列为"目前大多数情况下可以选择"的常规做法
2. **按 U_CEsat 分档配对**：没有同条码时，用饱和压降分选（旧做法，仍有效）
3. **DC 母线对称 + 低阻抗**：保证每个模块的欧姆电阻 R_DC 误差最小；「电源的阻抗应该非常低，以便尽可能地降低通态损耗和消除内部阻抗差异带来的影响」
4. **R_AC 也要算进去**：连接端子的电阻应包含在欧姆电阻内；并联前母线要做防污染与腐蚀处理

**一条容易漏的**：「在实际运行中，必须确保所有并联模块散热均匀」，且 **U_GE 必须保持一致**（因为 U_GE 影响 U_CEsat）。

## I · 骨架四：动态均流的真正抓手——DC 母线杂散电感对称

**核心机制**（书讲得很细）：IGBT 开关时电流变化，**磁场试图抵消这个变化**。模块间的磁场会重叠，重叠程度取决于模块间距与布局：

> 「对于系统边缘的模块，只有一个与之相邻的器件，所以磁场的分布不同于那些两侧都有模块的器件。」【书 p251】

→ **边缘模块与中间模块的磁场环境天生不对称**。这就是三并联时中间那个总是电流偏高的物理原因，**不是装配误差**。

**手段**：调整换流路径中的杂散电感来补偿。图 8.5 给出的做法是在 DC+ / DC− 母线上**挖空**（开槽）改变局部电感，图 8.6 是实测的开通过程电流分布对比（优化前三条曲线明显分离，优化后贴合）。

**代价与注意**：调整杂散电感时，「必须考虑续流二极管特性的影响」——你改的是整个换流回路的 L，不只是 IGBT 那一支。

**其余两个动态抓手**：
- **U_GE(TO) 差异** → 阈值低的先开、先承担电流。「现代的 IGBT 芯片中 U_GE(TO) 的差异很小，所以建议使用相同日期条码的 IGBT 模块来减小这种差异」
- **温度** → 动态参数随温度漂移，因此**基板温度均匀**同样服务于动态均流

## I · 骨架五：三种栅极驱动并联拓扑（含一个可直接用的电阻公式）

图 8.8 给了三类：**直接栅极驱动 / 非直接栅极驱动 / 隔离栅极驱动**。

### (1) 直接栅极驱动（一个 GDU 驱动全部）

每个 IGBT 有**自己的 R_G 和发射极电阻 R_Emitter**。R_Emitter 的作用是吸收辅助发射极中的动态补偿电流。

**设计公式**（式 8.2 / 8.3）：

```
R_GExt   = R_G + R_Emitter
R_Emitter = (1/3) · R_GExt
```

**两个致命细节**：
1. 「如果不限制该电流，其峰值电流可能高达数百安培」→ **R_Emitter 必须有脉冲电流能力**，建议用脉冲电流等级较高的分流电阻或金属膜电阻，不能用普通贴片
2. 「如果采用有源钳位，每个 IGBT 需要独立的保护电路」——因为钳位路径取决于各自的换流路径与杂散电感

**结构性缺陷**：补偿电流的方向和幅值可能不同 → 一个 R_Emitter 上产生正电压降、另一个产生负电压降 → **开关时进一步不对称**。缓解办法：对称布线、电缆等长并拧成一股；或**在栅极回路串入扼流圈替代 R_Emitter**（图 8.10，利用感抗抑制差值电流，磁阻还能减少动态补偿电流）。

> 书中提醒的一句很实用的话：「如果栅极电阻的误差为 5 %，那么在对称方面根本起不到任何作用。」→ **先保证 R_G 本身的一致性，再谈布线对称**，否则是无效努力。

### (2) 非直接栅极驱动（每个 IGBT 独立推挽级）

每个 IGBT 有独立推挽级 + 独立旁路电容 + 独立充放电回路，**靠推挽级的电压源解耦**，而不是靠控制电路解耦。

**优点**：旁路电容提供再次充电电流，发射极电阻不影响开关特性 → 可以用比直接驱动**更大**的 R_Emitter，吸收补偿电流更有效，且不需要高脉冲等级的电阻；每个 IGBT 可独立设置带反馈的集-射极有源钳位。
**缺点**：需要五芯电缆连推挽级 + 实际信号单元 + DC-DC 变换器 → 更多 PCB 与内部连线。
**注意**：推挽级电压必须比栅极目标电压高 —— 「当使用 BJT 时，为了使栅-射极电压能够达到 15V，必须确保推挽级的电压为 16V」。

### (3) 隔离栅极驱动（每模块独立驱动 + 信号隔离）

用无磁芯变压器 IC 或 SCALE-2 类方案，**传输时间误差极小**。

**优点**：控制信号与辅助电源电气隔离 → **动态补偿电流无法形成回路** → 负载电流对称性不再依赖单个 IGBT 输出电感；栅极对称保持时不会产生谐振。
**实测数据**：三个 PrimePACK 并联用 SCALE-2 驱动，「抖动时间低于 8ns」【书 p259】。
**必须配合的一条**：「推荐在二次侧（驱动器的 IGBT 侧）采用反馈电压控制。在 IGBT 开关时，即使每个驱动器电压只有 500mV 的偏差，也会导致换流时间不平衡。」

## I · 骨架六：外部无源平衡（成本最高的一档）

1. **输出电抗器**（图 8.15）：在半桥输出串电抗器，防止瞬时电流脉冲并平衡输出电流。**最常用、也最贵**
2. **dv/dt 滤波器复用**：输出电感 + 电容构成 dv/dt 滤波器，一举两得；对电机绕组共模电流与轴承电流有保护作用
   - dv/dt 估算式（8.4）：`du/dt = U_DC / √(L_σ1 · C_du/dt)` —— 负载上的 dv/dt **不由 IGBT 决定**，由 L_σ1、R、C_du/dt 共同决定
3. **扼流圈环形连接**（图 8.17 / 8.18）：利用共模效应，电流平衡时磁场相互抵消（表现为低阻抗），不平衡时发挥电感作用，实现**自平衡**。铁粉芯磁环已验证可用于**输出开关电流低于 400 A** 的场合
   - 代价：**扼流圈的损耗与电流不平衡度直接相关，越不平衡损耗越大**

## I · 骨架七：串联（中压场景才用）

**四个动因**：无所需电压等级（6 kV 母线时最大只有 6.5 kV 模块）、封装电压限制（62mm 模块最大 1.7 kV）、成本（两个 3.3 kV 替代一个 6.5 kV）、效率（低电压模块开关损耗小，可提高频率、减小滤波器）。

**难点与并联相反**：并联要均流，**串联要均压**，且静态与动态都要均压。

| 状态 | 不均压的根因 |
|---|---|
| 关断过程 | 关断速度不同（驱动级或器件差异）→ **最快的承受最高电压**，因为先关断的先承担 |
| 开通过程 | 分压不均 + 换流路径杂散电感 → **最慢的承受最高电压** |
| 静态阻断 | **漏电流 I_CES 不同**（受阻断电压与温度影响） |

> 图 8.19b 给出了三串联在关断/稳态/开通三段的电压分配波形：关断瞬间尖峰最不均衡，稳态最均衡，开通瞬间再次失衡。**这条说明均压措施必须同时覆盖动态与静态，只做静态均压电阻不够。**

## E · 触发场景

- 「两台 1000 A 并，能不能标 2000 A？」→ 不能。按式 8.1 最坏情况是 1756 A（降额 12 %），三台 16 %
- 「并联后中间那个模块总是更热」→ 先查磁场耦合不对称（边缘 vs 中间），不是装配问题
- 「静态均流很好，动态还是偏」→ 查表 8.1 的三项 `○/++`：DC 母线杂散电感、栅极回路 R/L、延迟时间
- 「并联用什么驱动？」→ 优先隔离驱动（补偿电流无回路 + 抖动 <8 ns）；用直接驱动必须接受 R_Emitter 的数百安培脉冲
- 「双脉冲能验证并联吗？」→ 能，但**要在改进型 H 桥电路上做**，且它反映不出温度系数（见下）
- 「6 kV 母线怎么选器件」→ 串联，但要同时做静态（漏电流分档）与动态（延迟/驱动）均压

## S · 步骤（并联设计评审七步）

1. **算降额**：δ_der = (1 − I_tot/(n·I_nom))×100 %，用"1 typ + (n−1) max"的最坏情况；把结果写进规格书而不是沿用旧经验值
2. **配对**：优先同日期条码；否则按 U_CEsat 分档；记录每台的 U_GE(TO) 与 R_G 实测值
3. **均温**：基板温度均匀性作为设计输入，不是装配后的结果
4. **母线对称**：R_DC 与 L_σ 双对称；**边缘模块与中间模块**分别核算，必要时开槽补偿
5. **驱动选型**：隔离驱动优先；直接驱动则按式 8.2/8.3 配 R_Emitter，并选脉冲等级足够的电阻
6. **验证**：双脉冲在**改进型 H 桥**（图 8.7b）上做，不用标准半桥——否则观测到的电流通路与最终应用不一致
7. **交叉验证**：注意双脉冲**无法反映温度系数**（测不出自加热），实际系统可能比台架更均衡；不要用台架的不均衡度直接外推现场

## B · 边界

- 覆盖 8.1–8.3；**8.3 串联的均压手段细节（书页 263）未逐页精读**，本节只到"根因"层
- 式 8.1 的 12 %/16 % 是**书中的特定算例**（125 ℃、给定 U_CEsat 差值），不是通用降额系数
- 「62mm 模块最大 900 A」「1.7 kV 最大 3.6 kA」「6.5 kV 为最大电压等级」均为**该书出版时的市场状况**，引用前需按当前产品线更新
- 图 8.6 的优化前后对比只读到"曲线分离 → 贴合"的定性结论，**未取得数值化的不均衡度**
- 扼流圈环形连接的 400 A 上限来自"铁粉芯磁环已被证明可以用于"，**不是标准限值**
- 书中"遵守规则就不太需要降额"这句话**不能当作取消降额的依据**：它成立的前提是对称设计 + 母线补偿 + 隔离控制三者同时做到，且需要实测验证

## 补 · 第八轮补充（第 8 章 p255–p264 的剩余内容）

> 本节补录主干精读（8.1–8.3）之外、p255–p264 区间内被略过的工程判据与数值，逐条带来源页，便于与主干交叉引用。

- **降额可以被工程手段替代**：书 p259 明确，直流母线杂散电感"挖空"调整 + 隔离驱动（SCALE-2 抖动 <8 ns、二次侧反馈电压控制，500mV 偏差即致换流失衡）做到位后，"就不太需要过去常用的 IGBT 并联降额方法"【书 p259】。注意这是前提齐备后的结论，不是免除降额的通用许可。

- **发射极电阻设计规则**：R_Emitter = R_Ext/3（式 8.2/8.3）；R_Emitter 须用**高脉冲电流等级**电阻（分流电阻或金属膜电阻），因为辅助发射极补偿电流峰值可达**数百安**，普通电阻会损坏器件【书 p255】。

- **栅极电阻容差 5% 根本不起作用**：并联对称性要求栅极/发射极电阻容差远小于 5%，否则对均流"根本起不到任何作用"【书 p257】；同时所有并联模块的**基板（散热器）须处于相同电位**，简单电缆连接不够——DCB 与散热器间耦合电容在浮地/电位不同时会使开关特性产生偏差【书 p256–257】。

- **串联均压五措施与各自代价**：① 平衡电阻 I_R:I_CES = 3:1~10:1（静态均压，图 8.20a）【书 p263】；② 缓冲电路（提高动态分压，但**贵、体积大、延迟开关过程**）；③ 有源钳位（稳压二极管串联实现雪崩电压，但**误差大、受温度影响、增加损耗**）；④ 修正开关时间（需传感器，成本高）；⑤ du/dt 控制（设计复杂、需快响应逻辑）。书明确：任何单一措施都不够，**须组合使用**【书 p263–264】。

- **串联时退饱和短路保护不起作用**：为关断短路/过载电流，所有串联模块须同时开关；但因 IGBT 存在差异，退饱和（desat）检测无法同时覆盖所有器件，故"退饱和和监测不起作用"——这是串联方案**最大的隐性代价**【书 p264】。

- **静态均流最坏情况算法**（书 p249，Tvj=125℃）：从 U_CE0 = 1.10V 出发，向 U_CEsat,typ = 2.35V（@1000A）与 U_CEsat,max = 2.80V（@756A）画线性化直线；并联时 U_CE 强制相等，故 U_CEsat 低者承担更多电流（1000A），高者承担更少（756A），代入式 (8.1) 得 δ_der。这是**最坏情况上界，不是统计期望**。
