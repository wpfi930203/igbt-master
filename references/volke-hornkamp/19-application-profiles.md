## R · 原文锚点

- 伺服「伺服驱动中的功率半导体需要具有**很强的过载能力**，一般要承受 **2~6 倍的额定电流**」【书 p305】
- 伺服「特别对于低速负载突变，为了保证在几十分之一秒到几秒内完成响应，最重要的是具有**足够大的热容量 Z_th,jc** 来消除半导体内部的损耗。因此在这类应用中，大多数的 IGBT 模块采用**带铜基板的模块**」【书 p305】
- 伺服「而且，IGBT 的键合点需要具有**很高负载周次能力**，从而能够保证其达到**十年或更长**的使用寿命」【书 p305】
- 风能「网侧（或线路侧）变换器运行在 **50 Hz 或 60 Hz**……机侧逆变器必须满足从 **0 Hz 到约 20 Hz** 的工作频率范围。假定两个变换器的**负载相等**，那么**机侧变换器的结温 ΔT_j 波动将更大**」【书 p310】
- 风能「模块的**最大压力工作点为 0 Hz 的基本频率（点）**，这时**结温变化最大**。应当注意，对于风力发电厂来说**无法明确该类运行点发生的周期**，因此在选用 IGBT 模块时**必须要考虑这一问题**」【书 p310，图 11.46】
- UPS「功率可以小至几百瓦也可以高达数兆瓦……**小功率的单相 UPS 大部分使用分立功率器件**，只有在**大功率的三相系统**中采用 IGBT [模块]」【书 p305】
- 牵引「世界上各个地区建立的铁路牵引电源系统的标准**各不相同**……可以通过使用变换器，来**忽略电网的问题**，简化研发，实现跨领域应用，因此可以利用**统一的驱动系统（基于设计原理）**」【书 p310】
- 牵引「在交流电源中，可以通过**变压器**满足电力电子设备输入级的需求。而在**直流系统**中，变换器可以**直接与电网连接**」【书 p310】
- 牵引标准表（书表 11.2）：**750 V DC**（英国）；**1.5 kV DC**（澳大利亚、法国、印度、日本、荷兰、美国）；**3.0 kV DC**（比利时、意大利、波兰、斯洛文尼亚、南非、西班牙、俄罗斯、乌克兰）；**15 kV / 16⅔ Hz**（奥地利、德国、挪威、瑞典、瑞士）；**25 kV / 50 Hz**（中国、丹麦、美国、芬兰、法国、希腊、匈牙利、意大利、俄罗斯、西班牙）；**50 kV / 60 Hz**（加拿大、南非、美国）【书 p310】
- 16⅔ Hz 的由来「这受制于**早期的铁路技术**，当时**无法制造高频单相机**……换流会产生**很强的电弧**，从而**增加对电机的磨损**。为了能够选择合适的发电机，最终把 50 Hz 除以 3 定为铁路供电系统的频率。**1995 年**，有些国家把该频率稍微增大到 **16.7 Hz**，这样可以**避免在换流站内产生多余的直流分量**」【书 p310 脚注】

## I · 骨架：四个应用剖面

| 剖面 | 电气特征 | 热特征 | 主导失效机理 | 选型落点 |
|---|---|---|---|---|
| **伺服** | 2~6× 额定电流短时过载，响应 10 ms~s 级 | 需要**大 Z_th,jc**（芯片+基板热容），不是低稳态 R_th | **键合线/芯片焊层**功率循环（高频加减速） | 带**铜基板**模块；键合点高 PC 能力；PIM/CIB 拓扑；必须配制动斩波器 |
| **UPS** | 小功率单相→**分立**；大功率三相→模块 | 稳态为主，过载较少 | 电解电容与风扇（系统级）＞ 模块本身 | 分立走 `17-package-family.md`；模块侧按稳态 R_th 选 |
| **风能（双馈）** | 网侧 50/60 Hz；**机侧 0~20 Hz** | **同一负载电流下，机侧 ΔT_j 远大于网侧** | **机侧功率循环**，且**0 Hz（停机/极低速）最恶劣** | 不能按网侧工况选；必须按机侧 ΔT_j 谱做 Miner（见 `05-reliability-life.md`） |
| **牵引** | 直流 750 V~3 kV 或交流 15 kV/16⅔ Hz、25 kV/50 Hz | 长时高负载 + 站间启停循环 | 功率循环 + 热循环并存；绝缘（高海拔/污秽） | 按表 11.2 定直流母线电压，再按 `16-datasheet-blocking.md` 表 5.1 定模块等级 |

## A1 · 案例：为什么"台架 100 万次"到风机上两年就坏

这是本书给出的**最硬的一条**，也是技能里"寿命数字必须带条件"这条纪律的实证。

书的推理链只有三步（p310 + 图 11.46）：

1. 双馈风机有**两个变换器**：网侧跑 50/60 Hz，机侧跑 **0~20 Hz**；
2. **同样负载电流**下，频率越低，一个基波周期内结温摆幅越大——因为低频时热量有足够时间"打进"更深的热阻层，ΔT_j 被放大；
3. **0 Hz 时 ΔT_j 最大**，而这恰好对应**停机/极低速**工况；而风电场**无法预知这种运行点的出现频次**。

于是"实验室 PC 跑 100 万次"与"现场两年"之间差的不是次数，而是**ΔTj 的分布**：
- 台架用固定 ΔTj（比如 80 K）+ 固定 t_on 做 100 万次；
- 现场是**低频大摆幅 + 高频小摆幅的混合谱**，大摆幅那部分对 Miner 的贡献被 1/N_f 放大。

**正确做法**（可直接落到脚本）：
1. 取机侧真实任务剖面（含 0 Hz 段）→ 用 `scripts/igbt_loss.py` 算 Ploss → `igbt_thermal.py` 算 Tj 序列；
2. `igbt_life.py cycles --min-range` 做雨流，**务必设最小摆幅门限**滤掉测量噪声；
3. 用**机侧**（不是网侧）的 ΔTj 谱跑 Miner；
4. 结论必须写成"在 XX 剖面、XX 判据下的 B10"，而不是"100 万次"。

## A2 · 案例：牵引标准表怎么用（别只记电压）

书表 11.2 的价值不在"各国电压"，而在**它解释了为什么同一个牵引变流器不能全球通用**：

- **直流区**（750 V / 1.5 kV / 3.0 kV）：变换器**直接接电网**，输入级是斩波或直-交，器件耐压按 DC 母线选；
- **交流区**（15 kV 16⅔ Hz / 25 kV 50 Hz / 50 kV 60 Hz）：靠**车载变压器**降压，变压器体积与频率成反比 → 16⅔ Hz 的变压器比 50 Hz 大三倍，这是欧洲机车重的历史原因（书 p310 脚注）；
- **16⅔ → 16.7 Hz 的改动（1995）** 是为消除换流站的**直流分量**，属电网侧问题，但会影响车载变压器的设计点。

**给封装/可靠性工程师的用法**：客户报"我们的牵引模块按 25 kV/50 Hz 设计"，你要追问的是**直流母线电压**与**开关频率**，不是接触网电压。前者定器件等级（`16-datasheet-blocking.md` 表 5.1），后者定 ΔTj 谱。

## E · 触发场景

- 客户问「你们这个模块能用在风机上吗」→ 先问**机侧还是网侧**，再要 **0 Hz 段**占空比；不能直接用网侧工况答复。
- **伺服**客户抱怨模块过热但平均电流不高 → 查过载倍数（2~6×）与 Z_th,jc，而不是稳态 R_th。
- 需要论证"为什么必须给任务剖面才能算寿命"→ 用本篇 A1 的三步链。
- **牵引**项目定器件电压等级 → 表 11.2 定接触网，再换算直流母线，再查表 5.1。
- 出口设备要**跨区域通用**→ 明确指出电网标准差异导致不能一套硬件通吃（书 p310）。

## B · 边界

- 11.6 是**应用概览**，书**没有给**任何应用的定量任务剖面（年循环数、ΔTj 直方图、载荷谱）。这些必须来自客户实测或 IEC/行业标准（如风电的 IEC 61400 系列），**本文不提供也不编造**。
- 图 11.46 只给了 ΔT_j 随基波频率的**定性曲线**（0~60 Hz，ΔT_j 从约 40 K 降到约 5 K 量级），**没有给具体模块型号与负载条件**，因此**不可直接引用为设计值**。
- 光伏（11.6.3）与中压逆变器（11.6.7）、开关磁阻（11.6.6）本次未精读，只知拓扑分类（书图 11.44 给出单相/三相、有/无变压器、H 桥/全桥/3 电平/Heric/H5 的分类树）——**不产生结论**。
- 伺服"十年或更长"是书作者对应用寿命目标的表述（p305），不是标准规定值。

### 风能三类系统的参数谱（图 11.45，p309）
- 感应电机 + 齿轮箱：发电机/输出 3×690V，转子频率 50Hz，无变换器（无直流母线、无 IGBT 开关频率/电压等级数据）。【书 p309】
- 同步直驱（MSC/LSC）：发电机 3×500V/690V/960V，转子频率 0..65Hz，直流母线 650V/1.1kV/1.8kV，IGBT 电压等级 1.2kV/1.7kV/3.3kV；开关频率书中印有两行 3..4kHz 与 0.5..1kHz（分别对应网侧 LSC / 机侧 MSC，图中未明示对应关系，见 H2 蒸馏「六·5」）。【书 p309】
- DFIG 双馈：发电机 3×690V，转子频率变化，直流母线 1.1kV，输出 3×690V，IGBT 开关频率 2.25kHz，IGBT 电压等级 1.7kV；**转子侧逆变器仅按额定装置输出的 25%~30% 设计**（控制转子速度匹配电网频率）。【书 p309】
- 设计算例（书图 11.45 参数谱，输入＝系统类型与额定值，结果＝母线电压/开关频率/器件电压等级）：p309 给出上述三类系统的完整参数对照表，可作风机变换器方案初选的输入清单。【书 p309】

### 风电 0Hz 应力判据（p310）
- 网侧变换器工作于 50/60Hz；**机侧变换器须覆盖 0Hz ~ 约 20Hz**。【书 p310】
- **0Hz 是结温波动最大、负载周次最严酷的工作点**：图 11.46 估读 ΔT_j 约 30K@0Hz → 约 8K@60Hz（T_j,max 约 130℃→约 118℃，T_j,min 约 105℃→约 112℃）。【书 p310】
- 风力发电厂**无法明确** 0Hz 类运行点发生的周期，因此 IGBT 模块选型**必须预留** 0Hz 工况（最大 ΔT_j、最大负载周次）的应力裕度。【书 p310】

### 三电平绝缘等级决策链（p297–298）
- 决策输入：直流母线 3kV 的三电平 NPC，因负载再生回馈引起母线电容电压不平衡，半桥上/下支路承受电压由 1.5kV 增至 3.3kV IGBT 模块。【书 p297】
- 中性点**接地**（散热器同电位）→ 模块绝缘等级 **3.3kV**；中性点**不接地** → 绝缘电压为直流母线电压 3kV，模块绝缘等级 **6.5kV**。【书 p297】
- 栅极驱动 DC-DC 变换器绝缘：标准值 U_iso=6kV；适配不接地三电平 NPC 与最大母线约 4.5kV 的 FCML 时须设计为 **U_iso=10.2kV**（非标准 6kV）。【书 p297】
- 设计算例（书图 11.29，输入＝中性点是否接地、母线电压，结果＝模块/驱动绝缘等级）：接地 3.3kV、不接地 6.5kV、驱动 10.2kV，即上表对应值。【书 p297–298】

### 其余应用剖面要点（p303–313）
- **伺服驱动**：功率半导体须承受 **2~6 倍额定电流** 过载；多采用**带铜基板**的模块以获大热容量 Z_th,JC；IGBT 键合点需高负载周次能力，保证**十年或更长**使用寿命（书作者表述，非标准规定值）。【书 p305】
- **UPS**：三相两电平（或三电平）拓扑常见于 **60kVA ~ 超过 500kVA**；整流端可用 6/12 脉冲或维也纳整流器。【书 p306–307】
- **Z 源逆变器**：输出 400V / 输入 100V 时须用 **U_CES=1.7kV** 器件取代 1.2kV（升压模式使 IGBT 阻断电压升高）。设计算例（输入＝输出 400V、输入 100V，结果＝U_CES 1.7kV 取代 1.2kV）：p303 直接给出。【书 p303】
- **中压驱动**：电动机工作电压 **2.4~7.2kV**，功率 **>200kW**（可超 10MW）；H 桥级联单元用 1.2kV/1.7kV IGBT 模块，多接头变压器供电。【书 p312–313】
- **开关磁阻电动机（SRM）**：开关频率＝输出频率，低速约 **100Hz**，选 **U_CEsat 与 U_F 最低** 的器件；续流二极管承受满载且热阻高，**选型比 IGBT 更严格**（尤其再生工况）。【书 p312】
