# `76` 内互连（引线键合 / Clip）

> **书源层 · 封装。** 引用须标「据封装 `76`（书 pXX）」。
> **本模块是功率器件内部电气互联的核心工序**，与 Volke `03`/`25`（键合线功率循环失效）和 Baliga `58`（只提形态）跨源并列（见本层 00-index §5 P2）。功率器件用**粗铝线冷超声**，与 IC 的金/铜线热超声路线不同。
> **两句话摘要**：① 键合本质是**超声波压焊**（母材不熔化、不需填充焊料）；功率器件用**粗铝线冷超声**，IC 用**金/铜线热超声**（焊线直径 < 50 μm，电流有限，只用于门极/控制芯片）。② **超声能量/压力/时间是焊点质量的三要素**，三者任一失当都会导向「根部裂纹 / 弱焊脱落 / 弹坑」；**第二键合点比第一键合点更易脱键**。
> **文本来源**：扫描版 OCR（书 p59–89）+ 原页图核对；MBD 倍数、Kirkendall 温度、纯度等已回原页确认。

## R · 原文锚点

> 「内互联主要的方法就是压焊，而且能量来自于超声波的高频振动，因此又称超声波压焊……超声波压焊是焊接的一种，其特征是母材不熔化，不需要填充焊料，需要通过加压来达到原子间结合的程度。」
> — 书 p60–61（3.4.1）

> 「对于功率分立器件，由于所处理的电流、电压比较大，通常采用比较粗的铝线冷超声焊接来实现芯片和引脚的内互联。」
> — 书 p62（3.4.2）

> 「采用金/铜线的超声波热压焊……焊丝早些时候是高纯度黄金，其纯度可以达到 99.99 % 以上……由于焊线直径一般不超过 50 μm，因此所能通过的电流有限，一般不用于较大功率的器件场合，但可用于功率器件的门极驱动场合。」
> — 书 p62（3.4.2）

## I · 骨架

### I.1 两种键合路线（书 p62，核心对照）

| 路线 | 焊材 | 工艺 | 适用 | 电流能力 |
|---|---|---|---|---|
| **热超声（球焊）** | 金线/铜线，纯度 **> 99.99 %** | 加热 + 超声 | 存储器/处理器/IC；功率器件的**门极驱动、控制芯片** | 焊线直径 **< 50 μm**，**电流有限，不用于大功率** |
| **冷超声（楔焊 Wedge Bond）** | 铝线，纯度 **99.99 %**（加 Si 增强度、加 Ni 抗腐蚀） | 室温超声（无加热） | **功率器件、整流器、模块** | 粗铝线，过**大电流** |

→ 书 p62 明确：功率器件因大电流用粗铝线冷超声，IC 用金/铜线热超声。**这是本技能反复遇到的「功率 vs IC」分界的又一处体现。**

### I.2 FAB / MBD 几何约束（书 p63）

球焊先放电熔出**烧球 FAB（Free Air Ball）**，FAB 直径决定焊点成形。

- **MBD（压扁后球径）= FAB 的 1.2~1.5 倍**；
- **> 1.5 倍上限**：球变形过大 → 颈缩 + 应力集中 → 裂纹；
- **< 1.2 倍下限**：焊接不充分、球脱落。

→ MBD 由**压力 + 超声能量 + 作用时间**三者共同决定，工艺工程师用 DOE 找最佳区间。

### I.3 Kirkendall 空洞（书 p73，金铝失效）

金线球焊的致命失效：**高温（> 300 ℃）下金向铝扩散形成 Au₂Al，键合点四周生成环状空洞** → 高阻/开路。

- **触发条件：温度 > 300 ℃ 且时间过长**（热压键合时芯片温度本就 > 300 ℃）。
- **诡异特征**：电测试时（如 5 V 冲击）合金被打碎**暂时恢复**，但可靠性极差，高温存储/工作后开路复发。

→ 这是「为什么功率器件不用金线球焊、改用粗铝线冷超声」的工程根（冷超声无金铝界面）。

### I.4 超声冷压焊三要素（书 p75–77，参数窗口）

铝线楔焊质量由**超声能量 + 压力 + 焊接时间**三要素决定：

| 要素 | 失当后果 |
|---|---|
| **超声能量↑过高** | 铝过多挤出成「耳朵」、边缘烧焦、根部凹陷 → **温度循环失效** |
| **超声能量↓过低** | 结合不牢、中部未焊区（污层残留） |
| **压力↑过大** | 铝扁平、从工具挤出、大未焊区 → 弱焊/脱落（**措施：降压力，不是加能量**） |
| **压力↓过小** | 焊丝滑动、芯片弹坑（die cratering）、铝垢残留 |
| **时间↑过长** | 挤出过多、边缘氧化物（黑色区） |
| **时间↓过短** | 无足够塑变、表面未破碎 → 脱落/极弱 |

→ **关键工程直觉（书 p76）**：压力太大导致的弱焊，**不能靠加能量解决，要降压力**——这是反直觉的。

### I.5 引线框架与表面粗糙度（书 p77）

- 引线框架基材：铜或铁镍合金，冲压 + 电镀增可焊性；
- **粗糙度并非越光滑越好**：超声焊靠摩擦生热塑性变形，适度粗糙反而可焊性好、接头强度高（书 p77，反直觉）；
- 装片用软钎焊（> 300 ℃）使框架易氧化 → 用 N₂/H₂ 混合保护气还原。

## A1 · 案例：粗铝线 vs 金线球焊的取舍（书 p62、p73）

功率 IGBT/整流器模块用**粗铝线冷超声**：避开金铝 Kirkendall 空洞、耐大电流、热疲劳好。金线球焊只用于门极驱动/控制芯片等非大电流场合。**一条经验法则：凡是功率通路，不用金线球焊。**

→ 与本技能 Volke `25` 的「键合线功率循环失效」呼应：粗铝线是功率模块寿命的薄弱环节，但前提是避开金铝界面。

## A2 · 本地复算

**A2.1 MBD 倍数窗口的量级自洽**

书给 MBD = 1.2~1.5 × FAB。若 FAB = 25 μm，则 MBD 合理区 **30~37.5 μm**；超出则按 I.2 判裂纹/脱落。**倍数窗口是几何判据，不涉及绝对量纲，引用安全。**

**A2.2 Kirkendall 温度 300 ℃ 与装片软钎焊温度的关联**

书 p77 提到装片软钎焊需要 **> 300 ℃**，而 I.3 说 Kirkendall 空洞触发也在 **> 300 ℃**——两处温度同源：高温是装片钎焊的必需，也是金铝键合失效的阈值。**若功率器件确需金线球焊，必须控制键合后高温工序时间**（书 p73 的「时间过长诱发」）。

## E · 触发场景

- 用户问「功率模块为什么用铝线不用金线」→ I.1 + I.3 + A1。
- 用户问「焊点根部裂纹/弱焊怎么调」→ I.4 三要素表 + 「压力太大要降压力」。
- 用户问「键合脱键、Kirkendall 空洞」→ I.3 + 第二键合点更脆弱（I.4 延伸）。

## S · 步骤

1. 选路线：功率通路→粗铝线冷超声；门极/控制→金线热超声（I.1）；
2. 球焊先定 FAB→MBD 落在 1.2~1.5× 区间（I.2）；
3. 三要素 DOE：超声能量/压力/时间各取窗口中点，破坏性拉力验证（I.4）；
4. 等离子清洗焊盘前处理（去氧化/油污）（书 p61）；
5. 控框架粗糙度 + N₂/H₂ 保护防氧化（I.5）。

## B · 边界

- **式 3-1~3-10（装片裂纹模型）在 `75`，不在本模块**；本模块只到键合界面。
- **Kirkendall 空洞的 300 ℃ 是书给阈值**，不同键合合金/时间窗口差异大；**不要当本厂规范**。
- **Clip 铜片（书 p3 提过）在本模块只作对照提及**，完整 Clip 工艺见 `82` 或后续。
