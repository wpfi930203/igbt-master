# `75` 芯片装片（Die Attach / 贴片·烧结）

> **书源层 · 封装。** 引用须标「据封装 `75`（书 pXX）」。
> **本模块是功率模块可靠性的头号工艺节点**——装片界面（芯片↔基板）的热阻与空洞直接决定功率循环寿命。它与 Volke `25`（die attach 寿命）和 Baliga `58`（形态谱系，明确「不是封装工艺书」）跨源并列（见本层 00-index §5 P1）。
> **两句话摘要**：① 装片四种路线：**胶联（导电/非导电树脂）/ 焊料（Pb-Sn）/ 共晶 / 银烧结**；功率器件因背面是电极，多用**高温软钎焊或银烧结**而非银胶。② **空洞率是装片第一判据**；银胶体积电阻率随银粉填充量从 60 % 的 >2.5×10⁻² Ω·cm 降到 80 % 的 2×10⁻⁴ Ω·cm。
> **文本来源**：扫描版 OCR（书 p33–58）+ 原页图核对；电阻率/填充量/银粉粒径已逐项回原页确认。

## R · 原文锚点

> 「装片就是把裸芯片通过导电或者不导电的方式装到合适的载体上，载体分为基板和框架这两大类……装片的产品质量要求：芯片与引线框架的连接机械强度高，导热性能好（ΔV_BE 小）和导电性能好（V_CEsat 小），装配平整，焊料厚度适中，定位准确。」
> — 书 p33（3.3 装片）

> 「目前比较主流的方式主要有以下 4 种，分别是胶联装片（分为导电或非导电树脂）、焊料装片（以铅锡合金为主）、共晶装片、银烧结装片。」
> — 书 p34（3.3）

> 「当银粉填充量为 60 % 时，体积电阻率大于 2.5×10⁻² Ω·cm，几乎不导电；当银粉填充量为 75 % 时，体积电阻率为 1×10⁻³ Ω·cm；当银粉填充量为 80 % 时，体积电阻率为 2×10⁻⁴ Ω·cm。」
> — 书 p35（3.3.1 胶联装片）

## I · 骨架

### I.1 装片质量四要求（书 p33）

1. **机械强度高**；
2. **导热好（ΔV_BE 小）**——结温敏感；
3. **导电好（V_CEsat 小）**——背面是电极，电阻直接进导通压降；
4. **装配平整、焊料厚度适中、定位准确**。

→ 装片质量缺陷清单（书 p33）：无沾污/碎裂/划伤/倒装/误装/扭转；框架无气泡/氧化/变形；**无空洞**、无翘片、焊料熔融良好。

### I.2 四种装片路线对比（书 p34）

| 路线 | 黏合材料 | 适用 | 关键风险 |
|---|---|---|---|
| **胶联装片** | 导电/非导电树脂（环氧 + 银粉/氧化铝粉） | IC、小功率晶体管；功率器件受限 | 电导率低、黏接强度偏低、固化时间长 |
| **焊料装片** | 铅锡合金（Pb/Sn） | 功率器件背面电极 | 表面张力致芯片倾斜、焊料层厚度失控 |
| **共晶装片** | 共晶合金 | 高可靠 | 温度窗口窄 |
| **银烧结装片** | 烧结银（纳米/微米银） | **高可靠功率模块（Si 与 SiC 共用）** | 工艺窗口（温度/压力/气氛）严，见 `82` |

### I.3 导电银胶（书 p34–37）

**银粉形态优先级（导电/导热接触面积）**：枝叶状 > 磷片状 > 杆状 > 球状（OCR「磷片」→「磷片状」）。**片状银粉更利于导电**（书 p35）。

**银粉粒径三档（书 p35）**：微晶 **< 0.1 μm**；微球 **0.1~2 μm**；片状 **> 2 μm**。

**银粉填充量 → 体积电阻率（书 p35，关键定量）**：

| 银粉填充量 | 体积电阻率 |
|---|---|
| 60 % | **> 2.5×10⁻² Ω·cm**（几乎不导电） |
| 75 % | **1×10⁻³ Ω·cm** |
| 80 % | **2×10⁻⁴ Ω·cm**（达 10⁻⁴ 量级） |

→ 填充量 > 75 % 才进入 10⁻⁴ Ω·cm 可用区；但填充过高会牺牲黏接强度（书 p36）。**银胶注射筒 10~25 g、保存 −40 ℃**（书 p34）。

**绝缘型（非导电胶）**用氧化硅/特氟龙填料，导热好、绝缘好，适用 IC 与小功率（书 p34）。

### I.4 装片三大常见问题（书 p38–39）

1. **芯片位置**（倾斜/偏倚）：设备精度 + 三点一线（芯片中心/拾取头/顶针）校准（书 p38 图 3-9）。
2. **芯片裂纹**：顶针上推 + 吸嘴下压的两面受力；参数失当（顶针冲击速度/尖锐度/数量/高度、吸嘴下压压力）超过硅与背金极限 → 背面顶洞或隐性裂纹（书 p38）。**隐性裂纹最危险：能过测试、应用中失效。**
3. **空洞**：焊料/胶层空洞 → 局部热阻飙升 → 功率循环早期失效（书 p33 缺陷清单明确「无空洞」）。

### I.5 芯片裂纹热应力模型（书 p39–40，式 3-1~3-8）

书给出焊料层热应力解析模型（硅芯片 / 焊料 / 框架 Cu 三层，中心均匀假设）：

- 材料常数 `β = √(G_焊料·t_焊料 / (E_si·t_si·t_焊料))`（书 p40 式 3-6，OCR 排版压缩，变量名以原页图为准）；
- 剪切应力 `τ(x) = G_焊料·(α_cu − α_si)·ΔT·sin(βx) / (β·t_焊料·cos(βL))`（书 p40 式 3-7）；
- 边界 `tan(βL) = (α_cu − α_si)·ΔT / (…)`（式 3-8）。

→ **机理**：裂纹源于芯片-焊料-框架 CTE 失配（Δα·ΔT）产生的剪切应力在芯片边缘（x=L）最大。**这是「为什么装片要控空洞、要选热膨胀匹配焊料」的定量根**——与 `80` 的界面热阻、Volke `25` 的 die attach 失效同源。

## A1 · 案例：功率器件为什么不用银胶而用焊料/烧结（书 p33、p35）

书 p35 明确：导电胶「电导率低……对于有较高散热和较低导通电阻要求的功率器件，则不太适合」。因此功率器件背面电极（MOSFET 背金 Ti/Ni/Ag 各 ~0.3 μm，总 ~1 μm，书 p29）走**高温软钎焊或银烧结**，把 V_CEsat 与热阻压到最低。

→ 这正是本技能反复处理的「功率模块 vs IC」分界：IC 用银胶即可，功率模块必须焊料/烧结。

## A2 · 本地复算

**A2.1 银粉填充量电阻率的量级自洽性**

书给 60 %→75 %→80 % 三档：2.5×10⁻² → 1×10⁻³ → 2×10⁻⁴ Ω·cm。相邻档位跨度：75 %/60 % 电阻率比 ≈ 25×；80 %/75 % ≈ 5×。**填充量每增 5 个百分点，电阻率降约一个数量级附近**——符合渗流理论（percolation）「填充越过阈值后导电通路骤增」的预期，量级自洽，无矛盾。

**A2.2 银胶 −40 ℃ 保存 vs 室温适用期**

书 p34「保存在 −40 ℃ 冰箱」、p36「室温下适用期长」不矛盾：低温抑制环氧预固化，取出回温后才开始交联。引用时标「据封装 `75`（书 p34）」，**不要当本厂规范**。

## E · 触发场景

- 用户问「功率模块背面怎么贴、能不能用银胶」→ I.2 + A1。
- 用户问「装片空洞为什么致命」→ I.4 第 3 点 + I.5 CTE 失配机理。
- 用户问「银胶电阻率多少」→ I.3 + A2.1（注意是 10⁻⁴ Ω·cm 量级，非 10⁻⁶）。

## S · 步骤

1. 定路线：IC/小功率→银胶；功率→焊料或银烧结（I.2）；
2. 银胶选银粉：小片状、填充 > 75 %（I.3）；
3. 拾片：三点一线校准 + 控顶针冲击/吸嘴压力防裂纹（I.4）；
4. 焊料装片：控表面张力防倾斜、保焊料厚度适中（I.4）；
5. 固化/烧结：银胶中温固化、烧结银控温压气氛（见 `82`）；
6. X-ray 检空洞（I.4 第 3 点）。
