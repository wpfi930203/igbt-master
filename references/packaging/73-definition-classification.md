# `73` 功率半导体封装的定义、分类与器件谱系

> **书源层 · 封装。** 引用须标「据封装 `73`（书 pXX）」。
> **本模块是封装层的入口**：它不教工艺，而是把「功率封装有哪些形态、功率器件有哪些类型、为什么功率封装要把散热放第一」三件事钉死，后续 `74`–`85` 的工艺模块都在它的框架里。
> **两句话摘要**：① 功率封装三大系列 = **TO 系列 / QFN·DFN（Clip 铜片）/ 模块系列**；分立器件以 TO 为主，模块以 IPM 到大功率为主。② **散热是功率封装的第一矛盾**（书 p2、p5 原话），因为功率器件工作在大电流、高电压，结温直接限制容量。
> **文本来源**：扫描版 OCR（书 p1–19）+ 原页图核对；OCR 混淆已修（`ICBT`→`IGBT`、`12OOV`→`1200V`、`晶闻管`→`晶闸管`、`并行不的`→`并行不悖`）。

## R · 原文锚点

> 「功率型封装是指应用于功率场所的封装，和一般集成电路封装有明显的区别是功率器件一般工作在大电流、高电压的应用场景，因此**散热是功率封装首先需要考虑和解决的问题**，其次是材料的选择和相应的工艺路线。」
> — 书 p2（第 1 章）

> 「按照和 PCB 连接方式的不同分为通孔直插式封装（THT）和表面贴片式封装（SMT）；按照封装材料分为金属封装、陶瓷封装、塑料封装……塑料模型封装开始大量涌现，它是以热固性树脂通过模具进行加热、加压来完成的……尚属于半气密或非气密的封接材料。」
> — 书 p1（第 1 章）

> 「功率半导体器件的技术领域可以划分为两大门类，即以发电、变电、输电为代表的**电力领域**和以**电源管理**应用为代表的电子领域……在电力领域，以超大功率晶闸管、IGCT 技术为代表，继续向高电压、大电流方向发展；而在电子领域，电源管理器件倾向于集成化、智能化以及更高的频率和准确度。」
> — 书 p3–4（第 1 章）

## I · 骨架

### I.1 封装的四项基本功能（书 p1）

1. **保护芯片**，使其免受外界损伤；
2. **重新分配输入/输出（I/O）**，为板级装配提供空间（OCR 误为「输人V输出」，已修）；
3. **多芯片内互联**，把电气性能从芯片向外界传递；
4. **环境耐受**：满足温度、压力、化学等环境条件下的使用要求。

→ 这四条里，功率封装把第 4 条（尤其温度）做到了极致——这是它区别于普通 IC 封装的本质。

### I.2 封装分类的三条轴（书 p1–2）

| 分类轴 | 类别 |
|---|---|
| **与 PCB 连接方式** | 通孔直插（THT）/ 表面贴装（SMT） |
| **封装材料** | 金属封装 / 陶瓷封装 / 塑料封装（主流，半气密或非气密） |
| **应用与外形** | 功率型 / 混合 IC / 光电 / 存储 / 处理器；TO、DIP、SOP、PLCC、QFP、QFN、BGA、CSP、Flip-Chip、COG、COF |

→ 气密密封（玻璃-金属、陶瓷-金属、低熔玻璃-陶瓷）可靠性最高但贵；塑料塑封大量生产、成本低但**吸湿、耐热差**，属半气密/非气密。

### I.3 功率封装三大系列（书 p3，本模块最核心的一张表）

| 系列 | 代表形态 | 散热/电性能特征 |
|---|---|---|
| **TO 系列** | TO220、TO251/252、TO263、TO247 | 直插或表贴，塑料封装为主，带裸露散热片 |
| **QFN/DFN 系列** | MOSFET、多芯片 Dr.MOS | 采用**铜片（Clip）工艺**的散热和电性能更优秀 |
| **模块系列** | 从 IPM（智能功率模块）到大功率模块 | 多芯片集成在一个外壳/模块里 |

→ **QFN/DFN 用 Clip 铜片替代键合线**：铜片短路电阻、降低寄生电感、导热更好——这是后续 `76`（内互连）要展开的「Clip 工艺 vs 引线键合」的伏笔。

### I.4 功率器件谱系与「谁替代谁」（书 p3–7）

书给出两条并行不悖的发展路线（OCR「并行不的」→「并行不悖」）：

- **电力领域**：超大功率晶闸管、IGCT → 高电压、大电流方向；
- **电子领域**：电源管理 → 集成化、智能化、高频、高精度方向。

器件分类维度（书 p4–6 整理）：

| 维度 | 类别 | 代表 |
|---|---|---|
| 可控程度 | 半控 / 全控 / 不可控 | 晶闸管 / IGBT·GTO·MOSFET / 电力二极管 |
| 驱动性质 | 电压驱动 / 电流驱动 | IGBT·MOSFET / GTR·晶闸管 |
| 载流子 | 双极 / 单极 / 复合 | 晶闸管·GTR / MOSFET / IGBT·MCT |

> **关键判断（书 p6 图 1-3）**：传统硅基器件按应用频率分层——晶闸管/GTO 在低频大功率，IGBT/IPM 在中频（约 10²–10⁴ Hz 量级，图标注 10²/10³/10⁴/10⁶ 四档），MOSFET 在高频（10⁶ 量级）。**IGBT 卡在「中频 + 中大电流」的甜区**，这正是本技能反复处理的对象。

### I.5 宽禁带材料的量级（书 p7，与 Baliga `55`/`72` 互补）

- **第三代宽禁带定义**：禁带宽度 ≥ **2.3 eV**；代表 SiC、GaN。
- **SiC vs GaN 分工**：GaN 偏 **1000 V 以下**高频小功率；SiC 适用 **1200 V 以上**高温大电力。
- **SiC 成本墙（书 p7）**：单片成本比 Si 高 **7~8 倍**——与 Baliga `72` 的「5.9 倍 \$/A」同源但口径不同（书 p7 是「单片成本」，Baliga 是「单位电流成本」），见 §B 与跨源并列 P6。
- **SiC 热导率 > GaN 三倍以上**（书 p7），高温应用更有优势。

## A1 · 案例：用 IGBT 改写逆变焊机（书 p3）

书给的具象案例：逆变焊机原来要**两个人才能拿动**，采用 IGBT + 变频技术后，**体积只有书包大小、重量仅几公斤**，性能/效率/可靠性同时质的飞跃。

→ 这是「一代新器件带动一代新装置」的具体注脚：IGBT 把「功率 + 体积」的矛盾解开了。本技能 `61`（运输应用）、`67`（可再生能源）里反复出现的「器件 → 装置」链路，根就在这里。

## A2 · 本地复算

**A2.1 晶闸管 vs IGBT 的频率分层对照（书 p6 图 1-3）**

图 1-3 标注的开关频率量级：晶闸管/GTO 约 10² Hz，IGBT/IPM 约 10³–10⁴ Hz，MOSFET 约 10⁶ Hz。这与本技能已有判据一致：

- Baliga `61` 运输应用中「母线电压 → 额定电压」对照表，IGBT 主战场是 kHz 级中频；
- Volke 层开关损耗模型（1/π = 0.3183 系数）正对应这个中频 VSI 场景。

**A2.2 SiC 成本 7~8 倍 vs Baliga 5.9 倍（口径对账）**

| 来源 | 倍数 | 口径 |
|---|---|---|
| 封装书 p7 | **7~8 倍** | 单片（wafer）成本 |
| Baliga `72` | **5.9 倍 \$/A** | 单位电流成本（面积赢 2.06 × 单价输 12.18） |

→ 两者不冲突：SiC 芯片面积更小（书 p7 也承认「大幅缩小芯片尺寸」），所以「单片成本 7~8 倍」经面积折算后落到「每安培 5.9 倍」。**引用时按口径二选一，不许折中**（见本层 00-index §6.3，登记待蒸馏回填）。

## S · 步骤

## B · 边界

- **本模块不教任何工艺窗口**（划片/装片/键合参数都不在此）。需要工艺 → `74`–`77`。
- **本模块不负责芯片物理**（元胞、SOA、BFOM → Baliga `51`/`55`/`56`）。
- **「7~8 倍成本」与「5.9 倍 \$/A」是不同的量纲**，混用会错一个数量级（A2.2）。
- OCR 已修的混淆（`ICBT`→`IGBT`、`12OOV`→`1200V`）**只在原始 OCR 文本里出现，正文一律按正确写法**；若回原页图发现仍有歧义，登记 00-index §6.4。
