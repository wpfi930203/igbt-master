# 79 · 失效分析 · 可靠性测试（第4章 书 p117–127）

> 层归属：封装工艺层（packaging / 书源三）。**跨门：4.5 失效分析 → H（失效分析门）；4.6 可靠性 → G（可靠性/寿命门）**。正交参考：volke-hornkamp/15（功率循环与寿命）、baliga/58 `B` 段（模块可靠性边界）、infineon/47（AQG 324 矩阵）。

## R · 原文锚点（书页）
- 4.5.1 方法论（p117–118）：失效机理二分——**过应力（瞬时、灾难性）vs 磨损（长期累积，先退化后失效）**；负载类型——机械/热/电气/辐射/化学；鱼骨图 + **6Ms**（机器/方法/材料/测量/人力/自然力）。
- 4.5.3 封装过程缺陷 10 类（p119–123）：装片空洞 / 键合不良 / 翘曲 / 芯片破裂 / 分层 / 塑封空洞 / 不均匀封装 / 塑封毛边 / 外来颗粒 / 不完全固化。
- 4.5.4 封装体失效（p123–125）：分层（水汽诱导，回流 220℃ ≫ 塑封料 Tg 110~200℃）/ **爆米花（气相诱导裂缝，安全湿气 ≈1100×10⁻⁶=0.11 wt%，125℃ 烘烤 24 h 去湿）** / 脆性断裂 / 韧性断裂 / 疲劳断裂（3 阶段，塑封裂缝扩展速率 ≈ 金属 3 倍）。
- 4.6 可靠性测试（p126–127）：HTSL / HTRB-GB / HTOL / THBT（双 85）/ 温度循环 / PCT / HAST 七项；判据统一为**特性波动 ≤20% 通过、3 批×每批 77 个、0/1 判据**。
- 单位：**`1 psi = 6.895 kPa = 0.0689476 bar`**；**`1 Torr = 133.322 Pa`**（塑封空洞真空压力范围 1~300 Torr）。

## I · 骨架（失效→可靠性闭环）
| 层级 | 关键判据 | 量级/阈值 |
|---|---|---|
| 装片空洞（非车规） | 总面积 ≤10%、单个 ≤5% | 超界→`RDS(ON)` 超标、`ΔVDs` 大、热聚集 |
| 键合不同极性间距 | ≥400 μm **或** ≥1 倍线径 | 短于→击穿短路风险 |
| 塑封空洞 | 真空压力 1~300 Torr 减少 | 排空/抽真空最小化空气量 |
| 爆米花安全湿气 | ≤0.11 wt% | 125℃ 烘烤 24 h 去除 |
| 可靠性波动判据 | ≤20% 且 0/1 | 3 批×77 个 |

## A1 · 案例（装片空洞与爆米花）
- 装片空洞：非车规级总面积 ≤10%、单个 ≤5%（书 p119）。空洞→导热不充分→热聚集点→功率循环裂纹→电特性不良，形成可靠性链式失效。
- 爆米花：回流焊 220℃ ≫ 塑封料 Tg（110~200℃），界面水汽蒸发成蒸汽压 + CTE 失配 + 吸湿膨胀（CME）共同致分层/破裂；QFP/TQFP 大而薄者最易发；安全湿气 ≈0.11 wt%，125℃/24 h 烘烤可充分去湿（书 p124）。

## A2 · 本地复算（单位与判据自洽）
1. **`1 psi = 6.895 kPa`**：15 psi（PCT 压力锅）= 15×6.895 ≈ 103.4 kPa ≈ 1 atm ✓（标准大气压 101.3 kPa，量级吻合）；19.5 psi（HAST）= 134.4 kPa，与“最严苛”定性一致 ✓。
2. **`1 Torr = 133.322 Pa`**：300 Torr ≈ 40 kPa（塑封真空上限）；1 Torr ≈ 133 Pa（近真空）✓。两单位体系与 volke 层真空灌胶/烧结气压单位需统一换算。
3. **可靠性波动 ≤20%**：七项测试统一判据（HTSL/HTRB/HTOL/THBT/温度循环/PCT/HAST），样本 3×77、0/1 判据——这是“统计接收”而非“物理阈值”，作方向性结论。
4. **温度循环两档**：`-65~150℃`（200/500 次）与 `-55~150℃`（500/1000 次）——与 volke 层功率循环（PC）是不同应力（温度循环无通电、PC 有通断），**不可混淆**（登记 §6.3 同一事实两数/口径差异）。

## E · 触发场景
- 回流焊后外观难查的裂缝、键合球断裂/硅凹坑 → 爆米花（先查湿气含量与烘烤）。
- 封装后 `RDS(ON)` 超标、热聚集 → 装片空洞（X-ray 扫描，查总面积/单个是否超限）。
- 车规项目可靠性 → 除 1000 h 电特性外，结合 **DPA（破坏性物理分析）** 解剖结构。
- SMD 器件正式可靠性前需 **Pre-Condition**（室温加湿 + 温度循环 + 3 次回流模拟）。
- 小间距/大电流引脚 → **晶须测试（Whisker Test）** 评估短路风险（3 个月以上烘箱）。

## S · 步骤（失效分析）
1. 电特性判定良/不良 → 2. 无损检查（X-ray/3D-CT/S-scan/T-scan 超声）→ 3. 有损检查（去塑封、显微镜、FIB、热点成像）→ 4. 鱼骨图/6Ms 归因 → 5. 提预防措施。

## B · 边界
- 本书 4.6 是**封装级**可靠性（HTSL/HTRB/THBT/PCT/HAST 等环境应力）；**功率循环（PC）、栅偏老化等器件级寿命见 volke/15 与 baliga/58**，不在此覆盖。
- 温度循环（无通电）≠ 功率循环（有通断），二者寿命模型不同——跨源并列，登记 §6.3。
- “`1685001000h`” 为 OCR 对 “168/500/1000 h” 的误拼，正文已还原为分档时长。
