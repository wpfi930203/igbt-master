# `74` 晶圆划片（Wafer Dicing）

> **书源层 · 封装。** 引用须标「据封装 `74`（书 pXX）」。
> **本模块是封装工艺链的第 1 道切割工序**，接在 `73` 的框架之后，下游是 `75` 装片。
> **两句话摘要**：① 划片 = 把晶圆分离成独立芯片；**金刚刀片切割**与**激光切割**是两条主线，前者有崩边风险、后者槽宽细且无崩片隐裂。② **贴膜（UV 膜/蓝膜）的剥离强度是划片良率的隐藏控制点**——黏度太强顶针取片会崩、太弱会飞片，且胶膜黏度随存储时间增大（书 p22）。
> **文本来源**：扫描版 OCR（书 p20–32）+ 原页图核对；数字（剥离强度、晶圆厚度、Si 材料常数）已逐项回原页确认。

## R · 原文锚点

> 「所谓划片就是把芯片从整张晶圆上分离成一个一个独立的具有特定功能单元的过程。早期的划片是用金刚刀片在显微镜下手工切割分离……所谓自动化设备是指安装了精密对准、对焦功能的机械装置，金刚刀片被设计成圆片安装在高速旋转的轴上。」
> — 书 p21（第 3 章 3.2）

> 「UV 膜提供两个层次的黏结：切割工艺中更强的黏结，之后为了易于剥离……高黏度的 UV 膜，其未经过紫外线照射时黏度很大，剥离强度在 5000 mN/20mm ~ 12000 mN/20mm，但是在紫外线灯光照射的时间延长和照射强度增加之后，剥离强度会降到 1000 mN/20mm 以下。」
> — 书 p22（3.2.2 胶膜选择）

> 「采用激光切割工艺……因为激光的优点很明显，高效率，切割槽宽细小，没有飞渣和毛边毛刺，最重要的是不会有类似机械金刚刀带来的崩片隐裂的风险，后者是半导体封装可靠性的永恒话题。」
> — 书 p24（3.2.3 特殊的胶膜）

## I · 骨架

### I.1 划片全流程（书 p20，图 3-1）

TO 封装基准流程：**划片 → 装片 → 内互联（键合）→ 塑封 → 打印 → 测试 → 切筋 → 电镀 → 老化 → 检验 → 包装**。划片是第一步，本质是「对芯片进行内互联和包封」前的芯片分离。

### I.2 贴膜（Wafer Mounting，书 p21–24）

划片前先把晶圆贴膜固定，**减薄前贴正面、划片前贴背面**。胶膜由三部分组成：塑料基膜 + 压敏黏膜 + 释放膜。

**核心矛盾（书 p22 原话）**：胶膜黏度随存储时间增大，「在长时间存储之后很难从胶膜上取下芯片」；但黏度太弱又会「芯片松动以至造成崩片、飞边」。

| 胶膜 | 剥离强度 | 特性 |
|---|---|---|
| **UV 膜（高黏）** | 未照 UV：**5000–12000 mN/20mm**；照后 **< 1000 mN/20mm** | 黏度可控（照 UV 降黏），稳定；贵 |
| **UV 膜（低黏，如 D-184）** | 未照：**~1000 mN/25mm**；照后 **~100 mN/25mm** | 基层 PVC 80 μm + 丙烯酸胶 10 μm；照后无残胶 |
| **蓝膜（电子级胶带）** | **1000–3000 mN/20mm** | 便宜但**受温度/时间影响变黏、易残胶** |

> **D-184 紫外条件（书 p23）**：照射密度 **230 mW/cm²**、功率 **190 mJ/cm²**、波长 **365 nm**；UV 灯使用超过 **1500 h 应更换**。

**选型规则（书 p23）**：小芯片（< 1 mm）用低黏 UV 膜；大芯片/薄芯片/高价值用 UV 膜（顶针冲击力大，需控黏防爆崩）；大芯片减薄划片用蓝膜（成本低）。

### I.3 晶圆减薄（书 p21）

| 阶段 | 厚度 |
|---|---|
| 研磨前 | **~700 μm** |
| 研磨后 | **200–300 μm**（可至 **50–100 μm**，视客户/应用） |

→ 减薄后翘曲会影响后续精确切割；**先划片后减薄**可避免减薄翘曲带来的划线困难（书 p25）。

### I.4 硅的力学特性（书 p25–26，表 3-1）——划片损伤的物理根

| 量 | 值 |
|---|---|
| 原子量 | 28.085 |
| 原子密度 | **5.00×10²² /cm³** |
| 晶格常数 | 0.5430 nm（金刚石型） |
| 熔点 | **1420 ℃** |
| 热导率（300 K） | **150 W/(m·K)** |
| 密度（固） | 2.329 g/cm³ |
| 摩氏硬度 | 6.5 |
| 熔硅表面张力 | 736 mN/m |

**关键力学结论（书 p26）**：室温下硅**无延展性、属脆性材料**；**温度高于 700 ℃ 才出现热塑性**；**抗拉应力 ≫ 抗剪应力，所以硅片容易碎裂**——这正是划片崩边/隐裂的物理根。表面加工损伤越严重机械性能越差；热氧化 SiO₂ 层可「愈合伤口」提高强度。

### I.5 两种切割路线（书 p24、p27、p28）

| 路线 | 机理 | 优点 | 代价 |
|---|---|---|---|
| **金刚刀片（机械分离）** | 金刚石颗粒 + 黏结材料，高速旋转锯切 | 成熟、性价比高 | **正面崩角/金属分层/背面崩角是永恒话题**（书 p24） |
| **激光切割** | 365 nm 激光，引导水流（Synova 喷水引导） | **槽宽细、无飞渣毛刺、无崩片隐裂**；200/300 mm 晶圆 **50 片/小时** | 会切断普通胶膜 → 需专用 LaserTape（不吸激光） |

**刀片设计三角（书 p28）**：金刚石颗粒大小 / 密度 / 黏结材料软硬，三者无法同时满足正面崩角、分层、背面崩角。经验最优：**较低金刚石密度 + 较软黏结材料**（牺牲刀寿换质量）。

## A1 · 案例：GaAs 与 SiC 的划片挑战（书 p22、p27）

- **GaAs** 比硅更脆 → 用昂贵的 UV 膜而非蓝膜（书 p22）。
- **SiC** 等第三代宽禁带 → 激光划线/划片成为可行选择（书 p27），且 SiC 切割常推荐**无胶膜系统**（真空卡盘 + 橡胶固定，书 p25）。

→ 这是本书与 Baliga `55`（SiC 器件物理）和本层 `84`（宽禁带封装）的工艺接口：材料越脆/越硬，划片越要换路线。

## A2 · 本地复算

**A2.1 剥离强度单位换算校验**

书给 UV 膜用 `mN/20mm`、D-184 用 `mN/25mm`，单位不一致。统一为 `N/20mm`：
- D-184 未照：1100 mN/25mm = **0.88 N/20mm**（×20/25）；照后 70 mN/25mm = **0.056 N/20mm**。
- 高黏 UV 膜未照上限 12000 mN/20mm = **12 N/20mm**；照后 < 1000 mN/20mm = **< 1 N/20mm**。
→ 照 UV 前后黏度可降 **1~2 个数量级**，这正是「切割时强黏、拾片时弱黏」的物理实现。**单位换算后量级自洽，无矛盾。**

**A2.2 Si 热导率 150 W/(m·K) 与本技能其它层的对照**

`73 · I.5` 提到「SiC 热导率 > GaN 三倍」；本表 Si 热导率 150 W/(m·K) 是后续 `80`（封装散热）里「芯片→散热器」链路的起点（SiC 模块热导率更高，散热余量更大）。

## S · 步骤

1. 减薄前贴正面膜、划片前贴背面膜（I.2）；
2. 选膜：小芯片低黏 UV、大/薄/贵芯片 UV、大芯片蓝膜（I.2 规则）；
3. 划片：刀片路线控金刚石密度/黏结软硬，或激光路线配 LaserTape（I.5）；
4. 照 UV 降黏 → 顶针拾片（注意灯时 < 1500 h、密度 230 mW/cm²）；
5. 清洗烘干防异物。

## B · 边界

- **本模块只到「分离成芯片」，不含装片/键合/塑封**——下游见 `75`/`76`/`77`。
- **剥离强度的具体数值是书给的量级**，不同厂商膜型号差异大；引用时标「据封装 `74`（书 p22）」，**不要当成本公司内部规范**。
- **激光切割会切断普通胶膜**——这是书明确警告，不能忽视（I.5）。
- OCR 混淆 `12OOV`/`ICBT` 等不在本模块出现；若出现 `硅的抗拉应力远大于抗剪应力` 被误读，回原页图（书 p26）。

## 与其它模块的接口

- → `75` 装片：划片后顶针拾片直接进装片工序；膜的黏度管控是划片↔装片的衔接点。
- → `73` 定义：划片是 TO 封装基准流程的第 1 步。
- → `84` 宽禁带封装：SiC/GaAs 划片的路线切换（A1）。
- → Baliga `55`（SiC 物理）：SiC 硬度高是划片换路线的根因。
