## 4. 三个必背的结构性结论（蒸馏自书，已回填）

1. **功率封装的第一矛盾是散热**，不是电气——所有功率封装的结构设计都围绕「把芯片结温降下来」展开（书 p2、p5 / `73`）。
2. **装片/烧结的空洞率是功率模块可靠性的头号工艺判据**——空洞导致局部热阻飙升、功率循环早期失效（`75`，非车规总面积 ≤10%、单个 ≤5%）。
3. **SiC/GaN 封装的核心不是「能封装」，而是「寄生电感够不够小」**——宽禁带器件的 dv/dt 比硅高一个数量级，寄生回路电感直接决定电压过冲（`84`）；且 SiC 模块若用焊料装片，寿命仅为 Si 基 70%，**必须用银烧结**（`82`/`84`）。

## 6. 引用红线（OCR 与原文边界）

1. **公式与数字一律以原页图为准，不许直接抄 OCR 结果。** OCR 会把 `10⁻⁶` 识别为 `10 6`、把 `0` 与 `O` 混淆（`12OOV` → `1200V`）、把 `/` 误为 `V`（`输入V输出` → `输入/输出`）。凡带上下标/单位的量，**回原页图核对**再写。
2. **图号可以引，图里读数不许引。** 「图 3-12 显示…」可以；「图 3-12 读出 5200 Hz」不行——图上读数 OCR 拿不到。
3. **表格结构丢失。** OCR 只出文本行，行列关系不可信，需要表格时回原页图。
4. **页码一律写「书 pXXX」，同时给 PDF 页**，方便回查：`PDF 页 = 书页 + 16`。
5. **本层不承担芯片内部物理与模块电气行为义务。** 凡涉及元胞结构、SOA 机理、BFOM（转 Baliga），凡涉及驱动保护/寿命模型/认证矩阵（转 Volke），**不要从本层编**。
