# 123 · IEC 60747-15:2024 文字符号与额定值·特性清单（§4–5：符号 / 额定值 / 特性）

> **层归属**：IEC 60747-15:2024 标准层；门：**A**（器件与应力），跨 **C**（热阻体系）/ **B**（机械/绝缘结构）
> **页引用**：用 §N.N 条款号。§4 符号、§5.1 总则、§5.2 额定值、§5.3 特性。
> **R·原文锚点**

## R·原文锚点
- §4 文字符号：电压电流（`IRMS` 端子电流、`Visol` 隔离电压、`Vim`/`Ve` 局部放电起辉/熄灭电压、`lisol` 隔离漏电流）；机械（`Ms` 安装扭矩、`Mt` 端子扭矩、`F` 安装力/拉出力、`a` 加速度、`m` 质量、`es`/`Rzc`/`Rzs` 底板/散热器平面度/粗糙度、`d(c-s)` TIM 厚度）；其他（`Lp` 寄生电感、`Cp` 端子-壳寄生电容、`Tx` 温度、`N_p` 至失效功率循环数）。
- §5.1 总则：孤立功率器件应标明为**壳额定（case rated）**或**散热器额定（heat sink rated）**；额定/特性在 25 °C 或约定温度下给出。
- §5.2 额定值（极限值）：`Visol`（§5.2.1，主端子/高压控制端 ↔ 底板，指定时间 RMS/DC 最大值）、**peak case non-rupture current**（§5.2.2）、`IRMS`（§5.2.3，最小安装扭矩 Mt + 最大端子温 Ttmax 下）、温度（§5.2.4 `Tsold`/`Tstg`）、机械额定（§5.2.5 `Ms`/`Mt`/`F`/拉出力/加速度/`es`/`Rzs`）、气候额定（§5.2.6）。
- §5.3 特性：机械（§5.3.1 `ds` 爬电距离/`da` 电气间隙/`m`/平面度）、`Lp` 寄生电感（§5.3.2）、`Cp` 寄生电容（§5.3.3）、`Vim`/`Ve` 隔离电压（§5.3.4/5.3.5）、**热阻体系（§5.3.6）**：`Rth(j-c)x`（结-壳，per switch X=D/T/I/M/B）、`Rth(c-s)`（壳-散热器）、`Rth(c-s)x`（per switch）、`Rth(j-s)x`（结-散热器，散热器额定）、`Rth(j-r)`（结-传感器）；**瞬态热阻抗 `Zth`（§5.3.7）**。

## I·骨架
1. **热阻完整链（本标准核心贡献）**：此前封装层/应用层多只到 `Rth(j-c)`；本标准补齐 **c-s（壳-散热器，由 TIM+安装决定）** 与 **j-s（结-散热器，散热器额定器件）**、**j-r（结-传感器）**，并规定 `Zth` 须以 Foster/Cauer 阶梯或曲线给出。
2. **隔离电压 Visol**：孤立器件核心安全额定，定义明确「主端子+高压控制端 对 底板」的 RMS/DC 最大值+指定时间；配套 `lisol`（漏电流）与局部放电 `Vim`/`Ve`（§5.3.4/5）。
3. **机械额定闭环**：安装扭矩 `Ms`（壳-散热器）/ `Mt`（端子）、散热器平面度 `es`、粗糙度 `Rzs`、TIM 厚度 `d(c-s)`——这些共同决定 `Rth(c-s)`（见 124 公式(3)）。
4. **寄生参数 Lp/Cp**：`Lp` 主端子间寄生电感（开关振荡/dv/dt 源头）、`Cp` 主端子-壳寄生电容（共模噪声/ dv/dt 容性耦合），进 D 门驱动保护与 E 门 EMI。

## A1·案例
某 IGBT 模块标 `Rth(j-c)=0.12 K/W`，系统散热仿真却需要「结到散热器」。→ 本标准 §5.3.6.2/6.3 给出 `Rth(c-s)`（壳-散热器，由 TIM+安装决定，典型含 TIM 0.03–0.05 K/W + 接触），总 `Rth(j-s)=Rth(j-c)+Rth(c-s)`；若直接把 `Rth(j-c)` 当系统热阻会低估 ΔT、过设计或反之过热。

## A2·本地复算
- `Rth(j-s)x = Rth(j-c)x + Rth(c-s)x`（壳额定器件，X=IGBT 时 I）。`Rth(c-s)` 公式(3) `=(Tcx−Tsx)/Px`，依赖 TIM 导热 λ 与厚度 d：`Rth(c-s) ≈ d/(λ·A) + R_contact`。§6.2.4.3 指定条件含 λ、参考点、安装扭矩——说明该值非器件固有，随安装变。
- 隔离电压与局部放电：`Vim`（起辉）>`Ve`（熄灭），验收以 `Visol` 耐压 + `lisol`<上限 + 可选 `Vim`/`Ve` 为组合判据（见 125 Table 2）。

## E·触发场景
- 模块热设计/系统散热仿真取 `Rth(c-s)`/`Rth(j-s)`/`Zth` 时进 §5.3.6/5.3.7（与封装层 79 热阻协作）。
- 绝缘设计/安规（爬电 `ds`、间隙 `da`、CTI）进 §5.3.1 + IEC 60664-1/60112。
- 寄生参数影响开关振荡（Lp）、共模噪声（Cp）进 §5.3.2/5.3.3 + D 门。

## S·步骤
1. 判器件类型（壳额定/散热器额定）→ 取对应热阻项。
2. 列 §5.2 额定值（Visol/壳不破裂/IRMS/机械/温度/气候）。
3. 列 §5.3 特性（机械/寄生/隔离/热阻/Zth）。
4. 与封装层、AQG 层对照，凡本标准特有项（Rth(c-s)/j-s/j-r、Visol、壳不破裂）标注出处。

## B·边界
- `Rth(c-s)`/`Rth(j-s)` 依赖安装（TIM、扭矩、平面度），**非器件固有常数**——引用须注明安装条件。
- `Visol` 是安全隔离额定，不是工作电压；局部放电 `Vim`/`Ve` 是附加诊断。
- 机械额定（Ms/Mt/es/Rzs）来自封装/安装标准，本标准引用不另定。
