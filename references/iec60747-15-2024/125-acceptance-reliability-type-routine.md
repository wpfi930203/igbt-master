# 125 · IEC 60747-15:2024 接收与可靠性·型式/例行试验（§7：耐久试验 Table 1–3）

> **层归属**：IEC 60747-15:2024 标准层；门：**G**（可靠性与认证），跨 **B**（绝缘/机械耐久）
> **页引用**：用 §N.N 条款号。§7.1 总则、§7.2 耐久清单（Table 1）、§7.3 接收判据（Table 2）、§7.4 型式/例行（Table 3）。
> **R·原文锚点**

## R·原文锚点
- §7.1 总则：除下列外，非隔离器件（IEC 60747 其他部分）的可靠性要求也适用。
- **§7.2 / Table 1 耐久试验清单**：HTRB（高温反偏，IEC 60749-5）、**H3TRB（高湿高温反偏，IEC 60749-5）**、功率循环（load，IEC 60749-34）、HTS（高温存储，60749-6）、LTS（低温存储，60068-2-1）、TC（温度循环，60749-25）、耐焊热（60749-15）、可焊性（60749-21）、机械冲击（60749-10）、振动（60749-12）。
- **§7.3 / Table 2 接收定义判据**：以 `Visol` < USL（上限规格限）、`lisol` < USL 为隔离接收判据（注：USL=upper specification limit）。
- **§7.4 / Table 3 最小型式与例行试验**：型式试验（type test，标 X 强制，部分破坏性）含隔离电压、壳不破裂电流（Annex A）、外形/爬电/间隙、底板平面度、热阻、Zth、Lp、Cp、局部放电、端子拉出力、温度循环、功率循环、机械冲击/振动、气候额定；例行试验（routine，通常 100% 全检）为所选子集。

## I·骨架
1. **H3TRB 入列（与宏微实测直接呼应）**：本标准 §7.2.2 将 **高湿高温反偏（H3TRB/HV-H3TRB）** 列为标准耐久试验（IEC 60749-5），印证宏微科技「HV-H3TRB 加速试验 1000H 23pcs / 1500H 6pcs / 168H 74pcs 均 PASS、双焊片+高温密封剂」路线的标准合规性——本标准是其方法级出处之一。
2. **接收判据双限**：隔离接收以 `Visol`（耐压值）+ `lisol`（漏电流）双上限为判据，与 §6.1.1 测量法闭环。
3. **型式/例行分级**：Table 3 明确「X=强制型式、例行=100% 或子集」，部分试验破坏性（壳不破裂、功率循环）→ 只能抽样，不能 100% 例行。

## A1·案例
宏微某 IGBT 模块做 HV-H3TRB 1000H：本标准 §7.2.2 给出 H3TRB 属标准耐久项（IEC 60749-5 方法），试验后接收以 Table 2 的 `Visol`/`lisol` + 其他参数漂移判据为准。报告应引「IEC 60747-15:2024 §7.2.2 + IEC 60749-5」而非仅内部经验，提升客户（尤其客户端高管可追溯性方案）可信度。

## A2·本地复算
- 接收判据数字化：`Visol(实测) ≥ 规格标称` 且 `lisol ≤ USL`（注意是「耐压不降 + 漏电流不超上限」双条件）。若仅耐压通过但 lisol 超 USL，仍判废（绝缘退化早期征兆）。
- 型式试验破坏性项（壳不破裂 Annex A、功率循环 60749-34）的样本量由详细规范定，不属 100% 例行（Table 3 注）。

## E·触发场景
- 模块可靠性鉴定（qualification）方案制定进 §7.2（耐久清单）+ §7.3（接收判据）。
- 来料/出货绝缘抽检进 §7.3（Visol/lisol）+ §7.4（例行试验子集）。
- HV-H3TRB 路线合规论证进 §7.2.2（与宏微实测数据联动）。

## S·步骤
1. 按 §7.2 Table 1 列耐久试验（必含 H3TRB、功率循环、TC/HTS/LTS、机械冲击/振动）。
2. 试验后按 §7.3 Table 2 判：隔离 `Visol`/`lisol` < USL，其他参数漂移在各自规格内。
3. 按 §7.4 Table 3 划分型式（X 强制，部分破坏性抽样）/例行（100% 或子集）。
4. 出鉴定报告，标注「IEC 60747-15:2024 §7」+ 对应 IEC 60749-x 方法标准。

## B·边界
- 本标准耐久清单**引用** IEC 60749-x 方法，不重复方法细节（需要时转相应 60749 标准）。
- 通过线/漂移限值「由详细规范给出」（同国标层 C2 红线），标准只给判据方向。
- 模块资格（模组级）仍优先 AQG 324 层；本标准管「孤立功率器件」级。

## 接口
- 上游：124（测量法，Visol/lisol 实测手段）。
- 跨层：AQG 层 101–109（模组资格，本标准为单器件级）、国标层 114（单管接收 §7，IDT 2007）、封装层 B 门（功率循环互连可靠性，IEC 60749-34）、门 H（H3TRB/功率循环失效机理）、宏微 HV-H3TRB 实测（1000H/1500H/168H 数据）。
