# 124 · IEC 60747-15:2024 试验与测量方法（§6：隔离电压验证 / 局部放电 / 寄生参数 / 热特性公式(2)–(7)）

## R·原文锚点
- **§6.1.1 隔离电压验证 `Visol`**：所有主端子+高压控制端短接 → 高电位端 H，底板接地 E；电压源 G（高内阻限流）缓慢升至规定值并保持规定时间，电流表 A 测 `lisol` 漏电流不得超过规定值（高压测试仪「hipot」原理，Figure 1）。
- **§6.1.2 温度传感器-端子隔离 `Visol1`**：当温度传感器连到底板电位时，验证其与其它端子的隔离电压（可约定较低 `Visol1`）。
- §6.2.1 局部放电起辉/熄灭电压 `Vim`/`Ve`：主端子-底板间，按 IEC 60270 / IEC 60664-1。
- §6.2.2 **寄生电感 `Lp`**：Figure 3/4 电路，DUT 插入、栅短接，用二极管关断 di/dt 在外部主端子感应电压阶跃 `Vstep`，`Lp = Vstep / (di/dt)`（式(1)）；要求低感母线+低感电流探头。
- §6.2.3 **寄生电容 `Cp`**：电容表 CM，器件按厂规装到接地散热器，指定端子接 I1、底板（I2）接地，读 C（Figure 5）。
- **§6.2.4 热特性（核心公式）**：
  - (2) `Rth(j-c)x = (Tvix − Tcx)/Px`
  - (3) `Rth(c-s)x = (Tcx − Tsx)/Px`
  - (4) `Rth(j-s)x = (Tvix − Tsx)/Px`
  - (5) `Zth(j-c)x = [Tvix(0)−Tcx(0)] − [Tvix(t)−Tcx(t)] / Px`
  - (6) `Zth(c-s)x = [Tcx(0)−Tsx(0)] − [Tcx(t)−Tsx(t)] / Px`
  - (7) `Zth(j-s)x = [Tvix(0)−Tsx(0)] − [Tvix(t)−Tsx(t)] / Px`
  - 其中 X=D/T/I/M/B（二极管/晶闸管/IGBT/MOSFET/BJT）；参考点 Tc（芯片下壳温，可钻孔或 sack hole 在热沉下 2(+1)mm 取）、Ts（散热器参考点）；依赖 TIM 导热、安装扭矩、平面度（§6.2.4.3 指定条件）。

## I·骨架
1. **Hipot 隔离验证**：`Visol` 测法即工业「耐压+漏电流」双判据——电压缓升保时 + `lisol`<上限；这是模块绝缘来料检验/出厂试验的规范母法（与宏微 HV-H3TRB 的绝缘验证呼应）。
2. **热阻三公式链**：本标准明确区分 `j-c`（芯片固有）、`c-s`（TIM+接触，随安装变）、`j-s`（系统级），并各给稳态 `Rth` 与瞬态 `Zth`；与封装层 `Rth(j-c)`、JESD51 结构函数形成互补。
3. **寄生参数直接测法**：`Lp` 用 di/dt 电压阶跃法（非 LCR 直接）、`Cp` 用接地安装电容表法——给出可复现的 DUT 级测量电路。

## A1·案例
模块出厂绝缘检验只做「耐压 2500V 不击穿」。→ 本标准 §6.1.1 要求**同时测 `lisol` 漏电流**且不得超过上限（仅「不击穿」不够，微安级漏电也可能预示绝缘退化）；若只判击穿会漏掉早期绝缘劣化。

## A2·本地复算
- `Rth(j-s) = Rth(j-c) + Rth(c-s)`，量化：IGBT `Rth(j-c)=0.12` + `Rth(c-s)=0.04`（TIM 0.04 K/W 量级）= 0.16 K/W；`Zth` 用阶梯（Foster）或曲线，瞬态峰值比稳态高（取决于功率脉冲宽度）。
- `Lp = Vstep/(di/dt)`：若 di/dt=1000 A/μs、Vstep=10 V → Lp=10 nH；该值决定关断电压过冲 `V_overshoot ≈ Lp·di/dt`，进 D 门栅保护/RCD 设计。

## E·触发场景
- 模块绝缘检验/安规验证进 §6.1（Visol + lisol）。
- 系统热仿真取 `Rth(c-s)`/`Rth(j-s)`/`Zth` 进 §6.2.4 + 封装层 79。
- 开关振荡/EMI 分析取 `Lp`/`Cp` 进 §6.2.2/6.2.3 + D 门。

## S·步骤
1. 隔离验证：短接主端子+高压控制端→H，底板→E，缓升电压保时，测 lisol<上限（§6.1.1）。
2. 寄生 Lp：搭 Figure 3 电路，di/dt 法取 Vstep 算 Lp（式1）。
3. 寄生 Cp：接地安装，电容表测（§6.2.3）。
4. 热阻：按 §6.2.4 取 Tc/Ts 参考点，用公式(2)–(4) 算 Rth，公式(5)–(7) 算 Zth。

## B·边界
- `Rth(c-s)` 公式含 TIM/安装依赖，**同一器件不同安装结果不同**——报告须附安装条件。
- `Visol` 耐压时间通常 ≥60 s（§6.1.1 指定条件），短时（<60 s）须注明（对应生产线 100% 例行可能缩短，见 125 Table 3 注）。
- 局部放电 `Vim`/`Ve` 为附加诊断，非所有器件强制（§5.3.4/5 标注 where appropriate）。
