# 89 · 功率器件工艺：晶圆、边缘终端与寿命控制（第4章 书 p103–131）

> 层归属：Lutz 层。**落门：A（器件与应力门，兼跨 B 工艺视角）**。⭐ 本模块填补 skill 空白：**边缘终端（负/正斜角、场限环、JTE、电场板）与复合中心工艺（Au/Pt/辐照）**在此前书源中无系统覆盖。正交参考：封装层 74（划片）、baliga/54（终端相关）、lutz/90（CAL 二极管为寿命控制的应用端）。

## R · 原文锚点（书页）
- **NTD 中子嬗变掺杂**（p105–106）：`³⁰Si(n,γ)→³¹Si→(β,2.6 h)→³¹P`；热中子在 Si 中衰减长度 **19 cm**；棒旋转后径向不均匀 **<4%**（15 cm 棒）；**N_phos=c·Φ·t，c=2.0×10⁻⁴ cm⁻¹**（天然 Si，[Jan76]）；Φ=10¹³~10¹⁴ cm⁻²s⁻¹，例：2×10¹³×3.5 h→**5×10¹³ cm⁻³，精度 ±3%**。放射性衰减等待 **3~5 天**（次级 ³¹P(n,γ)³²P→³²S 半衰期 14.3 d，磷浓度高时延长）；晶格缺陷 **800℃ 退火**。FZ 200 mm 晶片掺杂偏差已改进到 **±12%** [SIL06]，但 NTD 仍不可替代。
- **外延**（p106–107）：SiCl₄/H₂ 1150~1220℃、SiHCl₃ 1100~1175℃、SiH₂Cl₂ 1025~1100℃、SiH₄ 1150~1220℃（H₂ 载气）；衬底 HCl 气相腐蚀 1140~1240℃；n 掺 PH₃ / p 掺 B₂H₆。CZ 衬底用于外延（IC 与部分 MOSFET）；功率器件主流是 FZ（高阻、无氧碳）。
- **边缘终端·斜角类**（4.7.1，p118–120）：
  - **负斜角**（p⁺ 面磨角，图 4-16）：表面等位线压缩 → **雪崩中心**落在表面下方结区，**达不到 100% 体内击穿**；两负斜角组合用于双向阻断（晶闸管）。
  - **正斜角**（图 4-17）：等位线在表面展宽、无雪崩中心 → **可达 100% 体内击穿**；α 可取 **30°~80°**。
  - **腐蚀轮廓**（图 4-18）：n⁺ 侧腐蚀、正斜角等效；对表面电荷不敏感，硅胶钝化即可；但阳极锐角机械脆弱 → **不适合浅结现代器件**。
- **平面结终端**（4.7.2，p120–122）：**悬浮场限环**（[Kao67]，与 p 阳极一次掩模成形，使用最频繁）；**JTE/VLD**（横向递减掺杂，掩模窗口缝隙扩散，掺杂向边缘递减 [Scu89]——对表面电荷不敏感但掺杂窗口窄）；**电场板**（金属延伸覆盖钝化层，一阶/多台阶，图 4-21）。**经济约束：边缘终端面积不导通，应尽量小；边缘是功率器件的薄弱点**。
- **寿命控制·扩散型**（4.9.1，p123–125）：Au（[Far65]）与 Pt（[Mi76]，70 年代中期替代 Au）；间隙式扩散极快（**850℃/10 min 即穿透晶片**）、分布难控、批次分散大。
  - **Au**：能级近禁带中部 → 漏电流大； behaves 像降低本底掺杂 [Mi176,Nor89] → 开通电压峰 **V_FRM 可达无中心器件的数倍**（式 5-66 关联）；正-反向折中差。
  - **Pt**：无近禁带中部能级 → **漏电流几乎与无中心器件无异 → 结温上限可 150/175℃ 甚至 200℃**；但 V_on–Q_rr 折中比 Au 差；Q_rr 随温度剧增；高掺杂 p 发射极的 Pt 快恢复二极管呈**负的 V_on 温度系数**。
- **寿命控制·辐照型**（4.9.2，p125–126）：**高能电子辐照**（70 年代起）：均匀分布、剂量精确可调、**可在工艺末段（合金化/钝化之后）进行**；缺点分布恒定不利开关特性。**质子/氦离子注入**：高概率碰撞在离子径迹末端 → **局域复合中心，深度由离子能量调节**（CAL 二极管基础，见 90）。辐照后必须退火：压接式封装器件 **220℃**（后续无更高温度）；要焊接的器件 **340~350℃**（保证焊后续热不需再退火）。深能级标识（DLTS，图 4-25）：**OV 中心主导高注入寿命**；V 类中心决定产生寿命/漏电流（作用弱于 Au）。

## A2 · 本地复算（NTD 数值验证）
1. **N=c·Φ·t**：2.0×10⁻⁴ cm⁻¹×2×10¹³ cm⁻²s⁻¹×3.5×3600 s=2.0e-4·2e13·1.26e4=**5.04×10¹³ cm⁻³** ✓（书给 5×10¹³）。
2. **量级合理性**：5×10¹³ cm⁻³ ≈ ρ≈90 Ω·cm n-Si，对应 >5 kV 级 FZ 高阻基区 ✓（与 88 的 V_B-N_D 配准式量级衔接）。
3. **径向均匀性**：衰减长度 19 cm ≫ 棒径 10~15 cm + 旋转 → <4% 成立 ✓。
4. **Pt vs Au 结温上限逻辑**：漏电流 ~exp(−E_t/kT)，Au E_t≈E_i/2 → 高温漏电爆炸；Pt 深能级远离中部 → 可 175℃ ✓（与封装层 80 的 175℃(硅) 呼应）。

## E · 触发场景
- 「快恢复二极管漏电流超标/高温失效」→ 先查复合中心类型（Au？）→ 换 Pt 或电子辐照。
- 「器件耐压始终到不了体内值」→ 查边缘终端形态（负斜角=雪崩中心；正斜角/场限环/JTE 依电压等级与成本选择）。
- 「开通电压尖峰 V_FRM 异常大」→ Au 扩散器件的本底掺杂等效降低效应。
- 「需要局部寿命控制（如 CAL 阳极侧）」→ 质子/氦注入，深度=能量函数。
- 「辐照后器件特性漂移」→ 退火不足：压接 220℃/焊接 340~350℃。
- 「超高压器件基区电阻的均匀性」→ NTD ±3% vs FZ ±12%。

## S · 步骤（寿命控制工艺选型）
1. 定目标折中（V_on vs Q_rr vs 漏电流/结温）→ 2. 高结温/低漏电 → Pt 或辐照；低成本 → 电子辐照 → 3. 需要局域寿命分布 → 质子/He 注入 → 4. 按封装定退火温度 → 5. DLTS/电特性验证深能级谱。

## B · 边界
- 边缘终端定量设计（环间距/JTE 掺杂窗口）本书只给定性原理，具体数值设计需仿真。
- Au/Pt 扩散分布不可控是本质缺点——新品设计应首选辐照工艺。
- 电子辐照均匀分布对「开关特性局部优化」无效（对比质子注入）。
