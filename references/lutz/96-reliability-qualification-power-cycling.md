# 96 · 可靠性合格试验与功率循环寿命（第11章 书 p312–343）

> 层归属：Lutz 层。**落门：G（可靠性/寿命门，兼 B）**。⭐⭐ 本层 G 门核心——功率循环/温度循环失效物理与寿命模型。正交参考：封装层 79/83（环境应力试验、AQG324）、volke/15（寿命模型）、lutz/95（被试结构）。

## R · 原文锚点（书页）
- **试验体系**（11.6，p312–315，表 11-6）：三组——芯片相关合格试验 / 封装稳定性 7 项 / 机械完整性 2 项。关键条目（IEC 60747-9:1998 体系）：
  - **PC 功率循环**（内部加热+外部冷却）：0.5<t_cycle<10 s、**ΔT_j=60 K → 130000 周期（T_jmax=125℃）**；IEC 60749-34：**ΔT_j=100 K → 20000 周期**；换流模块（晶闸管/二极管类）10000/25 周期档。
  - **TC 温度循环**（外部加热冷却，2~6 min）：**ΔT_c=80 K、T_cmin=5℃** → 标准 2000 / 中功率 5000 周期；双室气体系统（T_change≤30 s，温度冲击）：100 周期。
  - **振动**（IEC 60068-2-6 Fc）：正弦 5 g、2 h 每方向(x,y,z)；**机械冲击**（IEC 60068-2-27 Ea）：半正弦 **50 g**、每方向 3 次。
  - 现代发展：「高温反偏」100% 额定阻断电压；PC 周期数要求 10000→20000。
- **失效标准**（表 11-7，IEC 60747-9 2001）：**I_CES/I_DRS ≤+100% USL**；**R_DS(on)/V_CE(sat)/V_F ≤+20% IMV**；**V_GS(th)/V_GE(th) +20% USL/−20% LSL**；**R_th(j-c)/(j-s) ≤+20% IMV**；**V_ISOL 不低于规定限**。逻辑：漏电流可放宽（USL 的 100%），**直接影响结温的参数（V_F、R_th）必须紧（20%）**。
- **寿命统计表达**（p323，Weibull）：功率循环失效分布 **Weibull 形状 α=12、尺度 β=69000 周期**；**50%:66930、10%:57200、1%:47030**（同一组实测）。
- **叠加功率循环**（p326–327）：ΔT_j=140 K 大周期叠加小 ΔT 短周期——**大 ΔT 主导失效**；线性疲劳积累假设与实验矛盾：交替双条件试验的失效周期≈两单条件之和（不同损伤机制互不影响 [Scl02b]）[Fer08]。
- **失效机制链**（11.6.7，p327–330）：
  - **键合线剥离**（11.6.7.4）：标准模块 ΔT_j=100 K 下焊线全剥离于 **10791~13000 周期**；剥离发生在焊线体内（非芯片金属化界面）；背面焊线最后失效（电弧闪络焊坑）。改善：**改进键合工艺+银烧结代焊料 → T_high=200℃**（焊接不再主导）[Amr06]；聚酰亚胺涂覆键合线增寿 [Cia01]。
  - **栅线剥离隐蔽性**：场效应栅漏电小，栅线剥离不易察觉 → **冷却相位插入栅极功能测试**（恒流源进电压限制模式）。
  - **金属化重建**（11.6.7.5）：Al CTE **23.5 ppm/K vs Si 2~4 ppm/K** → 周期性压应力 → Al 粒状结构重建 [Pad68]；热循环使界面重构增强 **2~5 倍**（等时退火对照 [San69]）；>175℃ 与 <175℃ 疲劳机制不同（扩散蠕变+位错 vs 压缩疲劳）[Phi71]。
- **寿命模型现状**（p327）：式 11-20/11-22 为纯统计拟合（N=f(ΔT_j,T_low,t_on,I,V,D)），**不同模型参数间无物理联系**；任务剖面计数用**雨流法** [Dow82]（对分辨率不敏感、按应变-应力特性加权）。

## A2 · 本地复算（Weibull 验证）
1. **中位数**：λ·(ln2)^(1/k)=69000×0.693^(1/12)=69000×0.9696≈**66896** ✓（书 66930）。
2. **10% 分位**：69000×(ln(10/9))^(1/12)=69000×0.8272≈**57076** ✓（书 57200）。
3. **1% 分位**：69000×(ln(100/99))^(1/12)=69000×0.6818≈**47044** ✓（书 47030）。三点半径内全部复现 → 形状 12/尺度 69000 可信。
4. **ΔT_j 折算**：130000 周期@ΔT_j=60 K vs 20000@100 K → 指数 ≈ ln(130000/20000)/ln(100/60)≈1.87/0.51≈**3.7**，与 Coffin-Manson 型指数 ~4~5 同量级（疲劳寿命 ∝ ΔT_j^−n）✓。
5. **CTE 失配应力**：Δα≈20 ppm/K × ΔT=100 K → 应变 0.2%/周期量级 → Al 层弹性极限内反复压缩 → 重建机制成立 ✓。

## E · 触发场景
- 「车规/牵引模块寿命验证」→ PC 20000 周期@ΔT_j=100 K 起步 + TC 2000@80 K；失效判据背熟表 11-7。
- 「功率循环测试做到一半 V_CE 漂了」→ 键合线剥离进展（+5%/+20% 趋势图，p322）；栅线剥离要冷却相位栅测才能抓到。
- 「寿命预测给客户」→ Weibull 报 10%/1% 分位（B10 寿命），不用均值；任务剖面用雨流计数。
- 「银烧结值不值」→ T_high 200℃ + 功循环大幅提升（对照封装层 82 表 7-3 >15 万次）。
- 「芯片铝金属化粗糙化/发黑」→ 金属化重建（SEM 可见晶粒重构）。

## S · 步骤（功率循环试验设计）
1. 定 ΔT_j 与 t_cycle（按应用任务剖面）→ 2. 定失效判据（表 11-7）+ 栅极冷却相位功能测试 → 3. 样本≥若干批、记录 V_CE(sat)/R_th 漂移曲线 → 4. 失效解剖（超声/断层）定位机制 → 5. Weibull 拟合报分位寿命 → 6. 与模型（11-20 型）对比，注明统计拟合局限。
