# 94 · IGBT：功能模式、等离子体工程与结构演进（第10章 书 p260–282）

> 层归属：Lutz 层。**落门：A（器件与应力门）**。⭐ 本层 IGBT 主模块。正交参考：baliga/58–60（IGBT 物理与开关）、volke/40–44（厂商实现）、lutz/90–91（续流二极管）、lutz/98（短路/动态雪崩应力）。

## R · 原文锚点（书页）
- **功能模式**（10.1，p260–262）：IGBT=MOSFET 的 n⁺ 漏换成 p 集电极；导通=沟道电子流注入 → 集电结正偏 → 空穴注入低掺杂基区 → **电导率调制**（曾名 COMFET/IGT；发明人 Becke & Wheatley 专利 1980 申请 [Bec80]）。pnpn 四层寄生晶闸管被**高电导发射极短路电阻 R_s 压制**（npn 小电流增益被消除）；**大电流时 npn 可被激活 → 闩锁（latch-up），破坏性**。
- **电流方程**（式 10-1/10-2）：`I_C=I_CE=I_CH/(1−α_pnp)`——**集电极电流总大于沟道电流**；饱和电流亦然（过流能力与短路特性由此）。
- **开关特性**（10.3，p263–266）：感性负载开通承受 FWD 的 I_RRM+Q_RR（式 10-4、5-82~84）。关断：沟道电流断 → 空穴电流流经 p 阱抽载流子 → **空穴电流增大是闩锁窗口，限制了可关断的最大电流**。电压过冲 `ΔV=L_par·di/dt+V_FRM`（式 10-5），**>1700 V 器件 V_FRM 项重要**。**拖尾电流**：NPT 高寿命 t_tail 可达几 μs；t_r、t_f ~100 ns 量级；E_off 简化估算 ∝ I_tail·V_bat·t_tail（式 10-6），实测用示波器乘积积分。关断栅压 −15 V（或 −8 V），对波形影响不大。
- **通态压降三成分**（式 10-15）：`V_C=V_ch+V_drift+V_bi`；**元胞间距折中**：间距↑→「二极管区」占比↑→V_drift↓，但沟道密度↓→V_ch↑；平面栅存在最优间距 [Omu97]。
- **注入增强（IE）原理**（10.6，p270–275）：栅下堆积层+p 阱构成**有效 n 发射极**；γₙ=1−j_p/j（式 10-16/10-17）——**降空穴电流 j_p（减 p 阱面积/大元胞间距）→ γₙ↑ → 发射极侧等离子体↑ → V_drift↓**。实现：IEGT [Kit93]、CSTBT（载流子存储层，[Tai96]，三菱）、HiGT（空穴势垒层，[Mor07]）、英飞凌沟槽栅 FS [Las00]。**沟槽栅与 MOSFET 沟槽栅逻辑相反**：MOSFET 里 R_ch 主导要多沟道并联；IGBT 里 R_ch 次要、等离子体浓度主导 → 沟道只放元胞中部，两侧留非接触区提等离子体（图 10-12/10-13：沟槽栅 FS 的发射极侧分布近似 pin 二极管）。
- **场阻止（FS）**（10.6.4，p275–277）：p 集电层前加 n 缓冲（场阻止/软穿通/轻穿通，各家同名异称）→ 梯形电场（实际近梯形，略偏三角）→ 同耐压下 **W_B 显著缩短，V_drift∝w²（式 10-13）→ V_C 显著降**。**工艺路线：FS 用均匀 n 掺杂晶圆（如 NPT），不像 PT 用 p⁺ 衬底外延**。
- **逆导 RC-IGBT**（10.8，p278–280）：集电极局部 n 层 → 单片集成二极管；灯镇流器首发 [Gri03]，硬开关需优化集成管反向恢复（集电极 n⁺ 作阴极发射极，重掺杂 p 作阳极 → **等离子体阳极高/阴极低，恢复硬**——对比 EMCON3 软分布，需局部寿命控制+MOS 控制二极管原理改善）。**[Rah08]：同面积模块 IGBT 有效面积 +50%、二极管 +200%；二极管分时发热 → 温度纹波缩小 → 模块寿命↑（→96 功率循环）**。
- **逆阻 RB-IGBT**：矩阵变流器用 [Nai04, Tai04]。
- **2010 年水位**（10.9，p280）：商用 **6.5 kV**；1200 V 档 V_C(E) **1.7 V@额定（2007）**，预期 <1.5 V；8~10 kV 在研。

## A2 · 本地复算（自洽性）
1. **I_C/I_CH 放大**：α_pnp 典型 0.4~0.5 → I_C≈(1.7~2)·I_CH ✓（IE 设计把 α_pnp 调低以增饱和裕度）。
2. **FS 省压降**：W_B 缩短 ~30%（对照 90 的 PT/NPT=0.70），V_drift∝w² → 基区分量降 ~50% ✓ 与 2007 年 1.7 V 水位衔接。
3. **拖尾能量量级**：E_off≈I_tail·V_bat·t_tail；I_tail≈0.2·I_C、t_tail≈2 μs、V_bat≈900 V（1200 V 档）→ E_off≈0.36·I_C·mJ/A…与厂商 E_off 数据同量级 ✓。
4. **RC-IGBT 面积账**：同壳内 IGBT+50% → 电流 +50% 名义；但热阻限制 → 实际只能用一部分（书原话）——设计余量核算时勿按 +50% 全额 ✓。

## E · 触发场景
- 「IGBT 饱和电流为什么比同沟道 MOSFET 大」→ 式 10-2 的 1/(1−α_pnp)。
- 「关断大电流炸管/闩锁」→ p 阱空穴电流窗口（10.3）→ 看关断 di/dt 与 R_s 设计。
- 「选 NPT/FS/PT」→ FS=梯形场+均匀晶圆（现代主流）；PT=外延（历史）；NPT=三角场高寿命。
- 「V_CE(sat) 想再降」→ IE/CSTBT/HiGT 等离子体工程路线，不是简单加元胞密度。
- 「>1700 V 过电压预算」→ ΔV 里的 V_FRM 项不可忽略（→91）。
- 「模块同面积提电流」→ RC-IGBT 面积账+温度纹波寿命收益。

## S · 步骤（IGBT 技术代际判读）
1. 看背面：p⁺外延衬底=PT / 均匀晶圆无缓冲=NPT / 均匀晶圆+n 缓冲=FS → 2. 看正面：平面 vs 沟槽；有无 IE 结构（CSTBT/HiGT/IEGT）→ 3. 推等离子体分布（图 10-13 类型）→ 4. 定 V_CE(sat)/E_off 期望区间 → 5. 对照数据手册验证。

## B · 边界
- 2010 年数据（6.5 kV、1.7 V、8~10 kV 在研）为书出版时点；当前水平见厂商层 40–49。
- RC-IGBT 的二极管优化依赖局部寿命控制与沟道注入调制——**不是简单并联**；2010 年初仍是研发主题。
- 拖尾电流终点测量困难（下降极缓）——E_off 以示波器积分为准，勿用 t_tail 估算替代实测。
- 闩锁在关断 di/dt 大时触发——与栅极电阻/驱动设计（D 门）联动。
- OCR 已还原：「类晶闻管」→类晶闸管；式 10-6 前置系数 OCR 缺失（以 ∝ 表述）。
