# 86 · 变流器体系与器件选用图谱（第1章 书 p1–13）

> 层归属：Lutz 层（references/lutz / 书源四）。**落门：E（应用与系统门）**。正交参考：volke-hornkamp/08（应用拓扑）、baliga/61–72（应用组合）、封装层 85（等级温度）。低密度综述章，短模块。

## R · 原文锚点（书页）
- 1.1.1 变流器三要素（p2–3）：**有源器件**（开通/关断能流，只有关断态与导通态，**不许线性区**）/ **无源元件**（磁性/电容储能，频率↑→体积↓）/ **控制单元**（含诊断）。变流器效率 ≈ **95%**；本质是「把连续能量流切割成能量小包再重组」——功率信息处理机。能量交换基本原理：**电容/电压源的能量只能有效转移进电感/电流源**。
- 1.1.2 变流器类型与器件选择（p4–6）：电流源变流器（CSI，直流环节电感，器件需**对称阻断**）vs 电压源变流器（VSI，直流环节电容，器件需**逆导**——反并联二极管续流，不产生附加压降）。VSI 三优势：部分负载效率更高 / 直流电容损耗低于电感 / 感性负载无需附加滤波。**结论：新设计（mVA~GVA）几乎全是 VSI**。电网换相（晶闸管整流）逐步被强迫换相淘汰。PEBB（电力电子组件）= 单模块集成完整相臂。
- 1.2 器件选用六要素（p6）：器件类型与额定值 / 开关频率 / 变流器寄生设计 / 拓扑（两电平·多电平·硬·软开关）/ 控极端换向速率 / 控制策略（滤波器与 EMI）。**热设计是物理极限**（损耗+冷却+最高温度）。
- 封装三档与功率范围（p6）：**分立式 ≤10 kW**（开关电源）/ **模块式至 1 MW**（多芯片并联）/ **压接式双面冷却至几 GW**。
- 应用电压等级锚点（p9–11）：标准击穿电压 **600/1200/1700 V**（覆盖绝大多数电网接口）；牵引直流 **600/1500/3000 V** + 交流 16.7/50 Hz；中压传动 >3 kV 用 GCT 三电平，>15 MW 保留 LCI（晶闸管负载换相）；HVDC 经典 **±500 kV/3 GW → ±800 kV/6 GW**（电流源、点对点）；VSI-HVDC（HVDCLight/Plus）经济区间 **<1 GW**；电解 **200~500 V / >100 kA**（晶闸管整流）；风电单机 50 kW（1985）→ **5 MW（2004）** → 海上预期 10 MW「全变流器」；PV 变流器 **150 W~1 MW**，大部分用 IGBT。
- 器件-频率-电流谱（图1-7，p8）：晶闸管（低频·大电流）→ GTO/GCT → IGBT（中频 1~10 kHz）→ MOSFET（100 kHz 级·低压）。

## I · 骨架（器件选型的系统约束链）
| 约束 | 判据 | 后果 |
|---|---|---|
| VSI 主导 | 感性负载需续流通道 | 器件必须逆导（反并联二极管） |
| 效率 ≈95% | 禁线性区 | 开关模式 + PWM，损耗=E_on+E_off+E_rec |
| 频率 vs 效率 | f↑→无源件↓、开关损耗↑ | 材料成本与效率的平衡点 |
| 功率档位 | 分立 ≤10kW / 模块 ≤1MW / 压接 ~GW | 封装形态由功率决定 |
| 热极限 | 损耗+冷却+T_jmax | 变流器设计的物理边界 |

## A1 · 案例（为什么电压源赢了）
电流源变流器的独特优势是**耐受内部与外部短路**（大功率 10 MVA 以上仍有用 GCT 的场景）；但直流环节大循环电流在部分负载下不减小、电容/电感损耗差、输出需电容补偿——三面皆输。器件厂商据此把资源投向**非对称晶体管**（导通/开关损耗更好折中）+ 集成续流二极管，VSI 成为默认拓扑（书 p5–6）。这解释了 IGBT 模块「IGBT+二极管」共生结构的来历。

## A2 · 本地复算（数字自洽）
1. **HVDC 功率核对**：±500 kV×3 GW → I ≈ 3 GW/(2×500 kV)=3 kA 双极每极 3 kA，量级合理；±800 kV×6 GW → 3.75 kA/极 ✓（同为 ~3–4 kA 级晶闸管阀电流，自洽）。
2. **电解槽**：100 kA×（200~500 V）= 20~50 MW 单槽，与晶闸管整流器容量匹配 ✓。
3. **600/1200/1700 V 序列**：对应 230/400/690 V 电网整流后母线（325/565/975 V）+ 余量，与 volke/61 的母线电压-器件电压映射一致 ✓。
4. **效率 95%** 与 infineon 层模块效率声明一致 ✓。

## E · 触发场景
- 「这个功率等级该选分立、模块还是压接？」→ 10 kW/1 MW/GW 三档边界（p6）。
- 「为什么 IGBT 模块总带反并联二极管？」→ VSI 感性负载续流的必然（p5）。
- 「对称阻断器件还有用吗？」→ CSI 短路耐受优势场景 + >2.5 kV 大功率（p4–5）。
- 选型六要素清单缺项检查（p6）。

## S · 步骤（系统级器件选型）
1. 定拓扑（VSI 默认）→ 2. 定功率档→封装形态 → 3. 定电压等级（600/1200/1700 或牵引/HVDC 序列）→ 4. 定频率（损耗-无源件折中）→ 5. 热设计验证物理极限 → 6. 控制与滤波/EMI 收尾。
