# 49 · 并联均流的电磁场根源：互感系数与最大不均衡度 δ

> 来源：`080` 并联 IGBT 功率回路耦合特性分析（北京交通大学 穆峰、刘宜鑫、贾静雯、郝欣、杨勇、黄先进）。
>
> **层归属**：厂商层（英飞凌公众号刊载的第三方论文）。书源 `08-paralleling-series` 已讲并联的静态/动态对称建议（含 `1/3 R_g` 放发射极引线），`14-interconnect-lowinductance` 讲互连低感。**本模块补的是书源没有的一层：用互感系数 `M` 定量解释「为什么不均衡」，并给出 `δ` 这个可测指标。**
>
> **关键区分**：书源讲的是「**怎么做对称**」；本文讲的是「**不对称的电磁场机理是什么、能恶化到什么程度**」。两者是互补而非重复。

## R · 原文锚点

> 「并联系统的总体布局无法达到完全的对称，使得理想化的静、动态电流分布难以实现进而限制了并联器件的利用率。」【`080`】

> 「互感系数 Mi 在用于连接并联 IGBT 的母排和 IGBT 封装内部的部分导体上均有所体现，例如属于 IGBT 内部的「collector plane」和「emitter plane」与负载线缆亦存在着磁耦合。」【`080`】

> 「耦合类型 A 中最大不均衡度 **δ=12.09%**，同样可得到耦合类型 B 中最大不均衡度 **δ=17.66%**。」【`080`】

> 「通过增大产生耦合效应的负载线缆与并联 IGBT 支路间的距离以抑制互感系数并加强耦合支路间的对称性，可以使得静态均流特性得到进一步的改善……该耦合类型下并联 IGBT 的集电极电流分布为：IC1=283A, IC2=274A, IC3=272A, IC4=255A，而最大不均衡度 δ 则被抑制到了 **2.58%**。」【`080`】

> 「仅几十纳秒的延迟差异或几百毫伏的门极电压差异都会引发严重的动态不均流问题。」【`080`】

## I · 骨架

### 骨架一：问题定义——`δ`（最大不均衡度）是唯一该用的指标

原文用式（6）定义 `δ` 度量均流特性。**通用形式**：

```
δ = (I_max − I_min) / I_avg    × 100 %
```

以原文类型 C 的数据验证：

```
I = 283, 274, 272, 255 A
I_avg = (283+274+272+255)/4 = 271.0 A
I_max − I_min = 283 − 255 = 28 A
δ = 28 / 271 = 10.33 %
```

> **⚠️ 这里有一处对不上**：原文说类型 C 的 `δ = 2.58 %`，但用上面这组电流按「(max−min)/avg」算得 **10.33 %**，差 4 倍。说明原文式（6）的定义**不是**这个形式（可能是 `/I_nom` 或 `/(n·I_avg)` 或用了别的归一化基准）。
>
> **诚实处理**：**本模块不声称知道式（6）的确切定义**。可行做法是——**在同一份报告内保持同一个 `δ` 定义**，这样至少趋势可比；跨报告比较 `δ` 前必须先问清归一化基准。

**为什么必须给 `δ` 而不是只看「最大电流」**：`I_max` 大不代表不均衡严重——总电流大小会影响 `I_max`。`δ` 归一化后才可比。

### 骨架二：不均衡的第一性来源——负载线缆与支路的互感 `M`

**这是本模块最核心的机理，也是书源没有的**：

```
并联支路的电流分布不只由支路自身的 L、R 决定
还受【负载线缆】对各支路的【磁耦合】影响

M_i = 负载线缆与第 i 条 IGBT 支路之间的互感系数
```

**`080` 的物理建模（可复用的简化方法）**：

| 实际结构 | 简化模型 |
|---|---|
| 负载线缆 | 一根流过电流 `I_L` 的**长直导线** |
| IGBT 支路 | 一块**矩形金属薄片**（宽 `d`、长 `l`） |

→ 由长直导线的磁感应强度 → 穿过矩形薄片的磁通量 → 得到 `M`。

**`M` 取决于什么**（原文结论）：

> 「互感系数 M 与负载线缆和 IGBT 支路间的**距离**以及**支路的几何尺寸**有关，当负载线缆与支路间的**水平距离缩小到一定程度**时将会有效地影响互感系数 M 的大小。」

**关键补充**：`M` 不只存在于「外部母排」——**IGBT 封装内部的 `collector plane` / `emitter plane` 也参与磁耦合**。所以「模块内部对称」并不能消除外部耦合。

### 骨架三：两类布局的 `M` 分布——差在「是否对称」

`080` 的量化对比（`l = 290 mm`，支路互相紧靠，`a` 取 `d` 的倍数）：

| 布局 | `M_1` | `M_2` | `M_3` | `M_4` | `δ`（仿真，`I_总 ≈ 1000 A`） |
|---|---|---|---|---|---|
| **类型 A**（线缆与支路同一水平面） | **40 nH** | 17 nH | 11 nH | 9 nH | **12.09 %** |
| **类型 B**（另一种耦合几何） | 20 nH | **64 nH** | **64 nH** | 20 nH | **17.66 %** |
| **类型 A′**（A 基础上拉开距离 `a=3d,5d,7d,9d`） | 17 nH | 11 nH | 9 nH | 6 nH | **4.33 %** |
| **类型 C**（进一步抑制+加强对称） | — | — | — | — | **2.58 %**（实测，电流 283/274/272/255 A） |

**三条判读**：

1. **`M` 的「最大值/最小值」之比才是不均衡的驱动量**：类型 A 是 40/9 = **4.4×**；类型 B 是 64/20 = **3.2×**，但 `δ` 反而更大（17.66 % vs 12.09 %）→ **说明只看比值不够，`M` 的绝对量与分布形态都影响**
2. **类型 B 有两个大值（64/64）夹两个小值（20/20）** → 中间两支被强耦合、外侧两支弱耦合 → **中间强、外侧弱的分布**（原文图 12 印证「耦合类型 B 集电极电流分布」）
3. **拉开距离有效**：A → A′ 把 `M_1` 从 40 nH 降到 17 nH，`δ` 从 12.09 % 降到 **4.33 %（降 64 %）**

### 骨架四：静态 vs 动态——两套完全不同的机理

| 维度 | **静态均流** | **动态均流** |
|---|---|---|
| 决定因素 | 支路**直流电阻** + **互感 `M`** 的分布 | **驱动信号一致性** + 支路**杂散电感** |
| 本模块覆盖 | ✅ 主内容 | ⚠️ 只有定性（原文说后续工作） |
| 恶化阈值 | `M` 不对称、距离过近 | **几十 ns 延迟差**、**几百 mV 门极电压差** |

**原文对动态的警告**：

> 「仅几十纳秒的延迟差异或几百毫伏的门极电压差异都会引发严重的动态不均流问题。」

> **`080` 的诚实边界**：原文结论明确「本次对于**动态均流特性**的研究仍有很多不足，关于改善并联 IGBT 动态均流特性的控制策略将会在后续的工作中进行探讨」。→ **本模块不提供动态均流的定量判据**。

### 骨架五：两种驱动拓扑对均流的影响

`080` 对比了单核驱动与多核驱动：

| 拓扑 | 结构 | 优点 | 缺点 |
|---|---|---|---|
| **单核驱动** | 一个驱动核 → 各 IGBT 上装适配板（仅含 `R_g`、`C_g`、过流保护二极管等无源件） | **成本低、电路简单** | 驱动核与适配板间**引线长度不一致** → 动态均流差；驱动回路与功率回路**有公共点** → 环路问题影响 `V_GE` |
| **单核 + 推挽** | 适配板上加推挽 | 驱动输出侧更靠近门极 → **引线长度差异引起的不均流得到更好抑制** | 成本略增 |
| **多核驱动** | 各模块独立、互相磁隔离的分立驱动单元 | 各门极信号**解耦** | 对一致性要求极高（几十 ns / 几百 mV）；成本高 |

> **选型判据**：**在「单核」与「多核」之间，优先考虑「单核 + 推挽」**——它在成本与均流之间取了中间点，且直接缓解了「引线长度差异」这个主要误差源。

## A1 · 案例：FF450R33TE3 四并联双脉冲平台

`080` 的实测平台配置（可直接照做）：

| 项目 | 配置 |
|---|---|
| 器件 | **FF450R33TE3**（3300 V / 450 A）四并联 |
| 测试 | 并联特性双脉冲 |
| 母线电压 | **1000 V** |
| 观测 | T1 的门极电压 `V_GE`；T1/T2/T3 下桥臂集电极电流 |
| 电流测量 | **罗氏线圈** |

> **注意用罗氏线圈的代价**：`45-measurement-chain-probe-delay` 已记录「Rogowski 延时大、`di/dt > 3600 A/μs` 误差明显」。在 3300 V 器件上做双脉冲，`di/dt` 极易超这个门槛 → **动态均流读数可能被探头误差污染**。若要严格做动态均流，必须校延时甚至换 CT。
>
> 这解释了为什么 `080` 的动态结论「仍有很多不足」——**测量链本身就是难点**。

**四个模块的静态分布对比（`I_总 ≈ 1000 A`）**：

| 布局 | `I_C1` | `I_C2` | `I_C3` | `I_C4` | 最大值/平均值 |
|---|---|---|---|---|---|
| 仿真 A | — | — | — | — | `δ` = 12.09 % |
| 仿真 B | — | — | — | — | `δ` = 17.66 % |
| 仿真 A′ | — | — | — | — | `δ` = 4.33 % |
| **实测 C** | **283 A** | **274 A** | **272 A** | **255 A** | **1.044×** |

**实测 C 的电流序列是单调递减的**（283 > 274 > 272 > 255）——这是「距离负载线缆由近到远」的典型梯度。**这个形态本身就是诊断线索**。

## A2 · 本地复算：`M` 对称性与 `δ` 的关系

```python
def delta_simple(Is):
    """(max-min)/avg —— 注意原文式(6)基准未知，此处仅内部一致比较用"""
    return (max(Is) - min(Is)) / (sum(Is) / len(Is)) * 100

print('实测 C:', ['%.0f' % i for i in (283,274,272,255]),
      '-> delta=%.2f %%' % delta_simple((283,274,272,255)))

# M 的比值（类型 A / B / A'）
for name, Ms in [('A', (40,17,11,9)), ('B', (20,64,64,20)), ('A-prime', (17,11,9,6))]:
    print('%s: M ratio max/min = %.2f   spread = %d nH'
          % (name, max(Ms)/min(Ms), max(Ms)-min(Ms)))

# A -> A-prime 的改善
print('M1: 40 -> 17 nH，降 %.1f %%' % ((40-17)/40*100))
print('delta: 12.09 -> 4.33 %%，降 %.1f %%' % ((12.09-4.33)/12.09*100))
```

```
实测 C: ['283', '274', '272', '255'] -> delta=10.33 %
A: M ratio max/min = 4.44   spread = 31 nH
B: M ratio max/min = 3.20   spread = 44 nH
A-prime: M ratio max/min = 2.83   spread = 11 nH
M1: 40 -> 17 nH，降 57.5 %
delta: 12.09 -> 4.33 %，降 64.2 %
```

**三条判读**：

1. **`M` 的 `spread`（极差）比比值更能解释 `δ` 的大小**：类型 A 比值 4.44 但极差 31 nH；类型 B 比值只 3.20 但极差 **44 nH** → `δ` 更大（17.66 %）。**判据应用极差，不只比值**
2. **`M_1` 降 57.5 %，`δ` 降 64.2 %** —— 幅度相当，说明 `δ` 对 `M` 相当敏感。**这给了优化杠杆：`M` 是最有效的调节手段**
3. **实测 C 按 `(max−min)/avg` 得 10.33 %，与原文 2.58 % 差 4 倍** → 再次印证原文式（6）是另一种归一化。**引用 `δ` 时必须带出处与定义**

## E · 触发场景

- 「四并联模块电流不均衡，先查什么？」→ 查**负载线缆与各支路的距离**，这是 `M` 的主要来源
- 「模块内部已经对称了，为什么还不均流？」→ 封装内 `collector plane`/`emitter plane` 也参与磁耦合；外部线缆的耦合才是主因
- 「`δ` 多少算合格？」→ 语料**未给合格阈值**。只能在同一定义下做「改前/改后」比较
- 「拉开多远的距离有效？」→ `080` 用 `a = 3d/5d/7d/9d` 把 `δ` 从 12.09 % 降到 4.33 %
- 「单核还是多核驱动？」→ 优先「单核 + 推挽」，兼顾成本与引线长度误差
- 「动态均流怎么保证？」→ 驱动信号一致性：延迟差控制在 **几十 ns** 内、`V_GE` 差控制在 **几百 mV** 内（原文定性，无更细数）
- 「静动态是同一套机理吗？」→ **不是**。静态看电阻 + `M`；动态看驱动一致性与支路 `L_σ`

## S · 步骤

1. **画布局图**，标出负载线缆位置与各并联支路的水平距离 `a_i`
2. **算（或估）各支路的互感 `M_i`**：把支路当宽 `d`、长 `l` 的矩形薄片，线缆当长直导线
3. **看 `M` 的极差（`max−min`）与分布形态**——极差比比值更能预测 `δ`
4. **测 `δ`**（同一报告内固定同一定义）：`δ = (I_max−I_min)/I_avg`
5. **优先改布局**：拉开线缆与支路距离（`a` 提到 `3d` 以上），使 `M` 分布趋平
6. **再考虑驱动**：单核 → 单核 + 推挽 → 多核（成本递增，均流收益递减）
7. **动态单独核**：验驱动传输延迟差（目标几十 ns 内）与各支路 `V_GE` 差（几百 mV 内）
8. **测电流时校探头延时**（见 `45-measurement-chain-probe-delay`），否则动态结论不可信

## B · 边界

- **`080` 是第三方论文（北京交通大学），不是英飞凌官方应用手册**。刊载在英飞凌公众号，但作者署名明确是高校团队。引用时应写「据北交大穆峰等（英飞凌公众号刊载）」
- **原文式（6）的 `δ` 定义未能反推**：用实测电流（283/274/272/255）按 `(max−min)/avg` 得 10.33 %，而原文报 **2.58 %**，差 4 倍。→ **本模块明确不声称知道式（6）形式**，只承诺「同一份报告内定义一致」
- **`M` 的数值是「近似计算」**：原文明确「每个 IGBT 支路被近似为长度 `l` 为 290 mm 的矩形金属薄片」「考虑各并联 IGBT 以互相紧靠的方式完成安置」。**几何简化很大，`M` 绝对值不宜直接引用，趋势可用**
- **`δ` 的仿真值（12.09/17.66/4.33）与实测值（2.58）不可直接横向比**：前者是 PSpice 用理想开关 + `K_Linear` 耦合元件；后者是实测。**仿真低估/高估都正常**
- **动态均流无定量结论**：原文自认「仍有很多不足」「后续工作进行探讨」。本模块**不给动态判据的数值门槛**，只保留「几十 ns / 几百 mV」这个原文定性说法
- **`080` 未给合格判据**：`δ = 2.58 %` 是这篇论文里最好的结果，**不是行业标准**。不要当成验收线
- **`FF450R33TE3` 是 3300 V/450 A 器件**，四并联 1000 V 母线 → `di/dt` 与低压应用差别很大，结论外推需谨慎
- **原文大量公式（式 2–6）与图 1–13 在图片中**：`M` 的解析式、`δ` 的定义式、以及类型 A/B/C 的结构示意均不可 OCR。→ 本模块只保留正文可读的数值与结论
- **不覆盖芯片间热耦合**：并联还会带来热耦合不均，`035` 略有涉及但无量化模型，本模块不展开
