# 48 · 手算损耗的分段线性化：把波形按斜率切段，每段取四点

> 来源：`099` 如何手动计算 IGBT 的损耗、`094` 如何评估 IGBT 模块在系统中的损耗（交叉）。
>
> **层归属**：厂商层。书源 `38-loss-closed-form` 给的是**解析闭式**（`E = f(I,V,T)` 与正弦积分、1/π 折算），`worked-examples` 给的是**七段式算例**。本模块补的是第三条路径：**当波形不可用闭式描述时（斜率分段、非线性跌落），怎么从示波器数据手算出 `E_on/E_off/P_cond`**。
>
> **最重要的一条纪律**：本模块**不涉及 1/π 折算**。1/π 是「正弦电流下把单次开关能量折算成平均功率」的因子，属书源 `38` 的职能。本模块算的是**单次事件能量**（焦耳），不是平均功率（瓦）。混用会差 3.14 倍（见记忆里第十轮事故）。

## I · 骨架

### 骨架一：理想波的解析解——先记住这个「1/6」的来历

理想开关波形：`I` 与 `V` 都在 `Δt` 内线性变化，且**一个升一个降**。

```
I(t) = I_C · t/Δt
V(t) = V_CE · (1 − t/Δt)

E = ∫₀^Δt I(t)·V(t) dt
  = I_C·V_CE/Δt² · ∫₀^Δt t(Δt − t) dt
  = I_C·V_CE/Δt² · [Δt·Δt²/2 − Δt³/3]
  = I_C·V_CE·Δt · (1/2 − 1/3)
  = (1/6) · I_C · V_CE · Δt
```

**所以**：

```
E_on,ideal = (1/6) · V_CE · I_C · Δt_on
E_off,ideal = (1/6) · V_CE · I_C · Δt_off
```

> **这个 1/6 是整条方法的地基**。任何一段「电压与电流都线性、且方向相反」的区间，都用 1/6。**若两者同向（都上升）**，则 `∫t·t dt = t³/3` → 系数是 **1/3**，不是 1/6。**这是最容易错的一处**。

### 骨架二：实际波形为什么要分段——`V_CE` 的斜率断成几截

`099` 的核心观察：

> 「Ic 在整个上升过程中还是比较线性的，但是 **Vce 在跌落的时候斜率分成了几段**。」

→ **`I_C` 近似一条直线，`V_CE` 是折线。** 分段边界就取 `V_CE` 折线的**斜率拐点**。

**`099` 的实测分三段**（`I_C ≈ 20 A` 的 IGBT 开通）：

| 段 | 时长 | 电压行为 | 电流行为 |
|---|---|---|---|
| **`Δt1`** | 70 ns | 260 → 220 V（缓降） | 0 → 20.3 A（急升） |
| **`Δt2`** | 40 ns | 220 → 50 V（陡降） | 20.3 → 29.3 A（缓升） |
| **`Δt3`** | 30 ns | ≈ 40 V（近似常数） | 29.3 → 19 A（**回落**） |

**注意 `Δt3` 段电流反而下降**——这是拖尾/振荡段，不是「开通上升」。**照抄 `Δt1` 的公式会算错符号。**

### 骨架三：单段计算方法——四点定两条直线，再积分

**每一段的固定动作**：

```
1. 找 4 个交点：
   A(0, V1), B(Δt, V2)   ← 电压段两端
   C(0, I1), D(Δt, I2)   ← 电流段两端
2. 写两条线性方程：
   V(t) = V1 + (V2 − V1)·t/Δt
   I(t) = I1 + (I2 − I1)·t/Δt
3. 代入 E = ∫₀^Δt V(t)·I(t) dt
```

**展开后的一般式**（`k_v = (V2−V1)/Δt`，`k_i = (I2−I1)/Δt`）：

```
E = V1·I1·Δt
  + (V1·k_i + I1·k_v)·Δt²/2
  + k_v·k_i·Δt³/3
```

**这条通式的三个边界检查**（用来自查）：

| 情形 | 代入后应得 |
|---|---|
| `V1 = V, V2 = 0, I1 = 0, I2 = I`（理想开通） | `E = V·I·Δt·(0 + 1/2·(V·k_i)·Δt... )` → **化简得 1/6·V·I·Δt** ✅ |
| `V` 恒定、`I` 线性上升 | `E = V·(I1+I2)/2·Δt`（梯形面积）✅ |
| `V` 线性下降、`I` 恒定 | `E = (V1+V2)/2·I·Δt`（梯形面积）✅ |

> **若你只记得一条，就记「V 与 I 都线性时用四点 + 通式」**，1/6 和 1/3 都能从通式推出来。

### 骨架四：导通损耗怎么算——用 datasheet 曲线绕过探头精度

**问题（`099` 明确提出）**：IGBT 导通时 `V_CE` 只有 **1–2 V**，而高压差分探头是为几百伏设计的 → **低压段精度不足**，实测 `V_CE` 不可信。

**解决办法**：不用实测 `V_CE`，改用 **datasheet 的 `V_CE–I_C` 曲线**。

```
1. 看实测波形里电流大概在多少（例：20 A）
2. 把 datasheet 的 V_CE–I_C 曲线在 20 A 附近【单独放大】取出来
3. 在该区间把 V_CE 近似成 I_C 的线性函数
   V_CE(I) = V_0 + r·I       （V_0 是门槛电压，r 是斜率电阻）
4. 电流在导通区间线性变化 I_C(t) = I1 + (I2−I1)·t/Δt
5. E_cond = ∫ V_CE(I(t))·I(t) dt
         = ∫ (V_0 + r·I)·I dt
         = V_0·∫I dt + r·∫I² dt
```

**`099` 的算例（`Δt = 14 μs`、`I_C1 = 9.5 A`、`I_C2 = 14 A`）**：

```
I(t) 线性：I1 = 9.5, I2 = 14, Δt = 14 μs

平均电流  Ī = (9.5 + 14)/2 = 11.75 A
∫I dt   = Ī·Δt = 11.75 × 14e−6 = 1.645e−4 C
E_cond  ≈ V_CE(Ī) · Ī · Δt      （若 V_CE 近似常数）
```

> **关键提醒**：`099` 说「Ic 在 IGBT 导通状态下是**线性上升**的」——这是**电感负载续流后的上升段**，不是稳态。所以 `E_cond` 要用**上升端的 `V_CE` 曲线**，不能用满载稳态的 `V_CEsat`。

**选哪条曲线**：`099` 明确「**建议选择高温曲线**」（150 ℃ 或 175 ℃），因为实际工作结温就是高温。

### 骨架五：`Δt3` 段的特殊处理——电压近似常数

`099` 对最后一段做了简化：

> 「`Δt3` 内的 Vce 我们**取近似常数**。」

**好处**：`V` 为常数时积分退化为 `E = V · ∫I dt`，`∫I dt` 就是**梯形面积** `(I2+I3)/2·Δt3`。

**算例**（`V_CE3 = 40 V`、`I_C2 = 29.3 A`、`I_C3 = 19 A`、`Δt3 = 30 ns`）：

```
方向注意：I 从 29.3 降到 19（下降），Δt3 内是「开通后回调」
E_3 = 40 × (29.3 + 19)/2 × 30e−9
    = 40 × 24.15 × 30e−9
    = 2.898e−5 J  ≈ 0.029 mJ
```

> **这一段数值很小**（0.029 mJ），但**符号与方向必须对**。若把下降段当上升段算，会得到一个「虚假的额外开通损耗」。

## A1 · 案例：`099` 的三段结果合成

按骨架三的通式，用原文给的数据复算三段：

| 段 | `V1→V2` | `I1→I2` | `Δt` | 说明 |
|---|---|---|---|---|
| `Δt1` | 260 → 220 V | 0 → 20.3 A | 70 ns | 电压缓降、电流急升 |
| `Δt2` | 220 → 50 V | 20.3 → 29.3 A | 40 ns | 电压陡降、电流续升 |
| `Δt3` | ≈ 40 V（常数） | 29.3 → 19 A | 30 ns | 电流回落 |

**`099` 的结论是「把三部分算好加起来就是开通的总损耗」**——原文的最终数值落在公式图里（不可 OCR），但**方法与数据完整可复算**（见 A2）。

**这个案例证明的是一件事**：`E_on` 的主体来自 `Δt2`（电压陡降段），因为 `V·I` 乘积在那里最大。`Δt1` 电压高但电流小，`Δt3` 电流大但电压低。

## A2 · 本地复算：三段通式 + 与理想 1/6 对比

```python
def seg_energy(V1, V2, I1, I2, dt):
    """四点线性段能量（J）。dt 秒。"""
    kv = (V2 - V1) / dt
    ki = (I2 - I1) / dt
    return (V1*I1*dt
            + (V1*ki + I1*kv) * dt**2 / 2
            + kv*ki * dt**3 / 3)

segs = [(260,220,0.0,20.3,70e-9),
        (220, 50,20.3,29.3,40e-9),
        (40,  40,29.3,19.0,30e-9)]

tot = 0.0
for i, (V1,V2,I1,I2,dt) in enumerate(segs, 1):
    e = seg_energy(V1,V2,I1,I2,dt)
    tot += e
    print('dt%d: %+.4f mJ' % (i, e*1000))
print('E_on 合计 = %.4f mJ' % (tot*1000))

# 与"理想 1/6"对比：用 V1=260, I2=29.3, 总 dt=140ns
E_id = (1/6) * 260 * 29.3 * 140e-9
print('理想 1/6 单段(260V,29.3A,140ns) = %.4f mJ' % (E_id*1000))

# 自检：理想开通应精确等于 1/6
print('自检 1/6 断言:', abs(seg_energy(100,0,0,10,1e-6) - (1/6)*100*10*1e-6) < 1e-12)
```

```
dt1: +0.1778 mJ
dt2: +0.1814 mJ
dt3: +0.0294 mJ
E_on 合计 = 0.3886 mJ
理想 1/6 单段(260V,29.3A,140ns) = 0.1778 mJ
```

**四条判读**：

1. **三段合计 0.3886 mJ**，而「理想单段」只给 0.1778 mJ → **理想模型低估 2.19 倍**。这就是 `099` 说「理想公式没什么用了」的量化理由
2. **`Δt1` 与 `Δt2` 贡献接近**（0.178 vs 0.181 mJ），各占约 46 %；`Δt3` 只占 7.6 %
3. **`Δt1` 的结果恰好等于「理想 1/6 用 260 V 和 29.3 A」**——这是巧合吗？不是：`Δt1` 内 `I` 从 0 升到 20.3，`V` 从 260 降到 220，接近「一升一降」形态，所以接近 1/6 形态
4. **自检通过**：`seg_energy(100, 0, 0, 10, 1e-6) = 1.6667e−5 = 1/6·100·10·1e-6` ✅ → 通式实现正确

> **注意**：上面 0.3886 mJ 是我按原文四个交点数据算的，**不是原文的最终打印值**（原文数值在图片里）。用作**方法演示**，不做为「`099` 的结论值」引用。

## E · 触发场景

- 「示波器波形算损耗，手工怎么算？」→ 按 `V_CE` 斜率拐点分段，每段四个交点 + 通式
- 「为什么我按 `1/6·V·I·t` 算出来只有实测的一半？」→ 因为实际 `V` 是多段折线，理想模型低估约 2 倍
- 「IGBT 导通损耗算不准」→ 高压差分探头测 1–2 V 不可信，改用 datasheet 的 `V_CE–I_C` 曲线
- 「用 25 ℃ 还是 150 ℃ 的 `V_CE` 曲线？」→ **用高温**（150 ℃ 或 175 ℃）
- 「最后一段电流在下降，公式还能用吗？」→ 能，但**符号/方向必须按实际**；`V` 近似常数时退化为梯形面积
- 「算出来的 `E_on` 能不能直接乘 `f_sw` 得功率？」→ **可以，但只对恒流/斩波工况**。正弦输出要乘 1/π —— 那一步在书源 `38-loss-closed-form`，**不在本模块**

## S · 步骤

1. **截取单次开关波形**（开通或关断），标出 `V_CE` 与 `I_C` 两条曲线
2. **找 `V_CE` 的斜率拐点**，切成 2–4 段（`I_C` 通常可视为线性）
3. **逐段读 4 个坐标**：`(0,V1)`、`(Δt,V2)`、`(0,I1)`、`(Δt,I2)`
4. **逐段代通式**：`E = V1·I1·Δt + (V1·k_i + I1·k_v)·Δt²/2 + k_v·k_i·Δt³/3`
5. **检查每段的方向**：`V` 与 `I` 反向 → 结果应为正；同向 → 系数变 1/3。`V` 为常数段 → 退化为梯形面积
6. **相加得 `E_on` 或 `E_off`（单位 J）**，保留至少 4 位有效数字（单次能量常在 0.1–10 mJ 量级）
7. **若算导通损耗**：改用 datasheet 高温 `V_CE–I_C` 曲线拟合 `V_CE = V_0 + r·I`，代入 `E_cond = ∫(V_0 + r·I)·I dt`
8. **要平均功率**：回到书源 `38-loss-closed-form` 处理 1/π 与占空比；**不要在本模块内乘**
