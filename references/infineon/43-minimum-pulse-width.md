# 43 · 最小脉宽与窄脉冲：一批可以直接引用的实测门槛

> 来源：`103` IGBT 窄脉冲现象解读、`105`（死区与频率的交叉）。
>
> **层归属**：厂商层。书源 `09-switching-application` 的 `B` 段自己写明：「**7.3 最小开通时间仍未独立成篇——书本身只给了「5–10 μs 作为参考点」这一句原则（见 R 段），没有可代入的式子与统一的数值结论**」。本模块**直接补上这条空白**：给出分器件、分电流、分电压的实测门槛值。

## R · 原文锚点

> 「以 1700V/1000A IGBT4 E4 来看，规格书中在结温 Tvj.op=150℃ 时，开关时间 tdon=0.6us, tr=0.12us 和 tdoff=1.3us, tf=0.59us，窄脉冲宽度不能小于规格书开关时间之和。」【`103`】

> 「当 ton<=1.3us 时，IGBT 此时已经处于线性区，没有完全导通，此时开关损耗会很大，关断电流 Ic 出现突变引起大 di/dt，IGBT 关断会出现高频振荡。」【`103`】

> 「从测试看这个例子 FF1000R17IE4，最小脉冲 ton 最为合理时间不要小于 3us。」【`103`】

> 「该模块脉冲宽度在 ton=1us 已经开始振荡，电压尖峰 Vcep 比 ton=20us 要高出 80V。因此，建议不要最小脉冲时间不要小于 1us。」【`103`，FF450R12ME3】

> 「以 2400A/3.3kV HE3 为例如下，其已经明确给出最小二极管导通时间 10us 作为限制。」【`103`]

> 「实际应用中那最小脉冲宽度限制是多少比较合理呢？这些问题用理论和公式很难推导出万能公式来直接计算，理论分析和研究也比较少。」【`103`】

## I · 骨架

### 骨架一：窄脉冲为什么会坏——载流子没充满就关断

**机理（一句话）**：IGBT/FWD 刚开通时**不会立即充满载流子**。若在载流子仍在扩散时关断，电流会**突然中断** → `di/dt` 增大 → 在换流杂散电感上产生**更高的关断过压**；二极管侧则表现为**反向恢复电流突变（snap-off）**。

**两条独立的表现**（对应双脉冲的两个点）：

| 窄脉冲类型 | 对应什么 | 出问题的部位 | 后果 |
|---|---|---|---|
| **窄脉冲关断 `t_off`** | = FWD 的正向导通时间 `t_on` | **二极管反向恢复** | 反向恢复峰值电流增大、`dv/dt`/`di/dt` 加快、可能超 FWD SOA；`snap-off` |
| **窄脉冲开通 `t_on`** | = IGBT 的导通时间 | **IGBT 关断过程** | 关断电压尖峰升高、电流拖尾突变、高频振荡 |

**这条与 `41-soa-three-categories` 的衔接**：二极管窄脉冲超 SOA 对应 `P_RQM`（反向恢复最大峰值功率）与 `I_FRM` 限制——书源 `09` 骨架五已给出 `I_FRM = 2×` 且仅 1 ms。

### 骨架二：第一性判据——不能短于「开关时间之和」

`103` 给出的**唯一一条原理性判据**：

```
t_on,min ≥ t_d(on) + t_r        （开通侧，保证真正进入饱和）
t_off,min ≥ t_d(off) + t_f      （关断侧，保证彻底关断）
```

以 **1700 V / 1000 A IGBT4（E4）@ `Tvj = 150 ℃`** 为例：

| 参数 | 值 |
|---|---|
| `t_d(on)` | 0.6 μs |
| `t_r` | 0.12 μs |
| `t_d(off)` | 1.3 μs |
| `t_f` | 0.59 μs |
| **开通侧之和** | 0.6 + 0.12 = **0.72 μs** |
| **关断侧之和** | 1.3 + 0.59 = **1.89 μs** |

**取严 → 1.89 μs**。而实测门槛是 3 μs（见骨架三）——**说明「开关时间之和」只是下限中的下限，实质约束来自过压/振荡，不是来自延迟。**

> **这是本模块最关键的判断**：不要用 `t_d + t_f` 当最小脉宽。它只保证「器件切换完成」，**不保证「关断时过压不超标」**。实测门槛普遍是它的 1.6–1.7 倍。

### 骨架三：实测门槛值——分器件、分电流（这张表是本模块的核心资产）

**① IGBT 侧（`t_on` 太小 → 关断过压）**

| 器件 | 电压/电流 | 测试条件 | 实测现象 | **推荐 `t_on,min`** |
|---|---|---|---|---|
| **FF1000R17IE4**（IGBT4 PrimePACK） | 1700 V / 1000 A | `V_CE = 800 V`、`I_C = 500 A`、`R_g = 1.7 Ω`、`V_GE = ±15 V`、`T_a = 25 ℃` | `t_on` 从 2 μs 减到 1.3 μs 时尖峰上升；**`t_on ≤ 1.3 μs` 已进入线性区，未完全导通** | **≥ 3 μs** |
| **FF450R12ME3** | 1200 V / 450 A | `V_CE = 700 V`、`I_C = 900 A`（2× 标称） | `t_on = 1 μs` 起振荡，尖峰比 `t_on = 20 μs` **高 80 V** | **≥ 1 μs** |

**电流依赖的三条规律**：

| 条件 | `t_on` 敏感度 | 处置 |
|---|---|---|
| **小电流（< 1/10 `I_C`）** | 影响很小，**可忽略** | 不必设最小脉宽约束 |
| **大电流（≥ 标称）** | 敏感，`t_on` 越小尖峰越高 | 必须设 |
| **极大电流（3× `I_nom`）** | 尖峰已超阻断电压，**被芯片钳位在固定水平，与 `t_on` 无关** | 已经是 SOA 问题，不是脉宽问题 |

> 第三行很重要：**电流足够大时，尖峰被芯片自身钳位，`t_on` 不再是变量**。这意味着「窄脉冲」不是万能的炸机解释——若尖峰与 `t_on` 无关，问题在别处（RBSOA / 回路电感）。

**② FWD 侧（`t_on` 太小 → 反向恢复恶化）**

| 器件/条件 | 现象 | **推荐 `t_on,min`** |
|---|---|---|
| **FF450R12ME3** 的 FWD，`I = 450 A` | `t_on < 2 μs` 时反向电流峰值增大；`t_on > 2 μs` 后基本不变 | **≥ 2 μs**（由"峰值不再变"定） |
| **FF1800R17IP5**（IGBT5 PrimePACK 3+）的 FWD，小电流 `I_F = 20 A` | `t_on = 3 μs` 时示波器已抓不住高频振荡幅值 | **≥ 3 μs** |
| **2400 A / 3.3 kV HE3** | datasheet **明标** | **10 μs**（规范值，非推荐） |

**`t_on = 3 μs` 时的量化反向特性**（FF1800R17IP5）：

| `V_R` | `dv/dt` | `di/dt` |
|---|---|---|
| **1200 V** | **44.3 kV/μs** | **14 kA/μs** |
| **900 V** | **32.1 kV/μs** | **12.9 kA/μs** |

**母线越高、脉宽越窄 → 反向恢复越剧烈**。这是「高压 + 窄脉冲」组合特别危险的原因。

### 骨架四：窄脉冲出现在哪里——由功率因数决定

这是 `103` 给出的**应用层映射**，直接可用于定位波形异常：

| 应用 | 功率因数 | 窄脉冲出现位置 |
|---|---|---|
| **光伏、储能** | **≈ ±1** | **靠近电流零点**附近 |
| **SVG、APF（无功发生器/有源滤波）** | **= 0** | **最大负载电流附近** |

> **这条极其实用**：看到「电流过零点附近的振荡/EMI」→ 光伏储能典型；看到「最大负载处炸」→ SVG/APF 典型。
>
> **机理**：PF ≈ 1 时，输出电压过零附近电流也过零 → 占空比极小 → 出现窄脉冲；PF = 0 时，输出电流峰值处电压过零 → 同一桥臂脉宽极窄。

### 骨架五：高压器件有规范值，低压器件只能测

| 电压等级 | 最小脉宽依据 | 说明 |
|---|---|---|
| **≥ 3.3 kV** | **datasheet 明标**（如 2400 A/3.3 kV HE3 明标 **`t_on,min = 10 μs`**） | 大功率系统回路 `L_σ` 大、开关时间长，开通过程易瞬时超 FWD 的 `P_RQM` |
| **≤ 1200 V** | **无统一规范，须实测** | 原文：「在低压 IGBT 应用中比较难对最小允许开通窄脉冲去定义和计算，推荐精确地测量来调整去评估」 |

> **这是本模块的诚实边界所在**：低压侧**没有可代入的公式**。原文明确「用理论和公式很难推导出万能公式」。**任何声称「低压 IGBT 最小脉宽 = 某个公式」的说法都无出处。**

## A1 · 案例：为什么窄脉冲在高频 PWM 下「时常发生」

原文：「这种现象随着 IGBT 被高频 PWM 调制信号驱动时，时常会无奈发生，**占空比越小越容易输出窄脉冲**」。

**叠加骨架四的功率因数映射**，形成一个完整的故障定位链：

```
高频 PWM + 低占空比 → 窄脉冲 → 载流子未充满 → di/dt 突增
→ 换流电感上过压 → 高频振荡 + EMI

发生位置由 PF 决定：PF≈1 → 电流零点；PF=0 → 电流峰值
```

**这条链同时解释了书源 `09` 里「5–10 μs 最小开通时间作为参考点」的来源**：那是个覆盖大多数情形的经验区间，而 `103` 的实测把这个区间**拆细成了 1 / 2 / 3 / 10 μs 四档**，按器件与电流区分。

## A2 · 本地复算：开关时间之和 vs 实测门槛的倍数

```python
def sum_on(tdon, tr):   return tdon + tr
def sum_off(tdoff, tf): return tdoff + tf

# FF1000R17IE4 (IGBT4 E4) @150C
print('FF1000R17IE4 开通和 =', round(sum_on(0.6, 0.12), 2), 'us')
print('FF1000R17IE4 关断和 =', round(sum_off(1.3, 0.59), 2), 'us')
print('实测门槛 3 us / 关断和 →', round(3 / 1.89, 2), '倍')

# FF450R12ME3 FWD: t_on>2us 峰值不再变
print('FF450R12ME3 FWD 门槛 2 us')

# dv/dt 随母线降幅
print('900V 相对 1200V 的 dv/dt 比 =', round(32.1 / 44.3, 3))
print('900V 相对 1200V 的 di/dt 比 =', round(12.9 / 14.0, 3))
```

```
FF1000R17IE4 开通和 = 0.72 us
FF1000R17IE4 关断和 = 1.89 us
实测门槛 3 us / 关断和 → 1.59 倍
FF450R12ME3 FWD 门槛 2 us
900V 相对 1200V 的 dv/dt 比 = 0.725
900V 相对 1200V 的 di/dt 比 = 0.921
```

**两条判读**：

1. **实测门槛 ≈ 开关时间之和的 1.6 倍**（1000 A 器件）。所以「开关时间之和」只能当下限，要留 1.5–2 倍余量
2. **母线从 1200 V 降到 900 V，`dv/dt` 只降 27.5 % 而 `di/dt` 只降 7.9 %** ——**不是线性关系**。所以不能按母线比例缩放心里的风险

## E · 触发场景

- 「最小脉宽给多少？」→ 分三层：3.3 kV 以上查 datasheet（10 μs）；1700 V/1000 A 级取 ≥3 μs；1200 V/450 A 级取 ≥1 μs（IGBT）/ ≥2 μs（FWD）
- 「能不能用 `t_d(on)+t_r` 当最小脉宽？」→ 只能当下限，实测门槛是它的约 1.6 倍
- 「电流过零点附近老是振荡/EMI」→ 光伏储能（PF≈1）的典型窄脉冲位置
- 「最大负载处炸机」→ SVG/APF（PF=0）的典型窄脉冲位置
- 「小电流时也要管窄脉冲吗？」→ 不用，< 1/10 `I_nom` 影响可忽略
- 「尖峰随脉宽变化不大，是什么问题？」→ 3× `I_nom` 时尖峰被芯片钳位，问题已不是脉宽，查 RBSOA / `L_σ`

## S · 步骤

1. **查 datasheet 的 `t_d(on)/t_r/t_d(off)/t_f`** → 算开关时间之和，作为**绝对下限**
2. **按电压等级取门槛**：≥3.3 kV 查明标值（常见 10 μs）；1200–1700 V 用骨架三的实测表做起点
3. **按电流修正**：< 1/10 `I_nom` 可放开；≥ `I_nom` 必须留足；3× `I_nom` 已是 SOA 问题
4. **按 PF 定位风险点**：PF≈1 查电流零点；PF=0 查电流峰值
5. **实测验证**：在目标 `V_CE`、`I_C`、`R_g` 下扫 `t_on`，找「尖峰不再随 `t_on` 变化」的拐点
6. **与死区一起核**：`t_on,min + t_DT ≤ D_min · T_sw`（见 `42-switching-frequency-limit`）
7. **高压侧额外核 FWD 的 `P_RQM`**：3 μs 时 `dv/dt` 可达 44.3 kV/μs，须确认不超 FWD SOA

## B · 边界

- **补的是书源明确的空白**：`09` 的 `B` 段原文写「7.3 最小开通时间未独立成篇，书只给 5–10 μs 参考点」。本模块的 1 / 2 / 3 / 10 μs 四档**全部来自厂商实测**，不能说「据《IGBT 模块》」
- **所有门槛值都绑定具体器件与测试条件**：FF1000R17IE4 的 3 μs 是在 `V_CE = 800 V`、`I_C = 500 A`（**半载**）、`R_g = 1.7 Ω`、`T_a = 25 ℃` 下测的。**满载、高温、不同 `R_g` 都会让门槛上升**
- **FF450R12ME3 的 1 μs 是在 2× 标称（900 A）下得出的**，普通负载下可更小
- **低压侧无公式**：原文明确「很难推导出万能公式」，「推荐精确地测量」。**本模块故意不提供任何低压脉宽计算式**——提供就是编造
- **`t_on,min` 与 `t_off,min` 是两个不同的约束**：`t_on` 太短害的是**关断过压**（IGBT 侧）；`t_off` 太短害的是**FWD 反向恢复**。混用会选错方向
- **3.3 kV 的 10 μs 是 datasheet 规范值**（2400 A/3.3 kV HE3），不是推荐值也不是实测值——引用时要区分「规范 / 实测 / 推荐」三种性质
- **不覆盖「窄脉冲导致 EMI 的确切频段」**：语料只说「高频振荡 + EMI」，无频段数据
- **不覆盖 FWD 侧的 `I_FRM` 与 `P_RQM` 具体数值**：`103` 只提到「不能超过 FWD SOA」，具体数见各 datasheet
