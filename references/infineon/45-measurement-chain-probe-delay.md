# 45 · 测量链与探头延时：探头选错时，波形「看着对」但损耗全错

> 来源：`094` 如何评估 IGBT 模块在系统中的损耗、`019` 测量 IGBT 开关特性对电压探头的要求、`027` 测量 IGBT 开关特性对电流探头的要求。
>
> **层归属**：厂商层。书源 `10-measurement` 的 `B` 段原文写着「**书中未给探头延时的补偿方法**」。本模块直接补这条空白：给出延时校准的具体操作、Rogowski 的 3600 A/μs 门槛、电压探头的 `BW = 350/t_r` 与高压带宽衰减、电流探头 `t_r` 判据。
>
> 交叉：书源 `10-measurement §补` 已有「带宽 5× 判据、每斜坡 ≥10 采样点、式 12.1/12.3」，那些是**示波器侧**；本模块是**探头侧**。两者不重叠，要一起用。

## R · 原文锚点

> 「需要注意的是电压探头和电流探头需要匹配延时，否则会引起比较大的测试误差。」【`094`】

> 「在用于数据手册的测试平台中，常见的电流探头是 PEARSON 探头，而实际系统的母排中，很难装入 PEARSON 探头，更多的采用 Rogowski-coil。需要注意的是 Rogowski-coil 的延时会比较大，而且当电流变化率超过 **3600 A/μs** 时，Rogowski-coil 会有比较明显的误差。」【`094`】

> 「延时是可以校准的，具体方法是在 IGBT 的开通时，把电压的下降点和电流的上升点调在同一个时间点上……如果实测中 CE 电压下降的位置与 IC 电流上升的位置不在同一个时间点，说明电压探头与电流探头的时间延迟不一致，需要校准。」【`027`】

> 「信号的上升时间和对应的带宽的公式为 BW=350/tr，其中 BW 的单位是 MHz，tr 是被测信号 10%~90% 的变化时间，单位是 ns。」【`019`】

> 「一般高压差分探头虽然标称 100MHz，但其实是指在小电压值测量下可达到的最高带宽。当进行几百伏的电压测量时带宽是会变小的……当测到 600V 的电压时，探头实际的带宽能力其实只有 2M 都不到。」【`019`】

## I · 骨架

### 骨架一：延时不匹配为什么毁掉损耗——两个高斯型误差的乘积

开关损耗 = ∫ `v(t)·i(t) dt`。**电压与电流通道若有 `Δt` 的时延差，则积分等于把 `v(t)` 与 `i(t−Δt)` 相乘**。

**为什么这特别致命**：`v` 与 `i` 在开关瞬间都变化极快，乘积对时序极其敏感。`Δt` 相当于 1–2 个 `t_r` 时，`E_on` 的误差可达几十个百分点——而**波形上肉眼看不出异常**。

> **`094` 的出发点就是这件事**：「数据手册的典型值为什么不够准确」的四条原因里，探头延时只占其一，但它是**唯一一条「你测出来的数本身就是错的」**。其余三条（驱动电感、栅极电容、驱动电压、母排电感）是**真实工况差异**，测对了就是真值。

### 骨架二：延时校准的操作方法（这是书源明确缺的那一段）

`027` 给的校准方法**极其简单，只有一句话**，但很实用：

```
步骤：在【开通瞬间】把
       电压的下降点（V_CE 开始下降的时刻）
       与 电流的上升点（I_C 开始上升的时刻）
    调到同一个时间点上。
```

**为什么这两个点该重合？** `027` 的解释很关键：

- **理想情况**：换流结束后 `V_CE` 才下降
- **实际情况**：母排有杂散电感，**桥臂一出现 `di/dt`，`V_CE` 就开始下降了**

→ **两个点应当同时发生**。若实测中不重合 → 两探头时延不一致 → 校准。

**这条校准的性质（必须说清）**：

> 「这种校准并非绝对精度的校准，而是使电压探头和电流探头同步的**相对意义上**的校准。」【`027`】

→ 它校准的是**两通道之间的相对时延**，不修正两者的绝对延迟。对算损耗够用，对算「绝对开通延迟 `t_d(on)`」不够用。

### 骨架三：电压探头的三个关键参数

| # | 参数 | 判据 | 陷阱 |
|---|---|---|---|
| **1** | **最大电压限制** | 分**差模**（正负端之间）与**共模**（正/负端对地）两个值 | 探头 ①：共模 2500 V / 差模 5000 V；探头 ②：两者都 5000 V。**测对地 3000 V 母线必须选 ②** |
| **2** | **带宽** | `BW = 350 / t_r`（`BW` 单位 MHz，`t_r` 单位 ns） | **标称带宽是小电压下的值**，高压下大幅衰减 |
| **3** | **衰减比** | 在峰值允许范围内**尽量选小衰减比** | 100 V 信号用 1/100 → 送 1 V；用 1/1000 → 送 0.1 V → **后者精度更差** |

**带宽算例（`019`）**：

```
母线 600 V，dv/dt = 3000 V/μs
t_r(10–90) = 600 V / 3000 V/μs = 0.2 μs = 200 ns

按 10–90 段折算（0.8 × 600 V = 480 V 走完）：
t_r = 480 / 3000 μs = 160 ns

BW = 350 / 160 = 2.19 MHz
```

> **注意原文的算法与我的复算不同**：原文直接「600 V / 3000 V/μs = 200 ns」再得「2.2 MHz」；严格按 `t_r` 的 **10–90 %** 定义应是 160 ns。**两者结果（2.2 MHz）在工程精度内一致，但推导口径不同**。引用时用「约 2.2 MHz」，不要纠结 200 还是 160 ns。

**致命陷阱**：标称 100 MHz 的高压差分探头，测 600 V 时**实际带宽不到 2 MHz**。→ 恰好卡在临界（需要 2.2 MHz）。**必须查探头的「电压-带宽曲线」（`019` 图 3），不能只看标称值。**

**补充**：无源单端探头的带宽**往往比差分探头高不少**，但失去共模抑制与浮地能力。

### 骨架四：电流探头的选型与带宽验证

**CT vs 柔性（Rogowski）四维对比（`027`）**：

| 维度 | CT（电流互感器） | 柔性（Rogowski） |
|---|---|---|
| **介入性** | 电流环**无法打开**，须先装探头再接线 | **可介入性好**，可对已有电路测量 |
| **供电** | **不需额外电源**，直接接示波器 | 有积分器 → 需外加电源或电池 |
| **带宽** | **更宽**，高速 IGBT 测量**有优势** | 相对较窄 |
| **延时** | 较小 | **较大**（`094` 强调） |
| **`di/dt` 上限** | — | **> 3600 A/μs 时误差明显**（`094`） |

> **选型判据**：`di/dt` 会超过 3600 A/μs → **不能用 Rogowski**，必须想办法装 CT 或 PEARSON。这正是「实际系统母排很难装 PEARSON」的痛点所在。

**电流带宽是否足够的实测判据（`027` 的巧办法）**：

比较「**探头标称 `t_r`**」与「**实测波形 90 %→10 % 的电流下降时间**」：

| 案例 | 探头 `t_r` | 实测 90→10 % 时间 | 判定 |
|---|---|---|---|
| (a) | **100 ns** | **28.2 ns** | ❌ 实测时间 **小于**探头标称 → **电流失真**，损耗测量不可信 |
| (b) | **25 ns** | **48.6 ns** | ✅ 实测时间 **大于**探头标称 → 符合要求，波形无振铃 |

**判据表述**：`t_r,probe` 必须**明显小于**被测信号的真实边沿时间。若两者接近或反超 → 探头成了瓶颈。

> 这条判据与书源 `10-measurement §补` 的「带宽 5× 判据」等价（`t_r` 小 5 倍 ≈ 带宽 5 倍），**但 `027` 给了「怎么从波形本身看出来」的操作方法**——不需要查带宽，直接比两个时间。

### 骨架五：为什么「数据手册损耗值」不能直接用——四类真实差异

`094` 把「用 datasheet 典型值算系统损耗」的系统性偏差归为四条：

| # | 差异来源 | 方向（一般） |
|---|---|---|
| **1** | **驱动环路电感**不同 | 实际系统常大于 datasheet 测试台 → `di/dt` 降低 → `E_on/E_off` 变化 |
| **2** | 驱动加 **`C_GE` / `C_GC`** 电容（改善 EMC 的常见做法） | 直接影响 `di/dt`、`dv/dt` → 影响 `E_on/E_off` |
| **3** | **驱动电压**不同（datasheet 通常 ±15 V） | `V_GE` 越高 → 短路电流与开关速度都变 |
| **4** | **母排杂散电感**不同（datasheet 用较小 `L_σ`） | 实际常更大 → 关断过压升高、`E_off` 上升、`E_on` 下降 |

→ **正解**：用**实际系统的母排与驱动板**做双脉冲测试，模块固定在**加热平台上调到 150 ℃ 恒温**（并等足够时间让 `T_vj` 也到温）。

**损耗拟合方法（`094`）**：

1. 固定电压与温度，扫不同电流 → 得 `E(I)` 曲线 → 拟合
2. 各电压（540 / 700 V）× 各温度（125 / 150 ℃）重复 → 得一族曲线
3. 用**线性等效法**推出 `E_on(I, V, T)`、`E_off(I, V, T)`、`E_rec(I, V, T)`

**已知缺陷**：**极低电流时误差偏大** → 用非线性模型或多段线性模型改善（`094` 自己承认）。

## A1 · 案例：dut = FF600R12ME4 的双脉冲现场

`094` 给出的通道标注，是现场核对接线的最快方式：

| 通道 | 信号 | 颜色 |
|---|---|---|
| CH2 | `V_GE` | 绿 |
| CH3 | `V_CE` | 蓝 |
| CH4 | `I_C` | 红 |

**流程要点**：

1. 加热平台调到 150 ℃，**等足够时间**让 `T_vj` 也到温（不是等台温读数到就行）
2. IGBT 与 Diode 分别做双脉冲（`094` 图 1-1 / 1-2）
3. **先校延时**（骨架二），再取 `E_on/E_off/E_rec`
4. 扫 `I`、扫 `V`（540/700 V）、扫 `T`（125/150 ℃）

> **顺序不能颠倒**：先测后校延时 = 白测一轮。`094` 把「匹配延时」写在方法段中间，很容易被跳过。

## A2 · 本地复算：探头带宽与 `t_r` 判据

```python
def bw_from_tr(tr_ns):
    return 350.0 / tr_ns

def tr_from_bw(bw_mhz):
    return 350.0 / bw_mhz

# 019 的算例
Vbus, dvdt = 600.0, 3000.0     # V, V/us
tr_full = Vbus / dvdt          # 全摆幅
tr_1090 = 0.8 * Vbus / dvdt    # 10-90%
print('全摆幅 t_r =', tr_full * 1000, 'ns  -> BW =', round(bw_from_tr(tr_full*1000), 2), 'MHz')
print('10-90  t_r =', tr_1090 * 1000, 'ns  -> BW =', round(bw_from_tr(tr_1090*1000), 2), 'MHz')

# 027 的电流探头判据
for name, trp, trs in [('(a) 100ns', 100, 28.2), ('(b) 25ns', 25, 48.6)]:
    verdict = '失真' if trs < trp else '合格'
    print('%s  probe_tr=%5.1f  signal_tr=%5.1f  ratio=%.2f  -> %s'
          % (name, trp, trs, trs / trp, verdict))
```

```
全摆幅 t_r = 200.0 ns  -> BW = 1.75 MHz
10-90  t_r = 160.0 ns  -> BW = 2.19 MHz
(a) 100ns  probe_tr=100.0  signal_tr=28.2  ratio=0.28  -> 失真
(b)  25ns  probe_tr= 25.0  signal_tr=48.6  ratio=1.94  -> 合格
```

**三条判读**：

1. **两种 `t_r` 口径差 1.25 倍，带宽差 1.25 倍**（1.75 vs 2.19 MHz）→ 原文说「理论上需要的带宽为 2.2 MHz」用的是 10–90 口径，但算式写的是全摆幅。**结论一致，推导不严**——这是原文的小瑕疵，不影响实用
2. **`ratio < 1` 必失真**：探头 `t_r` 比信号还慢，波形被探头抹平
3. **`ratio ≈ 2` 已合格**，但要稳建议 ≥ 3–5（与书源「带宽 5×」判据一致）

## E · 触发场景

- 「损耗算出来比 datasheet 差很多，是器件问题吗？」→ 先查探头延时是否匹配（`027` 的开通点对齐法）
- 「Rogowski 能不能测？」→ 看 `di/dt`：**> 3600 A/μs 误差明显**，改用 CT/PEARSON
- 「探头标称 100 MHz 够不够？」→ 查**电压-带宽曲线**。600 V 时可能只剩不到 2 MHz
- 「电流波形有振铃/失真，是电路振荡吗？」→ 先比「探头 `t_r`」与「实测 90→10 % 时间」，**反超即探头瓶颈**
- 「门极信号测不准」→ 选**小衰减比**档（能 1/10 就别用 1/100）
- 「浮地/高共模怎么测？」→ 看**共模**额定值，不是差模额定值
- 「哪些因素让 datasheet 的 `E` 不能直接用？」→ 四类：驱动电感、`C_GE/C_GC`、驱动电压、母排电感

## S · 步骤

1. **选电压探头**：核共模额定 ≥ 母线电压（含过压）；按 `BW = 350/t_r` 算需求；查高压下的带宽曲线；选最小可行衰减比
2. **选电流探头**：`di/dt > 3600 A/μs` → 排除 Rogowski；否则按介入性与带宽权衡
3. **验证电流探头带宽**：实测关断 90→10 % 时间，若 ≤ 探头 `t_r` → 换探头
4. **校延时**（关键步骤）：开通瞬间对齐「`V_CE` 开始下降」与「`I_C` 开始上升」
5. **控温**：加热平台设目标温度，**等 `T_vj` 到温**（不是台温到温）
6. **扫变量**：固定 `V`、`T`，扫 `I` → 拟合；再扫 `V`、`T` 得族
7. **记录**：把探头型号、衰减比、`t_r`、延时校准量、平台温度一并写进报告——否则数据无法复现
8. **低电流段**：`E` 拟合改用非线性或多段线性（低电流误差偏大）

## B · 边界

- **补的是书源明确的空白**：`10-measurement` 的 `B` 段原文「书中未给探头延时的补偿方法」。本模块的校准法来自厂商资料，**不能说「据《IGBT 模块》」**
- **延时校准是「相对」校准**：`027` 明确「并非绝对精度的校准」。→ 校完后能算损耗，**但不能用同一组数据去引「绝对开通延迟 `t_d(on)`」**
- **`3600 A/μs` 是 Rogowski 的单点门槛**：原文只说「比较明显的误差」，**没给误差随 `di/dt` 的增长规律**。→ 不要外推成「3700 A/μs 误差 X %」
- **`BW = 350/t_r` 是经验常数**：不同厂家常用 350 或 350 的近似值，`t_r` 定义（10–90 还是 20–80）不同则常数不同。**本式与 0.35/`t_r`(ns) 同一家族，注意单位**
- **`019` 的带宽算例推导不严**：正文「600 V/3000 V/μs = 200 ns」用的是全摆幅，但 `t_r` 标准定义是 10–90 %（对应 160 ns）。**本模块已并列两个口径**，结论 2.2 MHz 不受影响
- **「600 V 时带宽不到 2 MHz」是针对特定型号高压差分探头**的实测曲线，不同品牌差异极大，**必须查自己探头的曲线**
- **`027` 的 (a)/(b) 对比例子未给器件与工况**：只知道探头 `t_r` 是 100 ns 与 25 ns，信号边沿 28.2 与 48.6 ns。**不能当标准值引用**
- **`094` 的损耗拟合方法承认「极低电流时误差偏大」**：这是方法固有缺陷，不是操作失误 → 低电流段必须换模型
- **PEARSON 装不进实际母排是工程现实**：这句意味着「想用 datasheet 同款探头复现」通常做不到，只能退而求其次并接受误差
- **本模块不覆盖示波器侧**：采样率、垂直分辨率、每斜坡采样点数见书源 `10-measurement §补`
