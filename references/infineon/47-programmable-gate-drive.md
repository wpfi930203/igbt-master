# 47 · 驱动可编程化：TLTO、软关断、有源钳位的三条过压抑制路径

> 来源：`063` 如何抑制 IGBT 集电极过压尖峰、`069` 简单的 dv/dt 控制技术降低 IGBT 开通损耗、`023` 扩展驱动电流（部分交叉）。
>
> **层归属**：厂商层。书源 `31-protection-timing` 已有 TLTO（16 处，含 1125→733 V）与有源钳位（`01`/`08`/`31` 共 14 处），`32-soft-switching-snubber` 讲了软开关与缓冲。本模块的增量是：**TLTO 的完整参数化与时序机制**、**有源钳位所需的 21 A 电流的定量判据**、**X3 系列免外接 RC 的可编程化**、**并联双驱动降 `E_on` 25 %**。
>
> **跨源并列（重要）**：书源「加 `R_G` 能降关断 `di/dt`」与英飞凌「**一味加大门极电阻并不可取**」是**方向性分歧**。本模块在骨架零专门并列，不可只引一方。

## R · 原文锚点

> 「降低电流变化率，很多人想到的第一个办法是增加门极电阻，但这一方法**并不总是有用**，尤其是对 FS+trench stop 的技术。**略微增加门极电阻甚至可能增加 di/dt**，当门极电阻增加到非常大的时候，才会降低 di/dt。一味地增加门极关断电阻，会显著增加关断损耗，因此这种方法并不可取。」【`063`】

> 「两电平关断的思路是在关断过程中减慢关断速度……栅极电压不是直接降低到 0V 或者负电压，而是在很短的时间内，栅极电压先降到 UTLTO，这个电压**低于正常导通电压，但是高于米勒平台的电压**。然后再从 UTLTO 降低到 0V 或者是负电压。一般来说，UTLTO 可以选择 9~14V 之间的电压。」【`063`】

> 「图 a 中出现了 1125V 的峰值电压。在图 b 所示的测量方法中，电压只有 733V（在每个例子中直流母线电压为 400V，且都使用了一个 400A/1.2kV 的 IGBT）。」【`063`】

> 「如果 IGBT 外部栅极电压为 1ohm，栅极电压为 -15V，而阈值电压为 6V，为了再次开通 IGBT，必须使有源钳位的电流**大于 21A**。」【`063`】

> 「最新的英飞凌 1ED X3 digital 版本芯片，**不需外接器件**即可实现两电平关断的参数调节。并且，1ED X3 analog/digital 芯片还集成了软关断功能，无需外围器件，即可实现 **16 档软关断电流**的调节。」【`063`】

> 「使用本文推荐的栅极驱动时，标称电流（IC=40A）下的开通损耗可从 **4.8mJ 下降到 3.6mJ**。这相当于开通损耗 Eon **降低了 25% 左右**。」【`069`]

## I · 骨架

### 骨架零（跨源分歧）：加 `R_G` 到底能不能降 `di/dt`

这一条必须先说清，因为它决定后面的方案选择。

| 口径 | 说法 | 出处 |
|---|---|---|
| **书源（Volke）** | 加大栅极电阻能降关断 `di/dt`，但增加 `E_off`——是**交换**不是免费 | `09-switching-application`、`30-gate-drive-dynamics` |
| **英飞凌（`063`）** | 「**并不总是有用**」，尤其对 **FS + trench stop** 技术；**略微增加甚至可能增加 `di/dt`**；只有加**非常大**才降 `di/dt`，而那时 `E_off` 已显著上升 | `063` |

**为什么会有这个分歧**（`063` 的机理暗示，值得写出）：

FS（场截止）+ 沟槽栅器件在关断时，`di/dt` 不只受栅极控制，还受**拖尾电流**支配。拖尾段是背面注入的少数载流子复合，**与栅极电阻无关**。所以：
- 小幅度加 `R_G`：只压慢前半段（MOS 沟道段），**拖尾段不变**，甚至因电压重新分配而使表观 `di/dt` 上升
- 大幅度加 `R_G`：才影响整体，但 `E_off` 已大幅恶化

> **判据**：**不要用「加 `R_G`」作为降过压的第一手段**。先用骨架一～三的主动方案。

### 骨架一：TLTO（两电平关断）——把 `V_GE` 分两步降

**核心思路**：关断时 `V_GE` 不直接到 0/负，而是**先降到 `U_TLTO`（9~14 V），保持一段 `t_TLTO`，再降到 0/负**。

**为什么必须落在这个窗口**：

```
U_TLTO 必须 < 正常导通电压（约 15 V）    → 才开始关断
U_TLTO 必须 > 米勒平台电压               → 不会立刻进入米勒区
```

在这个窗口内，器件以**较低但受控的 `di/dt`** 换流 → 过压降低 → 然后再快速彻底关断。

**`063` 的量化效果（400 V 母线、400 A/1.2 kV IGBT，关断短路电流）**：

| 方案 | 峰值电压 | 相对 `U_DC` 的倍数 |
|---|---|---|
| **无 TLTO** | **1125 V** | **2.81×** |
| **有 TLTO** | **733 V** | **1.83×** |

降幅 = (1125 − 733)/1125 = **34.8 %**。原文还说「栅极电压和发射极-集电极电压中的强烈**振荡明显减轻**」——即 TLTO 不只降幅值，还抑振。

**两条实现路径**：

| 路径 | 器件 | 参数怎么定 | 外围 |
|---|---|---|---|
| **传统** | `1ED020I12-FT` / `1ED020I12_BT` | `TLSET` 引脚外接**肖特基二极管**（定电压）+**电容**（定时间） | 需外接 RC |
| **可编程（X3）** | **`1ED38X1MX12M`** | **数字化配置**电平与持续时间 | **免外接电容电阻** |

**时序机制（`063` 的细节，最容易被忽略）**：

> 「当电容充电达到一个特定的值，就会触发驱动器的输出信号 `U_OUT`，如果输入信号 `U_in` 比设定的 `t_TLTO` **短**，输入信号通常会被**抑制**，而输出信号会**保持不变**。」

→ **即：短于 `t_TLTO` 的输入脉冲会被吞掉。** 这是一条**硬副作用**：设了 TLTO，最小脉宽必须 ≥ `t_TLTO`，否则脉冲丢失。**与 `43-minimum-pulse-width` 联用时要一起核。**

### 骨架二：软关断——短路时的专用慢关断

**目标不同**：TLTO 是「平时关断降过压」；软关断是「**短路时**安全关断」。短路电流可达 `I_SC`（约 4~8× `I_nom`），此时 `di/dt` 极大，用正常 `R_G` 关断必炸。

**两段式机理**：

```
第 1 段：用【高阻抗】释放栅极电流 → 延迟 C_GE 放电 → 关断变慢（降 di/dt）
第 2 段：一旦 V_GE 降到某个值（例如 2 V）→ 高阻抗被【低阻抗】短路
        → 确保快速而完全地把 C_GE 放光
```

**为什么必须有第 2 段**：若一直用高阻抗，`V_GE` 会停在阈值附近 → 器件半开 → **损耗巨大且可能热失控**。第 2 段保证「慢下来之后必须彻底关断」。

**可编程化（`063`）**：

| 器件 | 配置方式 | 档位 |
|---|---|---|
| `1ED34X1MX12M` | **模拟** | **16 档**软关断电流 |
| `1ED38X1MX12M` | **数字** | **16 档**软关断电流 |

> **16 档的意义**：软关断电流必须与**具体模块的 `C_GE`、短路电流水平、允许 `di/dt`** 匹配。固定档位的芯片常常「要么太慢炸机、要么太快过压」，可编程才谈得上调优。

### 骨架三：有源钳位——用「重新开通」来压 `di/dt`

**原理链（`063` 的完整描述）**：

```
关断时 CE 间因 di/dt 产生尖峰
→ 一旦 V_CE 超过 VD1 的雪崩电压
→ 单向 TVS 二极管 VD1 导通并通流 I1
→ I1 流过 VD1、VD2、R_G 和 VT2
→ 若 I1 在 R_G 上产生的压降 > V_th，则 IGBT 再次开通
→ 从而降低关断过程中的 di/dt
```

> **本质**：这是一种**负反馈**——电压冲高就把器件「拉回半开」状态，削掉 `di/dt`。

**定量判据（`063` 给了完整算例，这是本模块最有用的公式）**：

```
要在 R_G 上产生 ≥ V_th 的压降：
    I_clamp · R_G ≥ V_th + |V_GE(off)|
→   I_clamp ≥ (V_th + |V_GE(off)|) / R_G
```

**算例**：`R_G = 1 Ω`、`V_GE(off) = −15 V`、`V_th = 6 V`

```
I_clamp ≥ (6 + 15) / 1 = 21 A
```

→ **TVS 的 VD1 与阻断二极管 VD2 都必须满足 21 A 脉冲电流**。

**TVS 选型**：必须是高压二极管，**常用系列 `1.5KExxx`**。

**三条固有缺点（`063` 明确列出）**：

| 缺点 | 后果 |
|---|---|
| **击穿电压与温度密切相关** | 高温下钳位点漂移 → 保护点不准 |
| **阻断二极管结电容较大** | `C_D2 · du/dt` 的位移电流会**额外加大**钳位支路电流 |
| **需高压二极管** | **附加成本较高** |

### 骨架四：改进型有源钳位——把反馈接到推挽级之前

`063` 给的第二种接法，绕开「大电流必须走 TVS」的问题：

```
I2 通过 VD5、R2 和 MOSFET VT8
R2 比 R_G 高很多 → 只要 I1 有一小部分流出就能产生足够电压
→ 打开 VT5、关闭 VT6
→ VT5 导通后，I1 不再经过 R_G，而是直接给 C_GE 充电
```

**三个好处（原文列出）**：

1. **通过二极管的电流很低** → 可用**更便宜的 TVS SMD 二极管**
2. **所需空间仅由爬电距离和电气间隙决定**
3. **电路反应非常快**

> **与骨架三对比**：骨架三要求 TVS 承受 21 A 脉冲（贵、大）；改进型只要「小电流触发 + 大电流走 `C_GE` 路径」。**同样的物理效果，器件成本差一个量级。**

### 骨架五：并联双驱动——分负载切换 `dv/dt` 的简单办法

`069` 的方案与前述三条**目标不同**：它降的是**开通损耗**，不是在处理过压。

**问题**：轻载时（`I_F < 25 % I_nom`）换流电流小，若开通太快会**严重振荡**；重载时希望开通快以省 `E_on`。单一 `R_gon` 无法两全。

**方案**：**两个驱动芯片并联**（例：两片 `1EDI60I12AF`）

| 负载区间 | 参与输出的芯片 | 等效 `R_g` |
|---|---|---|
| **轻载 / 低负荷** | 只用 IC1 | `R_g1`（较大，慢开） |
| **重载（> 50 % `I_nom`）** | IC1 + IC2 并联 | `R_g1 ∥ R_g2`（较小，快开） |

**切换机制**：`IC2` 的 `IN−` 端施加电平信号即可启用/停用。可由应用控制生成，也可用**传感信号**（温度、集电极电流）自动控制。

**`069` 的量化结果（`I_C = 40 A` 标称，IKW40N120T2）**：

| 方案 | `E_on` |
|---|---|
| 常规单驱动 | **4.8 mJ** |
| 并联双驱动 | **3.6 mJ** |
| 降幅 | **25 %** |

**`069` 的临界数值**：振荡「在正向电流达到标称电流 **25 %** 或以上时可以被大幅减弱甚至消除」→ 这就是切换阈值的设计依据。

**一条必须遵守的接线约束**：

> 「**只有驱动芯片 IC1 可以用于关断**。不然可能出现 IC1 在输出电流而 IC2 在吸收电流的情况，这会导致芯片中或相关栅极电阻中出现**过度的功率损耗**。」

## A1 · 案例：三条路径怎么选

| 场景 | 首选 | 理由 |
|---|---|---|
| **平时关断过压略高**（未超额定） | **TLTO** | 免加 `R_G`、不增 `E_off`、还能抑振 |
| **短路关断**（`I_SC` 4~8×） | **软关断**（必须） | 正常关断必炸；需 16 档匹配 `C_GE` |
| **过压已接近 `V_CES` 额定** | **有源钳位** | 唯一「闭环」方案，能压到 TVS 电压水平 |
| **成本敏感、空间紧张** | **改进型有源钳位** | TVS 只需小电流 |
| **想省 `E_on` 又要控 EMI** | **并联双驱动** | 分负载切换，`E_on` 最多降 25 % |

## A2 · 本地复算：TLTO 降幅与钳位电流

```python
# TLTO 效果（063：400V 母线，400A/1.2kV IGBT）
Udc = 400.0
v_no, v_tlto = 1125.0, 733.0
print('无 TLTO 峰/母线 =', round(v_no / Udc, 2))
print('有 TLTO 峰/母线 =', round(v_tlto / Udc, 2))
print('TLTO 降幅 = %.1f %%' % ((v_no - v_tlto) / v_no * 100))

# 有源钳位所需电流
def i_clamp_needed(Rg, Vth, Vge_off):
    return (Vth + abs(Vge_off)) / Rg

print()
for Rg in (0.5, 1.0, 2.0, 5.0):
    print('R_G=%.1f ohm -> I_clamp >= %.1f A' % (Rg, i_clamp_needed(Rg, 6, -15)))

# 并联双驱动 E_on
print()
print('E_on 降幅 = %.1f %%' % ((4.8 - 3.6) / 4.8 * 100))
```

```
无 TLTO 峰/母线 = 2.81
有 TLTO 峰/母线 = 1.83
TLTO 降幅 = 34.8 %

R_G=0.5 ohm -> I_clamp >= 42.0 A
R_G=1.0 ohm -> I_clamp >= 21.0 A
R_G=2.0 ohm -> I_clamp >= 10.5 A
R_G=5.0 ohm -> I_clamp >= 5.0 A

E_on 降幅 = 25.0 %
```

**三条判读**：

1. **TLTO 把过压从 2.81× 压到 1.83×** —— 这两个倍数比原文的 1125/733 V 更可移植，因为可换算到其它母线电压
2. **`R_G` 与所需钳位电流成反比**：`R_G = 1 Ω` 需 21 A，但 `R_G = 5 Ω` 只需 5 A。**代价是 `R_G` 大 `E_off` 高** → 这就是骨架零那条分歧的量化体现
3. **21 A 这个数只对 `R_G = 1 Ω`、`V_GE = −15 V`、`V_th = 6 V` 成立**，换参数要重算

## E · 触发场景

- 「加大关断电阻能降过压吗？」→ **对 FS+trench stop 器件不一定**，略微加大甚至可能让 `di/dt` 更大（见骨架零）
- 「关断尖峰 1125 V，母线才 400 V？」→ 用 TLTO，可降到 733 V
- 「TLTO 设多少伏？」→ **9~14 V**，必须 < 导通电压且 > 米勒平台
- 「装了 TLTO 后窄脉冲丢失了？」→ TLTO 会**吞掉短于 `t_TLTO` 的输入脉冲**，最小脉宽要加上这条
- 「短路时怎么关断？」→ **软关断**，两段式（高阻慢放 → 到 2 V 后低阻快放）
- 「有源钳位的 TVS 要多大电流？」→ 按 `(V_th + |V_GE,off|)/R_G` 算；`1 Ω`/`−15 V`/`6 V` → **21 A**
- 「有源钳位太贵」→ 用改进型（反馈到推挽前），TVS 只需小电流
- 「想省 `E_on` 又怕轻载振荡」→ 并联双驱动，25 % 负载以上切换

## S · 步骤

**A. 关断过压（TLTO 路线）**

1. 先算 `U_p = U_DC + L_σ·di/dt`，与 `V_CES` 比，确认是否真超
2. 确认器件是 FS+trench stop → **不要先试加 `R_G`**
3. 选 `U_TLTO` ∈ 9~14 V，须 < `V_GE(on)` 且 > 米勒平台
4. 定 `t_TLTO`，**并检查是否会吞掉应用需要的最短脉冲**
5. 优先选可编程型（`1ED38X1MX12M`），免外接 RC，便于现场调

**B. 短路关断（软关断路线）**

6. 选带软关断的驱动（`1ED34X1MX12M` 模拟 / `1ED38X1MX12M` 数字）
7. 按模块 `C_GE` 与 `I_SC` 在 **16 档**里选，使 `di/dt` 产生的过压 < `V_CES` 且关断时间 < `t_p`

**C. 有源钳位（仍不够时）**

8. 按 `I_clamp ≥ (V_th + |V_GE,off|)/R_G` 算电流，选 `1.5KExxx` 系列 TVS
9. 核 TVS 的**击穿电压温度系数**（高温漂移）
10. 核阻断二极管**结电容**引起的 `C_D2·du/dt` 额外电流
11. 若成本/空间受限 → 改**改进型接法**（反馈到推挽级之前）

**D. 降 `E_on`（并联双驱动）**

12. 定切换阈值（参考 25 % `I_nom`），`R_g2` 使并联后仍满足 `dv/dt` 上限
13. **关断只允许 IC1 参与**，否则 IC1/IC2 灌拉对冲，损耗剧增

## B · 边界

- **`063` 与书源在「加 `R_G` 能否降 `di/dt`」上有方向性分歧**：书源说能（代价是 `E_off`），`063` 说对 FS+trench stop「不一定，略微加甚至可能增加」。**本模块并列呈现，不裁决**。使用者须按自己的器件技术判断——`063` 的适用对象明确写了「FS + trench stop」
- **1125→733 V 是 400 V 母线、400 A/1.2 kV 器件、关断短路电流的单一实测**：不能外推成「TLTO 一律降 35 %」
- **`U_TLTO` = 9~14 V 是区间**：具体取值必须落在「< 导通电压」且「> 米勒平台」之间，**这两个边界随器件与温度变化**，不能只记 9~14 这个数
- **21 A 钳位电流是算例值**：只对 `R_G = 1 Ω`、`V_GE = −15 V`、`V_th = 6 V` 成立。原文措辞是「必须使有源钳位的电流大于 21A」，**不是通用门槛**
- **TLTO 吞短脉冲的副作用原文只说「输入信号通常会被抑制」**：未给可接受的最小脉宽量化关系 → 必须实测确认
- **`069` 的 25 % 降幅是 40 A/1200 V 单管（IKW40N120T2）、`R_g1 = 18 Ω` / `R_g2 = 47 Ω`（并联 13 Ω）的结果**，不能套到模块上
- **`1EDI60I12AF` 是 `069` 用的具体型号**：换型号要重新核并联可行性（推挽结构与防直通能力）
- **软关断的「高阻→2 V→低阻」是定性描述**：`063` 未给高阻的具体阻值范围，只说「相对高的阻抗」
