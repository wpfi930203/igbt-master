# 检查表 02 · 可靠性试验的发起与判定

> 用途：在启动一项可靠性试验**之前**、进行**之中**、以及**判定 EOL** 时，逐项自检。
> **纪律**：本表不提供试验条件数值。条件必须来自标准正文（AQG 324 / AEC-Q101 / IEC 60749-34-1）或客户规范。

---

## A. 试验之前（省掉这一步，数据基本废掉）

| # | 自检项 | 为什么重要 |
|---|---|---|
| A1 | **标准选对了吗？** 单管 → AEC-Q101；模组 → AQG 324；模组 PC 方法 → IEC 60749-34-1 | 用错标准是最常见的形式错误，报告直接被退回 |
| A2 | **标准版本写对了吗？** AQG 324 现行 Release 04.1/2025；AEC-Q101 现行 Rev E；IEC 60747-9:2019 | 版本错会被质疑专业性；且 2025 版对 SiC 有实质新增项 |
| A3 | **客户规范是否加严？** 车厂常把 AQG 324 当厂规并提高要求 | 客户规范优先级最高，用标准默认值可能不达标 |
| A4 | **机理对得上吗？** 这项试验想验证哪个界面/机理？ | **试验选择必须由失效模式驱动，不能"别人做我也做"** |
| A5 | **样本量与批次数够吗？** | 样本不足 → 无法给 B10 与置信区间；单批次 → 无法评估批间波动 |
| A6 | **初始基线建立了吗？** 电参数 + SAM + Rth | 没有基线，就无法判断"变化了没有" |
| A7 | **EOL 判据事先定义了吗？** | 事后定义判据 = 事后挑数据。必须在试验前写进方案 |
| A8 | **测试条件能否复现？** Rg/VCC/Tvj/Lσ/Δt 记录 | 不可复现的数据，跨批次/跨厂商对比无效 |
| A9 | **热阻测试的 K factor 标定了吗？** | TSEP 测温不准 → ΔTj 不准 → 整个寿命结论偏 |
| A10 | **安全措施？** 高压、高温、PD、爆炸风险 | 高压反偏下的电弧与样品炸裂是真实风险 |

## B. 试验之中（过程失控，结论无效）

| # | 监控项 | 失控表现 |
|---|---|---|
| B1 | 结温/壳温实测曲线（不是设定值） | 设定 125℃ 实测 118℃ → ΔTj 全错 |
| B2 | ΔTj 与 Tj,mean 的实测值 | 只报设定值，不报实测 = 数据不可用 |
| B3 | ton / toff 实测 | 电源响应慢会导致实际 ton 偏离 |
| B4 | 在线电参数监测（VCE(sat) / Rth 定期复测） | 只在终点测 → 看不到退化轨迹与早期失效 |
| B5 | 冷却条件稳定性（流量/风量/环境温度） | 波动会掩盖 ΔTj 变化 |
| B6 | 样品失效时间记录（不是只记"有几颗坏"） | 没有失效时间 → 无法做 Weibull |
| B7 | 失效样品保留（不得丢弃/混放） | 后续 FA 的唯一物证 |
| B8 | 中途异常事件记录（停电、超温、误操作） | 未记录的异常会污染数据 |

**关键认知**：`B4` 是最容易被省掉、也最影响结论的一步。**功率循环只测首尾，等于只测了寿命，没测到机理。**

## C. EOL 判定（这一步决定报告的价值）

| # | 判据 | 指向的失效机理 | 注意 |
|---|---|---|---|
| C1 | **通态压降上升约 5%** | 键合线抬升 / 跟部裂纹 / 铝层重构 | 需在同一测试电流与温度下比较 |
| C2 | **热阻上升约 20%** | 焊层 / 烧结层分层、空洞扩展 | 需在同一冷却条件下比较 |
| C3 | 漏电超限 | 终端/钝化退化、芯片缺陷 | HTRB/H3TRB 主判据 |
| C4 | 栅极漏电/VGE(th) 漂移超限 | 栅氧退化 | HTGB 主判据 |
| C5 | 突发失效（开路/短路） | 键合线断、芯片烧毁 | 需记录发生时刻 |

> C1/C2 的数值来自二手可交叉源，**必须以 AQG 324 正文核对**。本表的作用是提醒你"要同时记录两类判据"，不是给权威数值。

**必须做到**：**同时记录 C1 与 C2**。只报一个，会让报告失去"区分机理"的能力——而区分机理才是可靠性报告的全部价值。

---

## D. 数据记录的最低要求（缺一项，报告不合格）

任何一项可靠性结论，报告里必须能查到：

1. **标准**：编号 + 版本年份（`AQG 324 04.1/2025`，不是 `AQG324`）
2. **样品**：型号、批次、数量、生产日期
3. **条件**：VCE / IC / Rg / fsw / ton / toff / Tcoolant / ΔTj **实测值** / Tj,mean **实测值**
4. **判据**：EOL 定义（哪个参数、变化多少）
5. **基线**：试验前的对应参数值
6. **失效时间**：逐颗记录，不是总数
7. **失效机理**：至少给初判（电参数分离 + 无损检测）
8. **模型（如做寿命外推）**：模型名 + 系数来源 + 适用范围声明

---

## E. 报告写作的五个常见硬伤

| 硬伤 | 表现 | 后果 |
|---|---|---|
| **条件与结论脱节** | "通过 AQG 324" 但没写实测 ΔTj | 客户无法判断适用范围，等于没做 |
| **只报总数不报时间** | "10 颗坏了 2 颗" | 无法评估失效分布，无法外推 |
| **判据事后定** | 看到数据后再定"变化 8% 算失效" | 数据不可信 |
| **混淆 PC 与 TC** | 用 TC 结果论证键合线可靠性 | 机理错位 |
| **过度外推** | 用 1000h 试验直接说"保证 20 年" | 缺模型、缺 mission profile、缺加速因子验证 |

## F. 单管专用补充（AEC-Q101 路线）

| # | 项 | 注意 |
|---|---|---|
| F1 | MSL 预处理是否按目标等级做 | SMD 封装（TOLL/D2PAK）必需；错等级 → 爆米花 |
| F2 | IOL 或 PTC 的选择 | 二极管类难以达到 ΔTj≥100℃ 时改用 PTC（标准注释 T） |
| F3 | MOS/IGBT 专属项是否覆盖 | DI（介质完整性）、HTGB、UIS 不可漏 |
| F4 | 焊点/框架疲劳是否被覆盖 | 单管的主导失效在焊点，不在键合线 |
| F5 | 回流焊曲线是否与客户产线一致 | 不一致 → 实验室通过、产线失效 |

---

## G. 模组专用补充（AQG 324 路线）

| # | 项 | 注意 |
|---|---|---|
| G1 | PCsec 与 PCmin **都做了吗** | 只做一种 = 只验证一半机理 |
| G2 | SAM 是否覆盖全部关键界面 | 芯片/焊层/陶瓷/底板/灌封，缺一不可 |
| G3 | 绝缘与 PD 是否做到应用电压等级 | 1700V+ 与牵引/电网必做 PD |
| G4 | SiC 是否加了 DGS / DRB / dyn.H3TRB | 04.1/2025 新增，漏了等于用旧版 |
| G5 | 变更是否可用 Delta Qualification Matrix 裁剪 | 不必每次全项重做，但裁剪要有依据 |
| G6 | 高压（>2.5kV）是否评估宇宙射线通道 | 常规试验复现不出来，但现场会出事 |
