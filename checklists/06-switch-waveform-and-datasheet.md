# 检查表 06 · 开关波形判读与 datasheet 取舍（书第 3、5、6 章）

> **用途**：拿到一张开关波形 / 一份 datasheet 时，判断**这个数能不能用、这个波形说明什么**。这是"选型与签规格"的那一层，也是 05（台架）之前的一层。
>
> **纪律**：`【书 pXX】` 可直引；`[自定]` 表示书未给、必须由项目自定并写入记录；`[书未给]` 表示**该书没有这个内容，不得声称来自本书**。
>
> 关联：`references/volke-hornkamp/16-datasheet-blocking.md`、`30-gate-drive-dynamics.md`、`23-electrical-params-definition.md`、`31-protection-timing.md`；脚本 `igbt_book_budget.py terminal`、`igbt_book_ledger.py redline`。

## A. datasheet 上哪些数是设计依据

| # | 检查项 | 判据 | 书页 |
|---|---|---|---|
| A1 | **只有三个"真参数"** | **U_CEsat**（算损耗）/ **Q_G**（驱动设计）/ **R_th,jc**（热设计）；其余全是条件参数 | p143 |
| A2 | R_th,jc 的口径 | **整个模块只有一个**，不是"每芯片一个"；且是**壳**（基板）不是散热器 | p143 |
| A3 | E_on / E_off 的积分时间窗 | 受 IEC 60747-9 限定；**有厂家用更短时间轴给出更低损耗** —— 跨厂家比损耗前必须核窗口 | p143 |
| A4 | I_sc 能不能当 SCSOA 判据 | **不能**。它是 U_GE=15 V 下的**线性外推**，"仅仅是一个参考值" | p143 |
| A5 | R_th,ch 能不能算散热设计 | **不能直接用**。它只是参考值，换 TIM 规格/厚度/压力就变 | p143 |
| A6 | 能量积分的两个窗口 | **E 用 `I_C 10 % → U_CE 2 %`**；**Q_rr 用 `I_F 过零 → I_RM 2 %`** —— 两套规则**不许混** | p142–143、`23` |
| A7 | U_CEsat / V_CE0 / r_CE 的温度 | **必须用工作温度（125 或 150 ℃）曲线拟合**；25 ℃ 数据会低估 30–50 % | `[自定]`（书只给"正温度系数在负载电流下才显著"，p132） |
| A8 | NTC 的 B 值 | **分段查**，不能用一个 B 值算全温区（书例给 50/80/100 ℃ 三个） | 式 5.3，p146 |
| A9 | 反向阻断能力 | datasheet **一般不提及**，且明显低于正向；需要反向阻断时**串一个二极管** | p111 |
| A10 | 数据手册里的绝缘距离 | 厂家给的是**裕量后的值**，不是标准下限；且都是**未安装状态**，装上散热器/端子后会减小 | p82 |

## B. 关断波形：看到尖峰先算式 5.1

| # | 检查项 | 判据 | 书页 |
|---|---|---|---|
| B1 | 端子过压的算式 | `U_term,max = U_CES + L_σCE·di_C/dt` | 式 5.1，p142 |
| B2 | L_σ 取哪个数 | 按封装查：34 mm **30 nH** / 62 mm **20** / EconoDUAL3 **20** / IHM G1 **10** / IHM G2 **6** / PrimePACK3 **10 nH** | 表 2.2，p76 |
| B3 | L_σ 是否随拓扑变 | **是**。表 2.2 表注明"任何一个模块的杂散电感随着拓扑的变化而改变"——必须问清是哪个拓扑、哪两个端子间 | p76 |
| B4 | 是否按**最低温**核过 | 阻断能力**随温度升高而增强**：6.5 kV 器件 −50 ℃ 约 5.7 kV / 25 ℃ 6.3 / 125 ℃ 6.5（**−12.3 %**） | 图 3.34，p111 |
| B5 | 用脚本核一次 | `igbt_book_budget.py terminal --uces 1700 --lsig 30e-9 --didt 20e9 --u-bus 1073 --temp-derate 12.3` | — |
| B6 | 尖峰被"削平"在某个电压 | 可能是进入 **SSCM / 动态钳位**（1.2 kV NPT 实测可达 **1850 V**）。**已超 SOA，"没炸"≠"合规"** | 图 3.36，p112 |
| B7 | 静态 vs 动态雪崩 | **静态**雪崩（超 U_CES）「通常导致器件损坏」；**动态**雪崩（关断瞬态）在 SOA 内可不损坏 | p112 |

> **最常见的错**：按"母线 ≤ U_CES"判裕量。漏掉的正是 B1 的 Lσ·di/dt 那一项。同电压等级的 **34 mm 与 IHM 二代差 240 V 可用电压**（10 A/ns @1073 V 母线）。

## C. 开通/关断波形：判特性，不看"好看"

| # | 检查项 | 判据 | 书页 |
|---|---|---|---|
| C1 | **R_Gon 管 di/dt，外接 C_G 管 du/dt** | 二者解耦。三档实测：8.2 Ω → di/dt 5.0 kA/μs、du/dt 0.6 kV/μs、E_on **6.4 J**；3.3 Ω+100 nF → 4.5 / 1.0 / 4.1；1.0 Ω+330 nF → 5.1 / 2.8 / **2.8 J** | 图 6.40，p185 |
| C2 | "加大 R_G 换平滑"是否成立 | **不成立，是亏本买卖**。R_G 从 8.2 → 1.0 Ω，di/dt 只动 2 %，E_on 却降 56 % | p185 |
| C3 | di/dt 压 R_G 压不下去 | **正常**。书明说 R_Gon 调 di_C/dt，**上限由续流二极管定** —— 换二极管或加可饱和电抗器，不是加驱动 | p183–184 |
| C4 | 栅极回路是否振荡 | `R_G,min ≥ 2·√(ΣL_G/C_GE)`；30 nH / 100 nF → **1.1 Ω**。不满足**先减布线电感**，别加 R_G | 式 6.7，p172 |
| C5 | 驱动器峰值电流选型 | `I_peak ≈ 0.7·ΔU_GE/(R_Gint+R_Gext)`；**R_Gon / R_Goff 分开算，取较大者** | 式 6.5，p171 |
| C6 | 0.7 与 0.74 冲突吗 | **不冲突**。0.74 = 2/e 是二阶 RLC 解析解，0.7 是工程取整再叠寄生修正 | p172 |
| C7 | 关断侧有外接 C_G 时 | du/dt 与 di/dt **同减**、E_off **上升**，须另设 R_Goff 补偿（Trench-FS 除外） | p184 |
| C8 | 栅极引线 L_G 变长 | 单极性 0/15 V：只增开通延时、速度不变；双极性 −15/+15 V：开通更快并放大 di/dt、du/dt | p186–187 |
| C9 | 外接 C_G 是否串 R_CG | 必须串（**<1 Ω ~ 数 Ω**）抑振 | p186 |
| C10 | 寄生导通 | du/dt 经 C_GC 注位移电流推高 U_GE → 需**负压关断（−15 ~ −5 V）+ 米勒钳位** | p165–166 |

> **C1 的读法**：三条曲线不是"三种调法"，是**一条结论的三段证据**——di/dt 稳在 4.5–5.1、du/dt 升 4.7 倍、E_on 降 56 %。看到有人用"加大 R_G 让波形更平滑"来压 EMI，先让他把 E_on 的变化量报出来。

## D. 短路与保护波形

| # | 检查项 | 判据 | 书页 |
|---|---|---|---|
| D1 | DESAT 是**时间预算**，不是阈值 | `t_bl = C_bl·U_ref/I_DESAT`；加内部处理 1–3 μs，必须 **< t_SC** | 式 6.17，p189–190 |
| D2 | C_bl 与 t_bl 的对照 | **100 pF → 4.4 μs；220 pF → 7.1 μs**（图 6.47 实测）。220 pF 配 6 μs 器件**直接溢出** | p190 |
| D3 | 开机瞬间 DESAT 误报 | 先怀疑 **VD2 结电容**经 du/dt 额外灌流 `I_D2 = C_D2·du_CE/dt`（式 6.19）**缩短了 t_bl**，这是设计缺陷不是噪声 | p190 |
| D4 | 是否可用"R_1 取流式"替代 | 可以。约 1 mA 取流、灵敏度更低、**适用任意电压等级** | p191–192 |
| D5 | ≥3.3 kV 器件 | 标准 DESAT **不可行**（开通到饱和需数 μs），必须改 R_1 取流式或动态 U_ref(t) | p190 |
| D6 | 关断过程中短路 | **TLTO 与软关断均无法激活 → 无保护关断**。PFMEA 失效后果栏必须写这一条 | p210–211 |
| D7 | 软关断 / TLTO 的动作点 | 软关断高阻放电→**约 2 V 切低阻**；TLTO 初始 **11 V / 1 μs**，U_TLTO = 9–14 V | p209–211 |
| D8 | 过压抑制效果 | TLTO 实测：1.2 kV 器件短路关断 U_CE,max **1125 → 733 V** | p210 |
| D9 | 短路电流/耐受窗口 | I_SC **4–8× I_nom**、t_SC **6 或 10 μs**；**芯片 ≥200 ℃ 即坏** | p105–107 |
| D10 | 死区与最小脉冲 | 死区 **1–4 μs**（3.3–6.5 kV 更长）；最小脉冲抑制 **100–800 ns** | p212–213 |
| D11 | UVLO | 动作阈值 **11–12 V**；典型门限 10–13 V | p179、p205 |
| D12 | 故障锁存 | 关断通道 → 集电极开路上报 → 锁存至外部复位；无故障存储则超时自动重启（**超时值书未给**） | p213 |

## E. 参数定义与可比性（比波形更容易出事）

| # | 检查项 | 判据 | 书页 |
|---|---|---|---|
| E1 | 两个"13 万次"能不能比 | 先问：**脉冲式还是非脉冲式 PC**（脉冲式额外产生开关损耗）、**ΔTj 多少**、**t_cyc 多少**、判据 **5 % 还是 20 %** | p375 |
| E2 | PC 与 TC 考的部位 | **PC（PCsec）考键合线 + 芯片焊层**；**TC（PCmin）考系统焊层** —— 拿 PC 结果推焊层寿命是错的方向 | 表 14.5，p372–375 |
| E3 | 工业级默认条件 | PCsec：ΔTj **60 K** / **13 万次**；TC：ΔTc **80 K** / 2000–5000 次 | 表 14.4，p371 |
| E4 | 车规是不是"更松" | **不是**。AQG 324 常做 ΔTj ≥100 K 而周次下压到数万——摆幅更大、周次更少，**不能直接比周次** | `[推断，据表 14.4 对照]` |
| E5 | 判据的"例如" | 书给 `U_CEsat` 变化"例如 **5 %**"，**不是"必须 5 %"**；AQG 324 的 5 %/20 % 双判据是另一套体系 | p375 |
| E6 | 结温测量（TSEP） | 标定电流 **I_ref ≈ I_nom/1000**；此时 V_F 呈**负**温度系数，**与"IGBT 正温度系数"不矛盾** | p131–132 |
| E7 | 调制比 / 载波比的定义 | 书内定义与部分厂商不同，**跨厂家比损耗前先统一** | `23` |
| E8 | 测量延时 | 电压/电流通道间的延时差必须实测标定（**书第 12 章未给方法**） | `[书未给]` |

## F. 对"看起来都对"的波形做一次反证（本表的核心动作）

评审一张波形时，按这四问过一遍：

| # | 问 | 如果答不上来 |
|---|---|---|
| F1 | **这一组的 Rg、V_CC、T_vj、Lσ 四项都记了吗？** | 跨组对比无效（`05` F1） |
| F2 | **E 的积分窗口是哪一套？** | 与别人比的可能是营销数字（A3、A6） |
| F3 | **测的是 `T_c` 还是"传感器位置温度"？** | 无基板模块只能得 Z_th,jh，不是 Z_th,jc（`15` B 段） |
| F4 | **这是 25 ℃ 还是最低温的结果？** | 电气裕量可能凭空多 12 %（B4） |
