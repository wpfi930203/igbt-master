# 检查表 03 · 单管选型 / 二供替换评估

> 用途：评估"这颗国产 IGBT 能否替代现有型号"，或为新产品选单管。
> **核心纪律**：**不比 datasheet 首页的 typ 值。** 首页参数是营销页，真实区分度在测试条件栏、曲线和多条件表格里。

---

## A. 先决条件（没有这些，评估无法开始）

| # | 需要拿到 | 为什么 |
|---|---|---|
| A1 | 应用的 6 个工况量（VDC / IC / fsw / 冷却 / 目标寿命 / 绝缘与认证目标） | 无工况的替换评估是猜 |
| A2 | 原型号完整 datasheet（含**测试条件栏**与曲线） | 只拿首页参数无法对比 |
| A3 | 候选型号完整 datasheet（同上） |  |
| A4 | 两家是否同封装（引脚兼容性） | 引脚不兼容 → 需改 PCB，评估维度全变 |
| A5 | 客户/内部是否有"不得变更"的认证约束 | 车规变更往往需重新认证 |

---

## B. 静态参数对比（正确姿势）

| # | 对比项 | 怎么看 | 常见错误 |
|---|---|---|---|
| B1 | **VCE(sat) @ 额定 IC，且看 25℃ 与 125/150℃ 两点** | 要看**温度曲线**，不看单点 typ | 只比 25℃ typ，忽略高温劣化 |
| B2 | **VCE(sat) 的温度系数符号** | 大电流区应为正（利于并联）；小电流区可能为负 | 完全忽略温度系数 → 并联或轻载时热失控 |
| B3 | VGE(th) 及其温度系数 | 负温度系数 → 高温更易误开通 | 只看 typ 值，不看范围（min/max 跨度） |
| B4 | ICES @ 额定电压、最高温度 | 反映终端与钝化质量 | 只比 25℃ 漏电（都极小，无区分度） |
| B5 | IGES | 栅氧质量 | 忽略 |
| B6 | 短路耐受时间 tSC | 决定保护预算 | 忽略，直接套用原保护参数 |
| B7 | SOA（FBSOA / RBSOA / SCSOA） | 看曲线形状，不是单个数字 | 只看有没有"标了 SOA" |

> **B2 是这份表里最重要的一行。** 很多替换失败不是参数不够，是温度系数变了导致并联/轻载行为改变。

---

## C. 动态参数对比（必须同条件）

| # | 对比项 | 条件必须一致 | 否则 |
|---|---|---|---|
| C1 | Eon / Eoff | Rg、VCC、IC、Tvj、Lσ | 数据不可比（误差可达 30%+） |
| C2 | Erec（反并联二极管 / RC-IGBT） | 同上 + di/dt | 不可比 |
| C3 | tr / tf / td(on) / td(off) | 同上 | 不可比 |
| C4 | Qg / Qge / Qgc | VGE 摆幅、VCC | 驱动功率算错 |
| C5 | Cies / Coes / Cres | 测试频率与偏置 | 串扰评估错 |
| C6 | dv/dt、di/dt 能力 | 与 Rg 相关 | 影响 EMI 与电机绝缘 |

**执行建议**：若两家 datasheet 条件不同（很常见），**必须自己复测**，或在报告里明确写"条件不一致，数据仅供方向性参考"。

---

## D. 热与封装

| # | 对比项 | 注意 |
|---|---|---|
| D1 | Rth(j-c) 或 Rth(j-a) 及其**测试条件** | 条件不同不可比；单管的 Rth(j-a) 与 PCB 强相关 |
| D2 | 封装形式与热路径 | TO-247 通孔 vs TOLL 贴片，热路径完全不同 |
| D3 | 是否有 Kelvin 发射极（TO-247-4L / TOLL） | 有 → 开关损耗与振荡表现显著不同 |
| D4 | 内部互连（线键合 vs Clip） | Clip 的 Rce 与寄生更低 |
| D5 | 芯片面积（可由 Rth 与 VCE(sat) 间接推断） | 面积影响短路耐量与成本 |
| D6 | MSL 等级 | 与产线回流工艺匹配 |
| D7 | 爬电距离 / 电气间隙 | 高压应用合规 |

## D2. 芯片级判据（v2.11.0 新增，来自 Baliga 层）

> B/C/D 三节比的是**两张 datasheet**。这一节问的是**两颗芯片在物理上能做到什么**——datasheet 相同不代表物理等价，datasheet 不同也可能是同一颗芯片的不同标法。**换芯片（换供应商/换代次/换材料）时必过本节。**

| # | 判据 | 怎么看 | 出处 |
|---|---|---|---|
| D2-1 | **芯片面积能不能装得下** | 用两条功耗密度线卡：模块 **150 W/cm²**、单管 **125 W/cm²**。`面积 ≥ P_loss / 密度上限` | `baliga/72`、`baliga/50` |
| D2-2 | **同耐压下 `R_on,sp` 差几倍** | 这是芯片级的"能不能打得过"，不是封装问题。比 `R_on,sp`，不要比 `V_CE(sat)` 单点 | `baliga/55`、`baliga/53` |
| D2-3 | **电流密度随耐压怎么降** | 从低压到高压，电流密度约 **95 → 30 A/cm²** 单调降。同电流下高压器件面积必须更大 | `baliga/50` |
| D2-4 | **该用沟槽栅还是屏蔽平面栅** | 硅 IGBT 走**沟槽栅**（增益 `V_CE(sat)`）；SiC 走**屏蔽平面栅**（保栅氧场强）。**方向相反，不能照搬** | `baliga/51`、`baliga/55` |
| D2-5 | **降额该取几档** | 按约束类型查**四档谱**：电容钳位 1.3× / 谐振软开关 1.6–1.7× / 硬开关+受控负载 1.6–1.9× / 硬开关+敏感负载 2.0–2.2×。**不许一律套 1.5×** | `baliga/70 · I.3` |
| D2-6 | **换 SiC 打平了没有** | 别只看"SiC 贵 3 倍"。算 `$/A`：面积赢多少 × 单价输多少。打平门槛 **晶圆价 ≤509 \$/100 mm 片** | `baliga/72 · A2.4` |

> **D2-5 是本表最容易犯的错**：降额不是拍一个数，是**先问"什么会打死它"**——电容钳位场景受宇宙射线限制可用到 75.8 %，敏感负载只敢用 45 %，**同一器件能差 2.2 倍**。
>
> **D2-6 的陷阱**：`5.9 \$/A` 这个数**不是单价倍数**，是「面积赢 2.06 倍」与「单价输 12.18 倍」的乘积结果。把它当"贵 5.9 倍"去砍价，方向就错了——**该砍的是晶圆价，不是器件报价**。

## F. 替换决策矩阵（把结论落成一句话）

| 判定 | 条件 |
|---|---|
| **可直接替换** | 封装/引脚兼容 + 静态参数满足 + 同条件动态参数不劣于原型号 + 温度系数方向一致 + 认证覆盖 |
| **可替换但需改设计** | 上述有一项不满足但可通过改 Rg / 改散热 / 改驱动 / 改保护阈值解决 |
| **不建议替换** | tSC 显著更短（保护来不及） / VCE(sat) 温度系数方向相反（并联风险） / 封装热路径不匹配 |
| **不可替换** | 引脚/封装不兼容且无法改板；或客户认证不允许变更 |

---

## G. 报告必须写的话

替换评估报告的结论段，至少要包含：

1. **工况假设**：这份结论适用于什么 VDC/IC/fsw/冷却条件
2. **对比表**：每项都注明"同条件可比 / 条件不同仅方向性参考"
3. **风险项**：不满足的项 + 缓解措施（改 Rg、改散热、降额）
4. **验证建议**：需补做哪些实测（DPT、温升、短路、并联均流）
5. **不可替代的部分**：哪些结论必须由实测而非 datasheet 得出

> **不要写"经对比，性能相当，可以替换"这种话。** 它既没有条件，也没有风险，还没说验证方式——是这份行业里最典型的不合格结论。
