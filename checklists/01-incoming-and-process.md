# 检查表 01 · 来料与工艺过程（模组线）

> 用途：模组封装线的来料检验与关键工序过程控制点。
> **纪律**：本表给的是「该查什么」，**不是「合格判据是多少」**。判据必须来自客户规范 > 内部控制计划 > 行业标准。凡标 `[须确认]` 处，禁止凭本表下结论。

---

## A. 陶瓷覆铜板（DBC / AMB / DPC）

| # | 检查项 | 方法 | 关注点 | 判据来源 |
|---|---|---|---|---|
| A1 | 陶瓷种类与厚度 | 图纸/来料报告核对 | Al₂O₃ / AlN / Si₃N₄；厚度决定热阻与机械强度 | 图纸 `[须确认]` |
| A2 | 铜层厚度与线宽公差 | 切片 / 测厚 | 载流能力与蚀刻精度 | 图纸 `[须确认]` |
| A3 | 陶瓷裂纹 / 缺角 | 目检 + 光照透射 | 微裂纹是 TC 失效起点 | `[须确认]` |
| A4 | 铜层起泡 / 氧化 | 目检 | 影响键合与焊接润湿 | `[须确认]` |
| A5 | AMB 钎焊层空洞 | SAM | 大面积空洞 → 局部热点 | `[须确认]` |
| A6 | 表面镀层（Ni/Au/Ag）厚度 | XRF / 切片 | 影响 IMC 生长与烧结银附着 | `[须确认]` |
| A7 | 翘曲度 | 平面度测量 | 影响贴片共面性与焊层厚度均匀性 | `[须确认]` |
| A8 | 耐压 / 绝缘 | 抽检 | 陶瓷内部缺陷 | `[须确认]` |

**关键认知**：`A5` 的 AMB 钎焊层空洞与 `A6` 的镀层，是很多"芯片没问题但热阻超标"的真凶。先怀疑基板，别先怀疑芯片。

---

## B. 芯片（IGBT / FWD / RC-IGBT）

| # | 检查项 | 方法 | 关注点 |
|---|---|---|---|
| B1 | 芯片型号与批次可追溯 | 批次号 / 晶圆号记录 | **无 SN 追溯是本行业的系统性痛点**，至少做到批次级闭环 |
| B2 | 正面金属化厚度与成分 | 抽检 / 供应商报告 | 决定键合强度与铝层重构速率 |
| B3 | 背面金属化（发射极） | 供应商报告 | 决定焊料/烧结润湿与 IMC |
| B4 | 芯片厚度 | 测厚 | 影响 Rth、热容、TC 应力、短路耐量 |
| B5 | 钝化层完整性 | 显微镜 | 终端钝化是 H3TRB 的主战场 |
| B6 | 切割质量（崩边/微裂） | 显微镜 | 崩边会在 TC 中扩展成裂纹 |
| B7 | 电参数抽检 | 静态测试 | VCE(sat)、VGE(th)、ICES、IGES |

**追溯提醒**：如果客户要求单件追溯而产品无 SN，这是**设计层面的缺陷**，不是检验能补的。应在项目早期提出，而不是在客诉时才暴露。

## C. 芯片贴装材料与工艺

| # | 检查项 | 方法 | 关注点 |
|---|---|---|---|
| C1 | 焊料/烧结膏批次、储存、回温 | 记录 | 吸湿与沉降会导致空洞 |
| C2 | 焊层厚度 | 切片 / X-ray 断面 | 过薄 → CTE 约束强、疲劳快；过厚 → Rth 上升 |
| C3 | **空洞率** | X-ray / SAM | **热循环寿命的头号杀手**；判据按客户规范 |
| C4 | 空洞分布（不是只看总率） | X-ray 图像 | **集中在大电流路径或芯片中心的空洞，比均匀分散的更致命** |
| C5 | 烧结银：压力均匀性 / 气氛 / 温度曲线 | 设备记录 | 压力不均 → 密度不均 → 局部热阻高 |
| C6 | 烧结层密度 / 孔隙 | 切片 / 超声 | 密度不足 → 导热与强度双降 |
| C7 | 贴片偏移 / 旋转 | 视觉 / X-ray | 影响爬电距离与均流 |
| C8 | 剪切力抽检 | 推拉力机 | 必须做**统计**，单点无意义 |

**关键认知**：`C4` 是多数人漏掉的。**空洞率达标但空洞集中在芯片中心**的样品，功率循环会先挂。

## D. 键合（Al 粗线 / Cu 线 / Al 带）

| # | 检查项 | 方法 | 关注点 |
|---|---|---|---|
| D1 | 线径/带材规格与材质 | 来料核对 | 载流与疲劳寿命 |
| D2 | 键合位置精度 | 视觉 / 拉力抽检 | 偏离焊盘边缘 → 跟部应力集中 |
| D3 | 焊球/焊点形貌 | 显微镜 | 形貌异常预示参数漂移 |
| D4 | 拉力（pull）与剪切（shear） | 推拉力机，按批次统计 | **必须看分布与 Cpk，不看单点最大值** |
| D5 | 跟部裂纹（heel crack） | 切片 / 高倍显微 | **功率循环失效的典型起点** |
| D6 | 芯片表面 cratering | 去线后显微 | 铜线键合尤需监控 |
| D7 | 键合弧度与线长 | 视觉 | 影响 Lσ 与均流 |
| D8 | 键合参数（功率/压力/时间）趋势 | SPC | 工具磨损导致缓慢漂移 |

**关键认知**：`D4` 最常见的错误是"抽 5 根都合格就放行"。键合强度的分散度比均值更能预测现场失效。

## E. 灌封与外壳

| # | 检查项 | 方法 | 关注点 |
|---|---|---|---|
| E1 | 灌封料批次、配比、真空脱泡 | 记录 | 配比偏差 → 固化不完全 → 吸湿加剧 |
| E2 | 真空度与灌注速度 | 设备记录 | 决定气泡 |
| E3 | **空洞 / 气泡** | X-ray / SAM / 目检 | 大气泡在高电场区会引发 PD |
| E4 | 固化曲线 | 炉温曲线 | 欠固化 → 力学性能不足 |
| E5 | 灌封料与陶瓷/外壳界面浸润 | SAM / 切片 | **界面脱粘是 H3TRB 的常见起点** |
| E6 | 硅凝胶 vs 环氧的选择是否匹配应用 | 设计评审 | **硅凝胶不阻水**；高湿环境需专门评估 |
| E7 | 端子焊接/超声焊强度 | 拉力 | 端子脱落是现场失效之一 |
| E8 | 外壳气密性（如适用） | 氦检 |  |
| E9 | 标识与追溯码 | 目检 | 至少批次级 |

## F. 底板与系统装配界面

| # | 检查项 | 方法 | 关注点 |
|---|---|---|---|
| F1 | 基板-底板焊层空洞率 | SAM / X-ray | **热循环（TC）失效的主战场** |
| F2 | 底板平面度 / 翘曲 | 平面度测量 | 影响 TIM 厚度均匀性 |
| F3 | 底板材质（Cu / AlSiC）与镀层 | 来料核对 | CTE 与腐蚀 |
| F4 | 安装压力与扭矩 | 装配记录 | 压力不足 → TIM 接触热阻大；过大 → 陶瓷裂 |
| F5 | TIM 类型、厚度、涂覆均匀性 | 装配记录 / 抽检 | **Rth 的隐形杀手** |
| F6 | Pin-Fin 流道清洁度 | 目检 | 堵塞 → 局部过热 |

## 使用方式建议

1. **本表按工序顺序排**，可作为首件检验（FAI）与巡检的骨架。
2. 把每行的「判据」列填成你公司的实际值，形成内部受控文件。
3. **`[须确认]` 项不要凭经验填**——它们要么来自客户规范，要么需要工程验证数据支撑。
4. 与 PFMEA 联动：本表每一行都应能对应到 PFMEA 的一个失效模式与一个探测控制。**对不上的行，说明要么 PFMEA 漏了，要么这个检查是浪费。**
