# 检查表 07 · 答辩与评审用一页纸（igbt-master v2.7.0）

> **用途**：评审会前 10 分钟过一遍；被质疑时按编号回应。
> **纪律**：`【书 pXX】` 可直接引；`[自定]` 为书未给、须项目自定；`[书未给]` 表示**该书没有，不得声称来自本书**。
> **这张纸只做一件事**：让你在被追问时，**知道哪句话有出处、哪句话是自己的推断、哪句话不能说**。

## 0. 开场三句（先把边界说清，比后面讲什么都重要）

| # | 要说的 | 为什么先说 |
|---|---|---|
| 0.1 | 「本书是**德系模块视角的工程书**，不是标准汇编。凡我引用标准条款（AQG 324 / IEC 60747-9 / JEDEC），那是**我的知识**，不是这本书的内容。」 | 防止对方拿标准原文对撞时你无法交代出处 |
| 0.2 | 「书里**有 11 项是『书未给』或『给了但不可用』**，我在报告里已经全部标红，不会拿它们当依据。」 | 主动亮红线的可信度，远高于被抓到 |
| 0.3 | 「涉及客户现场的具体数值（扭矩、试漏压力、振动谱），**书上没有**，必须查厂商安装手册或对应标准。」 | 这是本书最大的边界，越早说越安全 |

## 1. 十个最容易被问住的问题（先背结论，再看依据）

| # | 提问 | 一句话答 | 依据 |
|---|---|---|---|
| Q1 | 「你们这个开关损耗，为什么跟厂家手册差一截？」 | **先问积分窗口，再问正弦/恒流口径。** 窗口短一截、口径错 π 倍，差 2~3 倍很正常 | 检查表 06 A3/A6；`38-loss-closed-form.md` |
| Q2 | 「损耗算出来比实测高 3 倍？」 | 单管在正弦 VSI 里用 **1/π = 0.318**，不是 1.0。错用 1.0 直接大 3.14 倍 | 式 3.16/3.26/3.28/3.29；`worked-examples` B⑧ |
| Q3 | 「死区要留多少？」 | **1~4 μs 区间，但要按式 7.5 算，不能拍。** 驱动传输延迟差常占一半 | 式 7.5，书 p228 图 7.7 |
| Q4 | 「你们说的 13 万次是哪种？」 | **PC（PCsec，秒级自加热，考键合线）**；TC（分钟级，考系统焊层）只有 2000~5000 次。两者不能比 | 表 14.4，`05` |
| Q5 | 「两家都写 13 万次，能比吗？」 | **不能。** 要同问：脉冲/非脉冲、ΔTj、t_cyc、判据 5% 还是 20% | 书 p375 |
| Q6 | 「灌了硅胶为什么还湿气失效？」 | **硅胶不是气密屏障**，模块是 IP00，H₂S/水汽会扩散穿过硅胶打 DCB 铜层 | 书 p278–279，`18` |
| Q7 | 「过压该加吸收电容吗？」 | **先分界面。** 模块端子过压（L·di/dt）加了有用；电机端反射过压（2·U_dc）加了一点用都没有 | 式 5.1 / 式 13.18，`39` |
| Q8 | 「T_j 测出来准不准？」 | 四种测法各带 10%~20% 误差，**红外还要求黑体/发射率/稳态/无遮挡四个前提** | 书 p281–289，`10` |
| Q9 | 「这个寿命能不能算到 20 年？」 | **没有剖面就没有寿命数字。** 一个 300 s 循环按 Miner 算出来只有 2.4 年 | 式 14.12，`05` |
| Q10 | 「书上的公式我照着算了，结果不对？」 | 先查是否踩到**三处书内错误式**：式 3.19 不可操作、式 6.12c η 方向错、式 13.21–13.24 高调制比发散 | `34-formula-index §12.2` |

## 2. 十一条红线（**永远不要说「据《IGBT 模块》……」**）

被问到下面任何一项时，标准回答是：**「书上没有这个数，需要查 XXX。」**

| # | 项目 | 正确来源 |
|---|---|---|
| R1 | Arrhenius 激活能 γ | 自有试验或厂商给定 |
| R2 | Coffin-Manson 指数 c | 厂商按型号标定 |
| R3 | Peck 湿度模型指数 n | 文献/自有试验 |
| R4 | Bayerer β1~β4、K | 厂商给定，**禁止跨型号套用** |
| R5 | 雪崩能量 E_as | 器件 datasheet |
| R6 | 驱动功率显式式 | 书有式 6.12c 但 η 方向错 → 用 `P=(Q_G·ΔU+…)·f / η` 并标「推断」 |
| R7 | 熔断器 I²t 具体值 | 熔断器厂商曲线 |
| R8 | HDF 具体数值 | **读图 13.20**，不要用式 13.21–13.24（见 §4） |
| R9 | 探头延时补偿 | 探头手册 |
| R10 | 缓冲电容（照抄式 13.9） | 式 13.9 量纲不成立，用 `C = L·I²/ΔU²` |
| R11 | 安装扭矩 / 试漏压力 / 振动谱 / 盐雾小时数 | 厂商安装手册、IEC 60721 / IEC 60068-2-52 |

## 3. 三处「书给了但错」——这是最贵的三条（v2.7.0 已逐页复核）

### 3.1 式 13.9 缓冲电容（p347）—— 量纲不成立

| | 写什么 |
|---|---|
| 书印 | `C_Snubber ≈ L_σ,total·I_peak /(U_CE,peak − U_DC)²` |
| 量纲 | `(V·s/A)·A/V² = s/V` —— **不是法拉** |
| 正确 | `C = L·I_peak²/(U_CE,peak − U_DC)²` |
| 差多少 | **I_peak 倍**；1000 A 时差 1000 倍 |
| 旁证 | 同页式 13.11 反解即得此式，量纲正确 —— **同页两式只能有一个对** |

### 3.2 式 6.12c 驱动功率（p176）—— η 的乘除方向

| | 写什么 |
|---|---|
| 书印 | `P_DC-DC = (P_GE + P_CG) · η`（η 明文定义为 **DC-DC 变换器效率**） |
| 问题 | 效率作乘 = 输出比输入还小，**违反能量守恒**；物理应为**除以 η** |
| 量化 | η=0.85 时，书式偏小 15%，正确式偏大 17.6%，**两者之比 = η² = 0.72** |
| 后果 | 按书式选 DC-DC，**额定功率少选约 18%**，高温满载会掉压 |
| 处理 | `29-driver-power-budget.md` 已标 `[推断]`，本技能不内置默认 η |

### 3.3 式 13.21–13.24 HDF（**p359，不是 p353–355**）—— 三档可信度

| 式 | 对象 | 判定 | 证据 |
|---|---|---|---|
| 13.21 | SPWM | **系数成立**，但 m 口径与图不同 | 用 c=1.25 缩放后与图 13.20 全程吻合（残差 <5%） |
| 13.22 | SVPWM | **系数成立**，同上 | 同上 |
| 13.23 | DPWM MIN | **不可用于定量** | 任何 m 下都偏图读数 3~10 倍 |
| 13.24 | DPWM MAX | **不可用于定量** | m≥0.7 变负，物理上不可能 |

**关键定量事实**：`4/π = 1.273`，而拟合得到的最佳缩放 `c = 1.25` —— **书式把 m 又乘了一次 4/π，等于做了两次变换**。这说明式里的 m 已经是折算后的量，与图横轴的 m 不是同一个东西，**书上没有说明**。

> **答辩怎么说**：「HDF 我读图 13.20，不解析式计算。书里那四条式子，SPWM/SVPWM 的系数对得上但 m 的定义和图不一致，DPWM 的两条在高调制比直接发散。这不是排版问题，是口径没交代。」

### 3.4 式 3.19 软因数（p99）—— 不是印错，是**不可操作**

| | 写什么 |
|---|---|
| 书印 | `S = t_f / t_a`，正文「代表 t_f 和 t_a 的比值」 |
| 真问题 | 图 3.17 的时间轴标的是 `t_a` 与 `t_b`，**没有 t_f 的终点** → `t_a` 到底指哪段，图上找不到 |
| 处置 | **不用 3.19**。改用同页式 3.20 的 `di/dt` 比值定义 —— 那一条无符号歧义、可实测 |

## 4. 三个口径差（不是书的错，但混了就错）

| 口径 | 正确用法 | 混用后果 |
|---|---|---|
| **开关损耗 1/π** | 正弦 VSI 单管用 `1/π`；恒流/斩波才用 `1.0` | 差 **3.14 倍** |
| **能量积分窗口** | E 用 `I_C 10% → U_CE 2%`；Q_rr 用 `I_F 过零 → I_RM 2%` | 两套混用得不出可比值 |
| **CTE 三套取值** | 定量只用表 4.2（**唯一明标 20 ℃**） | Si↔AlN 失配：A 套 0.1 vs B 套 2.0，**差 20 倍** |

## 5. 会被追问的「书未给」边界（诚实清单）

| 议题 | 书给到哪 | 再往下必须查 |
|---|---|---|
| 安装扭矩 | 只反复要求「按厂商最大/最小扭矩」，**全书无 N·m 值** | 厂商安装手册 |
| 试漏压力/保压 | 只讲要试漏，**无数值** | 厂商安装手册 |
| 振动谱 | 只讲共振与加支撑，**无 GRMS/频率** | IEC 60721-3-3、IEC 60068-2-6 |
| 盐雾 | 只讲端子腐蚀，**无小时数** | IEC 60068-2-52 |
| 空洞率 | 只讲空洞抬热阻，**无定量判据** | IPC-A-610 / 企业内部规范 |
| 硅脂厚度 | **给 50–100 μm**（齿形刮刀实测，p274）✅ | — |
| 散热器粗糙度 | **给 ≤10 μm 且不得过光**（p274–275）✅ | — |
| 储存条件 | **给 1K2：5–40 ℃ / 5–85%RH / ≤2 年**（p279）✅ | — |

## 6. 答辩前 10 分钟自检

```bash
# ① 报告里有没有把「书未给」挂到书本出处上
python scripts/igbt_book_ledger.py redline --file my_report.md

# ② 死区数字能不能复现书上的算例（1.200 / 1.395 μs）
python scripts/igbt_book_budget.py deadtime --book-example 25
python scripts/igbt_book_budget.py deadtime --book-example 150

# ③ 缓冲电容是不是用了能量式而不是式 13.9
python scripts/igbt_book_budget.py snubber --lsig 30e-9 --i-peak 1000 --uce-peak 1700 --udc 1100

# ④ 损耗是不是用了 1/π（不传 --sw-factor 即默认 1/π）
python scripts/igbt_loss.py --help
```

| # | 口头自检 | 不通过就别上场 |
|---|---|---|
| 6.1 | 每个数字后面能不能说出「书 pXX」或「[推断]」或「[自定]」 | 有一个说不出，就删掉或改标 |
| 6.2 | 有没有引用 E_as / γ / c / β1~β4 并挂书 | 有 → 立刻改 |
| 6.3 | 死区、缓冲电容、HDF 三个数是不是按上面口径算的 | 有任一没核 → 补核 |
| 6.4 | 客户现场数值（扭矩等）有没有标「厂商手册」 | 没标 → 补标 |
| 6.5 | 对方问「为什么和手册不一样」时，第一句说的是「先对窗口」吗 | 不是 → 背 Q1 |
